# 0055 阶段2耗散装配与阻尼接触

- 日期：2026-08-13
- 状态：已裁决并实现
- 触发：plans/08阶段2、plans/11预留的能量线，以及用户“1234干吧”授权

## 一、问题

既有`EnergyRegistry`只认势能项，`velocity_verlet`的末端加速度仍用旧速度，
故速度相关力下不再是二阶；瞬态接触只有`e=1`，没有任何物理耗散账。
同时，research/15已经证明0052初裁的`exp(-2)`只是在`ζ=1`处的分支连接值，
不是恢复系数绝对下界。

## 二、裁决

1. 每个注册项必须自带`kind = potential | dissipation`。势能与耗散仍走**同一个**
   `EnergyRegistry`，不另建一套力装配表；耗散项给`force_and_power()`，一次求值同时
   返回广义力N与非负耗散率N·mm/s。
2. 既有势能项的相对次序、求和表达式与保守加速度路径保持不变。混入耗散项后，
   `total()`跳过耗散项；已有势能总值、梯度、Hessian和无阻尼轨迹必须逐字节不变。
3. 新增`velocity_verlet_damped`，不替换`velocity_verlet`。位置用Verlet预测，
   速度用一阶预测求末端加速度，再作梯形校正。本仓在线性阻尼振子上实测步长减半
   位置误差比4.036/4.018/4.009，故声明形式阶与实测阶均为2。
4. 物理耗散由`integrate_with_dissipation()`按端点梯形累计；它只报告物理项，
   算法截断误差另由`初始机械能-末态机械能-累计耗散`残差暴露，不许混为一账。
5. 法向线性dashpot采用0052选定的**合力归零分离**：
   `N=max(0,N_s-c·g_dot)`。dashpot可以在出射段抵消弹簧力，但总接触力永不为拉力。
6. 目标恢复系数接口放开到全部有限可表示范围`0<e≤1`：`e=1`对应`ζ=0`；
   任意`0<e<1`有唯一有限`ζ`；`e=0`只在`ζ→∞`极限到达，失败关闭。
7. 步长顾问仍只吃纯数字。阻尼接触由接触层传入真实合力归零接触时长；
   `ζ≤1`稳定率取`ω0`，`ζ>1`取快根
   `(ζ+sqrt(ζ²-1))·ω0`。新积分器在全阻尼范围采用保守系数1，最紧的`ζ=1`
   已实测`h·ω0=0.995`衰减、`1.005`发散。

## 三、必须红与反向门

- 被计时子进程非成功退出不得产报告；碰撞CLI的返回码1须在调用点显式列为成功语义；
- 势能项改次序或未声明类型必须红；混入耗散项后既有势能三元组逐字节相同；
- 新积分器替换旧`velocity_verlet`注册名必须红；
- 速度相关振子实测不到二阶必须红；
- `e=0`、`e>1`、非有限e必须红；
- `ζ=5`若仍把`ω0`当稳定率必须红；
- 出射dashpot若让弹簧与阻尼合力小于零必须红；
- 负或非有限耗散率必须红。

## 四、没有裁成什么

- 没有把任一积分器翻成`production_ready`；没有碰隐式族、自适应拒步或事件定位。
- 没有声称接触耗散已覆盖摩擦、塑性、滚阻或材料标定；本批只有线性法向dashpot。
- 没有声称低恢复系数等于真实湿沙或橡皮泥；这里兑现的是所声明线性模型的数学。
- 没有改变C档第9条的完整定义：单次阻尼碰撞会补齐其中恢复系数一半，带重力的
  连续弹跳总时长仍须单独案例。
