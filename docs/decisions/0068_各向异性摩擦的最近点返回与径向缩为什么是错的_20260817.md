# 0068 各向异性摩擦：最近点返回，以及"径向缩"为什么是错的

日期：2026-08-17
状态：**已落地**（并行波次二轨道D，编号由0064第三节预分配）
主要文件：`src/physics_engine/contact/friction.py`、
案例`cases/anisotropic_friction_ellipse`

## 零、一句话

`coulomb_return_map`是各向同性径向返回；本轮补上椭圆屈服面上的
**最近点投影（关联流动）**，并用实测证明了**派活书给的那条捷径
（"把椭圆拉成圆、径向返回、再变回来"）与它自己点名为错的"径向缩"是同一个映射**。

## 一、要它的理由

消费方WDS已证伪各向同性径向返回：`μ_∥:μ_⊥ = 5:1`时混合角耗散短缺最高约60%，
且**会系统性偏置横向落位**（`e_lat`）。真实场景是REBCO带材在导轮上，
沿带长与沿带宽的摩擦系数不同，而横向落位偏差的目标量级只有2 mm。

三前提逐条：规范轴——接触族形制由0050冻结，本片落在切向那一半；
消费方——WDS已在用η-return替换它；产物指纹——见第四节，**逐位不变是构造出来的**。

## 二、推导：三件事在圆上重合，在椭圆上不重合

各向同性屈服面是圆`|f_t| ≤ μN`。圆上这三件**恰好是同一件**：

1. 沿`f_trial`方向缩回圆；
2. 欧氏度规下到圆的最近点投影；
3. 最大耗散原理（Hill）要求的关联流动：滑移增量沿屈服面外法向。

**于是"径向返回"这个名字看起来像是算法本身。** 各向异性屈服面是椭圆

    Φ(f) = (f_∥/(μ_∥N))² + (f_⊥/(μ_⊥N))² ≤ 1

而椭圆的外法向`∂Φ/∂f ∝ (f_∥/a², f_⊥/b²)`（`a = μ_∥N`、`b = μ_⊥N`）
**不平行于**`f`，除非`a = b`或`f`落在主轴上。第1与第3因此分家，**只有第3是物理**。

### 2.1 只有第3件是物理，这一步不能跳

最大耗散原理：给定实际滑移增量`Δu`，实际切向力在容许集`Φ ≤ 0`上使`f·Δu`最大。
它的KKT条件正是`Δu = Δγ·∂Φ/∂f`——**滑移增量沿外法向**。
再代进弹性预测`f = f_trial − k_t·Δu`得

    f_trial − f ∝ ∂Φ/∂f

而这恰是**欧氏度规下的最近点投影**的一阶条件。故第2与第3等价，
**但这一步依赖切向弹性刚度是各向同性的**`k_t·I`。若哪天切向刚度也各向异性，
最近点投影要改用能量范数下的投影，这条等价关系要重推——已写进案例页第四节第3条。

### 2.2 **派活书里那条捷径就是它自己点名为错的那个映射**

派活书说"径向缩回椭圆不是最近点投影，也不满足最大耗散原理"（对），
接着说正确做法是"在度规变换后的空间里做径向返回（把椭圆拉成圆、径向返回、再变回来）"。
**后半句展开之后就是前半句。** 记`S = diag(1/a, 1/b)`：

    g = S·f  →  圆上径向返回 g → g/|g|  →  回去 f = S⁻¹·(S·f_trial)/|S·f_trial|
                                              = f_trial / |S·f_trial|

**一个纯标量乘在`f_trial`上，方向一个字没变。** 逐分量实测两条路径最大差
**8.88e-16**（纯舍入，`μ_∥:μ_⊥ = 5:1`、37个方向×3个量级）。

更硬的一条：要让最近点投影在某个线性变换后变成径向，需要`T·S² = c·T`，
即`S² ∝ I`——**只有各向同性**。**不存在这样的线性变换。**
所以那条捷径不是"近似"，是同一个错映射的另一种写法。

**度规变换改变的是"缩多少"，不改变"沿哪个方向返回"。**

### 2.3 那"η-return"这个名字还成立吗

成立，但η是**塑性乘子**不是坐标缩放。把关联流动代进弹性预测后逐分量解出

    f_∥ = A·a²/(a² + η)      f_⊥ = B·b²/(b² + η)      η = k_t·Δγ

代回`Φ = 1`得一个关于η的标量方程，在`η ≥ 0`上严格单调下降且凸，故根唯一。
本仓按这个参数化实现，函数名`anisotropic_return_map`，η住在`_plastic_multiplier`里。

## 三、实测（先量后写；数全部来自本仓模块，不是从WDS抄的）

`μ_∥ = 0.5`、`μ_⊥ = 0.1`（5:1）、`N = 4 N`、`k_t = 3e4 N/mm`。

| 量 | 实测 | 闭式 |
|---|---|---|
| 关联流动的`\|sin(滑移, 外法向)\|`（λ ≥ 1.1） | **4.9e-15** | 0 |
| 同上，刚屈服档 λ=1.001 | 4.19e-13 | 0（容差是消去误差，见下） |
| `f·m̂`与支撑函数的相对差 | **1.9e-15** | 0 |
| **径向返回**的同一个`\|sin\|` | **0.923077 ⟹ 67.38°** | `(a²−b²)/(a²+b²) = 12/13` |
| **混合角耗散最高短缺** | **61.538%，在45°** | `(a−b)²/(a²+b²) = 8/13` |
| 45°处横向摩擦力被高估 | **恰好5.0倍** | `μ_∥/μ_⊥` |
| 各向同性（`μ = μ_∥`）顶替的最高短缺 | 80.0%，在**90°** | `1 − μ_⊥/μ_∥` |
| η迭代趟数 | 最坏17、均值约3 | —— |

### 3.1 WDS报60%，本仓量到61.538%——**而且要说清是哪个口径**

两个口径的数不同、**峰值位置也不同**：

* **口径A**（今天的引擎拿单个`μ_∥`顶上去 vs 椭圆）：最高**80%**，在**主轴**（90°）上；
* **口径B**（椭圆上径向缩 vs 最近点）：最高**61.538%**，在**45°混合角**上。

WDS说的是"**混合角**上最高60%"，**故它对应口径B**——口径A的峰值根本不在混合角上。
61.5%与60%相差1.5个百分点，在"报一个约数"的范围内；本页不去凑那个数，
**闭式`8/13`是可验的，60%不是**。案例把两个口径各判一条，
判据表里明写"不许把两个口径混起来报"。

### 3.2 刚屈服那一档的容差不是求解精度，是消去误差

`Δu = (f_trial − f)/k_t`在`λ → 1`时是两个几乎相等的数相减，方向误差按`eps/(λ−1)`放大。
实测λ=1.0001/1.001/1.01/1.1给3.59e-12/4.19e-13/3.31e-14/4.86e-15——**四档各差一个数量级**。
故它在清单里**单列一档**：混进去会让主档松100倍而看不出为什么。

顺带一条结构：**支撑函数那条判据对方向误差是二阶不敏感的**
（`h`的梯度恰是`f`，两边一阶变化相消），故它在全部λ上平在1.5—1.9e-15。
**方向那条更锐，大小那条更稳，两条一起才把两件事都钉住。**

## 四、五条形制裁决

### 4.1 退化**是构造出来的**，不是算出来的

`μ_∥ == μ_⊥`（逐位相等）时`anisotropic_return_map`**在任何自己的校验之前**
把参数原样转交`coulomb_return_map`，**连报错行为一起**。
所以"既有案例指纹不变"不需要任何数值论证。

**但只有这一条是不够的**：转交可以掩盖通用路径写错。
所以另立一条门**关掉转交、强走通用椭圆路径**，与圆的闭式并排——
实测最大相对逐分量差**2.96e-16**，且圆上恒**1趟**收敛（初值套的就是圆的闭式）。
注错验证：拿掉转交后只有第一条门红，说明两条各守各的。

### 4.2 摩擦朝向是**显式字段**，不许从任何量的符号里推

`FrictionEllipse(mu_along, mu_across, along_direction, normal)`。
理由是本仓自己的教训：`PenaltyAnnulusLimit`曾把朝向编码在坐标符号里，
**单元门永远抓不到**，端到端跑一次才炸（0.7.0那一批）。

配套三条门，**缺一就抓不到一整类错**：

1. `d_∥ → −d_∥`结果**逐位不变**（椭圆中心对称）；
2. 整体刚体转动，答案跟着转（防"朝向其实是从坐标轴推出来的"）；
3. **反向门**：交换`μ_∥`与`μ_⊥`必须给出**不同**答案。
   前两条会被一个"把`along_direction`整个忽略掉"的实现全部通过，
   **只有第3条能验出朝向真的被用上了**。

`along_direction`不要求预先落在切平面内——本类把它投影进去；
但**近乎平行于法向时拒收**（`IN_PLANE_DIRECTION_MIN_SINE = 1e-6`）：
投影后剩下的那点长度由舍入决定，**拿噪声当纵向轴用比报错坏得多**。

### 4.3 `μ = 0`拒收，不静默

`μ_⊥ = 0`把椭圆压成线段，那是一次**不同的**投影（往线段上夹紧），
按现有公式算会直接除零。本仓今天没有消费方要它，故构造期报错。
**登记为边界**，触发条件：第一个真要"某方向完全无摩擦"的消费方。

### 4.4 带法向分量的试探力**报错**，不静默扔掉

摩擦住在切平面里。容差`1e-9`相对量：比fp64舍入高七个数量级，
正常调用（`TangentialStickSpring`已扣掉法向）永远碰不到。
静默扔掉的后果与"粘着弹簧漏了法向投影"是同一种病——
**量被悄悄改了而报出来的仍是原值**。

### 4.5 `-0.0`收成`+0.0`——**这不是洁癖，是产物契约**

`f_∥·e_∥ + f_⊥·e_⊥`在面外那一格上恰好是`(±0.0) + (∓0.0)`，
**符号跟着`along_direction`的符号翻**，尽管两个值都精确等于零。
实测`canonical_bytes`把`-0.0`写成`-0.0`、`0.0`写成`0.0`，**字节不同**，
于是`State.fingerprint()`不同。这是4.2第1条门当场抓到的
（不是推出来的：它先红了，才有这一节）。

**`coulomb_return_map`没加这一步**，因为给它加等于改既有产物的指纹（三前提第三条）。
两条路径在这一点上的差别只出现在精确为零的分量上。**登记为已知差异，未修。**

## 五、明确没做的

1. **`advance_contact_quasistatic`与`advance_contacts_quasistatic`一个字没动。**
   它们把`friction_coefficient`当标量写死，接上椭圆要改签名——
   而0064把它们划在轨道D的红线外。**新映射是并列的第二条路径，旧路径默认不变。**
   案例因此不走`solve_equilibrium`，**这条写在案例页第四节第1条并给了触发条件**。
2. **不切默认。** 退化虽是逐位的，但"要不要把默认摩擦面换成椭圆"是另一件事，
   派活书明写那要走决策记录。**本页不裁它**——今天没有消费方声明两个系数。
3. **没有横向落位（`e_lat`）的端到端数。** 本轮量到的是"横向摩擦力被高估5倍"；
   从力到毫米级落位偏差要过带材的弯曲与输运，那是轨道A与轨道C的东西。
4. **没碰**`benchmarks/engine_budgets.baseline.json`、`docs/capability_ledger.json`、
   公开面清单、`ENGINE_RINGS`、根`README.md`。
   本案例**不让任何能力位从`partial`进`done`**：接触族要的是多体与恢复系数，
   而这一条验的是本仓自己的切向本构。
