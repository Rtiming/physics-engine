## 二、Hessian是怎么解析推出来的

`ℓ_i`取参考构型（Bergou的做法），于是`U`只经`c = cosθ`依赖位置：

    U = (EI/(2ℓ))·g(c)，g(c) = 4(1−c)/(1+c)
    g'(c) = −8/(1+c)²，g''(c) = 16/(1+c)³
    ∇U = (EI/(2ℓ))·g'(c)·∇c
    ∇²U = (EI/(2ℓ))·[g''(c)·∇c⊗∇c + g'(c)·∇²c]

以边矢量`u = x_i − x_{i−1}`、`v = x_{i+1} − x_i`为中间变量（`â`表单位化）：

    ∂c/∂u = (v̂ − c·û)/|u|,   ∂c/∂v = (û − c·v̂)/|v|
    ∂²c/∂u∂u = [3c·û⊗û − û⊗v̂ − v̂⊗û − c·I] / |u|²
    ∂²c/∂v∂v = [3c·v̂⊗v̂ − û⊗v̂ − v̂⊗û − c·I] / |v|²
    ∂²c/∂u∂v = [I − û⊗û − v̂⊗v̂ + c·û⊗v̂] / (|u||v|)

再经**常量**线性映射`(u,v) ← (x_{i−1}, x_i, x_{i+1})`（系数`u:(−1,1,0)`、`v:(0,−1,1)`）
落到九个自由度：`∇_x U = Bᵀ∇_z U`、`H_x = BᵀH_z B`。链式法则一次，无近似。

**求值走DER的分母、不走`(1−c)/(1+c)`**：`κ² = 4·|e_a×e_b|²/(|e_a||e_b| + e_a·e_b)²`
与它数学相等，但近直链时`1 − cosθ`是两个接近1的数相减，相对误差被放大`2/θ²`倍；
叉积平方没有这个问题。`g'`与`g''`同样用`1+c = D/(|u||v|)`改写。
分母`D`在θ→π（对折）时趋零——那是`2·tan(θ/2)`自身的奇点，**失败关闭**。

有限差分门实测（中心差分，步长`1e-6·max(1,|x|)`）：
梯度相对偏差**7.2e-10**、Hessian偏差/量级**3.3e-10**、Hessian非对称/量级**5.8e-17**。
**但那道门验不了物理**（spec/12第6.1节），下一节才是验物理的。

## 三、`3h/2`不是配出来的数，是推出来的——0027那条教训的第二例

第一版实现给出收敛比**2.0582 / 2.0323 / 2.0169**，一阶。

0027留了一条纪律："碰到收敛阶不对先查求积"。照做：扫固支顶点的Voronoi长度，
`1.0h`给一阶、**`1.5h`给3.9612 / 4.0512 / 4.0600（干净二阶）**，
而`1.45h`给3.147/2.832/2.513、`1.55h`与`1.65h`都退化——**1.5是唯一那个点**。

它有精确推导。以边角`φ_j`写离散弯曲能，正确的固支处理是在钳口另加一个半格顶点
`(EI/(2·(h/2)))·φ_0²`（夹持点到第一条边中点只有`h/2`的弧长）。
把第一条边整根钉死等于强行令`φ_0 = 0`，**把那半格柔度整个删掉**。
把`φ_0`做静态凝聚消掉即可看出该还回多少：

    min_{φ_0} (EI/h)·φ_0² + (EI/(2h))·(φ_1 − φ_0)²  →  φ_0 = φ_1/3
    代回得 (EI/(3h))·φ_1² = (EI/(2·(3h/2)))·φ_1²

即固支顶点的等效Voronoi长度**恰为`3h/2`**。三条旁证：

1. **与载荷无关**：β=0.8给3.909/3.967/3.989、β=3.0给3.961/4.051/4.060、
   β=5.0给3.921/4.067/4.089。若是配出来的数，它会跟着载荷跑。
2. **自由端不需要对应修正**（那里`κ(L)=0`，漏掉的半格是O(h³)）：
   把自由端权乘0.5或1.5，收敛比4.063/4.066与3.935/4.040，**都不动**。
   这条同时排除了"是不是两端都少算了半格"的错误归因。
3. **方向对得上**：取`h`时离散梁在钳口偏刚，端点挠度偏小（n=10实测y/L=0.5437
   对真值0.6033）；`3h/2`把柔度还回去正是补这个。

**与0027的关系：症状相同、病根同类而不同处。** 那次是梯形求积的端点半权，
这次是被钉死的第一条边吞掉的半格柔度。两次都**不是**"边界条件的阶次"——
0027警告过，归因错就会去改边界条件，而那改不动它。这次一次就归对了，
靠的正是0027留下的那句"先查求积"。

## 四、oracle：Carlson闭式，且与WDS的正交求积互证

生成器只算椭圆积分：**不import `physics_engine.energies`、不调`solve_equilibrium`**。
`K`/`E`/`F`用**Carlson对称形式**`R_F`/`R_D`的重复化算法（纯标准库，零依赖）。

**跨仓对拍**：WDS `validation/cantilever.py`用scipy的QUADPACK对**同一首次积分**
做端点奇点代换后的正交求积——完全不同的数值路线。五档载荷逐点相对偏差：

| β | x_L/L | y_L/L | α |
|---|---|---|---|
| 0.2 | 2.2e-16 | 3.6e-15 | 4.2e-16 |
| 0.8 | 4.4e-15 | 1.3e-14 | 9.1e-15 |
| 1.5 | 1.2e-16 | 1.1e-15 | 6.9e-16 |
| 3.0 | 3.0e-16 | 5.5e-16 | 1.1e-16 |
| 5.0 | 1.8e-16 | 4.0e-15 | 1.6e-15 |

生成器另跑三条自校验，任何一条不过就不出金标。其中第二条值得单说：
不只断言"小载荷退化到`δ=PL³/(3EI)`"，而是断言**第一修正恰为β的二次**
（β十倍则偏差百倍，实测100.004与99.79）。前者只验一个端点值，
后者验的是闭式的形状，且**校验里不需要写下任何系数**。

**登记一条闭式自身的失效**：`y_L/L = 1 − (…)`是相消形式，β≲1e-4时失去有效数字
（β=1e-6相对偏差4.9e-4，纯数值非物理）。本案例用β=3不受影响，
但自校验因此选在β∈[1e-3, 1e-1]。

**后者不是漏洞，是结构使然**；前者说明那条门对求和次序的灵敏度依赖构型，

## 六、本块最重要的发现：**物理案例验不了能量表达式**

spec/12第6.1节说"有限差分门验不了物理"。本块撞到了它的**镜像**。

第一次做弦长形式的验红时只改了`curvature_sq`、没改`first`/`second`
（`g'`与`g''`仍是tan形式的）。结果：**整个案例照绿，逐档误差与原来12位有效数字全同**
（2.107301800853e-02 / 5.319909414263e-03 / 1.313170851257e-03 / 3.234392862362e-04）。

原因一说就明白：**求解器只用梯度与Hessian找解**，能量值只进线搜索的
"降了没有"判断。一个只活在`energy()`里的错误可以从物理案例底下整个溜过去。

所以两道门的分工要重述一次，比spec/12第6.1节的原话更细：

| 门 | 验什么 | 单独存在时的盲区 |
|---|---|---|
| 有限差分 | 梯度/Hessian是不是那个`energy`的导数 | **能量本身错了照样绿** |
| 物理案例（闭式解） | 梯度那一路算出来的物理对不对 | **只活在`energy()`里的错误照样绿** |
| 手算解析值（本块新增） | `energy`那个表达式本身 | 只覆盖手算得动的构型 |

第三行是本块补上的：θ=90°给κ²=4、θ=120°给κ²=12（`2·tan60° = 2√3`），
`U = (EI/(2ℓ))·κ²`是手算数。同一个数还顺手把弦长近似排除掉了——
小挠度用弦长`|x₀−2x₁+x₂|²/h² = 4sin²(θ/2)`，在这两个角上分别只有几何精确值的
1/2与1/4。**一个手算数同时验了公式对不对、和它是不是那个小挠度近似。**

## 八、明确不做的与已知缺口

- **没有点载荷能量项**。端部集中力只能用`UniformGravity` + 集中质量表示，
  而`EnergyContext`要求质量为正，故非端点节点取1e-15 kg（合力占端载荷2.6e-11，
  实测在1e-12/1e-15/1e-18之间换只影响第5位有效数字）。
  **这是声明并有门守着的近似**，但正确的修法是加一个`PointLoad`项——
  research/05第2.3节里Euler屈曲、Timoshenko悬臂都要它。
- **各向同性，没有材料标架**。没有`κ1`/`κ2`分解、没有`EI_easy`/`EI_hard`、
  没有自然曲率、没有扭转。WDS的`BendingEnergy`那三样都有；
  搬它们要先有状态里的每边扭转角`γ`，那是下一块。
- **求解器在这个问题上是脆的**（案例页第四节量化登记）：无载荷步自适应、
  无信赖域、Hessian非正定时无修正。本案例的参数是**选出来的可行点，不是稳健区间**。
  修它要动`solve.py`。
- **`AxialStretch`的Hessian仍只有有限差分背书**（0024登记、0027未闭合的缺口仍未闭合）。
  本项的Hessian现在有闭式解背书（间接，经梯度那一路），但那不是同一件事。
- **没有加速档实现**，因此0016的对拍义务今天仍不附着（0024第六节同口径）。
- 稠密LU、无稀疏线性求解、无预条件。本案例最细档已到156个自由度、
  单次求解约48次牛顿迭代，是本仓最慢的案例。
