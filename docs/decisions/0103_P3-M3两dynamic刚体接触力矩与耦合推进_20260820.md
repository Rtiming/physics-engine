## 一、先证伪“直接复用现有接触流水线”

0101留的下一片是“两个dynamic体与显式候选接进现有dynamic接触流水线”。
读当前源码后，这句话只对了一半：

1. `contact_pipeline.SphereContactPipeline`吃的是“每个球绑一个平动节点”的
   `State`，设计上明确没有刚体杆臂和力矩；
2. `contact_dynamics`虽然能算`r×F`，但它只覆盖一个刚体对静止平面，
   文件头也明写“不做多体”；
3. `rigidbody.integrate_free_flight`一次只推一个13维刚体。若顺序调两次，
   RK4的四个子阶段会看到不同时刻/不同版本的对方状态，作用反作用不在同一组合态上评价。

因此可复用的是三个更底层的真接口：

- `PreparedModelScene`用完整dynamic state mapping生成两体几何位姿；
- `CollisionEvent`给出候选次序、窄相穿透、从B指向A的法向和两个见证点；
- `rigidbody`给出单体Euler方程、四元数运动学和积分器声明。

本批新增的是两体力学组装层，不绕过这三个权威。

## 二、刚体公式只保留一份

`rigidbody.rigid_body_state_derivative`成为“已组装合力/体系力矩→13维状态导数”的公开实验入口。
原`integrate_free_flight`的callback路径与新的26维耦合路径共用同一个内部公式：

```text
dc/dt = v
dv/dt = 1000 F / m
I domega/dt = 1000 tau - omega x (I omega)
dq/dt = 0.5 q tensor_product (omega_body, 0)
```

新单元门用一个对角惯量、非零合力/力矩手算全13个导数分量；非13维输入必须红。

## 三、`dynamic_contact`的最小物理

### 3.1 输入闭包

`DynamicSpherePairRuntime`第一片强制：

1. `PreparedModelScene`是`time_s`参数化；
2. 恰好两个dynamic体，恰好一对显式候选，候选两端就是这两体；
3. 两个geometry均是解析`Sphere`；非球在构造期拒绝，不等到积分中途降级；
4. 每次评价必须交付完整、无多余body的dynamic state mapping；
5. 只接受`confidence=narrow_phase`且同时带法向/两见证点的事件。

法向、见证点和穿透还必须闭合Bullet同形的恒等式：

```text
witness_a = witness_b - penetration * normal_ab
```

故意绕过该门时，植入y偏0.25mm的坏见证点被静默接受，专用必红测试实际失败；
恢复后测试通过。

### 3.2 作用反作用与力矩

法向从B指向A，故法向力为：

```text
F_a = N normal_ab
F_b = -F_a
N = k delta + max(-c v_rel,n, 0)
```

阻尼只在相对压缩时生效，分离时不产生“吸住”的拉力。两体分别使用自己的见证点：

```text
r_a = witness_a - COM_a
r_b = witness_b - COM_b
tau_a = r_a x F_a
tau_b = r_b x F_b
```

两个世界系力逐位反号；两个世界系力矩再各自换到体系后进入Euler方程。
第一片只有法向力，两个作用点之差与法向平行，所以系统总力矩为零。
响应同时分开罚簧力、阻尼力与正的耗散功率`c max(-v_rel,n,0)^2`；
耦合积分用同一RK4的1/6、2/6、2/6、1/6子阶段权重累计阻尼耗散，
不允许状态丢了能量而诊断里没有账。

### 3.3 26维同步积分

两个13维状态在每个RK4子阶段先合成同一份两体场景，再查一次候选、装两侧旋量。
每个完整步分别对两个四元数执行与单体相同的归一化前护栏。

积分入口自动执行全候选接触刚度步长界；转动模态界仍是另一条独立上限，
本批没有把两条偷偷合成一个新声明。两个刚体积分器的`production_ready`仍为`False`。

## 四、P3-M3独立oracle

`cases/dynamic_two_body_contact`含两档：

1. **偏心COM旋量档**：两球心x=-9.5/9.5mm、半径10mm、穿透1mm，
   COM在各自geometry frame内y=2mm。独立手算得`F_a=(-100,0,0)N`、
   `F_b=(100,0,0)N`、`tau_a=(0,0,-200)Nmm`、`tau_b=(0,0,200)Nmm`；
   关于世界原点的总力矩为零。
2. **对齐COM闭式档**：两等质量从1mm初压缩静止释放。约化质量0.5kg，
   `omega=sqrt(1000k/m_eff)`，四分之一周期时穿透归零，两体速度为
   `±0.5 omega`，总动量为零，总动能等于初始罚簧能50Nmm。

案例数54→55；主能力17/42与端到端0/6不变。

## 五、性能与GPU

400步双体接触每趟有1600次耦合导数求值。初版三组各9次中位为
642.828/615.667/614.442ms。cProfile显示主热点不在窄相数学，而是公开刚体accessor
每次都对同一`RIGID_BODY_LAYOUT`重算规范JSON SHA：46428次指纹占0.785s插桩墙钟。

修复不删指纹门：状态持有的layout就是模块权威对象时直接放行；从严格reader重建的
等价layout仍计算指纹，新反向门守这条fallback。末版又补上法向/见证点完整性校验和
RK4阻尼耗散记账，三组中位为214.142/195.208/195.662ms，三组中位195.662ms，
相对修复前615.667ms下降68.2%。同批P3-M2单体500步三组中位24.679/26.794/26.179ms，
三组中位26.179ms，相对本批基线中位26.224ms没有可见回推。

这条路径仍只有26个状态量、1对候选和大量Python对象组装；GPU不会消除解释器/场景验证成本。
当前有效路线仍是CPU上把不变量前移。等同时有大批独立接触对并且profile指向数组核，
再过spec/13三门槛。

## 六、已知边界

1. 只有解析球—球、单候选、法向罚簧与压缩阻尼；无切向摩擦历史、滚动阻力或多候选。
2. 没有静止/运动平面、胶囊/盒/网格的dynamic响应。
3. 显式RK4仍非辛且非生产积分器；本案例只覆盖短时接触。
4. 质量属性、刚度和初始穿透均为合成`hypothesis_only`。
5. 无WII adapter、WDS采用、真实资产或现场标定。
