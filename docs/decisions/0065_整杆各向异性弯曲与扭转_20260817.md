### 坐标约定钉死在一处

`d1`＝穿厚方向、`d2`＝带宽方向；`κ1 = 0.5(m2_l+m2_r)·κb`配`EI_easy`、
`κ2 = −0.5(m1_l+m1_r)·κb`配`EI_hard`。推导在`rod.py`第一节。
`κ1`/`κ2`是**离散**曲率（无量纲、已在对偶元上积分过），物理曲率要除`l̄`。

## 二、三道物理门（0064第4.4节点名，后两道同行WDS没有）

| 门 | 判什么 | 实测偏差 | 必红用例 |
|---|---|---|---|
| **螺旋线运动学** | `κ = R/(R²+p²)`、`τ = p/(R²+p²)`，且`κ2`在螺旋线上是**机器零** | `κ2 ≤ 1.9e-15`（N=21/41/81/161上1.07/1.92/5.20/8.83e-15，**不随h下降**）；`κ`偏差2.44e-4、`τ`偏差3.82e-4（N=41），两者收敛比都是**4.00**（二阶） | B：`_curvatures`里`cos_left`→`sin_left`（＝取错`d1`），`κ2`从1e-15跳到1e-1 → **红** |
| **易/难轴互换** | 参考`d1`转90°，挠度比**必须等于**`EI_hard/EI_easy` | 比值999.99972，相对偏差**2.79e-7**；且它随载荷平方下降（F=0.05/0.005/0.0005 N → 2.79e-7/2.79e-9/2.65e-11），**那是几何非线性不是门的噪声** | C：两个刚度对调，比值变成1/1000 → **红** |
| **闭式扭转** | 端扭矩杆`θ = M·L_eff/GJ`。**全仓此前没有任何扭转金标** | `θ = 1.2337662337662278`、闭式`1.2337662337662338`，相对偏差**4.885e-15**；牛顿1步收敛；逐顶点扭率极差6.85e-17 | D：扭转项漏掉`/l̄`，`θ`差`l̄`倍（本例10倍） → **红** |

三条要点，都是量出来才知道的：

1. **`κ2`的机器零是结构性的，不是收敛来的。** 螺旋线上两条相邻弦的`κb`与顶点解析
   副法线严格共线，而两个**边中点**法线之和严格平行于顶点法线，于是内积恰为零。
   `m1`取边中点法线而不是端点法线是这条成立的前提，写在测试的docstring里。
2. **易/难轴门必须把γ全钉住**才验的是纯弯曲各向异性。不钉，杆会自己转过去用软轴——
   那是另一件事（第四节的外层循环门验它）。
3. **闭式扭转的`L`是`Σ l̄_i`＝端边中点之间的距离**（N=21、h=10时190 mm，杆长200 mm）。
   拿杆长去对会得到5%的"偏差"然后被当成精度问题去调。**那10 mm是形制不是误差。**

### 顺带量出来的一条：固支半格柔度，这次是第三例

整杆的固支悬臂**不加订正只有一阶收敛**（挠度偏差0.145/0.0738/0.0372/0.0187，比值≈2）；
按`energies.clamped_chain_bending_vertices`那条静态凝聚推导，把固支顶点的对偶长度取`3h/2`
之后是干净的二阶（2.350e-2/6.063e-3/1.539e-3/3.880e-4，比值3.876/3.939/3.968）。
这是0027那条教训的**第三例**，症状相同、病根同类而不同处。
因此`RodReference`留了`dual_lengths_mm`显式覆盖口，**只为这一件事留**，注释写明了理由。

## 三、0064第4.1节要的两个墙钟：**jet比既有解析慢约42倍**

配对计时（同一轮里交替量两侧，取逐轮比值中位数；节点42、内顶点40，
macOS arm64 / Python 3.13.12）：

| 项 | 逐顶点中位数 | 说明 |
|---|---:|---|
| `rod`各向异性弯曲 `hessian_entries`（11变量`Jet2`） | **2555 µs** | 本轨道的新项 |
| 既有`DiscreteElasticBending` `hessian_entries`（解析闭式） | **62 µs** | 同规模、同一次运行里量的 |
| `rod`扭转 `hessian_entries`（2变量`Jet2`） | 23 µs | 便宜，符合预期 |
| `rod`各向异性弯曲 `energy`（0阶，无jet） | 12.0 µs | |
| 既有`DiscreteElasticBending` `energy` | 3.2 µs | |

**逐轮配对比值：`hessian_entries` 41.8×（范围38.1—45.7），`energy` 3.65×。**

**计时条件必须并排写出来**：这批数是在1分钟负载**7.35**（5/15分钟11.08/11.40）
的机器上量的——波次二四条轨道在并行跑。按spec/13的资源合格口径，
**绝对值是UNQUALIFIED**；轻载时同一台机量到的绝对值是1635 µs vs 48 µs（比值34×）。
所以**可引用的是比值34—46×，不是那个绝对毫秒数**。

### 这两个数意味着什么

`energy`那一列的3.65×里没有jet——它是"两个曲率分量＋四次三角函数＋逐顶点两个刚度"
的固有代价，各向异性本身就要付。**jet的代价全在`hessian_entries`那一行**：
11变量`Jet2`每次乘除要建一个121项的tuple-of-tuples，而曲率核里这样的运算有几十次。

按40个内顶点算，一次Hessian装配约**102 ms**；一次牛顿求解要装几次。
这条与0030量的"求解那一步按`n^2.6`增长"是两个不同的杠杆，**而这一条更靠前**：
在本轨道的规模上，装配已经不再是"75%时间"，它是几乎全部。

**要不要转解析，现在有分母了。** 0064第4.1节把这个问题挂到"等那两个数"，
本页交出的答案是：**上限是42倍，且它只发生在二阶通道**。
一个折中路线在数上是成立的——梯度走`Jet1`（本轨道已经这么做，`need_hessian=False`时
不付121项的账）、只把Hessian转解析。**本页不裁这一条**，理由与0064第4.1节同源：
那要一次真实的端到端画像（哪个案例、多少顶点、几次牛顿），而本波次没有那个案例。

## 四、0064第4.2节要的三个数：**带状快路确实被打掉了**

布局按裁决实现：`node_positions_mm`（3N）在前，`edge_twist_angles`（N−1）在末尾。

| 问题规模 | 自由自由度 m | **实测半带宽 b** | **带状是否触发**（判据`2b+1 < m//3`） | 稠密LU | 带状LU |
|---|---:|---:|---|---:|---:|
| 42节点（钉住前两节点＋γ₀） | 160 | **122** | `245 < 53` → **否** | 72—82 ms | 27 ms |
| 82节点（同上） | 320 | **242** | `485 < 106` → **否** | 551—567 ms | 164—199 ms |
| 对照：同一个Hessian，把γ全钉住 | 120 / 240 | **8** | **是** | — | — |

三条结论：

1. **半带宽实测122（42节点）与242（82节点），确实是`O(3N)`**，与0064第4.2节的预判一致；
2. **带状路径不触发**——`solve.py`第218行那条结构性判据把它挡在外面；
3. **但被挡掉的那条路在这里其实是快的**：同一个约化矩阵上，带状LU是稠密的
   **0.30—0.37倍**（两个规模上都是）。两条路的解相差2.76e-12（相对），
   即**带状在这个带宽上给的是同一个答案**。

第3条是本节唯一没被预料到的：判据挡掉它不是因为它错，是因为
`2b+1 < m/3`这条**结构性**判据在`b ≈ 3m/4`时保守了。
`_solve_dense`是高斯-约当（上下都消），`_solve_banded`是LU+回代——
即使带宽接近满，后者的常数因子也小一半，而`O(m·b²)`在`b = 0.76m`时是`0.58 m³`。

**本页不改那条判据**，理由和0064第4.2节不改布局是同一条：
判据是`solve.py`的形制，动它要看全仓所有调用点（链式问题上它今天是对的，
`bandwidth_of`实测半带宽恒为2那一档正是它服务的对象），
而本轨道只是**第一个**撞上它的调用方。**先把数摆出来，改不改另立一批。**
对照那一行（γ全钉住时半带宽掉回8）说明：**γ块放末尾是半带宽爆掉的唯一原因**，
交错布局确实能救回带状——但那是一次不可逆的形制选择，仍然不该在只有一个调用方时做。

## 五、retransport外层循环，与"抄了公式不抄外循环就红"那道门

`m_ref`冻结成常数 ⟹ `RodTwist`对位置**没有任何依赖**（有一条断言直接验这个：
扭转项在位置块上的梯度恒为零）⟹ **单次`solve_equilibrium`里弯曲与扭转的交换根本不存在。**

`solve_rod_with_retransport`写在`solve_equilibrium`**之上**，每轮：
求解 → 用冻结帧与当前γ算出材料director `m1` → 把`m1`时间输运到新切向 →
在新构型上重建Bishop帧 → 用带符号角把γ反算回来并解缠 → 重建项与注册表 → 再求解。

### 那道门：球面三角holonomy

切向序列`x̂ → ŷ → ẑ → x̂`围出一个**三个角都是直角**的球面测地三角形，
面积`4π/8 = π/2`；由Gauss-Bonnet，平行输运绕它一周的holonomy**恰是π/2**。
这是一条与被验内核完全独立的闭式。

杆从直（切向全`x̂`）走到这个构型，材料帧保住不变：

| | 重输运 | 不重输运（＝抄了公式不抄外循环） |
|---|---|---|
| 运动学：`γ₃ − γ₀` | `−1.5707963267948966`，与`−π/2`**逐位相同** | γ停在全零 |
| 运动学：扭转能量 | 9.4995 N·mm | **恒等于`0.0`** |
| 求解：第0轮扭转能量 | `0.0`（此时参考帧还是直杆的） | — |
| 求解：收敛后扭转能量 | `3.166498078682835` | **`0.0`** |
| 求解：串联扭簧闭式`0.5·GJ·(π/2)²/(3h)` | `3.1664980786828356`（相对偏差**1.4e-16**） | — |
| 求解：γ分布 | `(0, −π/6, −π/3, −π/2)`，逐段严格均匀 | 全零 |

**不抄外循环的偏差是100%，而且不报任何错。** 这正是plans/14第3.1节第4条那句
"抄了公式不抄外循环，得到的杆弯不出扭"，现在它是一条可执行的断言。

必红F（把`retransport`改成原样返回旧帧与旧γ）：两条用例都**红**。

## 七、边界：这一片**不是**什么

* **纯弹性**。没有纤维塑性、没有轴向`N`、没有截面翘曲/压扁/剪切。
  `rod`与`sections`/`section_beam`那一片**今天没有接口**，合并要另走决策；
* **没有槽壁接触**。plans/14第2.3节说的"双轴弯曲＋扭转＋槽壁接触三件一起算"，
  本轨道交了前两件，**第三件没有**。所以那个5.9%仍然定位不到区间里的哪一点；
* **不进`docs/capability_ledger.json`**。按0064第二节，本波次四条轨道没有一条让某位
  从`partial`进`done`——本轨道也不例外：它没有端到端案例，只有单元级的闭式门；
* **没有`cases/`案例目录**。理由写在第八节，这是本轨道明确的欠账；
* **retransport不是隐式耦合**。外层循环是显式的、由调用方定轮数的；
  `RodSolveStage.retransport_rounds`默认2，取1意味着最后一次重输运之后没有再求解，
  交换只走了一半。这一条写在`RodSolveStage`的字段注释里。
