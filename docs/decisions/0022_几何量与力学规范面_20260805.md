## 一、裁的是什么

1. **spec/12单开一页**，不并进spec/11（plans/02第六节第2项的两个候选取前者）。
   理由：spec/11管的是"模拟世界里的形状"，其范围声明明确把制造实体挡在外面；
   把状态、能量项协议、时间推进塞进去会让那一页的范围边界失效。
2. **spec/12是"接缝规范"不是"物理设计"**。0015裁的是"把物理搬过来",
   所以本页定的是一块内核凭什么能进、进来怎么被调用、怎么证明搬对了——
   十条规则里绝大多数是WDS既有法条与既有实践的蒸馏，增量四处逐条标注理由。
3. **`geometry.py`只做纯新增，不碰`shapes.py`**。新函数收shape对象、返回质量属性；
   `shapes.py`的`mass_kg`保持可选、语义不变。字节风险为零（0001第三前提）。
4. **本页与spec/12都不登记面**。今天`geometry.py`的返回值全在进程内。
   但这是有时限的豁免：状态数组/积分器诊断第一次跨边界时必须先登记面
   （spec/12页首写明了这条时限）。

**增量四处（明确标注并给理由）：**

1. **积分器的共同接口**。WDS三套积分器（Newmark平均加速度、隐式中点、generalized-α）
   各自内嵌在自己的求解器里，**没有共同签名**。引擎要在一个仓里并存多个积分器
   并让案例判据跨积分器复用——第九节的漂移排序判据必须能对三个积分器跑同一个案例，
   否则那条判据根本写不出来。
2. **选路径要申报无量纲比**。WDS算过那个比（卷绕线速50 mm/s对轴向波速3.63 m/ms
   = 1.4e-5，惯性小五个数量级），但没把"必须申报"立成条款。立它的理由是
   WDS自己那条已知失效——瞬态在卷绕工况不收敛；申报义务若当初就在，
   那条失效会在跑之前被读出来。
3. **守恒量三种写法各自的假通过堵法 + 地板双向**。WDS有防"噪声造假失败"的地板，
   没有防"全零造假通过"的前置断言。两个方向都要写。
4. **"能逐字节就必须逐字节，容差是需要理由的退档"**。0016给的是
   "结果不变→逐字节／路径不同→容差"，读起来像二选一；WDS的实践更严
   （专门保留零阶通道来守逐位）。本页按WDS的实践收紧0016的下限。

## 四、`geometry.py`：形制与它用的解析闭式解

纯标准库、无状态纯函数、返回显式元组。公开名只进本模块`__all__`，不进`__init__.py`
（plans/02第3.2节的并行期约定）。

**三条边界写在模块头**（都是spec/14第五节说的"静默1000倍"级风险）：

1. 惯量**绕质心、在局部轴下、单位kg·mm²**，参考点写进字段名
   `inertia_about_centroid_kg_mm2`；换参考点必须显式调`shift_inertia_kg_mm2`；
2. 长度mm、质量kg、密度kg/m³；密度到mm制只用到**mm³↔m³**这条纯长度量纲换算，
   正是spec/14第五节登记过的那一条，不是自己猜的因子；
3. 不猜没声明的几何——带法兰的圆柱与网格资产一律失败关闭（第六节）。

公开面：`mass_properties` / `volume_mm3` / `centroid_mm` / `shift_inertia_kg_mm2` /
`sdf_mm` / `MassProperties` / `Matrix3` / `MM3_PER_M3` / `GeometryError`。

`mass_properties`收`density_kg_m3`或`mass_kg`**恰一个**：两条来路都真实存在
（材料记录带密度、`SimBody.mass_kg`是称出来的），两个同时给会产生一个
**没人会去核对的隐含体积**，所以失败关闭，不做"以质量为准"的静默取舍。

### 4.1 用到的解析闭式解

| 原语 | 体积 | 惯量（绕质心） |
|---|---|---|
| Sphere | `4πr³/3` | `I = (2/5)mr²`各向同性 |
| FiniteCylinder（无法兰） | `2πR²W` | 轴向`mR²/2`；横向`m(3R² + 4W²)/12` |
| RoundedBox（`r_f = 0`） | `abc` | `I = m(a² + b²)/12` |
| Capsule | `πr²L + 4πr³/3` | 轴向`= m_cyl·r²/2 + (2/5)m_sph·r²`；横向`= m_cyl(3r²+L²)/12 + (83/320)m_sph r² + m_sph(L/2 + 3r/8)²` |
| RoundedBox（一般） | Steiner展开`abc + S·r + πr²·Σ边长 + 4πr³/3` | 按核心盒 + 6面板 + 12个四分之一圆柱 + 8个角八分球分块积二阶矩，再`Ixx = Jy + Jz` |

半球那两个常数值得留痕：半球绕**自身质心**的横向矩是`(83/320)m_h r²`
（`(2/5)m_h r²`减去质心偏移`3r/8`的平行轴项），帽心到胶囊质心的距离是`L/2 + 3r/8`。
`L→0`时两式合并回`(2/5)mr²`——这条退化在测试里是硬判据。

圆角盒按四族分块而不是套现成公式，好处是**三个方向的公式只写一遍**
（用`(Jx, Jy, Jz)`再组合成`Ixx = Jy + Jz`），写错一处三条门同时红；
且它有三条独立的解析退化极限可查：`r→0`是盒、`h→0`是球、`hx,hy→0`是胶囊。
三条极限在实现之前已手推核对过，第三条尤其硬——它把**两个原语的独立代码路径**
接在一起。

### 4.2 rounded-core SDF

`φ(x) = φ_core(x) − r_f`（spec/11规则2）。四种原语都是**精确**符号距离不是保守下界：
球的核是一个点、胶囊的核是线段、圆角盒的核是盒（走标准盒SDF）、
有限圆柱的核是它自己（`r_f = 0`，走`(径向, 轴向)`二维盒SDF）。

### 4.3 判据分三层（`tests/test_geometry.py`，33条，0.11秒）

- **解析闭式解**（最强）：上表逐条；圆角盒的Steiner体积在实现里是**分块积**出来的、
  在测试里是**整式**——两条推导路径不同，不是轴7规则3禁止的"在测试里复述oracle公式"；
- **跨实现对拍**：三条退化极限 + 一条以`sdf_mm`为独立oracle的数值求积
  （32³格、按`0.5 − φ/Δ`折体积分数，实测最差3.5e-3，容差1e-2留约3倍余量）；
- **自洽门**：平行轴定理（把盒沿x劈成两半、各自平移回去再相加）、
  惯量张量对称正定（Sylvester判据，不引入自写特征值求解器）、
  轴对称体三个主不变量与摆放方向无关（等价于谱不变，同样不需要特征值求解器）。

## 六、发现但没修的缺口

1. **`FiniteCylinder`的法兰没有轴向尺寸字段**。`shapes.py`只声明了
   `flange_outer_radius_mm`，法兰宽度不在声明里，因此带法兰的圆柱**体积不由声明决定**。
   `local_aabb_mm`按`r = flange_outer_radius or radius`、`z`跨满`±half_width`取包盒——
   那是**包络**，拿它当质量分布会把导轮算成一个实心大盘，错得没有告警。
   本批的处理是**失败关闭**并在消息里点名缺的是什么。
   补它要动spec/11的形状词汇（加法兰轴向尺寸，或把法兰声明成独立的第二个形），
   属于spec/11的修订，不在本批授权范围内。
2. **`MeshAsset`没有质量模型**。引擎从不读网格字节（`shapes.py`的既有边界），
   声明的AABB是包络不是质量分布。同样失败关闭。
   这与plans/02第一节实测缺陷1（示例场景的包络是编的）是同一条缝的两侧：
   引擎既不读网格、又拿声明当真，所以任何"从网格算惯量"的路都得先解决读网格这件事。
3. **`geometry.py`没有加速档实现**。0016要求"有加速实现的内核随批附对拍",
   本模块**没有**加速实现，因此不触发对拍义务。这是有意的：
   四种原语的质量属性是`O(1)`闭式解，没有可加速的循环；
   真正需要加速档的是能量装配（8.1节：75%时间在那里），不是这里。
   若将来要对一批形状批量求质量属性，那时的对拍义务照0016执行。

## 七、B档判据的本机核算（spec/12第九节的数从这里来）

plans/02第四节第8条给的四条判据，本批在本机逐条核算过（尚无`integrate.py`，
用一次性脚本验的是**判据本身成不成立**，不是验实现）：

| 判据 | 实测 |
|---|---|
| velocity Verlet对常加速度精确 | `h`=0.1/0.05/0.01三档相对误差3.6e-16 / 5.4e-16 / 0.0——浮点噪声，非离散误差 |
| 半隐式Euler误差与`a·T·h/2`之比 | 0.999999999999990 / 1.000000000000038 / 0.999999999999920，即`1 ± 8e-14`；判据写的`1 ± 1e-8`留了六个数量级余量 |
| Verlet对`cos(ωT)`误差随h减半降4倍 | ω=2、T=3、h=0.02/0.01/0.005：误差1.117e-4 / 2.794e-5 / 6.985e-6，比值3.9985与3.9996 |
| 漂移排序 | ω=2、h=0.01、2000步相对能量漂移：explicit 1.2252e+00 > symplectic 1.0052e-02 > verlet 5.5453e-05，且三者均非零 |

**核算过程里长出的两条判据修正（已写进spec/12第九节）：**

1. **显式Euler的误差恰为`−a·T·h/2`**（实测比值−1.000000000000008 /
   −0.999999999999979 / −1.000000000000038）。它与半隐式Euler的误差**大小相同符号相反**,
   所以**只比绝对值的判据分不开这两个积分器**。plans/02的原文按字面读已经含符号，
   但实现时极易写成`abs()`，spec/12把这件事写明。
2. **`cos(ωT)`那条的比值不能写成"恰为4"**。4是渐近值，粗档还没完全进渐近区
   （3.9985就是这件事）；写死会让一个正确的实现在粗档上红。
   spec/12给的是`[3.9, 4.1]`并写明理由，与第四节4.3"比收敛阶不比单点"同一条纪律。
