# 0002 更名与物理引擎定位（2026-08-04晚）

状态：已裁决（用户口述）。

## 裁决

1. 本仓定位是**物理引擎**，不只是两个孪生仓的契约骨架：除物理域外，还要装
   **模型生成、物理性质（材料）、外观（颜色）**等模块，分模块组织。
2. 仓名由`twin-engine`更为**`physics-engine`**（建仓当晚更名，远程尚未建立，
   零成本；将来开源时可另起品牌名）。

## 随裁决落下的

- [docs/spec/01_模块地图与域划分_v0.md](../spec/01_模块地图与域划分_v0.md)：
  四圈模块图（内核/物理域/资产/呈现交互）、各能力现居地实测
  （modelgen在GCW、mechanics在WDS、optics在FTS、materials形制在WDS、
  离线渲染在lab_render、交互在viewport-input）、消费方登记、三条边界
  （资产圈不做物理、引擎不吞工作台、规范先行不松动）。
- 消费方登记新增`case2-digital-twin`为潜在第三个消费方——它的存在使
  0001的共享引擎裁决更站得住。
