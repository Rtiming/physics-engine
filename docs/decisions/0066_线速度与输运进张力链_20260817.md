# 0066 线速度与输运进张力链：`T = M/R`原来是一个稳态

日期：2026-08-17
状态：**已落地**。轨道B（决策0064第三节预分配），
勘察正本是[plans/14](../plans/14_现场场景勘察_真实工件是非平面槽_20260817.md)第3.2节。

## 一、问题：那个模型里没有扰动，所以控制器没有东西可控

0062轨道乙落地的`drives.SpoolTension`把张力写成

    T = M / R(n)

**这条式子里没有时间、没有速度、也没有带材。** 于是`drives.TensionLoop`
虽然有一个理想PID、有时延线、有传感器量化，**它调的是一个不会被扰动的量**：
只要电流不动，张力就不动。

plans/14第3.2节把这条挂成二号缺口，并指出**数据源在上游已经有了**：
WII的`wii_motion_timeline.v2`逐样点带`material_feed_length_mm`（单调非减）、
`time_s`（严格递增、`time_origin = "run_start"`）与`pause_intervals`。
本仓`motion.py`能吃位姿时间线，**没有任何东西吃长度**。

**所以这不是"上游没给"，是"下游没接"。** 本轮接的就是这一段。

## 二、建了什么：三件真物理，落在新模块`transport.py`

    输运账     dL_mat/dt = v_放线 − v_收线
    带材弹性   ε = (L_geo − L_mat)/L_mat 、 T = EA·ε
    力矩平衡   J·dω/dt = T·R − M − c·ω          （ω > 0）

第三条是本轮**符号上最容易搞反的一条**：磁粉离合器是**制动不是驱动**，
放线盘上没有电机，带材是唯一的驱动源。**张力升高让放线盘加速**，
加速之后跨段里材料变多、应变变小、张力回落——负反馈是这么闭合的。

### 2.1 为什么长成新模块而不是塞进`drives.py`

与0062第9.1节同一条判据的第二次应用：**import决定环，不是愿望决定环**。
`transport`只import基座`scene`圈的`motion`（取`PauseInterval`）与标准库，
没有一条边越到别的域，也没有向上；它登记在**力学域**。

它没有长进`motion.py`也是方向问题：`motion`在基座，而跨段张力是力学；
把张力塞进`motion`等于让基座反向依赖力学，正是0035那次抓到的"方向反了"。

**`PauseInterval`复用而不重写**，理由与`drives`不自己实现时延同源：
重写一遍等于开第二条真相源，而两条时间线对"什么叫一段暂停"必须是同一个约定。

## 三、本轮最要紧的一个结论：`T = M/R`不是一条定律，是一个稳态

力矩平衡取`dω/dt = 0`（此时必有`ω·R = v`，否则材料长度永远在变）：

    T_ss = M/R + c·v/R²

**`c = 0`时它恰是`T = M/R`。** 案例有一道**零容差**门判两边给出同一个浮点数
（实测两边都是`20.0`）。

这句话有三个后果，逐条写清：

1. **`drives.SpoolTension`没有错**，它是那条平衡在零轴承阻力矩下的稳态解；
2. **但它是零线速度口径的**：真机线速度不为零时差一个`c·v/R²`。
   `drives`那一侧因此加了一个带线速度的前馈
   `SpoolTension.brake_torque_for_tension_nmm`（`M = T·R − c·v/R`），
   并有一道门判它在`c = 0`时与`torque_nmm`**逐位相同**；
3. **它上面没有扰动可控**。要让控制器有东西可控，走`transport.SpanTransportLoop`。

`SpoolTension`的既有字节形制、门与调用点**一个字没动**（0064波次二的分槽纪律）。

## 四、判据：阶跃响应**不是**教科书那条二阶阶跃

线性化（`K ≡ −dT/dL_mat = EA·L_geo/L_mat²`）：

    ω_n = sqrt(1000·R²·K/J)          ζ = (1000·c/J)/(2·ω_n)

那个`1000`是`1 N = 1000 kg·mm/s²`。**掉了它`ω_n`差`sqrt(1000) = 31.6`倍**，
案例有一条专门的捕手门（与`two_body_spring`那条同源）。

收线端速度阶跃时**张力连续而速度差当场跳`−Δv`**，初值因此带一个斜率冲击
`y'(0) = ω_n/(2ζ)`——等价于传递函数多一个零点。解仍是闭式：

    y(t) = 1 − e^{−ζω_n t}·[cos(ω_d t) − ((1−2ζ²)/(2ζ√(1−ζ²)))·sin(ω_d t)]
    t_p  = (π − acos ζ)/ω_d                       ← 标准二阶是 π/ω_d
    超调 = exp(−ζ(π − acos ζ)/√(1−ζ²)) / (2ζ)

### 4.1 `exp(−ζΦ/√(1−ζ²))`在本仓第三次出现，而`ζ = 0.5`是一个盲区

| 出处 | `Φ` | 前因子 |
|---|---|---|
| `contact.restitution_from_damping_ratio` | `2·acos ζ` | 无（0052第一节的截断约定） |
| `drives.step_response_overshoot` | `π` | 无（半个阻尼周期） |
| `transport.velocity_step_overshoot` | `π − acos ζ` | **有**，`1/(2ζ)` |

`drives.py`已经记着前两条"只在`ζ = 0`处相等"。**本条更难看**：

    π − acos ζ = 2·acos ζ  ⟺  acos ζ = π/3  ⟺  ζ = 0.5

而`1/(2ζ)`在同一点**恰好是1**。**两处退化撞在同一个点上**，于是
`ζ = 0.5`时本式给`0.29843605919227484`、恢复系数式给`0.2984360591922749`
——**差一个ulp，是同一个实数**。

`ζ = 0.5`正是写测试时最顺手的那个值。**只在它上面判，判不出这两件事是两件事**，
而且**它不会红**——它只会让一道门变成没有内容的门。判据因此在五个`ζ`上扫，
并有一条门断言"退化点只有这一个"。

这一条与`drives.py`那条"实测当场否掉'逐位相同'的判断"是同一族，方向相反：
那次是**以为相同、实测不同**，这次是**结构上不同、而在最常用的那个点上实测相同**。

## 五、那道方向门判什么，以及它红过

### 5.1 "张力升高让哪一端慢下来"这个问法没有答案

派活时的问法预设了"有一端会慢下来"。**在本模型里没有一端会慢下来**：

* 收线端是伺服给定的（`ED3L-08AEA`在CSP位置模式），张力改不动它；
* 放线端**加速**——离合器是制动，张力大了盘就被拉得更快。

真正慢下来的是**跨段材料的净流失速率**，而那不是任何一端的速度。
这条写进`PayoutReel`的docstring与案例页。

### 5.2 门本体是两个纯函数，因为在真实对象上永远造不出红

`K > 0`与`R²/J > 0`都是结构性的，所以判据抽成
`tension_feedback_gain_per_s2`（两个偏导的乘积必须为负）与
`assert_span_transport_directions`（三个符号：等速恰为零、多送下降、多收上升），
注错用例把反号的偏导、把对调了两端的速率函数直接喂进去。
形制取0064第八节那条"判据本体抽成纯函数"。

**零增益与正增益一起挡住**：判据写的是`< 0`而不是`!= 正`——
增益为零正是`SpoolTension`那个模型（张力与长度账脱钩，扰动进不来也出不去）。

### 5.3 反面被跑出来了，而它跑的方向与我先写下的相反

本页初稿写的是"两端对调之后指数发散到`1.7e5 N`"。**实测当场否掉**：
对调之后反馈确实是正的，但收线端加速这个扰动把它推向**另一侧**——
张力单调下降、放线盘被制动器越拖越慢，第**7595**步（`t = 7.595 ms`）
转速穿过零，被`PayoutReel`那条`ω ≤ 0`失败关闭接住，此时张力已从20 N掉到**8.593 N**。

| | 单调？ | 60 ms内的张力 | 结局 |
|---|---|---|---|
| 正确 | 否（振荡） | 19.281 — 21.373 N | 跑完 |
| 对调 | **是（单调降）** | 8.593 — 20.000 N | 7.595 ms时`ω ≤ 0`关闭 |

**这一条记下来是因为它是"先写数再去量"这个坏习惯的又一次现形**，
而且这次是在决策页自己身上。

## 六、实测数（全部2026-08-17，本机Mac）

### 6.1 阶跃响应

参数：`EA = 60000 N`、`L_geo = 300 mm`、`R = 60 mm`、`J = 5000 kg·mm²`、
`M = 1200 N·mm`、`v = 20 mm/s`、`Δv = 2 mm/s`（10%）、`dt = 1e-6`。

| 档 | `c` | `ζ` | 超调闭式 | 超调实测 | 相对偏差 |
|---|---|---|---|---|---|
| 额定 | 50 | 0.0131717 | 37.176327 | 37.176663 | **9.03e-6** |
| 加阻尼 | 1000 | 0.2634085 | 1.1493664 | 1.1492819 | **7.35e-5** |

峰值时刻两档都是**1.76e-5**相对（闭式`4.17307 ms`／`5.01691 ms`）；
峰值幅值**8.80e-6**／**3.93e-5**（闭式`1.0604535 N`／`1.1940924 N`）。

**稳态误差**：加阻尼档跑到`t = 0.08 s`（`dt = 2e-6`）时残差
**−1.735e-4 N**，即**6.64e-6**相对——那是剩下的指数尾巴
（`e^{−ζω_n·0.08} = 3.3e-4`乘幅值1.19 N），不是偏差。
**额定档在同样时长上根本没有稳态可言**，见下。

### 6.2 本轮最要紧的一个数：开环几乎不衰减

`c = 0`时跑满**12.08个周期**（0.2 s、200 000步），
**末周期幅值/首周期幅值 = 0.99999998**——十二个周期一共衰减了2e-8。
幅值`1.0544563 N`对闭式`K·Δv/ω_n = 1.0544439`（相对1.17e-5），
首峰落在四分之一周期`4.138 ms`（相对7.84e-6）。

**`c = 0`是理想化的，但真实量级的轴承阻力矩（`c = 50`）只给`ζ = 0.0132`**，
衰减时间常数`1/(ζω_n) = 0.2 s`——**比一次落位动作还长**。

一次**10%的线速度阶跃让张力摆1.05 N，是20 N的5.3%，而它自己不会停。**
**这就是控制器要控的那个东西**，也是本轨道的存在理由。

### 6.3 收敛阶与它的floor

`Δv = 0.2`（1%）、四档`dt = 1.6e-5 → 2e-6`、`t = 0.02 s`：
误差`3.605e-5 / 1.803e-5 / 9.021e-6 / 4.513e-6`，
比值**1.99906 / 1.99911 / 1.99868**。门判`[1.9, 2.1]`，**不写死为2**。

**金标是线性化解，它给误差垫了一条floor**（与`capstan_tension_ratio`那条
"拿`e^{μΔφ}`当逐节点判据"同形）。线性化偏差`∝ Δv²`而响应`∝ Δv`，
所以相对floor`∝ Δv`：

| `Δv` | 同一批`dt`上的比值 |
|---|---|
| 0.2 mm/s | 1.99906 / 1.99911 / 1.99868 |
| 2.0 mm/s | 1.99652 / 1.99404 / **1.98863** |

再往细里走（`Δv = 2`、`dt`到2.5e-7）实测掉到**1.9168**。
**症状看起来像"收敛阶坏了"，病根却是判据本身。** 有一条活门守着这个关系。

## 七、`ε ≤ 0`（松弛）的裁决：原语取零并给出`is_slack`，容忍与否显式声明

两条候选路各自的代价：

* **失败关闭**：松弛在这个模型里是**可达状态**（收线端慢于放线端时必然到达），
  对一个可达状态失败关闭，等于让模型在它本该描述的那一刻炸掉；
* **静默取零**：松弛时`L_geo`**不再是跨段的长度**——带材垂成一条悬链线，
  此后这个模型给出的一切都不再有意义，而调用方看不见这件事。

**裁决**：`FreeSpan.tension_n`取零、`FreeSpan.is_slack`同时给出，
把"张力是零"与"模型已经出界"分成两个可读的事实；
**是否容忍出界由`SpanTransportLoop.forbid_slack`显式声明，没有默认值**。
与`TensionLoop.measurement_transfer`"没有默认值是有意的"同源：
把它做成默认值，等于让这条边界默默消失。两面各一条门。

## 八、上游契约怎么被读：三条形制门

`MaterialFeedTimeline`除了单调非减之外，还判两条别处没有的：

1. **零增量段必须被声明的暂停覆盖**。plans/14与WII都点过：零运动段
   **没有可推断的时长**——一段长度不变的采样与一段丢失的数据在字节上没有区别。
   所以本仓的判法是反过来的：**要么声明它是暂停，要么它就是丢数据**；
2. **反方向也判**：声明为暂停、期间材料却还在走，是声明与数据自相矛盾。
   只判正方向的话，一个把`pause_intervals`当装饰的上游可以随便贴，
   而下游会照着那条声明去跳过一段真在走的材料；
3. **暂停端点必须落在样点时刻上**。段内恒速语义下，从段中间开始的暂停
   会让这一段的速率无从定义。

"上游保证过"与"本仓验过"不是同一件事——单调非减上游已经保证，本仓照样自己判。

## 九、本轮明确没做的

| 没做 | 理由 |
|---|---|
| **跨段几何长度随位姿变** | 那是plans/14第3.3节的**三号缺口**（落位点几何层），本波次轨道C的活。本轮取常数并在模块/案例页各声明一次。**后果是本轮算不了"臂动作为扰动源"**，只能算收线端速度扰动 |
| **`transport`与`drives.TensionLoop`装配在一起** | 接起来要一层把`brake_torque_nmm`交给`MagneticParticleClutch`的装配层，且要重裁"控制器接在哪一路"。**那是一次装配决策，不是一次import** |
| **停转/静摩擦保持段** | `ω ≤ 0`时磁粉制动器进入`|T·R| ≤ M`的保持段，那是一条互补条件、要一套return-map。本轮失败关闭 |
| **材料注入** | `feed.py`的docstring自陈那是"带材从轮面流过、边界随材料移动"。本模块是**欧拉**的长度账（跨段是控制体），`feed.py`是**拉格朗日**的节点账，两者互不覆盖。**`feed.py`本轮一个字没动** |
| **带材的横向行为** | 这里的带材是一根一维弹簧：只有`EA`，没有宽度、弯曲、扭转、横漂 |
| **主分母动一位** | S6.3与S5.4仍`partial`：执行器物理有了速度这一维，但落位点几何与装配层都还没有。`capability_ledger.json`本轮**没有被碰**（0064第二节） |
| **spec/15第二节登记表加`transport`一行** | 那是四条轨道共同的同点插入面，而0064第二节的四个冲突面没有把它算进去。**本轮不抢着改它**，由波次收口一次补齐——门④只判`ENGINE_RINGS`，它已经登记 |

## 十、后续触发条件

  `FreeSpan.geometric_length_mm`从字段变成入参；届时线性化的参考点要重裁
