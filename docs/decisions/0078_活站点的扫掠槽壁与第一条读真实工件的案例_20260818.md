## 一、这一件不是"往梯度里加一项"——那样会当场把FD门判红，而且判得对

0075第四节量出：冻结帧丢掉的是

    ∇g_精确 = ∇g_本项 − A·t,    A = τ·(tanα·u + σ·v) / D,    D = 1 − u·κ_s − v·κ_n

在plans/14九档几何上**丢失0.9721%—14.2522%、接触力方向偏0.5569°—8.1113°**，
而摩擦锥是按力的**方向**算的。

**最省事的补法是把`A·t`加进`gradient()`而不动`energy()`。那是错的。**
那样梯度就不再是所实现能量的导数：本仓的FD门（"梯度对能量"）会红，**它应该红**——
那时求解器沿着一个不是任何势的下降方向走，线搜索与收敛判据全部失去依据。

**所以改的是能量本身**：`g(x)`里的`(p, s, n)`由`x`定，每次求值都重新定位最近站点。
`A·t`于是**自己就在梯度里**（隐函数定理，不是补丁），三样之间的关系重新说得清。

## 二、内核仍然只吃数字——多吃的是**帧的变化率**

`PenaltyGrooveSweepLive`**不持有`GrooveCenterline`**（0074第二节第1条）。
它每条壁多拿三个数：站点处的`κ_s`、`κ_n`、`τ`。由这三个数与站点三标架，
局部曲线被**唯一确定**为一条**Darboux矢量恒定**的曲线：

    ω = τ·t − κ_n·s + κ_s·n

`ω`在动帧分量里恒定 ⟹ `dω/da = ω × ω = 0` ⟹ 它在**空间里**也是常矢量，
于是帧是绕`ω̂`的刚性转动、`C(a) = p + ∫₀^a t(ξ)dξ`有闭式（Rodrigues的积分）。三件事同时成立：

1. 帧在任何`a`上**严格正交归一**（是一个真转动，不是线性外推后再正交化）；
2. 曲线在`a = 0`处的三个不变量**恰好**是给进来的那三个数；
3. 整条模型曲线上`dκ/da = dτ/da ≡ 0`——**这一条是刻意的**，见第三节。

**这不是把中心线当螺旋线。** 0075第四节末段警告过"螺旋线把`κ`与`τ`锁死成一个比值"，
那条警告针对的是拿螺旋线当**整条**中心线的金标。这里是**局部**模型，
三个不变量各自独立取值（`ω`有三个自由分量），没有任何比值被锁死。

**一条互相独立的验证**：本族用的曲线与0075用的（"圆弧＋绕切向按`τ·a`自转的帧"）
**不是同一条**，而在同一组`(κ_s, κ_n, τ, u, v, tanα)`上两者给出**同一个**
`|A|/|∇g| = 5.3707%`与力方向偏角`3.0743°`。这不是巧合：
`∇g`那一式只依赖不变量，不依赖曲线的其余部分。

### 站点重定位怎么解

最近点条件`F(x, a) = (x − C(a))·t(a) = 0`。`∂F/∂a = −1 + u·κ_s + v·κ_n = −D`，
于是牛顿步恰是`a ← a + F/D`——**二次收敛，正常构型3—5步**。
`D ≤ 0`当场抛（节点落到局部曲率中心上或之外，"最近站点"不再唯一）。

`κ_s = κ_n = τ`**恰好为零**时不解：帧不转时`u`、`v`与`a`无关（`t ⟂ s`是代数事实），
直接走与`PenaltyGrooveSweep._frame`**逐字节相同**的那一串运算。
于是0075那条"直中心线＋`tanα = 0` ⟹ 与`PenaltyAnnulusLimit`逐位相同"
**整条链条**对本族照样成立。**实测四档构型（含活动的锥面档与`v < 0`那档）逐位相同。**

## 三、Hessian仍然不精确——**这是一个裁决，不是一个遗漏**，而代价被量成了数

本族的模型里`dκ/da = dτ/da ≡ 0`，所以**模型自己的**`∇²g`推得完。没有推，理由只有一条：
**真实中心线上那两个量不为零，而且今天取不出来。**
0075第四节第3条实测：`dτ/da`干净（−2.5e-14），而`dκ_s/da`**过一个站点当场变号**
（±1.402e-4，真值0）——病根是位置插值跨站点只有`C¹`。

推一个"对模型精确、对真曲线不精确"的Hessian，等于把一条近似**伪装成**精确：
FD门会全绿，而绿的是模型不是工件。**本仓的纪律是"不知道就说不知道"。**

所以交的是**精确能量＋精确梯度＋Gauss-Newton切线**（inexact Newton）。
缺的是`k·g·∇²g`；`g`活动时`g < 0`，那是一块**负定**贡献，于是切线**偏刚**：
步子偏短、单调、不发散，只是不再二次收敛。

### 代价的实测：**牛顿从二阶掉到一阶**

一个节点、一面活壁、一根各向同性锚弹簧（让秩一的`k(∇g⊗∇g)`加上它之后非奇异）。
**梯度是精确的，所以不动点与用哪个切线无关**——变的只有逼近的速率。
跑到`‖∇U‖ < 1e-9`：

| 几何（plans/14） | `τ` °/mm | Gauss-Newton迭代 | 精确切线迭代 | 线性收缩率（中位） | 实测阶 |
|---|---:|---:|---:|---:|---|
| `clean_a`（最松） | 0.454 | **6** | 4 | **0.00748** | 0.975—1.000 |
| `v2-01-bracket`（中位） | 2.550 | **7** | 5 | **0.02008** | 0.982—0.989 |
| `v1-coil-1`（最扭） | 6.648 | **9** | 5 | **0.04565** | 0.984—0.993 |

**阶恰好是1**（二阶时相邻两个比值会差一个平方，这里它们互相之间只差几个百分点）。
**收缩率大致随`τ`线性**（0.0075 / 0.020 / 0.046 对 0.454 / 2.550 / 6.648），
与"缺的那一块正比于`τ`"的推导一致。

**换算成人话：多两到四次牛顿，换回接触力方向不再偏0.56°—8.11°。**

## 五、三条裁决

### 1. 默认仍走冻结帧，活站点档由案例声明

`PenaltyGrooveSweep`一个字节没动。理由：本族每次求值多一条标量牛顿，
而绝大多数构型上冻结帧够用——**需要接触力方向的案例才付这个代价**。
0075登记的触发条件（"一次牛顿里跨过一整个采样步"、"切向分量本身进判据"）不变，
只是现在有东西可切。

### 2. 走出这一段就**失败关闭**，不静默跳段

每条壁带一个`arc_limit_mm`，`|a*|`超过它就抛`ContactError`。
跨过去之后这条壁携带的`(κ_s, κ_n, τ)`是**上一段**的指纹而不是曲线在那里的性质
（0075第四节第3条实测：`κ_s`过站点变号）。**这时给出一个数比抛出来更坏**，
因为那个数看不出是错的。诊断面是`wall_arc_offset_mm`——调用方可以在求解之间读它。

**代价写在明处**：抛在`energy()`里，于是一次线搜索的探测步就能中断求解。
这是有意的取舍（安静的错数 vs 吵闹的中断），**但它没有被真实案例压过**——
本轮的案例都是单节点小位移，登记在第七节。

### 3. 构造期多判两条：`t`的正交性与帧的**手性**

冻结帧那一族`t`根本不进来，所以它只判`s ⟂ n`。本族的`t`是模型曲线的起始切向，
`t ⟂ s`与`t ⟂ n`各判一次；另判`s = n × t`的**手性**——
**左手帧让`κ_s`与`τ`整体反号**，而三根轴仍然两两正交、仍然都是单位向量。
那两个数正是本族比冻结帧多做的全部事情，**符号错了力就往反方向偏，而什么都不会报错**。

### 6.3 两种差分取法差19%—25%，而积分差 < 1%——**机理被量成一条零容差恒等式**

真语料实测（`τ_max`，`forward` 对 `central`）：6.5686/4.9594、2.5496/2.0589、
6.6467/5.0734、2.1837/1.6901、3.1458/2.3568，比值**0.70—0.81**；
而`∫|τ|ds`两种取法差 **< 1%**。

**这不是哪一种错了。** 案例的金标二把机理做成了一条闭式：直链站点表，
帧只在**一个采样步**里绕切向转过`Δ`：

    forward 在尖峰站点给 sinΔ/h          ← 一站吃满
    central 在尖峰站点给 sinΔ/(2h)       ← 恰好一半
    central 在下一个站点也给 sinΔ/(2h)   ← 另一半摊过去了

    τ_max(central)/τ_max(forward) = 1/2      **恰好，零容差**（sinΔ整个约掉）
    ∫|τ|ds 两种取法相同（= sinΔ）            **恰好**

于是结论是：**峰值统计依赖差分取法，积分统计不依赖**——
plans/14那张表里的`τ_max`读作"这个几何在2 mm采样下的峰"，而不是曲线的性质。
**那些峰在2 mm采样下没有收敛。**

### 7.2 六道空门各是一个不同的形态，逐条

而`0.0`同时满足两种判据。补的是
`test_the_straight_branch_judges_exactly_zero_not_merely_small`（`τ = 1e-12`）。
**`τ = 0`是一条声明，"很小"是一个量——替它判成零等于替它把声明改了。**

**(3) `σ`那一条——判据只走了一侧。**
残差那几条判据**全都只判`σ = +1`**，而`σ = +1`时`σ·v = v`，删掉`σ`一个字节不差。
补的是`test_the_closed_form_holds_on_the_other_side_too`
（`−s`那一侧另手推一遍闭式，并判两侧的`A`**不是**互为相反数）。
**与0075第三节判据一那条"`σ = −1`那一侧另有一条门"同源**——同一个坑踩了第二次。

**(4) `C(a)`那一项——所有求值点都在`a* ≈ 0`附近。**
`(a − sin θa/θ) = θ²a³/6 + …`是`a`的**三阶**小量，在`|a| < 0.1`上比机器精度还小。
删掉它，模型曲线就不再以弧长为参数，而**没有一条判据在用得上它的量级上求过值**。
补的是`test_the_model_curve_is_arc_length_parametrised_away_from_the_station`
（`a* ≈ 5 mm`处再判一次FD二阶）。
**顺带发现`u = 2.3`那一档在`a* ≈ 5`处已经脱开了**（`g = +0.247`）——
帧沿5 mm转过约12.7°，截面坐标跟着转。那本身就是"帧真的在转"的读数。

**(5)(6) 那两条`laydown`的——语料全是均匀采样。**
仓内合成语料与GCW真语料**都是2 mm均匀采样**，而均匀网格上
"非均匀三点系数"与"均匀系数"恰好相同、"按弧长权"与"按站点数权"也恰好相同。
**"采样均匀"是那一批语料的性质，不是这两个函数的前提。**
补的是`test_a_nonuniform_sampling_is_weighted_by_arc`（步长1.0/3.0交替）。

**而三点系数那一条补了一次还没堵上**：非均匀之后两种写法只差**2.3倍绝对误差**，
一条按绝对值判的门要么松得放它过去、要么紧得把正确写法也判红。
**改判收敛阶才干净**（`test_the_nonuniform_three_point_weights_stay_second_order`）：

| 细化 | 正确的三点系数 | 均匀系数（错） |
|---|---:|---:|
| 1.0 → 0.5 | **4.00** | 3.38 |
| 0.5 → 0.25 | **4.00** | 3.06 |
| 0.25 → 0.125 | **4.00** | 2.72 |

错写法的比值**一路往2掉**——那是一阶的招牌。
**而且必须判`τ`不判`κ_s`**：`κ_s`那一档两种写法都给4.00
（误差的一阶项沿切向、投到`s`上归零），**只判`κ_s`这道门仍然是空的**。

### 7.3 剩下那一条不是空门，是一条**不改变答案**的变异

`_station`的牛顿把`step = residual / jacobian`写成`step = residual`。
补了六道门之后它**仍然0红**，而这一次**是对的**：

那是一条不动点迭代`a ← a + F(a)`，收敛条件`|1 + F'| = |1 − D| < 1`在`0 < D < 2`上成立，
**而不动点`F = 0`与除不除`D`无关**。于是收敛到的`a*`一样、`g`一样、`∇g`一样，
变的只有**迭代次数**。

**不为它补门。** 要判它就得判迭代次数，而那是把实现细节写成判据
（`ARC_SOLVE_ITERATIONS = 20`本来就是给病态构型的余量）。
**如实登记：这一行代数上是可替换的，`/ jacobian`留着是因为它是牛顿而不是别的什么，
二次收敛的余量比"能收敛"值钱。**

### 7.4 一条判据自己写错了两次，也登记

第一版`test_the_live_hessian_is_the_rank_one_outer_product...`只判"秩一"，
而**用冻结梯度做外积照样是秩一**——那条判据对"Hessian与梯度不自洽"这个
最可能的写法**完全没有分辨力**。补反向断言时又写错一格：只判`hessian[0][0]`，
而丢掉的那一项沿`t = (0, 1, 0)`，**那一格恰好一点没变**。最后改成判整个矩阵的最大偏差。

**形态：一条判据看起来在判一件事，实际判的是另一件更弱的事。**
与0075第五节那道`max(v, 0)`空门是同一族，但病根不同——
那一条是分支没被执行过，这一条是**执行了而判据看不见**。

### 7.5 没有被注错验过的，如实登记

* `_station`的"牛顿20步不收敛"那一条**没有构造出用例**：`∂F/∂a = −D`在`D > 0`时
  是良态的二次收敛，本轮**没能找到一个既过`D > 0`又不收敛的构型**。
  它是一条防御而不是一条被验过的分支；
* `groove_sweep_live_walls`里"探针塌成零宽"那一条同样没有用例：触发它需要一个零长的段，
  而`_require_stations`在中心线构造期就把那种表拒了——**两道门在这里是重叠的**；
* `centerline_invariants`对`topology="closed"`那条接缝分支**今天没有语料走得到**：
  真实CSV一律声明`open`（GCW把闭合曲线导成开放折线，首末差一个采样步，
  `_require_stations`因此拒`closed`）；
* `quantities`的`need_gradient=False`分支只有一条绿用例走过，**没有注错**
  （0075第五节把冻结帧那一族的同一条登记过，本轮至少让它被执行）。
