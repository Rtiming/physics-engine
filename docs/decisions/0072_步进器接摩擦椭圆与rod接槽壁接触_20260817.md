## 一、1.6：步进器接摩擦椭圆

### 1.1 形状：屈服面是**声明**，法向由步进器每趟给

进步进器的不是`FrictionEllipse`而是新的`FrictionEllipseSpec`
（两个μ ＋ 纵向轴的`NormalSource`）。理由是**法向每趟都变**：
曲面接触上它随位形转（0050第四节的实测），而`FrictionEllipse`把法向
冻进构造期。交一个带着上一趟法向的椭圆进来，下一趟试探力就落在
**另一个**切平面里，`anisotropic_return_map`会以"试探力带法向分量"当场报错——
**症状看着像输入错，病根是把一个每趟变的量当成了构造期常量**。

于是步进器每趟拿``direction = normal_of(current)``现造一个椭圆，
**与粘着弹簧用的是同一个值**（不是各算一次）。那一条本身有门守着：
把椭圆的法向换成另一个常量，`test_the_ellipse_really_runs_through_solve_equilibrium`
当场红（注错M6）。

``friction_coefficient``与``friction_ellipse``**恰好给一个**，两个都给或都不给
都在构造期/入口拒收。两个都给比都不给更该拒：它会静默按某一个跑而调用方
以为按另一个跑，形态与`PenaltyAnnulusLimit`那次端到端事故完全相同。

### 1.2 逐位退化：**判的是`float.hex()`，不是`==`**

0068第4.1节把退化做成"构造出来的"——``μ_∥ == μ_⊥``时`anisotropic_return_map`
原样转交`coulomb_return_map`。本轮把同一条纪律延到**屈服残差**那一半：
新函数`yield_excess_n`在各向同性时走的是与旧步进器**逐字相同的那一串运算**
（同一个求和次序、同一个乘法），所以整条路径的逐位退化不需要任何数值论证。

两档实测，**判的是IEEE-754位型**（`float.hex()`，不是`==`——0068吃过
``-0.0 == 0.0``为真而`canonical_bytes`不同那一课）：

| 装置 | 规模 | 结果 |
|---|---|---|
| 半空间单槽位（滑移分支、45°斜拉） | 1点1趟 | 状态向量、切向力、判别、滑移、屈服残差、趟数**逐位相同** |
| 绞盘多槽位 | 8点 × 60载荷步 × 每步4趟 | 同上，整条状态向量逐位相同 |

**既有的12组合逐位对拍门与多槽位那一批门一条都没变**：
`tests/test_contact_multi_stepper.py`与`tests/test_contact_stepper.py`
两个文件**一个字未动**，62条全绿。旧签名（只给``friction_coefficient``）
走的确实还是旧那串代码——`_return_map`的圆分支是原代码逐字搬进去的，
并另有一条门拿`cases/capstan_tension_ratio`同参数的逐节点张力比钉着
（1.1085677512897048 … 1.1287788684931237）。

### 1.3 通用支也退化：**偏差是被扰动带出来的**

0068第4.1节的第二条纪律（转交可以掩盖通用路径写错）在这里的对应物是：
把``μ_⊥``抬``2⁻⁴⁰``相对（9.09e-13），`is_isotropic`为假 ⟹ **转交被掐掉、
通用支被强制走完整条绞盘**。四档扫描：

| μ扰动（相对） | 状态相对偏差 | 比 |
|---|---|---|
| 1.4552e-11 | 4.6198e-12 | 0.318 |
| 3.6380e-12 | 8.2647e-13 | 0.227 |
| 9.0949e-13 | **5.8561e-13** | 0.644 |
| 2.2737e-13 | 3.1641e-13 | 1.392 |

偏差随扰动一起降到``3e-13``附近就不再降——**那是求解器容差的地板
（``residual_tol_n = 1e-6 N``对20 N量级的力），不是通用支的误差**。
最后一档比值大于1正是那条地板露出来的样子。
门判的因此是**响应比**而不是"很接近"：一个写错的通用支也可能凑巧很接近。

### 1.4 不切默认——0068第五节第2条继续成立

**能走这条路**与**默认走这条路**是两件事。今天仍然没有任何消费方声明过
两个系数（plans/15第4.1节第2项：带-轮``μ_∥``/``μ_⊥``是五项待实测之一）。
退化虽然是逐位的，本页**不裁切默认**，理由与0068逐字相同。

## 二、**派活书给的绞盘分辨不出两条屈服面**——这一节是本页的要点

派活书要的是"同一个绞盘算例，各向同性与椭圆两条都跑通"。
两条**都跑通了，而且给出逐位相同的答案**。

原因是几何的，不是实现的：平面绞盘上``z``全钉住 ⟹ 接触法向恒在``xy``面内、
面外轴恒为``ẑ``、而`TangentialStickSpring`扣掉法向之后试探力的``z``分量
**恒等于零**。于是试探力永远落在椭圆的**主轴**上——
0068第二节写着"椭圆的外法向不平行于``f``，**除非``a = b``或``f``落在主轴上**"，
这个算例落的正是后一个例外。

**所以"绞盘上椭圆也跑通了"这句话本身不构成任何证据。**
本轮把这条钉成一条断言（`test_a_planar_capstan_cannot_tell_the_two_yield_surfaces_apart`，
判逐位相同），它同时是"走整条路"那道门为什么要把纵向轴转开的证明。

转开多少：**45°**，物理上就是**轮轴偏斜**（plans/15第4.1节第3项那个待实测量），
数值上是0068量出的混合角耗散短缺取最大的那个角。

### 2.1 转开之后：椭圆真的改了平衡解

椭圆只经由**锚点**影响求解（粘着弹簧的刚度是各向同性的``k_t·I``，
映射改的是锚点，而锚点是下一趟装配粘着弹簧的输入）。
所以"进了求解"的可观测形式就是位形与张力真的变了。
8段、60载荷步、``μ_∥:μ_⊥ = 5:1``、偏斜45°：

| 量 | 圆（``μ = μ_∥``） | 椭圆 |
|---|---|---|
| 逐节点张力比（首/末） | 1.108568 / 1.128779 | **1.078824 / 1.101176** |
| 首节点张力 | 12.690751 N | **15.377579 N** |
| 位置最大差 | —— | **2.3261e-3 mm** |

八格张力比**同向变小**，方向也对得上闭式：偏斜``β``时沿滑移方向的有效摩擦
是支撑函数``h/N = √(μ_∥²cos²β + μ_⊥²sin²β) = √0.13 = 0.36056``，比``μ_∥ = 0.5``小，
绞盘攒不起那么多张力。

### 2.2 两条判据的精度差三个数量级，**而那个差额有名字**

| 判据 | 装置 | 实测 |
|---|---|---|
| 力落在椭圆上``\|Φ − 1\|`` | 半空间（法向不转） | **2.2204e-16**（恰一个ulp） |
| 同上 | 绞盘（法向随位形转） | 2.61e-14 → **2.31e-12**（沿包角单调涨） |
| 支撑函数``f·m̂ = h(m̂)``相对差 | 绞盘 | **1.1549e-12** |

绞盘那两条比0068在映射层量到的1.9e-15大三个数量级，**差额不是精度问题**：
事后复原的椭圆是拿求解**之后**的法向与纵轴造的，而步进器用的是**装配时**那一个。
**逐节点从入口的1.3e-14单调涨到出口的1.2e-12，单调性本身就说明它是"转了多少"
而不是"算错了多少"**——所以本轮另立了法向不转的那一档，把``Φ = 1``钉到一个ulp。

## 三、1.7：`rod`接槽壁接触，槽壁挡住扭转

### 3.1 开的是**第三类自由度**

在它之前接触把自由度硬分成两类并互相拒绝：罚法向四族只按``3·node + axis``
索引位置块，准静态步进器的落位校验明写"节点块之外是锚点槽，写进去就是改别人的历史"。
**边扭角γ两边都不属于**，于是`PenaltyAnnulusLimit`只能声明"无扭转假设"，
并在docstring里写着"一旦有扭转，边缘点位置就错了``(w/2)·sin(扭角)``"。

`PenaltyGrooveWall`的局部模板是**5个变量**：``[x_i(3), γ_{i−1}, γ_i]``——
位置块3个、γ块2个。它是本仓第一个两边都够得着的接触项。

采样点取带材的两条材料边``x_i ± (w/2)·m̂2``，``m̂2``由**相邻两条边的
材料帧合成再归一**（平分线）：

    m2(e) = −sin(γ_e)·d1[e] + cos(γ_e)·d2[e]
    m̂2_i = (m2(i−1) + m2(i)) / |m2(i−1) + m2(i)|

归一化不是可省的：两条单位矢量的和长度是``cos(Δγ/2)``，不归一就等于让半宽
随扭角悄悄缩水。**它与`AnisotropicRodBending._curvatures`里那个
``0.5·(m2_l + m2_r)``不同**——那里要的是对偶元平均（已经积分过的离散量），
这里要的是一个方向。两处都不许照抄对方，注错N2判这一条。

### 3.2 它住在`rod.py`而不是`contact/penalty.py`——理由与代价

派活书说"要改的是接触项的局部模板"。**我判断那句话说的是能力不是文件位置**，
并把类放进了`rod.py`。三条理由，第三条是决定性的：

1. 它复用既有的`_RodEnergyTerm`装配面，于是spec/12第3.1节那条
   "融合路径与单独调`energy`逐字节相同"是**继承来的**而不是重写一遍的
   （重写一份50行的装配循环正是那条承诺最容易破掉的地方）；
2. 它整个用rod的词汇表达（内顶点、边扭角、冻结材料帧）；
3. **它不新增任何一条import边**。放进`contact/penalty.py`要么新增
   `contact → rod`，要么跨模块import一个私有基类。

代价如实写：从`contact/`那一侧grep"槽壁"找不到实现，只找得到
`PenaltyAnnulusLimit`那条"无扭转假设"的说明。**本页与README两处都点名了它在哪。**

### 3.3 闭式：一条钳位的离散扭簧链

直杆上弯曲项恒零（0065门三的配套断言），扭转是均匀的离散扭簧链，
无壁时γ严格线性（实测扭率极差``1.6e-17``）。加上槽壁之后
**只有一个约束是活动的**（γ单调上升、槽左右对称 ⟹ 只有槽内最扭的那个顶点顶上壁），
它把该顶点的带宽方向倾角钳在

    θ_c = arcsin(half_gap / half_width)

直杆的Bishop帧逐边相同 ⟹ 平分线的倾角**精确**等于``(γ_v + γ_{v+1})/2``（不是近似）。
约束经平分线对称作用在``γ_v``与``γ_{v+1}``上，扭矩平衡给``s_M − s_L = s_R − s_M``，
连同两端条件解出

    γ_v = (4θ_c + (2θ_c − θ_end)/R) / (4 + 1/L + 1/R)

``L``是槽左侧的区间数、``R``是槽右侧的。**这条闭式不import被验内核的任何东西。**

### 3.4 实测：挡住多少、实际扭多少

21节点（20边、19内顶点）、杆长200 mm、带宽4 mm（半宽2 mm）、
``GJ = 77 N·mm²``、两端规定扭角0.9 rad、槽覆盖内顶点6—12、
半间隙0.5 mm、``k = 1e4 N/mm``、20个载荷步：

| 量 | 值 |
|---|---|
| 无槽壁时槽段承担 | 0.331578947368421 rad |
| **有槽壁时实际扭** | **0.171853604667360 rad** |
| **槽壁挡住** | **0.159725342701061 rad ＝ 48.171%** |
| 闭式给的实际扭 | 0.171849531831566 rad（差**4.0728e-06**，见下一节） |
| 壁力 | **0.167599 N**（两条face活动，都在顶点12上） |
| 钳住的带宽方向倾角 | 0.252680255142 rad ＝ ``arcsin(0.5/2.0)``，＋8.6548e-06 |

十档槽宽全部对上闭式，且挡住的比例单调：
0.9→17.788%、0.8→25.629%、0.7→33.285%、0.6→40.790%、0.5→48.171%、
0.4→55.455%、0.3→62.663%、0.2→69.816%、0.15→73.378%、0.1→76.933%。

| ``k`` N/mm | 槽段实际扭 rad | 与闭式的差 |
|---:|---|---:|
| 1e3 | 0.171890252064 | 4.0720e-05 |
| 1e4 | 0.171853604667 | 4.0728e-06 |
| 1e5 | 0.171849939123 | 4.0729e-07 |

**每档整整齐齐差十倍**，壁力四档收敛到同一个数（0.167564 → 0.167603 N）。
这条把"engine与闭式差4e-6"从"精度不明的接近"变成
`PenaltyNormalContact`那句已知的模型代价——**位置有``O(1/k)``的误差，力没有误差**。

### 3.6 无槽壁退回``θ = M·L_eff/GJ``：**逐位相同，而且是0065那串数字**

槽张得很开（半间隙1.99与1.9 mm，后者最小间隙只有**0.0350 mm**——贴着壁而没碰上）
时的端扭矩算例：

* ``θ = 1.2337662337662278``、闭式``1.2337662337662338``、相对偏差**4.885e-15**——
  **与0065第二节门三报的是同一串数字，一位不差**；
* 整条状态向量与**不含本项**的那一次求解**逐位相同**。
  "很接近"会放过一个漏了互补条件（``g > 0 ⟹ f ≡ 0``）的实现，
  而那种实现给出的是一个小而系统的偏置。**互补在这里是零容差判据。**

配套的"判据本身被验"：半间隙收到1.5 mm（最小间隙``−6.0e-6 mm``，刚碰上）时
``θ``掉到0.8756950701146152——差**29.02%**。**活动集的边界是锐的，
不是"反正都碰不到"。**

### 3.7 顺手量出来的两条

1. **对称槽的净力恰好为零。** 这道门起草时断言的是"位置块梯度也非零"，
   **当场红了，而红得对**：带材两条边一条压上壁一条压下壁，两个法向力等大反向——
   **槽壁给的是一个纯力偶**。门因此改判两条：对称槽上位置梯度逐位为零（零容差），
   只声明一片壁时位置梯度非零（那才证明模板真的索引得到位置块）。
2. **梯度/Hessian经中心差分独立验过**：最大绝对差梯度``9.0e-6``、Hessian``3.6e-6``
   （``h = 1e-6``、能量``6e4``量级），位置与γ都被扰动过。

### 3.8 收敛：不收敛是**停机判据太紧**，不是模型的问题

γ块梯度到``3e4 N·mm/rad``（罚刚度1e4 × 半宽2mm × …）。同一批十档算例：

| ``residual_tol_n`` | 十档里收敛几档 |
|---|---|
| 1e-10 | **2** |
| 1e-8 | 8 |
| **1e-6** | **10** |

**而答案本身不随容差变**（三档的"挡住百分比"一致到小数点后四位）。
``1e-6``对``3e4``的梯度是``3e-11``相对，已经贴着装配的舍入地板。
**这条写出来，是因为反过来归因会去改罚刚度或载荷步，而那两个都改不动它。**
载荷步本身仍是必要的（罚势``C¹``非``C²``，活动集翻转处线搜索会失效），
本轮取20步。
