## 零、先更正派活书里的一个数

派活书（plans/18转述0085）写着"距离场对解析SDF的逼近误差随分辨率**四阶**"。
**那是错的**，0085第三节原文是"值、梯度、Hessian都是**二阶**"，
第九节9.2那一列比值4.0012／4.0002是**二阶的实测出口**（h减半、误差降4倍＝二阶），
不是四阶。**四阶要预滤波，而0085明写不做**（窄带块稀疏没有"整条带"可解三对角系统）。

这条更正照0089第四节那条纪律办：**派活书里的数是一句转述，不是结论。**

## 一、裁决一：S3.2的`missing`里那三个词是**三道题**，不是一道

S3.2的`missing`原文是"`collision.py`只有球/胶囊族窄相；**圆柱/盒/网格窄相为零**；
plans/08阶段7的EPA还是MPR是0052第八节明写『今天裁会是猜』的待裁项"。

**把"圆柱/盒"与"网格"写在同一个逗号里，是这一格四个月没动的根本原因**——
它们的拦路虎完全不同：

| 题 | 拦路虎 | 本页怎么办 |
|---|---|---|
| **圆柱／盒** | 没有拦路虎。它们在`shapes.py`里是**参数化原语**不是网格，有符号距离**有闭式**，精确到舍入 | **今天闭合**（第四节） |
| **网格** | **内核不读网格字节**。`MeshAsset`只带路径＋SHA-256＋声明的AABB，**一个顶点都没有** | 三条路全都够不着；只能由外部烘好的场经**协议**进来（第五节） |
| **一般凸体对凸体的穿透深度**（胶囊对盒等） | 要么GJK族要么迭代，两条本页都不走 | **不做**，保持`broad_phase`，登记GAP |

**第二行是本页最要紧的一句**：EPA、MPR、距离场查询三条路争的是"拿到几何之后怎么算"，
而本仓卡在"几何进不来"。0052第八节把这一格记成"EPA还是MPR"的算法选型题，
**那个记法本身就把病灶记错了位置**。

## 二、裁决二：三条路各自解不了的题

三条路都按0074第一节那条"几何判定与接触力学是两道题"读——
本页问的是**几何判定**这一侧：给两个位姿好的体，分离量是多少。

### 2.1 EPA（GJK之后挖穿透深度）——出局

| 解不了的题 | 出处 |
|---|---|
| **只答穿透那一半**。分离构型要先跑GJK；EPA本身给不出分离距离。而本仓既有窄相是**一个数两用**（`separation < 0`才报事件，同一个数既是间隙也是穿透），换成GJK+EPA就是两套代码两条精度 | `collision.py`现行实现 |
| **要凸体**。非凸就要先凸分解，而**不vendored凸分解库已裁**（Bullet被V-HACD钉死五年、上游已EOL并导流CoACD的判例） | 0073第七节第1条 |
| 而本仓真实件**全部非凸**：凸性单侧检验通过率**0.15%／3.72%／26.19%** | 0074第二节第2条实测 |
| **多面体扩张的数值脆点要容差**（退化单纯形、共面与近共面面片），而**本仓给不出那个容差的来源**——给一个就是猜 | AGENTS.md诚实可信度条款 |
| **它需要真实几何**（顶点集或支撑函数），本仓的`MeshAsset`不带 | `shapes.py`的`MeshAsset`字段表 |

### 2.2 MPR（Minkowski Portal Refinement）——出局

| 解不了的题 | 出处 |
|---|---|
| **同样要凸体**：portal细化的收敛性建在Minkowski差的凸性上。撞同一堵墙 | 0073第七节第1条＋0074第二节第2条 |
| **需要一个内点**（体心）。对一个只有AABB声明的`MeshAsset`，本仓拿不到——**AABB中心不是体心**，非凸件上它可能根本不在体内 | `shapes.py`；0074第二节第2条 |
| **它给的是沿一条射线的穿透深度，一般不是最小平移距离**——是近似 | MPR的定义 |
| **同样需要真实几何** | 同上 |

**0052第八节要的那两个数（MPR近似误差与罚刚度柔度误差谁大），本页不测。**
理由不是"懒得测"，是**测了不改结论**：MPR在前置上（要凸体、要内点、要几何）
已经三条全不满足，那两个数量的是"如果能用它，它准不准"。
**如实写在这里比测一个用不上的数诚实**——这也是0052第八节自己那条通则的正读法：
"裁决要有出处或有实测"，本页给的是出处。

### 2.3 距离场查询——**选它，但它解不了的题一样多**

| 解不了的题 | 出处 |
|---|---|
| **它不给"形对形"，只给"点对场"**。φ(x)−r读成穿透深度**只对球型探针成立**；一般形状取min φ给的是**面到面的距离**，不是最小平移穿透深度。于是本页的场那条路**只接球型探针**，胶囊对场当场拒 | 本页第五节 |
| **分辨率误差O(h²)，且不是随机的**：对凸障碍**系统性偏松**（场报出来的距离比真值大，物体沉得更深），主项h²/(3ρ) | 0085第三节＋`cases/sdf_contact_convergence` |
| **窄带外失败关闭，不能外推**。0085实测"远在体外"与"深在体内"两种点的信号**一模一样**（都是`None`）——存下来的字节里没有任何一个带符号 | 0085第四节 |
| **内存按表面积长**；且块粒度**吃掉窄带的节省**（实测同球同盒h=0.5只省到**0.9010**） | 0074第5.1节＋0085第五节GAP第四行 |

| **它今天没有落盘形制**（`SignedDistanceField`只能在进程内构造） | 0085第五节GAP第三行 |
| **域隔离门不许`collision.py`import它**——见下一节。这条0085没有、派活书也没有，是本轨自己撞上的 | `tests/governance/test_domain_isolation.py` |

## 三、裁决三：距离场进`collision.py`走**协议**，不走import

`tests/governance/test_domain_isolation.py`的登记表里：

* `collision`在**基座**`modelgen`圈（与`geometry`／`mesh`／`modelgen`／`shapes`同圈）；
* `contact`（含`contact.field`）在**力学域**。

而该门第三条规则原文是"**基座模块 → 只许到基座。基座不依赖任何上层**"。
于是`collision.py`写一行`from physics_engine.contact.field import SignedDistanceField`
**当场红**，而那道门是共享文件，本轨不碰它（0084第三节）。

**这不是障碍，是把形制指对了方向**：基座定协议、物理域给实现，依赖仍然只向下。
`collision.py`因此声明一个结构化协议`SignedDistanceSource`
（`spacing_mm`／`value_mm`／`hessian_per_mm`／`contains_stencil`四样），
`contact.field.SignedDistanceField`**恰好逐条满足**，鸭子类型直接可用，一行import都不需要。
装配由上层（案例、`contact_pipeline`、消费方）做——那本来就是它们的活。

**这条要写进决策而不是只留在代码注释里**，因为它是可复用的判据：
将来任何"基座要用物理域的一个能力"的需求，答案都是协议而不是import，
否则就是让门去背一次愿望。

## 四、裁决四：闭式那一半怎么落

**新增的窄相一律是精确闭式的有符号距离，不是任何迭代。** 落三样：

1. **形状的精确有符号距离**（局部系）：`Sphere`／`Capsule`／`RoundedBox`／
   `FiniteCylinder`（无法兰）。四条都是标准闭式，**体内体外都精确**；
2. **球型探针对任意上述原语**：`separation = φ_B(c_A) − r_A`。
   球的Minkowski和还是球，所以这个数**同时是分离距离与穿透深度**，与既有球/胶囊族同一个语义；
3. **半空间**：`HalfSpace`是**查询侧的目标，不是`shapes.py`的形状**。
   理由是硬的——半空间**没有有限AABB**，进不了`PosedBody.world_aabb_mm`，
   也就进不了broad phase。它对四种原语的分离量由**支撑函数**给，四条全是闭式；
4. **盒对盒，仅轴对齐**（两个体的姿态都是单位四元数）：逐轴闭式，
   分离时`sqrt(Σ max(gap_i,0)²)`、相交时`max_i gap_i`，再各减一个圆角半径。
   **姿态一旦不是单位四元数就退回`broad_phase`**——旋转盒对旋转盒没有闭式，
   而本页不做迭代。

### 4.1 `FiniteCylinder`的法兰**没有实体语义**——失败关闭

`FiniteCylinder.flange_outer_radius_mm`在全仓只有一个用途：**把AABB撑大**
（`local_aabb_mm`取`flange_outer_radius_mm or radius_mm`）。
**没有任何声明说得出法兰是什么形**：两端各一片还是整段？厚度多少？内侧有没有倒角？

于是精确窄相对带法兰的圆柱**当场拒**（`CollisionQueryError`），不按无法兰算。
按无法兰算会**系统性少报穿透**（法兰比槽底大15 mm，那不是小量），
而少报是静默的那一半——AGENTS.md诚实可信度条款判的正是这一类。

**这是本轨抓到的一个真缺口**：`shapes.py`里有一个只影响AABB、不影响任何实体判定的字段，
而`_cell()`那个真实导轮（R45／法兰R60／半宽9）正好带着它。登记成GAP。

## 五、裁决五：场那条路的形制与它的诚实声明

### 5.1 `confidence`加第三档`sampled_field`

`CollisionEvent.confidence`今天是`Literal["broad_phase", "narrow_phase"]`。
**场给的数不能叫`narrow_phase`**——那一档在本仓的既有语义里是"精确到舍入"，
而场带O(h²)的分辨率误差。**把它叫`narrow_phase`就是冒充**（派活书第戊2条第3点原话：
"一个在非凸体上给出『精确穿透深度』的实现是冒充"）。

于是加第三档`sampled_field`，含义逐字是：
**"这个数是从一个有限分辨率的采样场里读出来的，它带一个已声明的偏差估计。"**

### 5.2 偏差估计**算得出来，所以必须给**

0085第三节把拟插值的展开写死了：

    S(x) = φ(x) + (h²/6)·∇²φ(x) + O(h⁴)

而场自己就能给`∇²φ`（`hessian_per_mm`）。于是**主项偏差是可计算的**：

    estimated_bias_mm = (h²/6)·tr(∇²φ)

不是一个手写的"经验容差"，是那条展开式的直接读数。三条自洽出口：

* **半空间**：φ仿射 ⟹ `∇²φ ≡ 0` ⟹ 估计恒为**0**，与0085"任何分辨率下精确"对得上；
* **球（半径R，查询点在半径ρ处）**：`∇²(|x|−R) = 2/ρ` ⟹ 估计`h²/(3ρ)`，
  **与`cases/sdf_contact_convergence`那条已经量过的主项`−h²/(3z*)`逐字同形**（差一个符号是因为那里量的是位置偏移，这里量的是距离本身）；
* **符号**：凸障碍上`tr(∇²φ) > 0` ⟹ 估计为正 ⟹ 场报的距离偏大 ⟹ **偏松**，
  与0085第三节"对凸障碍系统性偏松"同向。

**它是估计不是界**：O(h⁴)余项没有被它覆盖，`NarrowPhaseResult`的字段名与docstring
都按"估计"写，不许被读成"误差上界"。**不知道就说不知道**，这里知道的是主项。

### 5.3 非凸上它给的是什么

场对非凸件**没有额外代价**（0074第二节第2条），但要说清楚它给的是什么：
**球型探针的`φ(c) − r`在非凸件上仍然是"球心到表面的最近距离减半径"**，
那是一个良定义的量，而且**就是这一对的穿透深度**（球的Minkowski和还是球）。
**不良定义的是"两个一般形状之间的穿透深度"**，而本页根本不给那个数。
这就是第二节2.3第一行那条限制存在的理由。

## 六、裁决六：失败关闭的两个不同口径

派活书第戊2条第4点要"查询不出来要抛"。本页把它拆成两条，因为**两个调用面的契约不同**：

* **直查API**（`narrow_phase_separation_mm`、`half_space_separation_mm`、
  `shape_signed_distance_mm`）**没有"不知道"这个返回值**，所以答不出来一律
  `CollisionQueryError`。带法兰的圆柱、`MeshAsset`、旋转盒对盒、窄带外的点，四条全抛；
* **场景查询**（`BroadPhaseCollisionQuery.check_state`）**有"不知道"这个返回值**，
  它就是`confidence="broad_phase"` ＋ `penetration_mm=None`——
  那是这个字段2026-08-04出生时的全部理由。所以场景查询在答不出来时**降级而不是抛**：
  事件照报（不漏报），深度留空（不冒充）。

**两条都不是"返回一个看起来合理的数"**，这才是那句要求的实质。
写成两条而不是一条，是因为把场景查询也改成抛会**破掉不漏报这条唯一硬承诺**：
一个查不了的对会让整场查询炸掉，于是同场景里其他能算的对也一起没了。
