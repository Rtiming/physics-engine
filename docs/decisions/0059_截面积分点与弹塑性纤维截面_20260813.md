# 0059 截面积分点与弹塑性纤维截面

- 日期：2026-08-13
- 状态：已裁决并实现
- 触发：plans/09确认的下一步“plans/08阶段4：截面积分点”，以及用户授权一代理并行调研同行方法

## 一、先裁一处现有文档冲突

plans/08写“截面积分点不加自由度”；plans/06又把“体积与厚度”的关闭判据写成
“截面上的分布量有自由度、被解出来”。两句若都把“自由度”理解为全局未知量，
不能同时成立。

同行主源给出的事实一致：

| 主源事实 | 本仓采用的边界 |
|---|---|
| Abaqus从梁截面广义应变计算各截面点材料响应，再积分为截面力；反向塑性需要更多截面点。[Beam Section Behavior](https://docs.software.vt.edu/abaqusv2024/English/SIMACAEELMRefMap/simaelm-c-beamsectionbehavior.htm)、[analysis-integrated beam section](https://docs.software.vt.edu/abaqusv2024/English/SIMACAEELMRefMap/simaelm-c-usingbeamsection.htm) | 截面点是本构/求积点，不是节点位移自由度；点可以各有材料历史。 |
| OpenSees固定提交`40f6a3d`的`FiberSection3d`从截面变形算逐纤维应变、逐点调用材料、积分N/M与切线，并逐纤维commit/revert。[L453-L528](https://github.com/OpenSees/OpenSees/blob/40f6a3d6d6c1efebb4cb7a85943bb6e163afa93a/SRC/material/section/FiberSection3d.cpp#L453-L528)、[L684-L732](https://github.com/OpenSees/OpenSees/blob/40f6a3d6d6c1efebb4cb7a85943bb6e163afa93a/SRC/material/section/FiberSection3d.cpp#L684-L732) | 几何、材料参数、逐点历史、当前结果分层；失败trial不得污染已提交历史。 |
| MOOSE壳的节点自由度与厚度求积点是两条轴；stateful material property按元素、求积点存储并有明确内存代价。[Shell elements](https://mooseframework.inl.gov/modules/solid_mechanics/ShellElements.html)、[Materials System](https://mooseframework.inl.gov/syntax/Materials/index.html) | “不增加全局未知量”不等于“不增加状态宽度或内存”。 |
| CalculiX的用户单元把`INTEGRATION POINTS`与`MAXDOF`分开声明。[CalculiX 2.23手册p.629](https://dhondt.de/ccx_2.23.pdf#page=629) | 求积点数、状态标量数、全局未知DOF必须分别报告。 |

**裁决**：

1. 截面广义变形`epsilon_0/kappa`是两个运动学坐标；当前自由回弹入口固定
   `epsilon_0`、只把`kappa`作为标量局部平衡未知量，尚无N/M二维联立求解；
2. 截面点的应变/应力是由广义变形导出的本构/求积响应，不是独立全局运动学未知量；
3. 每点塑性应变与累积塑性应变是真历史，显式进`State`，但不进本轮局部Newton未知块；
4. 本轮完成的是“阶段4最小截面本构/分布切片”，不关闭“体积与厚度”整条；
5. S5.1从todo升partial：力学截面与逐点分布已有第一片，但无压扁/翘曲/局部场；
6. S1.2保持todo：机械积分点不能冒充电磁截面场自由度。Norris闭式采样仍不是求`K_i`。

`StateLayout.dof_count`历史名称覆盖整条状态向量宽度，包含历史尾部。新
`RectangularSectionLayout`另报`generalized_dof_count=2`与
`history_scalar_count=2*n`，禁止拿64点布局的130个状态标量冒充130个平衡未知量；
也禁止把两个广义坐标冒充“当前已经联立求解了两个未知量”。

## 二、第一片为什么选矩形弹塑性纤维，不选Norris或线弹性梁

线弹性矩形截面只会把`sum(E*A_i*y_i²)`重新算成一个近似`EI`，很容易全绿而没有
检验点级非线性；plans/08已经点名这是陷阱。

Norris的`K(x)`是现成解析闭式。把闭式在积分点上求值再积分，仍是采样/求积，
不会让`K_i`成为受总电流约束与非局部磁核支配的未知量；拿它作“求解案例”会把
S1.2报高。

矩形截面一维理想弹塑性纯弯同时具备：点应变梯度、弹塑性共存、逐点不可逆历史、
N/M积分、算法一致切线、解析M-kappa与解析回弹。它用零运行时依赖即可形成第1档金标，
且直接服务WDS的带材力学方向。

## 三、求积、状态与身份

第一版用沿厚度的**等面积中点纤维**，规则ID
`section_rule/midpoint_equal_area/1`。这是本仓设计选择，不是同行唯一答案：

- Gauss对光滑积分同点数效率高，但不含表面点；
- Simpson/Lobatto可含端点，适合需要真实表面输出或表面先屈服的任务；
- OpenSees文档中的Gauss-Lobatto主要是**沿梁长度**的beam integration，不能直接
  偷换成截面厚度规则。见官方[Legendre](https://opensees.github.io/OpenSeesDocumentation/user/manual/model/beamIntegrations/Legendre.html)与
  [Lobatto](https://opensees.github.io/OpenSeesDocumentation/user/manual/model/beamIntegrations/Lobatto.html)。

本轮选择中点纤维的理由是：每点代表一块非零面积、历史槽一一对应、零依赖、矩形带材
第一消费方足够；并明确禁止把最外中点结果叫表面应力。第二条真实需求出现前不预支
通用正交规则库。

布局次序冻结为：

```text
[epsilon_0, kappa, plastic_strain[0:n], accumulated_plastic_strain[0:n]]
```

几何`b/h`、点数、规则ID与`section_id`一起算参考内容地址，并追加到有效`layout_id`。
原因是一个实跑必红抓到的真洞：同点数但厚度不同的两个截面原本产生同一布局指纹，
旧塑性历史会按相同索引被错误装回；修后两者指纹不同且交叉装载失败关闭。

## 四、本构、trial/commit与局部平衡

逐点小应变：

```text
epsilon_i = epsilon_0 + kappa*y_i
sigma_trial = E*(epsilon_i - epsilon_p_old)
f_trial = |sigma_trial| - sigma_y
```

`f_trial<=0`走弹性；否则一维return-map给
`Delta_gamma=f_trial/E`、`sigma=sign(sigma_trial)*sigma_y`，并更新该点塑性应变与
累积塑性应变。`evaluate_section_response`不修改传入状态，只返回候选`next_state`；
外层迭代收敛后才由调用方提交，因此失败trial不会污染历史。

截面返回`N/M`、完整点响应与一致切线：

```text
N = sum(sigma_i*A_i)
M = sum(sigma_i*A_i*y_i)
dM/dkappa = sum(E_t_i*A_i*y_i^2)
```

局部曲率求解要求调用方显式给夹根区间与绝对弯矩残差。第一版纯二分正确但profile显示
64点回弹要40次完整点装配，热点几乎全在重复`evaluate_section_response`。随后改为
**区间保护Newton**：一致切线候选留在区间内才采用，否则退回二分；零切线塑性平台
仍有区间兜底。

本机同一64点案例七组各500次实测：

| 路径 | 迭代 | 中位数/solve | 关系 |
|---|---:|---:|---:|
| 纯二分 | 40 | `0.011474 s` | 基线 |
| 区间保护Newton | 2 | `0.000852 s` | **13.5×** |

墙钟只记账、不作功能门；确定性性能门是“本案例有可用一致切线时迭代不超过8次”。

## 五、第1档解析案例

案例`rectangular_section_springback`取`b=12 mm`、`h=4 mm`、
`E=200000 N/mm²`、`sigma_y=250 N/mm²`。令`c=h/2`、
`kappa_y=sigma_y/(E*c)`、`M_p=b*sigma_y*c²`：

```text
|M| = E*I*|kappa|                                      |kappa| <= kappa_y
|M| = b*sigma_y*(c²-a²/3), a=sigma_y/(E*|kappa|)      |kappa| > kappa_y
```

`kappa=2*kappa_y`时连续闭式`M=11*M_p/12=11000 N·mm`。8/16/32/64点的
屈服边界恰落在纤维边界，中点误差加密一倍精确缩小4倍。加载后求`M=0`的自由回弹；
连续闭式曲率`1/2560 mm^-1`，64点离散解另由`Fraction`精确生成。

金标生成器不import`sections`，只用`Fraction`分段闭式；生产端走return-map与受保护
Newton。正向门同时验汇总弯矩、全64点应力/历史/屈服标志、二阶收敛、回弹平衡、
同曲率不同历史、同路径状态逐字节重放。

## 六、必须红与反向边界

- 实现前`tests/test_sections.py`收集按预期红于
  `ModuleNotFoundError: physics_engine.sections`；
- 同点数不同厚度的布局指纹最初相同，新增身份门实跑红后才绑定参考内容地址；
- 纯二分40次装配被确定性迭代门判红，profile后改受保护Newton为2次；
- 案例`RED_MATRIX`六格分别注入：永远线弹性、质心单点、点序反转、共享点状态、
  卸载丢历史、无历史点应力；六格必须各自抛`OracleError`；
- 反向门明确最外中点不在表面，禁止把它改名为表面应力；
- 非有限/非正材料参数、点数小于2、坏历史、错布局、不夹根区间全部失败关闭。

## 七、没有裁成什么

- 没有二维任意截面、横剪、扭转、翘曲、压扁、局部屈曲、复合层或温度；
- 没有自适应换点与旧历史投影；换规则即新布局；
- 没有把截面项装进全局梁单元、`EnergyRegistry`或`solve_equilibrium`；
- 没有新增facet或运行时依赖；模块是实验档全路径import，不进顶层re-export；
- 没有改既有数值路径，旧案例产物应逐字节不变；
- 没有把S1.2或S5.1升done，没有改变`12/42`、`6/13`或`0/6`三条分子。
