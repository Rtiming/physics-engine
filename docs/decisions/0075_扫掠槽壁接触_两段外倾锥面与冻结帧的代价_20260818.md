## 一、这一项是什么

一条沿真实中心线的扫掠槽：带材节点在槽里，两侧槽壁把它顶回来。
在最近站点的截面里记``d = x − p``、``u = d·s``（横向）、``v = d·n``（深度），
第σ侧壁（``σ = ±1``）的间隙

    g_σ = w/2 + v·tanα − (σ·u + r),      U = ½k·g²  （仅 g < 0）

接触层要的三样（0074第二节第1条：**只有这三样**）：

| | 本项 |
|---|---|
| `g` | 上式 |
| `∇g` | ``tanα·n − σ·s``，**常矢量** |
| `∇²g` | **恒为零**（不是近似为零） |
| `H` | ``k·(∇g ⊗ ∇g)``，仅活动 |

活动条件**两条**：``g < 0``，且``v``落在槽深窗``[v_min, v_max]``内。

## 二、三处几何形制上的改动，逐条写明为什么

简报给的几何是``halfwidth(v) = w/2 + max(v, 0)·tanα``、``g = halfwidth − |u| − r``。
**两处都改了**，理由是同一条，且这条不是偏好而是本仓自己申报过的适用域。

`solve.py`第29行原文：「**适用域**：``U``二次连续可微、Hessian在解附近正定」。

### 1. `|u|`拆成左右两个单边壁

``|u|``在``u = 0``处不可微 ⟹ ``g``只有``C⁰`` ⟹ ``U``只有``C¹``。
**而``u = 0``是槽心，那不是罕见构型，那是标称构型**——每一个平放在槽里的
带材节点都恰好落在那个不可微点上，牛顿会在那里抖。

拆成两个单边壁之后，每一项在自己的活动域里是多项式、``C^∞``。
这与`PenaltyAnnulusLimit`把两片法兰写成两个独立限位面是同一条形制，
并继承它那条纪律：**一侧被顶住时另一侧一个牛顿都不出**（零容差互补）。

### 2. `max(v, 0)`换成`v`——同一条理由的第二次

``max(v, 0)``在``v = 0``处不可微，**而``v = 0``正是槽底**——带材平躺时就在那个点上。
它会让``halfwidth``只有``C⁰``、``U``只有``C¹``，与第1条犯的是同一个错，只是换了一根轴。

换成线性的``w/2 + v·tanα``等于**把锥面当成一整张平面延拓到槽底以下**，
与`PenaltyNormalContact`把半空间延拓到面背后同理：``v < 0``那一侧被槽底接触挡着到不了，
**延拓的那一段没有物理，但它换来的光滑性是求解器明文要的**。

> **这一条差点成了一道空门，见第五节。**

### 3. 槽深窗是活动条件，不是能量的一部分

真槽有深度：``v``超窗时这面壁在那儿不存在。与`PenaltyAnnulusLimit`的环带判据、
`PenaltyCylinderContact`的轴向硬切同源——**力在窗边界上跳**，
所以本项给出`wall_depth_mm`让案例为它设门。

## 三、三条验收判据的实测数

### 判据一：退化逐位

直中心线＋``tanα = 0``时，本项与`PenaltyAnnulusLimit`在同一构型上的
间隙/能量/梯度/Hessian **`float.hex()`逐字符相同**。实测（`u = 2.05`、`v = 0.9`、
``w/2 = 4.0``、``r = 2.0``、``k = 5e3``，通用方向的帧）：

| 量 | 扫掠槽壁 | 平面环带 |
|---|---|---|
| `g`（`+s`侧） | `-0x1.9999999999a00p-5` | `-0x1.9999999999a00p-5` |
| `U` | 逐位相同 | 逐位相同 |
| `∇U`三分量 | 逐位相同 | 逐位相同 |
| `H`九项 | 逐位相同 | 逐位相同 |

**逐位相等靠的是运算次序，不是代数恒等。** `_frame`里那个
``halfwidth − (lateral + radius)``的括号位置是承重墙：改成
``(halfwidth − lateral) − radius``数学上一样、在本构型上**逐位不一样**
（`-0x1.9999999999a00p-5` vs `-0x1.99999999999c0p-5`），退化门当场红。
`test_the_bracket_position_in_the_gap_expression_is_load_bearing`先证明这两种写法
在本构型上确实不同，**否则判据一是一道没有分辨力的门**。

``σ = −1``那一侧另有一条门：那一侧走``halfwidth − ((−u) + r)``，
环带走``−1·((−w/2) − (u − r))``，**表达式树不同，逐位相等靠的是IEEE取整对取负对称**。
只判一侧的话这条性质从没被执行过。

### 判据二：锥面与平面显著不同——**而plans/15那句话缺一个前提**

plans/15第2.2条写的是"锥面给的是逐渐爬升的回正力、平面给的是硬碰"。
**深度被钉住时那句话是错的**，实测（``α = 10°``、``k = 5e3 N/mm``）：

| 横移 | 间隙 | 平面横向力 | 锥面横向力 | 锥面举升力 | 合力之比 |
|---:|---:|---:|---:|---:|---:|
| 2.2 mm | −0.2 mm | 1000.0000 N | **1000.0000 N（逐位相同）** | 176.3270 N | 1.0154266 |
| 2.5 mm | −0.5 mm | 2500.0000 N | **2500.0000 N（逐位相同）** | 440.8175 N | 1.0154266 |
| 3.0 mm | −1.0 mm | 5000.0000 N | **5000.0000 N（逐位相同）** | 881.6349 N | 1.0154266 |

**回正力一点没变**（``∇g``的``s``分量与``tanα``无关）。锥面真正做的事是
**把一部分接触力转成把带材举出槽的分量**，合力大小差一个``secα = 1.0154266``。

"回正力变软"是**深度自由**时那个举升分量反过来改平衡位置的结果。
深度自由、压紧力``F_hold = 3 N``、槽深窗上界6 mm，实测：

| 横移 | 平面：深度 | 平面：横向力 | 锥面：深度 | 锥面：横向力 | 平面/锥面 |
|---:|---:|---:|---:|---:|---:|
| 2.05 mm | −0.0006 mm | 250.0000 N | 0.2643 mm | **17.0138455 N** | **14.694** |
| 2.20 mm | −0.0006 mm | 1000.0000 N | 1.1150 mm | **17.0138455 N** | **58.776** |
| 2.50 mm | −0.0006 mm | 2500.0000 N | 2.8163 mm | **17.0138455 N** | **146.939** |
| 2.80 mm | −0.0006 mm | 4000.0000 N | 4.5177 mm | **17.0138455 N** | **235.103** |
| 3.00 mm | −0.0006 mm | 5000.0000 N | 5.6520 mm | **17.0138455 N** | **293.878** |

**锥面的横向力是一个常数**，闭式``F_hold/tanα = 17.0138455 N``，
与横移量无关——带材不是被顶住，是**一路爬上去**。
平面按``k``线性上升且无界。两者之比随横移**线性发散：14.7 → 293.9**。

再往外推，带材爬出槽口：闭式``u_逃逸 = w/2 + v_max·tanα − r + F_hold/(k·tanα)
= 3.0613646 mm``，实测用60步二分把"收敛/求解器报奇异"这条定性分界夹到
`< 1e-6 mm`，与闭式相对偏差 < 1e-9。**超过它平衡问题本身失去良态，
而那是物理不是数值失效**——壁不在了，深度自由度不受任何能量项约束。

### 判据三：有限差分一致——**没有收敛阶可报，这是更强的结论**

活动集内``U = ½k·g²``且``g``是``x``的一次多项式 ⟹ ``U``是**二次多项式** ⟹
三阶导恒为零 ⟹ **中心差分的截断项恰好是零**。剩下的只有舍入，量级``ε·U/h²``。

于是误差随``h``变小而**变大**，实测（``u = 2.9``、``v = 0.7``）：

| `h` | `|FD(U) − ∇U|` 相对 | `|FD(∇U) − H|` 相对 |
|---:|---:|---:|
| 1e-1 | 5.6042e-14 | 5.5778e-14 |
| 1e-2 | 8.9277e-13 | 8.9626e-13 |
| 1e-3 | 4.1019e-12 | 4.0983e-12 |
| 1e-4 | 3.5363e-11 | 3.5361e-11 |
| 1e-5 | 3.6647e-10 | 3.6554e-10 |
| 1e-6 | 2.6145e-09 | 2.6165e-09 |

斜率是``−1``（纯舍入）而不是``+2``（截断）。**"实测二阶收敛"只说明截断项按预期缩小，
这里说明截断项根本不存在**——能量、梯度、Hessian三者互为对方的精确导数，
没有一条被截断的项藏在里面。判据因此写成两条：大步长上误差落到机器精度以下，
且步长缩小100倍时误差**上升**（否则说明有一条截断项混进来了）。

**真正会收敛的那条FD在下一节**：对"活最近点"的间隙做中心差分，实测比
**4.0000 / 4.0000 / 4.0000 / 3.9998**。

## 四、这一项**丢掉了什么**——本页最要紧的一节

`PenaltyGrooveSweep`的每一条壁拿到的是一个**冻结的**站点``(p, s, n)``；
沿中心线的扫掠由`groove_sweep_walls`在装配期完成
（调`nearest_arc_length_mm`＋`sample_at`，然后交出一串数）。
**内核只吃数字**（0074第二节第1条），与`PenaltyAnnulusLimit`拿``(轴上一点, 轴方向)``
而不是拿一个圆柱对象同构。

**代价是``∂a*/∂x``那一项。它是可算的，下面就是它。**

### 4.1 包络定理在这里只杀掉了一半

记帧沿弧长的导数（一般贴合帧，不是Frenet）：

    t' = κ_s·s + κ_n·n,    s' = −κ_s·t + τ·n,    n' = −κ_n·t − τ·s

其中``τ``是**帧绕切向的自转率**（plans/14管它叫"帧扭率"）。
最近点条件``F(x, a) = (x − C(a))·t(a) = 0``给出

    x − p = u·s + v·n        （沿t的分量恒为零）
    ∂F/∂a = −1 + u·κ_s + v·κ_n =: −D
    ∇a = t / D,              D = 1 − u·κ_s − v·κ_n

于是

    ∂u/∂a = −t·s + (x−p)·s' = 0 + v·τ          ← 第一项归零，这就是包络定理
    ∂v/∂a = −t·n + (x−p)·n' = 0 − u·τ
    ∇u = s + (v·τ/D)·t,      ∇v = n − (u·τ/D)·t

**注意``−t·s``与``−t·n``那两项确实归零了**——那正是简报说的"包络定理"。
**但它杀不掉``(x−p)·s'``与``(x−p)·n'``**：帧本身在绕切向自转，
截面坐标``(u, v)``因此随``a``旋转，而那一项与``τ``成正比。

**结论：简报里"∂a/∂x那一项对g的一阶贡献为零"这句话，对距离``|x − p|``成立、
对``u``与``v``各自不成立，两者只在``τ = 0``时重合。** 本页不含糊地记下这条订正。

### 4.2 丢掉的那一项的闭式，以及它有多大

    ∇g_精确 = tanα·∇v − σ·∇u = (tanα·n − σ·s) − A·t
    A = τ·(tanα·u + σ·v) / D,     D = 1 − u·κ_s − v·κ_n

即 **``∇g_精确 = ∇g_本项 − A·t``，丢掉的整项沿切向**。

代入plans/14第2.2节`v2-01-bracket`的实测不变量
（``ε_edge`` p100那行``R = 145.6 mm``、``τ_max = 2.550 °/mm``；
两者是**不同向的独立量**，故金标用"圆弧＋绕切向按``τ·a``自转的帧"而不用螺旋线），
在``u = 2.3 mm``、``v = 0.8 mm``、``α = 10°``处实测：

| 量 | 值 |
|---|---:|
| `κ_s` | +0.006848347 /mm |
| `κ_n` | +0.000520940 /mm |
| `τ` | −0.044505896 /mm（= −2.550 °/mm） |
| `D` | 0.983832050 |
| `A` | −0.054535908 |
| `|∇g_本项|` | 1.015426612 |
| **相对丢失** | **5.3707 %** |
| **力方向偏角** | **3.0743°** |

**5.37%不是可以忽略的数，也不是误差上界**——它是这一个构型、这一档不变量下的值。
闭式与**数值中心差分**（对解析曲线上"活最近点"的间隙求导）两条腿互不引用，
实测二阶收敛比4.0000/4.0000/4.0000/3.9998。

### 4.3 为什么这一版不把它补进去

**因为补了梯度就必须补Hessian，而``∇²g``的那一项今天不可表示。**

``∇²g``要对``G(a, u, v) = tanα·n − σ·s − A·t``再求一次导，其中``∂G/∂a``含
``dκ_s/da``、``dκ_n/da``、``dτ/da``。而`CenterlineSemantics`的
``frame_interpolation``今天只有`hold_station`与`reorthonormalised_linear`两档：
前者段内帧是常量（``τ ≡ 0``、``κ ≡ 0``），后者的帧在站点上只有``C⁰``，
**二阶帧导数是站点处的一个δ函数**。算它等于凭空造精度。

若只补梯度不补Hessian：解仍然对（解由``∇U = 0``定），只是牛顿收敛变慢——
**但那样三条FD一致性判据里就有一条永远对不上**，
而本仓的纪律是"门要么判得准，要么不设"。**两害相权，本版选"三样自洽 + 把丢掉的量出来"。**

**触发条件（不许含糊）**：当案例需要在一次牛顿里跨过一整个采样步、
或需要接触力的**切向分量**本身进判据时，按4.2式把``A·t``补进`gradient`，
并**先动`CenterlineSemantics`的帧插值语义**（至少要一档``C²``的帧），
再把``∇²g``推完。在那之前，调用方的用法是**在求解之间重调`groove_sweep_walls`
重新线性化**——与活动集更新同一档节奏。
