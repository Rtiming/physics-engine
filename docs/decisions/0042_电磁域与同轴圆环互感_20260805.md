## 二、采信的闭式：核过，但核出一个约定陷阱

    k² = 4·r₁·r₂ / ((r₁+r₂)² + d²)
    M  = μ₀·√(r₁·r₂)·[ (2/k − k)·K(k) − (2/k)·E(k) ]

出处：Maxwell《A Treatise on Electricity and Magnetism》vol.2 §701；
Grover《Inductance Calculations》ch.13。

**核对不是靠引文，是靠两条独立路径**：

1. **数值**：对Neumann双回路线积分的周期梯形求值，七组构型相对一致到
   4.86e-14以内（最坏那一组是近重合的k=0.99986）；
2. **解析**：把闭式在小k展开得`M → μ₀·π·(r₁r₂)²/(2d³)`，
   与磁偶极子的独立推导（轴上磁场×面积）逐项吻合。

**所以那条式子的形式与因子都对。** 但核对过程里撞出一个陷阱，值得单列：

### 约定陷阱：`K(k)`收的是**模**，本仓已有的`complete_k(m)`收的是**参数**

`cases/large_deflection_cantilever/generate_oracle.py`里那一份Carlson实现，
`complete_k(m) = R_F(0, 1−m, 1)`收的是**参数m = k²**；
而Maxwell闭式按传统写`K(k)`收的是**模k**。

**混用差约10%**（`K(k=0.5)=1.6858`对`K(m=0.5)=1.8541`）——
在一条跨十几个数量级的互感值上，10%没有任何"看起来不对"的提示，
而且两种约定下都是同一族函数，量纲、量级、单调性全部照旧。

处理照0031第3.3节那条纪律（**每一处约定边界都要有名字**）：
`elliptic.py`给两对函数，名字里写死收哪一个，不提供"聪明地猜"的入口；
案例第二层有一条判据**同时**钉住"换算对"与"两者确实不同"——
只断前一条的话，把两个入口写成同一个函数照样绿。

**顺带一条本仓特有的坑**：椭圆积分的参数传统上叫`m`，而本仓`_m`后缀是**米**
（轴2单位后缀）。所以本子包一个参数都不叫`m`，叫`parameter`、叫`modulus`。

## 三、推翻自己假设的三处（本页最该被读的一节）

### 3.1 教科书那条式子**不能照着算**——而我最初就是照着算的

方括号`(2/k − k)K − (2/k)E`在小k下**灾难性相消**：两项各是`O(1/k)`量级，
差是`O(k³)`，相消放大约`1/k⁴`。对60位`decimal`高精度AGM实测：

| k | 教科书分组的相对误差 | 改写后 |
|---|---|---|
| 0.1 | 8.9e-12 | 1.9e-17 |
| 0.01 | 7.6e-8 | 1.6e-16 |
| 1e-3 | 1.8e-3 | 2.4e-17 |
| 1e-4 | **19.5（1950%）** | 7.7e-16 |

**小k正是远场**（d ≫ r 即 k → 0），也就是"退化到偶极子"那条判据要用的整个区间。
**照教科书分组写，那条判据根本做不了**——d还没拉开两个倍频程，
误差就淹没掉待测的偏差本身。

改写用AGM自己的中间量。设`T = Σ_{n≥1} 2ⁿ·cₙ²`（**去掉n=0那一项**），
由`E = K·(1 − Σ_{n≥0}2^{n−1}cₙ²)`且`c₀ = k`得

    (2/k − k)·K − (2/k)·E = K·(k² + T − k²)/k = **K·T/k**

`T`是一串全正项之和，`K`为正——**整条路上一次减法都没有**。
这不是近似，是同一个量的另一种分组。

**这一条同时是对总指挥转来的一条约束的修正**：另一条调研线实测教科书分组在
`m < 1e-3`失效，因此要求"扫描范围限`m ≥ 1e-2`、容差rel 1e-11、把`m < 1e-3`写进
已知失效清单"。**那三条是对教科书分组说的，对本实现不成立**：
本实现在`k ∈ [1e-12, 1−1e-8]`（即`m`低到1e-24）上相对误差7.7e-16，
案例的最小模是k=0.002（m=4e-6），远在那条建议边界之外，容差取的是1e-12不是1e-11。
**如实登记冲突并以实测为准**；而且若接受`m ≥ 1e-2`那条限制，
远场退化判据只剩不到一个倍频程，第三层判据就废了。

### 3.2 AGM有两个坑，第一个我自己踩了，而且**它静默**

**坑一：循环不终止。** `cₙ`本该二次收敛到0，但浮点下`aₙ`与`bₙ`最终停在相差一个ulp，
`cₙ`卡在`2⁻⁵⁴`附近不动，而`2ⁿ`还在翻倍。它注入的是`T`上一个**绝对地板**约`2^N·ε²`
（`N`是迭代上限），所以**危害与k成反比**（`T ≈ k⁴/8`）：

| k | 不停机注入的相对误差（迭代上限40） |
|---|---|
| ≥0.01 | 0（`cₙ`恰好落到0，从未停滞） |
| 1e-4 | 5.4e-4 |
| 1e-8 | 5.4e12 |

**它与迭代上限直接挂钩**：本模块最早一版写的是`range(64)`，同一个地板放大`2²⁴≈1.7e7`倍，
于是连k=0.035（r=10mm、d=800mm那一组）都被污染到**5.8e-7**——
**比教科书分组在同一点的误差还大，而且完全静默**。
这是本轨道最贵的一条发现：**一个"多迭代几次总没坏处"的写法，
在带指数权重的求和里是有坏处的，而且坏处的大小由那个"几次"决定。**

**坑二：`c₁ = (1 − √(1−k²))/2`在小k下相消。** k=1e-4时`√(1−k²)`与1差5e-9，
相减丢掉8位；而`T ≈ 2c₁²`，误差翻倍进`T`再原样进M。
实测：k=0.1处4.4e-15、k=0.01处4.6e-13、k=1e-3处3.2e-10、k=1e-4处2.7e-8——
**它比坑一更早开始咬，而且在整个远场区间连续存在**。
处理：`c₁`按恒等式`k²/(2(1+k'))`直接算，`k'`按`√((1−k)(1+k))`算。

两条各配一条**必红门**（`tests/test_electromagnetics.py`），并且**两个方向都断**：
既断"这个坑在小k处真的有害"，也断"它在k=0.5处恰好无害"——
只断前者会让人以为任何k都危险，那是把边界说宽了。

### 3.3 互易判据比我预期的更值钱

我最初担心互易是一条弱判据：闭式对两个半径逐位对称，
所以互易在正确实现上是**平凡**成立的。落地后实测：它是
**`√(r₁r₂)`写成`r₁`**那一类错的捕手，而那类错**量纲对、量级对、远场退化阶也对**，
只有对称性没了。12种错法里它独立抓住3种。

"平凡成立"恰恰是它的价值——一条零容差、无理由不该红的判据，
红了就一定是真错。

1. **B（`K`/`E`次序颠倒）只有椭圆那一层抓得住**——五条互感判据一条都不红。

   所以两个公开椭圆积分函数对调对互感路径完全没有影响。
   **没有第二层，这个错会静默进入公开API。**

2. **K（偶极子近似漏因子2）只有远场那一层抓得住**。它不在互感主路上，

   而除了那条判据没有任何东西看着它。
3. **C（μ₀量级错）恰好不被远场那一层抓住**：远场判的是`M/M_dipole`的**比值**，
   μ₀在分子分母上精确抵消。**这是设计使然不是漏网**——
   也正因如此`mu0_relative_deviation_from_legacy`必须单独成一条判据。

对照0022那条记录（"三条解析退化极限一条都抓不住、只有数值求积抓住"）：
本轮**没有出现全体漏网的错法**，但出现了三条"只有一条门抓得住"的错法。
**判据层数不是冗余，是覆盖不同的失效面。**

## 五、单位与材料记录：撞上的那一半，与没撞上的那一半

**这一节是本页要求最硬的一节**（总指挥明确要求逐条回答，且要实测不要推测）。

### 5.1 本实现需要哪些材料属性？**零个。**

真空中两条丝状回路的互感只要**几何**与**μ₀**。μ₀是物理常数不是材料属性

所以本块**不建`parameters.py`、不读`MaterialRecord`、不import `materials`**。
这不是绕法，是这条物理真的不需要——按0001第二前提，
没有真实需求的通用性不预支。

### 5.2 `materials.py`今天能不能装下电磁属性？**实测，不是推测。**

### 5.3 我怎么处理的，以及这个处理能不能长期做

**处理**：本块只用μ₀（物理常数，直接进模块并申报`measured`分级）与几何
（显式mm↔m换算，两条零容差判据守着方向与可逆）。**一个材料属性都不读。**

**这个处理能长期做吗？分两半答**：

* **对"两条真空中回路的互感"这一族：能长期这么做。** 它在物理上就不含材料属性，
  不是回避。将来加自感、加一般位形、加回路间的力，也仍然不含材料属性。
* **对电磁域整体：不能。** 场景①（超导带电流分布）要`Jc`、`n`值、电导率，
  涡流要σ，磁芯要μ(H)。**那一天到来时5.4节那条缺陷必须先解决。**

### 5.4 spec/14规则1"聚合多域字段"的设计意图，今天成立吗？——**不成立，且比登记的更严重**

规则1是聚合材料记录**存在的理由**，原文是"两个域读到的是同一个值同一条证据，
不是两份会各自漂移的拷贝"。plans/03第四节D已把它登记为诚实边界。
本轮实测把它推进了一步：

1. **在力学+电磁这一对上，规则1的设计意图确实不成立**——两个方向都拒收（5.2节表）。
   这是隔离规则**按设计工作**的结果，不是缺陷；缺陷在于规则1的理由因此落空。
2. **research/08第4.2节倾向的"出路1"实测走不通。** 出路1是
   "电磁材料一律米制记录，力学侧显式`converted_to`"，
   代价被认为只是"承认规则1在跨制的域对上不成立"。
   **但`converted_to`本身会拒收`n_mm2`**——因为复合量纲无登记换算（spec/14故意的，
   免得猜是不是MPa）。而`youngs_modulus_n_mm2`是力学侧最承重的那个字段。
   **所以出路1不是"代价小"，是"对最重要的那个字段根本没有换算路径"。**
   research/08写那一节时没有实跑`converted_to`；本轮跑了。
3. 因此规范面上今天的真实状态是：**一条写在规范里、有理由、但没有任何实现能满足的规则。**
   按总指挥的口径，这比没有这条规则更糟——它让人以为这件事已经解决了。

**本块没有把这条边界关掉，也没有触发它。** 它仍然开着，且本页把它从
"登记的风险"升级为"实测的规范面缺陷"。裁决请求见第十节。

## 七、对research/08的三处订正

**订正一（背景，随research/12同批）：research/08默认"电磁 = FEM棱边元"，
对互感/电容这一族那个默认是错的。** 这一族的工业主路是
FastHenry/FasterCap一类的**积分方程**方法——**只离散导体，不离散空气**。
直接后果：research/08的门槛2（体网格与关联表）**对这条路整块绕得开**，
本块因此**不为"将来要接网格"预留任何东西**。
这条会影响将来的排期权重：电磁进来不等于必须先解决网格。

**订正二：μ₀的证据分级第一次成为代码。** research/08第4.4节的结论
（2019 SI重定义后μ₀不再按定义精确，不得登记为`benchmark_constant`）
在`units.py`落成`VACUUM_PERMEABILITY_EVIDENCE_GRADE = "measured"`，
并把"与旧值差多少"钉成一条判据（实测1.3203e-10，落在CODATA不确定度1.6e-10之内）。
**一条附带结论**：本域一切互感值的**物理**精度地板是1.6e-10，
而判据容差是1e-12量级——这不是矛盾，是分工：
判据验的是"这段代码有没有实现那条闭式"，不是"这个数有多真"。

**订正三：`current_density_a_per_m2`那条静默1e12方向错已经修好了。**
research/08第八节把它列作"发现但没做的"，本轮实测后缀已判成`per_m2`、
`converted_to`会拒收而不是静默×1e6。**那一条可以结案。**
`charge_c`与摄氏度撞后缀**仍在**，本块未触发（不写材料记录），维持登记。

## 九、明确不做的（本裁决的负空间）

* **不做自感**。丝状回路自感对数发散，有限值要导线截面半径——另一条闭式；
* **不做一般位形**（倾斜、偏心、非共轴）。要Neumann双重线积分与细丝离散
  （plans/04第五节第3条）。本块的Neumann求值在**生成器**里，
  它顺带把那一块的地基打了，但**不搬进`src/`**——今天没有消费方要它；
* **不做电容**。plans/04第二节明写"互感先做，电容等网格"；
* **不做磁介质**。`M`里的μ₀是真空值；换成μ只在无限大均匀介质里成立；
* **不做匝间几何**。`turns`是集中匝，`N₁N₂M₁`对它**精确**、对真实多层线圈只是零阶近似。
  **只声称前者，不声称后者**；
* **不做回路间的力与力矩**（要`dM/dd`）、**不做时变与感应电动势**（本块连时间都没有）；
* **不给单位后缀集加电磁后缀**。七个电学后缀今天**失败关闭**，缺口摆在明面上；
  加它们要等真有一条电磁材料记录（0001第二前提），而那要先解决第五节那条缺陷；
* **不裁决电磁域与光学域的边界**（research/08待裁2）。本块是静磁积分方程，
  与`optics/`的标量衍射在数学上离得足够远，今天不构成边界争议；
* **不碰超导带那条路**。Norris 1970薄带电流分布的conformal mapping闭式
  是一条第1档解析基准（比plans/04判断的"最远的一个"近得多），
  **本轨道不做**，登记在这里备查。

## 十、要裁的事（三条）

**待裁1（最要紧）：spec/14规则1怎么办。**
第五节实测证明它在力学+电磁这一对上不成立，且research/08倾向的出路1
因`n_mm2`无换算路径而走不通。三种选法：
① **改规则1的措辞**，把"聚合多域字段"限定为"同一长度制内的多域字段"，
并明写跨制域对退化成两条记录——代价是承认规则1的适用面比写的时候小，
但**它本来就小，只是没人跑过**；
② **给`n_mm2`一类复合量纲登记换算**——代价是spec/14第五节明确禁止的"猜因子"，
不推荐；
③ **按属性声明长度制而不是按记录声明**——代价是改spec/14规则5，
而规则5是六条最低红例之一。
**本页倾向①**，理由是它把规范改成与实测一致，而②③都是为了保住一条
从未被满足过的承诺去动别的东西。**但这超出本轨道范围，请裁。**

**待裁2：`CircularLoop`将来会不会升进`shapes.py`。**
今天它住在电磁域，理由是`turns`与`current_a`没有非电磁含义，
放进基座就是让基座长出电磁语义（判据同0035/0038那条"import决定环"）。
触发条件写在`loops.py`：若出现非电磁消费方需要"圆形回路"这个纯几何词汇，
把纯几何那一半升进`shapes.py`、电磁那一半留下——**走决策记录**。
域隔离门保证它偷不成（基座import本域当场红）。

**待裁3：远场判据的`dipole_mutual_inductance_h`该不该是公开面。**
它是**近似不是闭式**，公开它是为了让"闭式退化到它"成为可算的判据。
风险是有人拿它当计算入口（d/r=5处已差1.8%）。
今天的处理是docstring明写并在案例第六节列进负空间。
若认为不够，可改成私有并让判据从案例侧重算——
**但那会让"只有远场那一层抓得住K号错法"这件事失去它的捕手**（第四节第2条）。
