## 一、为什么先做干涉，以及范围到哪为止

plans/04第七节把光学三块（衍射/干涉/散射）的"有没有解析oracle"列成一张表，
干涉那行写的是"**有且很强**"：双光束`I = I1+I2+2√(I1I2)cosΔφ`、条纹间距闭式、
迈克尔逊与杨氏双缝都是教科书闭式。同一张表把衍射与散射的共同前置写成
"二维复数场 + FFT"——那是0031已经声明的"下一块"。

于是本轨道的范围**严格限定在闭式代数**：

| 做 | 不做 |
|---|---|
| 双光束强度、两个极值、可见度 | 场传播、角谱、菲涅耳、任何FFT |
| 杨氏双缝：`Δx = λL/d`、傍轴与**精确**光程差、傍轴适用性的可算判据 | 双缝的衍射包络（真实图样是干涉因子×衍射因子） |
| 迈克尔逊：`OPD = 2d`，高条纹级次下的相位精度 | 扫描、干涉图、任何变换 |
| 部分相干的**模**`|γ|` | `arg(γ)`、相干长度、光源谱（第三节） |
| 能量守恒（条纹平均恒为`I1+I2`） | 多光束（法布里-珀罗）、偏振、等厚/等倾 |

**本块一个数组都没有，一次FFT都没有。** 0031第五节那条"不做二维场传播"原样成立。

`src/physics_engine/optics/interference.py`（19 419字节，15个公开名）+
`cases/two_beam_interference`（4条oracle）+ `tests/cases/test_two_beam_interference.py`
（5条）+ `tests/test_optics_interference.py`（33条协议门）。

## 二、FTS里有没有可复用的干涉核心——判断与理由

**任务要求先查这件事**（本仓有过`k*(d_a·d_b)`写成`(k*d_a)*d_b`导致末位漂移的
教训，两份等价实现是这类问题的温床）。逐个模块看下来，结论分三层：

**① `fts.py`里没有干涉核心可复用，因为那里根本没有干涉。**
`fts.py`给的三样是：归一化sinc、无切趾ILS`sinc(2Lδσ)`、Norton-Beer窗与它的通量
代价。**整个模块里没有一次`cos`、没有相位、没有`I1`/`I2`。** 原因是它工作在
**谱域**：ILS是"被截断的干涉图的傅里叶变换"，而那个变换是人**一次性解析做完**
之后把闭式`sinc`写进代码的。干涉图本身——`I(Δ) = I1+I2+2√(I1I2)cos(2πσΔ)`——
从来没有在仓里出现过。把`normalised_sinc`拿来做双光束叠加是范畴错误：
sinc是**截断窗**的变换，不是条纹定律。

**② 真正该复用、也确实复用了的，是单位边界那一处。**
相位换算`Δφ = 2π·OPD/λ`必须经`diffraction.py`的`angular_wavenumber_rad_per_m`，
**本模块不自己写`2*math.pi/wavelength`**。理由正是0031第3.3节那张表：
谱学波数σ与角波数k差一个2π且不报错，这道边界在子包内只许有一处实现。
`interference.py`因此import `diffraction`（同域，域隔离门允许）。
**没有为此新造`units.py`**：今天只有两个模块用它，抽第三层是为想象中的
第三个消费方预支结构（三前提第二条）。触发条件写明：第三个模块要用时再抽。

**③ 与FTS的关系改成一条判据，不改成一份代码。**
FTS与迈克尔逊本是同一台仪器，这个事实值钱的地方在于它能变成一条**跨模块的门**：

> ILS首零`δσ₀ = 1/(2L)`按定义是分辨极限。它的物理内容是——波数差一个`δσ₀`的
> 两束光，在整个扫描程`2L`（OPD从`−L`到`+L`）上相对相位**恰好滑过一个整条纹2π**。

案例第四层就断言这件事：用`fts.unapodised_first_zero_per_m`取首零、用本模块的
`phase_difference_rad`算两条相位之差，期望值写`2π`。**它不引入任何FFT**
（只是两条余弦的相位差），却把两个模块的口径钉死：`fts.max_opd_m`是**光程差**，
所以要扫到`L`动镜只需走`L/2`——这条也单列成一条协议门。

**④ 一处刻意不复用：那两个"2"。**
`fts.DOUBLE_SIDED_OPD_FACTOR = 2.0`说的是"干涉图录在`−L..+L`上"；
本模块的`MICHELSON_OPD_PER_MIRROR_DISPLACEMENT = 2.0`说的是"光去一趟回一趟"。
**数值相同纯属巧合，物理不是一回事。** 合并成一个常量会让半年后的人以为
改一处就改了两处。两处各写各的，并在两边的docstring里互相点名。

## 三、相干性：做`|γ|`，显式不做`arg(γ)`

任务给了两条路——做部分相干，或者明确声明只做完全相干并写清理由。**选了前者**，
因为部分相干在闭式里只是一个乘数，却能把可见度拆成**两个可分别检验的因子**：

    V = [2√(I1I2)/(I1+I2)] × |γ|

只验等强构型时，一个"把`|γ|`当成整个可见度"的实现照样绿；本案例同时验
`visibility_partial_equal`（等强，`V = |γ| = 0.4`）与`visibility_partial_unequal`
（不等强，`V = 0.8×0.4 = 0.32`），两条合起来才把两个因子分开。注入实测：
把`|γ|`从可见度里删掉红6条，把`|γ|`写成`|γ|²`红5条。

**明确不做`arg(γ)`**，理由不是来不及：它要么由光源谱经Wiener-Khinchin算出来
（那是傅里叶变换，0031已声明为下一块），要么由消费方测量后传进来——
今天没有任何消费方需要它。准单色、谱型对称的光源上`arg(γ) = 0`，本块覆盖这一档。
触发条件：某个消费方要算非对称谱、或要用相干度做定位时重开。

**同时改写了0031的一句负空间声明。** `optics/__init__.py`原文写着
"偏振、相干、色散、非线性——一个都没有"。本块落地后这句话不再成立，
因此那一行被改成"相干只做`|γ|`不做`arg(γ)`"并注明由本决策改写。
**负空间声明过期了要改，不改就是谎**——这条比多写一个函数重要。

## 四、相消：三个能算出来的放大因子，和一个负强度

0031在`J1`上处理过小宗量相消。`cos(Δφ)`这一侧的相消形态不同，且**不止一处**。
逐条查下来有三个放大因子，全部写进了对应容差的`reason`栏：

**① 暗纹：`Δφ → π`且`I1 ≈ I2`时`I1+I2−2√(I1I2)`是两个几乎相等的正数相减。**
放大因子`√I2/|√I1−√I2|`。实测：

| 构型 | 放大因子 | 朴素式的相对误差 | 不相消式的相对误差 |
|---|---|---|---|
| I1=1、I2=1+1e-7（真值2.5e-15） | 2.0e7 | **6.6%** | 1.15e-9 |
| I1=6.8878588572697…、I2=…237471（真值3.79e-23） | 4.3e11 | **返回−1.78e-15** | 6.55e-5 |

处理是恒等变形

    Imin = (√I1 − √I2)² + 2√(I1I2)(1 − |γ|)

**两项都非负，一次相消都没有**（`|γ| ≥ 0.5`时`1−|γ|`按Sterbenz引理还是精确的）。
`two_beam_min_intensity`走这条路。**朴素式会返回负强度**——40万对随机近等强
（相对差1e-9内）扫描里**49 933对命中，12.5%**。负强度不是精度问题，
是算出了一个不存在的东西，所以案例里钉了一对实测标本并断言不相消那条路永远非负。

**诚实补一句**：恒等变形不是无条件更好。`I1=3`、`I2=0.75`时它给0.7499999999999999
（低1 ulp），而朴素式恰好给0.75——**`I1`与`I2`相差远时它反而多一次舍入**。
它的价值只在`I1 ≈ I2`，那也正是它被需要的地方。这句话写进了案例判据表。

通用的`two_beam_intensity(Δφ=π)`仍然相消，这是通用式的代价：案例把同一个物理量
用两条路各判一次——一条判相对5e-9，一条只能判绝对5e-16。**差的不是精度是写法**。

**② 相位精度随条纹级次线性退化。** `Δφ = 2πN`，`N = OPD/λ`。内核走
`angular_wavenumber_rad_per_m(λ) × OPD`，三次舍入使相对误差`3u`，
绝对误差因此约`3u·2π·N = 2.1e-15·N`。这个系数写成模块常量
`PHASE_ACCURACY_RAD_PER_FRINGE_ORDER`，**并且被验**：协议门在400个OPD上对
`Fraction`精确约化的参考求值，两个方向都断（必须是上界、也不许松一个数量级），
实测最坏是申报值的0.43倍。案例的迈克尔逊构型故意取到`N = 15802.78`，
相位误差界3.32e-11 rad、强度误差界9.96e-11（实测1.15e-11）。
**级次是公开的**（`fringe_order`）——"这次算得有多准"必须能被调用方问出来。

**③ 傍轴偏差的实测值。** `1 − OPD_exact/OPD_paraxial`是两个相对差只有`dev`的数
相减，放大因子`1/dev`。反直觉的一点：**最坏点是最靠里的取样点不是最外面那个**
（x=0.25Δx处`dev`=2.06e-7、放大4.86e6；x=40Δx处`dev`=5.09e-3、放大只有196）。
越近轴、傍轴近似越准，这个比值就越难算准。容差2e-9由这个最坏点定。

**④ 另有一处相消被写法躲开了**：精确光程差`√A − √B`在近轴时两个根号都≈`L`=1.2 m
而差只有6.33e-7 m，直接相减丢约6位。内核走`2xd/(√A+√B)`（分子`A−B = 2xd`是精确的
代数化简），协议门实测两条路差**8.3e-11相对**——**那6位就是它**，且越近轴丢得越多。

三条最值得记的：

- **A是本轨道最贵的一条发现的反面**：实测`I1 = I2 = 1.0`时`2√(I1I2)`与`2(I1I2)`
  **逐位相同**。一个只用归一化等强构型的案例对这个错法**完全瞎**。
  本案例的强度对因此取(3.0, 0.75)与(2.0, 2.0)，等强那对也故意避开1.0。
  这一条不是推理出来的，是先写了`(1.0, 1.0)`、再实测发现注入不红才改的。
- **I说明外部证人不可替代**：把L与d在条纹间距**和**傍轴光程差里一起写反，

  拆穿它的是**精确两点源几何**——一条不经过任何被验公式的外部参照。
  "案例要有一条不共用假设的路"这句话，这里是它的活标本。
- **J说明判据密度是不均匀的**：傍轴偏差闭式漏一个2，只有
  `deviation_estimate_over_measured`这一对量抓得住，别的门全绿。
  适用性判据是这个案例里最薄的一处，如实记在这里。

### 没有被任何门抓住的错法（本节的重点）

**调用方把度数传进`phase_difference_rad`参数位。** 注入D验的是"模块内部把弧度
转成了度"——那个会红5条；但**跨调用点的单位约定，本模块无从判别**：
传进来的180.0就是一个有限浮点数，既不是nan也不越界。唯一的防线是参数名带`_rad`。
`tests/test_optics_interference.py::test_degrees_passed_as_radians_cannot_be_detected_by_this_module`
把这个洞钉在测试里，免得半年后有人以为这里有门守着。

同类还有一条：**两束光的强度单位不一致**（I1按W/m²、I2按mW/m²）同样无人守。
这两条都写进了案例的已知失效清单。

## 六、四层判据与"容差是算出来的"

四层各自独立（每层红了说明的事不同）：

1. **定律本身**：8点强度、四组可见度、两条退化极限（`I2→0`与`|γ|→0`，
   **两个不同的退化机制落到同一结论，各验各的**，都是零容差）；
2. **条纹几何**：`Δx = λL/d`、傍轴与精确光程差、傍轴适用性的可算判据、
   二分精确几何求出的第一亮纹位置（比傍轴预测远3.209e-6，与偏差同号）；
3. **能量守恒**：条纹的**相位平均**（与条纹间距、与`|γ|`、与光程差机制全都无关，
   **独立门**）与**空间平均**（同时用到条纹间距与整条相位链，**耦合门**，
   如实标注不独立）。四个构型的相位平均**实测残差都恰为0**；
4. **迈克尔逊与FTS桥**：高条纹级次下的相位与强度、以及第二节④那条桥。

容差全部由解析界算出。38条量里15条有有限余量，**最紧的3.0倍**
（`intensity_at_pi_near_equal`，因为那条容差本身就贴着相消的界）；
其余23条实测误差恰为0，或按零容差逐位相等。**有两条是先写松/写紧再按实测改的，
都记在案例判据表里**：`intensity_samples_partial_coherence`第一版1e-15只余1.1倍
（实测8.88e-16恰是ulp(5.6)，是按感觉写的不是按界写的），
`min_intensity_negative_naive_case`第一版判绝对5e-16——比真值大七个数量级，
那样的判据只是在说"结果接近0"，改成判相对2e-4之后才真的锁住4位有效数字。

**清单里有一条零容差布尔判据守着容差本身**：生成器不import内核，所以
`PHASE_ACCURACY_RAD_PER_FRINGE_ORDER`在两边各存了一份；
`declared_phase_accuracy_matches_manifest`不许它们漂——第四层三条容差
全是拿它乘条纹级次算出来的，它漂了容差就成了空话。

金标生成器走三条与内核不同的路：`Fraction`精确相位约化、60位`Decimal`的Taylor
余弦（**不调libm**）、精确光程差按定义式直接相减。生成器一次0.12 s。

## 八、明确不做的（本裁决的负空间）

- **不做场传播、不做FFT**——0031那条原样成立，本块一个数组都没有；
- **不做多光束**（法布里-珀罗的`1/(1+F·sin²)`）；
- **不做`arg(γ)`、相干长度、光源谱**（第三节，带触发条件）；
- **不做偏振**。正交偏振不干涉（Fresnel-Arago）；`|γ|`可以吸收这一项，
  但那是消费方的申报不是本模块的计算；
- **不做等厚/等倾干涉**。薄膜的半波损失要折射率与入射角；第二个构型取迈克尔逊
  是因为它与已有的FTS共用同一根光程差轴（第二节④）；
