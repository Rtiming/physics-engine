# 0013 算法与硬件后端轨道立项（2026-08-05凌晨）

状态：已裁决（用户口述："算法本身要足够优；硬件性能充分利用，可能要做
驱动上的适配——这是开发计划之一；先把规范制定好，确保正确"）。

## 决定

1. "算法优化+硬件后端适配"列为引擎开发轨道**M-E4**（plans/00）。
2. **规范先行已执行**：spec/13 v0.1草案成文——算法侧四义务（profile
   先行、对拍分档、变更三件套、不许静默改精度）；后端侧五规则（单一
   物理定义多后端执行、数组API边界、CPU fp64参照真值+等价门、三门槛、
   **确定性分级申报**）；驱动版本进run包溯源；平台事实入册
   （Metal无fp64=本机无GPU求解器路线）。
3. 排期认定：第一个真实牵引=WDS符号codegen（其M5-B3）；`backends/`
   模块只在第一个内核真要跨设备且三门槛过后才落码——不为"看起来快"
   预支重资产。

## 为什么大半条款直接有效

三门槛、无状态纯函数、Taichi禁令、一致性门都是消费方既有法律，
本页只是升格为引擎法条并补上行业缺口（确定性分级——GPU原子乱序
不得声称指纹，这条外部引擎普遍没有显式化）。

## 不做的

- 不现在写任何后端代码；
- 本机Mac不立GPU求解器项（Metal无fp64，已测事实）；
- 不引入Taichi。
