## 二、抓到的三件（比新功能值钱的那一项）

### 2.1 **真缺陷，而且它在教科书算法里**：BHMIE的对数导数起点`+15`不够

Bohren & Huffman的`BHMIE`（以及照抄它的大多数实现）把对数导数
`D_n(mx) = ψ'_n/ψ_n`的向下递推起点取成`n_start = max(n_max, ceil|mx|) + 15`。

**实测它不够**：

| 构型 | `+15`给的`Q_ext` | 收敛值 | 相对差 |
|---|---|---|---|
| x=500、m=1.33（无吸收） | 2.031189119014 | 2.030373894631 | **4.0e-4** |
| x=50、m=1.5（无吸收） | 2.171072858910 | 2.171072712900 | 6.7e-8 |

4.0e-4对一个**自称"严格级数解"**的实现来说不是舍入而是错，
而且**一个字都不报**：级数照样收敛、能量照样守恒、幺正性照样满足
（它们全都对一个统一偏移的`D_n`不敏感）。

**它是被一条门打出来的**，那条门本身值得记下来：
`mie_coefficients`有一个`logarithmic_derivative_lift`参数，
判据用它**把起点抬高再算一遍**，要求两次逐位一致。
**不设这条门的话，`+15`就只是一个被相信的数**——
而"被相信的数"正是本仓反复吃亏的形态。

处理：把对数导数的起点换成与`spherical_bessel_j_array`**同一条规则**
（`max(阶, |z|)` 再加 `max(25, sqrt(40 × 那个数))`）。
换完之后抬高20/50/100/200/400阶**一位都不变**。

同一条门在`spherical_bessel`那边也有（`start_lift`），实测抬高10阶后
最大差1.1102e-16。

### 2.2 **教科书的`ψ_n`向上递推在小宗量上返回噪声**

`BHMIE`对`ψ_n(x)`用向上递推`ψ_n = (2n−1)/x·ψ_{n−1} − ψ_{n−2}`，
种子`ψ_0 = sin x`、`ψ_1 = sin x/x − cos x`。
`j_n`是那条递推的**极小解**，向上递推对极小解从来就是不稳的。

对50位`decimal`参照实测（**相对**误差）：

| x | n | 向上递推 | 本仓的向下递推 |
|---|---|---|---|
| 1e-3 | 1 | 1.134e-10 | **0**（逐位相同） |
| 1e-3 | 2 | 1.700e-03 | **0** |
| 1e-3 | 3 | **5.952e+04** | **0** |
| 1e-2 | 3 | 7.547e-04 | 1.357e-16 |
| 1e-1 | 3 | 4.743e-08 | 2.225e-16 |
| 1 | 3 | 7.569e-14 | 1.926e-16 |

`x=1e-3`、`n=3`那一格**答案比真值大六万倍**，而`n=3`恰恰是
`mie_max_order(1e-3)`——即Mie在那个尺度参数上真的会用到它。

**如实记的一条边界**：那几阶对`Q_sca`的贡献本来就极小，
所以这条缺陷**对本仓Mie效率的实际影响没有单独量过**。
"这个函数在这里返回的是噪声"这件事必须写下来，
但不许由此推出"所以BHMIE的Q_sca也错了"——**那是一句没测过的话**。

本仓的`ψ_n`走Miller向下递推 + 三角种子归一
（归一化锚点在`j_0`与`j_1`里取**真值模较大的那一个**，
于是小`x`选`j_0 = sin x/x`（无相消）、`x = mπ`附近选`j_1`（`j_0`过零））。

### 2.3 **我自己第一版的截断判据是个空门**

Mie的截断判据第一版只看**末项占比**（末项对求和的相对贡献）。
扫描128个构型（x取16档1e-6到1e3 × m取8种）时它露了：

* x=50、m=1.5：末项占比 **2.065e-18**（几乎为0），
  而截到`n_max`对截到`n_max+10`的**真正截断误差是6.2e-8**。

原因很简单：**末项可以恰好落在一个近零点上**，而它后面的项不是。
一条"末项很小所以收敛了"的判据在那种构型上给绿。

处理：判据不变（末项占比仍是那条便宜的在线检查），
但**加一条门把它与真正的截断误差一起量**。
修好2.1之后重扫：末项占比最坏1.6963e-10、真正的截断误差最坏1.2287e-10，
**且逐个构型前者盖住后者**。申报`MIE_SERIES_TAIL_TOLERANCE = 1e-8`（余量59倍），
并在常量注释里写明**那是实测的经验关系不是定理**。

## 三、裁决一：矩孔那一格缺的不是实现，是判据

S4.6的`missing`原文："label里三件（单缝／双缝／**矩孔**）只做了两件——
「矩孔」那一格没有被传播验过。`rectangular_aperture`这个构件是有的，
但仓里**每一处**调用它的地方`half_width_y_m`都取`1.0e9 × pitch`。"

**那是缝不是孔**：y方向占满窗口，图样是一维`sinc²(x)`。

四条判据，每条附必红（`tests/test_optics_rectangular_aperture.py`，15条，0.51秒）：

1. **孔真的是孔**：亮采样恰好`Mx·My = 32`、亮行恰好4、亮列恰好8
   （三个整数，零容差）。必红**正面构造了仓里那个`1e9 × pitch`的写法**
   并断言它亮满所有64行——于是"label三件只做了两件"这句话在仓里
   有了一个**可执行的**证据，而不是一句台账里的话；
2. **两个方向各自的前三个零点归一化强度恰为0.0**（不是"很小"）。
   **x能验到m=3、y只能验到m=1**，因为奈奎斯特那一格归到负侧、
   m=3已经折成m=−1——这条被**正面断言**而不是绕开；
3. **图样可分离**：`I(r,c)/I(0,0) = (I(r,0)/I(0,0))·(I(0,c)/I(0,0))`，
   残差 **7.7716e-16 = 3.50 eps**（上界16 eps，余量4.6倍）。
   必红是**圆孔**：同一条式子上 **3.5852e-2**，比上界大 **1.0e13** 倍。
   **它与`optics/field`那边的`fft2`可分离性门不是同一件事**——
   那一条对**任何**输入都成立（包括圆孔），这一条只对可分离孔径成立；
4. **单缝是矩孔的极限，而且是一个可以判的数**：离轴行的功率份额有闭式
   `ROWS/My − 1`，实测`My=2 → 3.0`、`My=4 → 1.0`、`My=8 → 0.0`
   **三个数与闭式逐位相同**（零容差，两侧都是2的幂上的Parseval配平）。
   掩模本身与`1e9`写法**逐位相同**（`float.hex()`对拍）。

外加：对连续`sinc²(x)·sinc²(y)`的偏差2.8192e-2，
固定物理孔径加密网格 2.8192e-2 → 7.9721e-3 → 2.1429e-3 → 5.5719e-4，
阶 **1.822 → 1.895 → 1.943**；必红是把参照写成只有`sinc²(x)`（偏差1.0000）。

还有一条**从来没被走到过的分支**：0086那条"边界落在采样点上失败关闭"
在**y方向**上从未被执行——既有调用的`1e9`半宽远在窗口外，那条判据直接`return`。
本轨正面走了一次。

## 四、裁决二：角谱那一侧的金标，两条判据是傍轴形制给不出的

S4.5的`missing`原文："**角谱那一侧没有任何案例冻结金标**——
平面波本征函数／倏逝波衰减／`z→0`逐位／半群四条今天只活在`tests/`里，
而案例`double_slit_propagated`走的是夫琅禾费那一支。按本仓的分档，
`tests/`里的门守的是实现、案例冻结的才是判据，**所以这一位是partial不是done**。"

新案例`cases/angular_spectrum_propagation`：4条oracle、13个量，
conformance六条**0.05秒**，生成器一次**0.06秒**。

**生成器走二维直接求和**：没有行列分解、没有位反转、没有旋转因子表，
不import `physics_engine.optics`；相位按整数`(rv+cu) mod N`约化再进`exp`
（0086第5.2节那条教训：不这么写，参照自己的误差会盖过被验对象，差65倍）。

**两条角谱独有（任何傍轴形制都给不出）**：

1. **平面波本征值**里的根号是精确的`sqrt(1−(λf)²)`，傍轴展成`1−(λf)²/2`。
   实测残差3.5253e-15（容差1.6e-14）；精确与傍轴的差逐bin冻住：
   `λf=0.1978`处3.9161e-4、`0.9888`处**7.1041e-1**、倏逝四个bin上7.8580e-1到1.0116；
2. **倏逝功率损失，而且它只是一个数**。亚波长网格（间距100纳米、
   波长632.8纳米，32格里**只有11格是传播的**）上4采样宽的缝：
   精确角谱给 **0.895526867531937**、傍轴给 **恰好1.0**
   （傍轴传递函数的指数是纯虚的，`|H| = 1`逐bin成立，
   于是同一条Parseval求和的分子分母**逐项相同**）。
   **验这个数不需要复述任何公式**，而且没有任何傍轴形制能给出它。
   两者的差 1.0 − 0.8955 = **0.1045** 就是"傍轴给不出角谱"这句话的量。

另外三条方向：MFT-FFT等价在角谱那一支上（12个**跨四象限**的采样点，
最坏9.9920e-16）；`z→0`与`ifft2(fft2)`**逐位相同**（零容差）、
对入射场2.0024e-16；半群3.1402e-16；宏观网格（0格倏逝）能量守恒偏差1.1102e-16。

**顺带把矩孔的三个整数零容差冻进这条案例**——于是S4.6缺的那一格
也有了一份**案例级**的证据而不只是`tests/`。

## 五、裁决三：Mie的三条形制选择

### 5.1 `ψ_n`走Miller向下递推而不是教科书的向上递推（理由见第2.2节）

### 5.2 内场只算**对数导数**，一个复宗量的球贝塞尔函数都不算

Mie系数里球内那一侧只通过`D_n(mx) = ψ'_n(mx)/ψ_n(mx)`进入，
而`D`有自己的向下递推`D_{n−1} = n/z − 1/(D_n + n/z)`。
这是`BHMIE`那条算法里**唯一值得照抄的部分**——
照抄它省掉了一整套复数球贝塞尔实现。
（起点规则那部分不值得照抄，见第2.1节。）

### 5.3 两个必须写下来的约定

* **时间约定`exp(−iωt)`** ⟹ 外行波是`h_n^(1)` ⟹ 吸收对应`m = n + ik`且`k ≥ 0`。
  翻错会得到一个**发光的球**（级数照样收敛、散射效率照样为正，只有吸收为负），
  所以`Im(m) < 0`**当场失败关闭**并在报错里点名约定；
* **尺度参数吃半径不是直径**（`x = 2πa/λ`）。与`diffraction.airy_argument`
  吃半径同一条实践：签名替调用方记住。传直径进来小球散射效率差`2⁴ = 16`倍。

### 5.4 截断显式声明并失败关闭（判据本身也被验，见第2.3节）

`n_max = ceil(x + 4x^⅓ + 2)`（Wiscombe），末项占比超申报**当场炸**；
`x`只在`[1e-6, 1e3]`、`|m|`只在`(0, 10]`上测过，**域外拒答而不是外推**。
**不给"自动加阶直到收敛"的循环**——那会把一个可以被判据看见的失败
变成一个安静的重试。

### 5.5 四条互相独立的验收，逐条实测

1. **能量守恒／幺正性**：无吸收球`Q_ext = Q_sca`最坏相对差 **1.281e-16**
   （六个构型里**四个恰为0**）；**逐阶**`| |a_n|² − Re(a_n) |`最坏 **2.220e-16**。
   `Q_ext`取实部、`Q_sca`取模平方，是两条不同的式子，所以这是真判据。
   **`Q_abs`按定义就是两者之差，所以"消光=散射+吸收"本身不是判据**，本轨不假装它是；
2. **退化到瑞利**，两条互不依赖：
   * 只用**严格级数**验`C_sca ∝ 1/λ⁴`——固定半径、五个波长上`C_sca·λ⁴`的散布
     20nm→4.8101e-3、10nm→1.4003e-3、5nm→3.6187e-4、2.5nm→9.1197e-5，
     阶 **1.780／1.952／1.988**（残余是严格级数比瑞利多的`O(x²)`修正）；
   * 严格级数 对 瑞利闭式（静电偶极子那条**完全不同的推导**）：
     8.4179e-3 → 2.6541e-3 → 6.9546e-4 → 1.7582e-4 → 4.4077e-5，
     阶 **1.665／1.932／1.984／1.996**。吸收那条同样：阶1.935／1.977／1.990／1.995；
3. **大球极限（Extinction Paradox）**：不止断"接近2"，
   **断它按`x^(−2/3)`趋近**——`|Q_ext − 2|`相邻档比值实测
   0.634430／0.634339／0.633527／0.632662，理论`2^(−2/3) = 0.629961`，
   **从上方单调趋近**。x=800时`|Q_ext − 2| = 2.2837e-2`。
   **"接近2"是软判据**（任何缓慢下降的曲线都满足），"按`x^(−2/3)`接近2"不是；
4. **截断**：见5.4与第2.3节。

新案例`cases/mie_sphere_scattering`把这四条冻下来，
**金标的来路各不相同**：50位十进制的独立实现（上升级数 + 两阶直接相除的
对数导数 + 自己的泰勒`sin`/`cos`，**连libm都不共用**）、
解析的0（幺正性）、静电偶极子闭式、解析标度律`2^(−2/3)`。

## 八、本页登记的GAP

| GAP | 触发条件 |
|---|---|
| **Mie只有效率因子，没有角分布**（`S_1`/`S_2`、`π_n`/`τ_n`、不对称因子`g`、`Q_back`一行都没有） | 第一个真的要角分布的消费方出现时。届时要连带Legendre函数那一层，**并且要重新裁"角分布的判据是什么"**——效率因子有幺正性与两个极限三条独立门，角分布只有积分回效率这一条 |
| **有吸收球的逐阶系数没有对过高精度参照** | 高精度参照那一侧要求`m`是实数（`Decimal`没有复数）。有吸收那一侧今天由瑞利吸收闭式（小球端）与消光佯谬标度律（大球端）两头夹住，中间只有自洽门。触发条件：有消费方在中等`x`的吸收球上用它，或者本仓愿意写一套复数十进制算术时 |
| **教科书向上递推对`Q_sca`的实际影响没有单独量过** | 它现在只被记成"那个函数在小宗量上返回噪声"。真要下"所以BHMIE的效率也错了"这个结论，得单独量一遍——**今天没量，所以不说** |
| **`|m|x`很大时对数导数的起点规则只在`|m|x <= 1e4`上验过** | 申报上界是`x <= 1e3`且`|m| <= 10`，即`|m|x <= 1e4`。放宽任一上界时，第2.1节那条"抬高起点再算一遍"的门必须重跑——**那条门是这个规则唯一的守卫** |
| **Mie没有对过任何一份已发表的基准表** | 本轨的判据全部是**自洽门＋两个物理极限**（幺正性、瑞利、消光佯谬）加一份**我自己写的**50位十进制实现。50位那一份与被验实现算的是同一条公式（B&H式4.53），所以**一次共同的转写错误在它上面看不出来**——挡住这种错的是另外三条（它们各自来自不同的物理），但那不等于对过Wiscombe的MIEV0基准表。触发条件：能拿到一份可引用的基准数值时（本轨在离线环境里没有），把`x`与`m`各取几档逐条对一遍 |
| **两条新案例只在本机（macOS/arm64/CPython 3.13）跑过** | Windows/Linux首次复核时。半群那条与`sin`/`cos`的幅角约化有关（本案例`k·z = 6.28e3`弧度，比0086那条门的1e5小一个多数量级，所以敏感度更低）；**红了先查平台不要先放宽** |

## 九、明确不做的（本裁决的负空间）

* **不做核壳球、椭球、团簇、粗糙表面、双折射球**——"均匀各向同性"是
  Mie严格解成立的**前提**；

  本轨的Mie是**另一层**（完整的Maxwell边值问题），两者不互相替代；
* **不做加速档**：Mie在申报上界`x = 1000`处是1.1毫秒，没有理由；
* **不碰`optics/__init__.py`与任何既有`src/`文件**（0089第三节）；
* **不改`cases/README.md`、`capability_ledger.json`、
  `engine_budgets.baseline.json`、`CHANGELOG.md`、`plans/07`、
