# 0054 步长顾问与可计算的步长界（2026-08-12）

状态：**已落地**（轨道A，阶段1）。承接[0052第五、六节](0052_阶段1至3开工前的七条裁决_20260812.md)。

## 一、改了什么承重件

`IntegratorDeclaration`新增一个字段：`oscillatory_step_coefficient: float | None = None`。

它是`step_bound`的**可计算部分**——让线性振子能量保持有界的最大`h·ω`。

**为什么不复用`step_bound`**：那是字符串。
**一个字段同时干两件事，结果是两件都干不好**——
在本页之前，"这个积分器的步长上界是多少"只能靠人读一句话，
而步长顾问要算数。

字段带默认值`None`，因此**不破坏既有构造**（`rigidbody.py`那两个转动积分器
不改一个字节就继续可构造，它们的系数保持`None`）。

## 二、实测把一条已发布的声明打脸了

`explicit_euler`此前的`step_bound`写的是：

> h < 2/ω_max（线性振子）；一般系统由最高频模态定

**读起来像个可用的界。它不是。**

2/ω是**实轴**稳定区半径，而线性振子的特征值在**虚轴**上。
显式Euler对`ẍ = −ω²x`的放大因子恒为`sqrt(1 + h²ω²) > 1`——**任何`h`都增长**。

**本仓实测（2026-08-12，40个周期，能量比）**：

| h·ω | `explicit_euler` | `symplectic_euler` | `velocity_verlet` |
|---|---|---|---|
| 0.10 | **7.2e10** | 0.992 | 1.000 |
| 1.99 | 4.3e87 | 3.74 | 0.994 |
| **2.00** | 1.2e88 | **1.3e5** | **1.0000** |
| 2.01 | 6.4e87 | 2.8e23 | 1.3e21 |

两条读出来的结论：

1. 辛的两个**边界正好在2.0**（2.00有界、2.01发散）；
2. `explicit_euler`**在`h·ω=0.1`就已经涨到7.2e10倍**。

**它的`dissipation_accounting`一直写着"能量单调增长（反耗散）"——
所以同一份声明里的两格在讲互相矛盾的故事，而没有任何东西看着这件事。**

**裁**：`explicit_euler`的系数是`None`，`step_bound`改写并说明它此前是误导；
步长顾问对`None`**失败关闭**。

**给个数才是最坏的**——使用者会照着用。

## 三、顾问放`integrate.py`，只吃纯数字

按0052第五节。**本仓实测确认前提成立**：`integrate.py`今天只有4行import，
全是标准库，**包内import为0**。那条独立性意味着积分器可以被单独拿走用——
顾问不该是破它的那个。有一条结构断言常驻守着这一条。

代价如实登记：`ω_max`由调用方自己算，**算错了顾问看不出来**。
唯一的缓解是对非正/非有限入参失败关闭。算`ω_max`的辅助放在接触那边。

## 四、两个界并排给，并说明哪个在管事

顾问返回`StepAdvice`，同时给稳定界与接触分辨界。

**只给一个数会让使用者不知道"再放松一点会先撞上什么"，
而这两个界的失败方式完全不同**：

- 撞**稳定界**是爆掉——**看得见**；
- 撞**分辨界**是静默地算出一个错的恢复系数——**看不见**。

实测：`建议/稳定界 = π/(2N)`，与plans/08那张表逐行对上
（N=2→0.785且恢复系数错14.3%；N=20→0.0785；N=40→0.0393）。
**N≥2时管事的永远是分辨界**，稳定界从来不是那个紧的。

`steps_per_contact`默认20：plans/08实测20步误差1.6e-4，
而O'Sullivan & Bray 2004的`Δt ≤ 0.17·sqrt(m/K)`换算约18.5步——
**同行经验数与本仓实测落在同一格**。

低于4步**失败关闭**：plans/08实测2步/接触时恢复系数是**1.1433**——
大于1，积分误差把能量喂进了碰撞。**一个能算出`e > 1`的配置不该被建议出来。**

  转动的最快模态与线性振子不是一回事（RK4声明里写的2.785是实轴半径，

  **登记在此**，触发条件：第一个需要给转动积分器建议步长的消费方出现时，
  按第二节同样的方法实测，**不许照抄2.785**；

  **登记在此**，触发条件：阶段2加阻尼后若该现象消失或反转，回来查；
