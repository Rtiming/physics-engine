## 二、我自己在派活书里写错了一个数——写代码之前用精确有理算术抓到的

我给轨D2的任务书里第2条判据写的是"滑与不滑的分界`tanθ ≤ 3μ`（经典结果）"。
**那个数是错的**，而且错法很具体：**它是实心圆盘/圆柱的数，不是实心球的**。

用`Fraction`精确算（无浮点）：设`I = k·mR²`，无滑滚下坡有

    a/(g·sinθ) = 1/(1 + k)          所需摩擦 f/(m·g·sinθ) = k/(1 + k)
    无滑条件    f ≤ μN = μ·m·g·cosθ  ⟹  tanθ ≤ (1 + k)/k · μ

| 体 | `k` | `a/(g sinθ)` | 无滑上限 |
|---|---|---|---|
| **实心球** | 2/5 | **5/7** | **tanθ ≤ (7/2)·μ = 3.5μ** |
| 球壳 | 2/3 | 3/5 | tanθ ≤ (5/2)·μ |
| **实心圆盘/柱** | **1/2** | **2/3** | **tanθ ≤ 3·μ** |

**`5/7`与`3μ`不是同一个体的两个数**——`5/7`是实心球，`3μ`是实心圆盘。
实心球的无滑上限是**3.5μ**。

`5/7`那一半我核过，与`research/05`印的一致。**错的只有我加的那半句。**

**这条留在这里不删**，理由与0079那条"文档里的数没人复算过"同源：
**派活方写下的数同样没人复算过**，而这次它差了一个体。
下面第三节的推导因此不引任何现成的数，逐条自己算。

## 三、路径B要判的四条闭式（本页自己推，案例页照抄）

记斜面倾角`θ`、重力`g`、球半径`R`、质量`m`、`I = (2/5)mR²`（**实心球**）。

1. **无滑滚下坡的质心加速度**：`a = (5/7)·g·sinθ`；
2. **维持无滑所需的摩擦力**：`f = (2/7)·m·g·sinθ`（**注意它与`μ`无关**——
   它是"要多少"，不是"有多少"）；
3. **无滑与滑的分界**：`tanθ ≤ (7/2)·μ`；
4. **滑着滚那一支**：摩擦饱和在`μN`，于是
   `a = g(sinθ − μ·cosθ)`、角加速度`α = (5μ·g·cosθ)/(2R)`，
   **两者不再由`a = αR`联系**——那正是"滑了"的可观测定义。

**第4条是本页最要紧的一条设计判据**：`a = αR`成立与否是一个**可测的布尔量**，
它把"无滑"从一个假定变成一件被判的事。轨S在C7那一轮用"锚点动没动"做了同形的事
（不读力、只问一个布尔量），本页照抄那条形制。
