## 一、丙1：力矩装配看到的模态**不是**罚接触的刚度模态

### 1.1 缺的是什么

0083第五节已经在`contact_pipeline`落了一条"h相对接触刚度"的上限
（`CONTACT_STIFFNESS_STEP_BOUND`），并在第八节登记："**两个模块各自需要一条**
（一个是罚接触、一个是力矩装配下的显式积分）"。

**为什么不能照抄那一条**，一句话：**那一层没有杆臂。**

`contact_pipeline`的两端都是绑在**平动**节点上的球，接触力只改质心速度，
于是它的模态永远是一个标量``ω0 = √(1000·k/m_eff)``，`m_eff`是约化质量。
`contact_dynamics`的力作用在一个有杆臂的点上，``τ = r × F``把**同一个力**
送进了转动方程——同一个`k`看到的因此是一个**六维算子**的谱。

### 1.2 推导（模块docstring里写着同一份）

1. 第`i`个支承点的速度``u_i = v + ω × r_i = J_i·(v, ω)``，``J_i = [I₃ | −[r_i]×]``；
2. 该点的接触力``F_i = −κ·P·u_i``（`P`法向取``n̂n̂ᵀ``、切向取``I₃−n̂n̂ᵀ``；
   `κ`法向取`k_n`或`c_n`、切向取`k_t`），广义力旋量``−κ·J_iᵀ P J_i·(v,ω)``；
3. 运动方程``d(v,ω)/dt = 1000·G·W``，``G = diag(I₃/m, I⁻¹)``
   （那个`1000`与`rigidbody`第610/625行是同一个`MM_PER_M`，从`energies`import，
   本模块不自己再写一个）；
4. 速率算子``1000·κ·G·Σ_i J_iᵀ P J_i``。记
   ``ρ = λ(G·Σ J_iᵀ n̂n̂ᵀ J_i)``、``σ = λ(G·Σ J_iᵀ (I₃−n̂n̂ᵀ) J_i)``，单位1/kg；
5. **法向族是二阶的**（有刚度也有阻尼），读法与`contact_pipeline`**逐字相同**：
   ``ω0 = √(1000·k_n·ρ)``、``ζ = (c_n/2)·√(1000·ρ/k_n)``、
   速率取`ω0`（ζ≤1）或``(ζ+√(ζ²−1))·ω0``（ζ>1）。
   ``D_n = (c_n/k_n)·K_n``是**恒等**关系（同一个投影），
   两个算子严格共特征向量，这一步不是近似；
6. **切向族是一阶的**（速度型摩擦只有阻尼没有刚度），速率直接是``1000·k_t·σ``。

单点无杆臂时``ρ → 1/m``、``σ → 1/m``，第5步逐字退化成`contact_pipeline`那条式子，
有一道门钉着（`test_a_single_point_with_no_lever_degenerates_to_the_pipeline_formula`，
`rel = 4e-16`）。**有杆臂时它们分道扬镳，而那正是本条上限存在的理由。**

### 1.3 数值实现的三条选择，逐条给理由

* **对称化走``S = Cᵀ K C``**（``C·Cᵀ = G``）：`G`分块对角、平动块是``I₃/m``、
  转动块是``I⁻¹ = L⁻ᵀL⁻¹``（`L`是`I`的Cholesky因子），所以`C`是**闭式**的。
  ``eig(C Cᵀ K) = eig(Cᵀ K C)``不是近似，是`AB`与`BA`同谱；
* **6×6用循环Jacobi**。`rigidbody._symmetric_eigenvalues`特意避开了迭代，
  理由是"不需要声明迭代到什么时候停"。6×6没有闭式，这条声明躲不掉——
  **那就把它写在明处**：`JACOBI_OFF_DIAGONAL_REL_TOL = 1e-15`、
  `JACOBI_MAX_SWEEPS = 60`，扫满不收敛**失败关闭**；
* **姿态无关的保守上确界**。两个投影都满足``P ⪯ I₃``，于是
  ``Σ J_iᵀ P J_i ⪯ Σ J_iᵀJ_i``，后者不含`n̂`，它的谱是**所有姿态**的上界。
  这一支必须有：上限要在**整条轨迹**上成立，而支承点的体系坐标是常量、
  接触法向在体系里却随姿态转——翻倒那条案例里体真的翻过去了。
  实测本仓那只箱子的底面四角组：精确值272、姿态无关上确界307.5（1/kg），
  **13%的保守换一条全程成立的话**。

### 1.4 支承组：候选池不是"全部声明过的点"

`contact_pipeline`那条纪律是"扫候选池不扫活动集"（撞上的那一帧才发现步长太大已经晚了）。
本模块多一层：**把一只长方体的八个角当成一组是错的另一头**——
八个角永远不可能同时贴同一个平面。实测：

| 分组 | `σ_max`（1/kg） | `k_t = 0.03`下的上限 |
|---|---|---|
| 按面（六组，最紧的是`±z`面） | 307.5（姿态无关） | 3.02e-4 s |
| 八个角当一组 | 480.0 | 1.93e-4 s（**紧了56%**） |

八角一组给的上限比案例实际用的`dt = 2e-4`**还紧**——那会把一条跑得好好的案例
判成不稳定。形制因此是：**调用方声明若干组，每组是一批能同时承载的点，
`tightest_step_bound`取最紧的那组**。一只长方体就是六个面六组。

## 二、丙2：`k_t`的两条硬边界是**同一条判据**，差别只在症状

### 2.1 登记时它们被记成两条不同的东西

* [0082](0082_翻倒进多支承点接触_底面是一组物质点_20260818.md)第五节与案例页第四节第2条：
  "`k_t`大会让**切向阻尼模态的显式稳定上限**压到步长以下……
  四点组的偏航阻尼率是`k_t·Σr⊥²·1000/I_zz`，本几何下`k_t = 0.03`、`dt = 4e-4`时
  它是`2.88 > 2.785`——**实测当场发散**"；
* `cases/rolling_ball_incline`第四节第1条："`k_t = 5e5`与`5e3`时模型进入**颤振区**……
  瞬时切向力被钉在摩擦锥上、`sliding`恒为真"。

两页都写着它们**理由相反**。

### 2.2 实测：同一个`λh > 稳定区半径`，差别只在摩擦锥截没截住

| 案例 | `σ_max`（1/kg） | 声明的`k_t`上限 | 案例取的`k_t` | 实测起点 | 症状 |
|---|---|---|---|---|---|
| 翻倒（四点底面，`dt = 4e-4`） | 272.0 | **0.025597** | 0.03（高17%） | `k_t ∈ [0.028313, 0.028314]`，`λh = 3.0805` | **发散**（横坡角速度到`7.9e-2`／`9.6e-2` rad/s） |
| 翻倒（同上，`dt = 2e-4`） | 272.0 | **0.051195** | 0.03（59%） | — | 稳定（末态横坡角速度`1e-14`量级） |
| 翻倒（二分组两点，`dt = 4e-4`） | 136.0 | **0.051195** | 0.03（59%） | — | 稳定 |
| 滚球（单点，`dt = 1e-6`） | 3.5 | **795.71** | 50（6.3%） | `k_t ∈ [920.618, 920.636]`，`λh = 3.2222` | **颤振**（`sliding`恒为真、平均加速度仍对） |

**结论**：违反它的症状有两种，判据只有一条。切向力没被摩擦锥截住时越界的模态
直接发散；被截住时力钉在`μ|F_n|`上、幅值涨不上去，于是变成绕着摩擦锥的极限环——
那就是"颤振区"。**哪一条更紧由`σ_max`决定，不由症状决定。**

案例页那条"四点与八点两组取`dt = 2e-4`，两点平面组才用`4e-4`"的分法，
本声明**逐条重现**（上表第2、3行）。

### 2.3 声明是**保守的**，保守多少要被量出来

实测起点`λh ≈ 3.08`（翻倒）与`≈ 3.22`（滚球），比2.785松**10.6%**与**15.7%**。
理由：越界之后先饱和的那些支承点不再是线性阻尼器（翻倒那条案例的上坡侧
本来就已经饱和），于是有效算子比线性化的那个软。**保守是安全的那个方向**，
门判的是"保守"这个方向本身（声明放行的最大那个`k_t`实跑必须不发散），
不判那10.6%这个数。

### 2.4 还有一条**下限**，两条夹出来的窗口可以是空的

速度型摩擦的稳态蠕滑是``|v_t| = F_req/k_t``，要它小到能被叫作"粘住"，
`k_t`就必须大——**方向与稳定上界相反**。`creep_resolution_lower_bound`
把它写成``k_t ≥ F_req / v_allowed``，两个输入都必须显式给
（没有一个普适的"够小"）。

实测翻倒那条案例：取案例自己声明的稳态蠕滑1.542040 mm/s
（于是要传的切向力是``2·k_t·v ≈ 0.0925 N``）、允许蠕滑2 mm/s，

| 步长 | 上界 | 下界 | 窗口 |
|---|---|---|---|
| `4e-4` | 0.025597 | 0.046261 | **空的** |
| `2e-4` | 0.051195 | 0.046261 | 非空（很窄） |

**窗口空掉是一条真结论**：这个步长下既想稳又想粘住办不到，要改的是`h`。
而案例当初的办法**正是**把步长压到`2e-4`。

### 2.5 抓到的真缺陷：0082那条式子**只算了偏航模态**

0082第五节与案例页记的`k_t·Σr⊥²·1000/I_zz`是**偏航**（绕接触法向转）那一个模态。
实测它**不是最紧的**：

| 模态 | 迁移率（1/kg） | `k_t = 0.03`下的速率 | `dt = 4e-4`上的`λh` |
|---|---|---|---|
| 平动＋俯仰耦合``N/m + N·h²/I_yy`` | **272.0** | 8160 | **3.264** |
| 偏航``Σr_⊥²/I_zz`` | 240.0 | 7200 | 2.88（0082记的那个数） |

偏航低**13.3%**，于是那条式子给的上限是0.0290——**几乎放行**了实测发散的0.03
（差1.4%）。这是一次典型的**模态枚举不全**：
"看似有一条上限、其实只挡了一半物理"，与research/17第五节抓到`rigidbody`那次同族。

本页的做法因此不是"再补一个模态"，是**算整个六维算子的谱**——
枚举不全这一类错从形制上消掉。

**要主代理代为更正的地方**：`cases/box_tipping_threshold/case.md`第四节第2条
那句"四点组的偏航阻尼率是`k_t·Σr⊥²·1000/I_zz`……它是`2.88`"，
今天的实测是**最紧模态`λh = 3.264`**，偏航那条只是谱里的第三个。
（那份案例页不在本轨的可改清单里，本页只登记。）

### 2.6 顺带一条小出入，如实记下

案例页写`c_n = 0.01`时"约`ζ = 0.4`"，本页按沉浮模态算出来是**0.2**
（``ω0 = 2000``、``ζ = 1000·(4c_n)/(2·m·ω0) = 0.2``）。案例页写的是"约"，
不构成判据，**本页不改它，只记一笔**。

## 四、丙4：收敛阶扫描器，**判据本身先被验**

### 4.1 入口

`tools/convergence_order.py`，形制照`tools/profile_hotspots.py`。两条估计路径：

* **对解析真值**：``e_i = |u(h_i) − u*|``，阶``p = log(e_i/e_{i+1}) / log(h_i/h_{i+1})``；
* **Richardson**（没有真值时唯一能用的）：
  ``p = log(|u_i − u_{i+1}| / |u_{i+1} − u_{i+2}|) / log(h_i/h_{i+1})``。

`verify`子命令把两条路径同时套在`cases/harmonic_oscillator`那条**已知阶**的
解析问题上，三个积分器（显式Euler 1阶／辛Euler 1阶／velocity Verlet 2阶）
逐条对拍。**三条一起判**才排除得掉"永远返回形式阶"这种实现。
本机实测（`--levels 4`，逐条"对真值／Richardson"）：
显式Euler **1.0094／1.0277**、辛Euler **1.0035／1.0102**、
velocity Verlet **2.0000／1.9998**，全部在±0.15内。

### 4.2 实跑抓到一个**会给出漂亮假数**的陷阱

第一版滚球阶梯取``h₀ = 1.2e-5``、``T = 0.02``，于是`T/h`是1666.67、3333.33……
`round`之后各档的真实末时刻差到``±4e-6 s``。球那时正以``2348 mm/s²``加速，
**末时刻差`4e-6 s`就等于速度差`0.0094 mm/s`**——而逐档差实测正是
``0.0144 / 0.0072 / 0.0036 / 0.0018``。

**量到的"一阶收敛"整条是末时刻偏移，一点截断误差都没有。**
它甚至给出了教科书般漂亮的比值（恒为2.0000、四档全同）——
**一个漂亮的数字在这里恰恰是错的那个**。

现在`assert_horizon_is_an_integer_number_of_steps`把它挡在门外。

### 4.3 另外两条护栏，都是被实测逼出来的

* **舍入地板**（`RICHARDSON_NOISE_FLOOR_REL = 2⁻⁴⁰ ≈ 9.1e-13`）：
  差落到它以下时**不报阶**，报一句"这一档的截断误差比双精度还小"。
  实测撞上：滚球无滑支在`T = 4e-3`、`h ≤ 1.25e-5`上逐档差只有`1e-14`量级，
  而一个不判地板的估计器会从那些差里算出`−0.32 / −2.59 / −0.99`这样的"阶"；
* **阶梯要先过丙1那条步长上限**：越界那一档给的不是"误差大一点"而是发散，
  而一条含发散点的阶梯照样拟合得出一个像模像样的阶。

### 4.4 本机小规模的初步结果 —— **非最终**

口径：本机Mac（负载会飘）、`--scale local`、5档步长。
**收敛阶跨机器稳定**（它不是墙钟量），上master只是为了跑得完更细的阶梯。

| 问题 | 阶梯 | 渐近阶 | 逐档差单调？ |
|---|---|---|---|
| `rolling_ball_roll`（μ=0.3，T=4e-3） | 1.25e-5 → 7.8e-7 | **测不出来** | — |
| `rolling_ball_slide`（μ=0.05，T=4e-3） | 同上 | 1.98 | **否** |
| `box_rocking`（20°绕平衡摇摆，T=4e-3，观测`ω_y`） | 5e-5 → 3.1e-6 | 1.23 | **是**（0.96／0.92／1.23） |
| `box_tipping_topple`（32°，T=6e-2） | 2e-4 → 1.25e-5 | −0.25 | **否** |

**逐条怎么读**：

1. **`rolling_ball_roll`测不出来是一条结论**：在案例声明的步长附近，
   沿坡质心速度已经收敛到机器精度（逐档差`1.4e-14`，观测量9.5918）。
   案例的不变性判据因此是**有内容的**——它判的那个量真的不随步长动；
2. **`box_rocking`是唯一一条单调的**，而它量的正是"力矩装配这条路本身"
   （四个角全程承载、没有接触集切换）。实测**约一阶**，不是RK4的形式四阶；
3. 另外两条**不单调、没进渐近区**，本页不把那两个数当收敛阶引用。

### 4.5 一条**否定**的排查结果，如实写

`box_rocking`只有一阶，第一反应是`sphere/support_points`那条**单向法向阻尼**
（"只在压缩时耗散，不在分离时吸住"）在摇摆时每周期两次穿过`normal_speed = 0`，
把右端项打成C0。**离线把`c_n`置零重跑，阶仍然在1.15—2.49之间跳、并不回到四阶**——
**这条假设不成立，或者不是唯一的病因**。

接触律里还有三处同族的分支（`gap >= 0`、`normal_magnitude < 0`、
切向`min(k_t|v_t|, μ|F_n|)`的饱和切换、`slip_speed == 0`），
**哪一处主导没有查清**。登记为GAP（第六节），触发条件写在那里。

### 4.6 要主代理上master跑的那条命令，逐字

```bash
bash tools/master/run_on_master.sh 'python tools/convergence_order.py verify'
bash tools/master/run_on_master.sh 'python tools/convergence_order.py run --problem all --levels 6 --scale full'
```

`--scale full`把时长拉到案例自己那一档（滚球`T = 2e-2`、翻倒`T = 1.5e-1`），
6档步长最细一档要跑十万量级的接触步。**本机跑得动的是`local`那一档。**

## 六、本页登记的GAP（逐条带触发条件）

| GAP | 触发条件 |
|---|---|
| **步长上限不做两族之间的耦合**。法向族与切向族各自在自己的投影上被精确对角化，但完整系统是二次特征值问题``M q̈ + (D_n+D_t) q̇ + K_n q = 0``，两族特征向量一般不重合。**分开算不是保守的**（可能比真值松），今天两条案例上实测都保守 | 第一个把`c_n`与`k_t`调到同一量级的消费方 |
| **不做几何刚度**（杆臂随姿态转出来的那一项）**与陀螺项**。后者由`rigidbody`那条转动模态上限管，两条取更紧的那个；前者在小倾角上是高阶量，**没有量过它多大** | 第一个在大倾角下依赖这条上限的消费方 |
| **上限随姿态变，姿态无关那一支是保守的上确界**（本仓那只箱子松13%）。"扫全姿态求上确界的精确值"没有做 | 第一个嫌那13%太贵的消费方 |
| **`box_rocking`只有一阶，病因没查清**。单向法向阻尼那条假设已被实测否掉（`c_n = 0`仍不回四阶）；接触律里还有`gap >= 0`、`normal_magnitude < 0`、切向饱和切换、`slip_speed == 0`四处同族分支 | 第一个要在接触案例上声称四阶精度的消费方；届时要做的是**逐条关掉分支再测**，而不是换一个更细的阶梯 |
| **两条接触案例的收敛阶在本机小规模上不单调**，本页不把那两个数当收敛阶引用 | 主代理上master跑完`--scale full`；那一档跑完之前plans/16 GAP第1条**只关掉一半**（入口有了、判据自验过了，全规模数还没有） |
| **`drives`那次改动的墙钟没有量** | 主代理上master按0083第七节那套四轮交错量一次 |
| **`k_t`窗口的下界要调用方给`F_req`与`v_allowed`**，本模块不替它猜 | 第一个希望由几何自动推出`F_req`的消费方 |
| **`contact/penalty._frame`（自时间8.4秒）仍未动** | 0083第八节第2条原样保留：`contact/`不在本轨可改清单里，且它在真算几何，要先有一份自己的对拍设计 |
