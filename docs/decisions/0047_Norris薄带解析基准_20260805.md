## 一、公式的出处，与一处**未能定论**的出入

三条公式**逐条去核实过**，不是抄二手。

| 公式 | 采信出处 | 核实结果 |
|---|---|---|
| 片电流分布`K(x)` | W. T. Norris, *J. Phys. D* **3** (1970) 489；写法取自Pardo等arXiv:1410.0772 | **形式一致，式号存疑**：research/12记作式(69)，本轮公开检索到的引用给的是式(67)。**本轮未能定论**，案例页因此只引论文不引式号 |
| Norris薄带交流损耗 | Grilli等arXiv:1306.6251式46 | **形式核实通过**。检索到的等价写法是功率式`P/l = f·μ0·Ic²·g(i)/π`，`g(i) = (1−i)ln(1−i) + (1+i)ln(1+i) − i²`；除以`f`并归一化后恰为`2·g(i)`，**与任务书给的形式逐字一致** |
| Norris椭圆截面交流损耗 | 同上，式47 | **形式核实通过**。等价写法`P/l = f·μ0·Ic²·e(i)/(2π)`，`e(i) = (2−i)·i + 2(1−i)ln(1−i)`；归一化后恰为`e(i)`，同样逐字一致 |

**三条公式一个字都没改。** `b`分母那处（research/12记原文写作`I_m`）
按两个零容差极限反推确认为`Ic`，本仓按`Ic`写——这条判断由电流守恒独立验过。

## 二、本轮**推翻**的三条（两条是research/12的，一条是我自己的）

### 第一条：research/12实测的"薄带`i=1e-3`给3.331e-13"**是数值噪声不是物理**

research/12判据表写：`i=1e-3`时薄带式给`3.331e-13`对`i⁴/3 = 3.333e-13`，
建议rel 1e-3，理由"渐近式的下一阶是`O(i²)`相对修正"。

**实测复现**：那个`3.331e-13`是用`log(1+i)`/`log(1−i)`直接算出来的，
相对偏差6.6e-4——而`O(i²)`修正在`i=1e-3`处只有**4.0e-7**，差三个数量级。
真值（50位算术）是`3.3333346666673814e-13`，相对`i⁴/3`偏离**4.000002e-07**，
与`0.4·i²`吻合到六位。

**那个数是对数相消**：结果`~i⁴/3`而中间项`~i`，相消因子约`6/i³`。
本实现在`i ≤ 0.7`走无相消的幂级数，实测最坏2.36e-15。
**理由栏对薄带是对的，实测数不是。**

### 第二条：椭圆式的下一阶**是`O(i)`不是`O(i²)`**

research/12把两条渐近的理由都写成"下一阶是`O(i²)`相对修正"。
对薄带成立（级数次项`2i⁶/15`比首项`i⁴/3`是`0.4i²`），
**对椭圆不成立**：次项`i⁴/6`比首项`i³/3`是`i/2`。
`i=1e-3`处实测偏离**5.003002e-04**，与`i/2 = 5.0e-04`吻合到四位。

**后果**：两条渐近的容差**必须差三个数量级**（薄带1e-6、椭圆1e-3），
不能像research/12建议的那样共用一个1e-3——共用的话薄带那条余量2500倍，
等于没有判别力。十倍程斜率那两条同理（1e-7对2e-4）。

### 第三条（我自己的）：判据表的expected**第一版写错了位置**

我第一版把渐近判据的expected写成"闭式的实测值"，容差1e-6/1e-3。
写完一测——**余量是无穷大**，因为测量值就是expected本身。
那条判据测的是"闭式还是不是上次那个数"，**渐近这件事一个字也没验到**。

改成expected是幂律断言的那个`1`（以及幂次`4`与`3`），容差承载下一阶。
余量随之落到2.5倍与2.0倍。**"余量算出来是无穷大"是判据失效的信号**，
这条经验值得留下。

另外两处自我推翻：
- `flux_front_positions_m`第一版按"各1 eps"拍了5e-16，`i=0.99`那点**当场红**。
  红得对——`dlnb/dlni = −i²/(1−i²)`在`i=0.99`处是49.25，那条式在那里不是1 eps是50 eps；
- `K`的arctan自变量第一版按原式`sqrt((a²−b²)/(b²−x²))`写，样点最坏1.07e-12。
  改成`(a·i)/sqrt((b−|x|)(b+|x|))`后**4.48e-14**（24倍）：
  `a²−b² = (a·i)²`恒等所以分子无相消，`b−|x|`由Sterbenz引理精确相减。

## 三、必红矩阵：**五种错法 × 五条门，逐格实测**

矩阵冻结在`tests/cases/test_norris_thin_strip.py::RED_MATRIX`，
测试断言的是**整张矩阵逐格一致**而不是"至少一条门红"——
后者会让"哪条门抓住了"无从审计，而这正是本节最值钱的信息。

| 错法 | 分布表 | 电流守恒 | `b`取值表 | **`b`两个零容差极限** | 结构判据 |
|---|---|---|---|---|---|
| `b`漏写`sqrt`：`b = (w/2)(1−i²)` | 红 | 红 | 红 | **绿** | **绿** |
| `arctan`分子分母颠倒 | 红 | 红 | 绿 | **绿** | 红 |
| `2/π`写成`π/2` | 红 | 红 | 绿 | **绿** | 红 |
| `\|x\|<b`与`\|x\|≥b`两支写反 | 红 | 红 | 绿 | **绿** | 红 |
| `b`漏写平方：`b = (w/2)sqrt(1−i)` | 红 | 红 | 红 | **绿** | **绿** |

### 哪条错法没被哪条门抓住——**本节要求点名的那一条**

**`b`公式那一族（漏`sqrt`、漏平方）被两个零容差极限完整放过。**

原因是这一族错法**恰好保住了那两个极限**：
`b = (w/2)(1−i²)`与`b = (w/2)sqrt(1−i)`在`i=0`都给`w/2`、在`i=1`都给`0`，
而且**照样单调递减**。于是零容差极限绿、结构判据也绿，
只有**电流守恒**与`b`取值表红。

这与0022记的那次是同一个形状：
"三条解析退化极限一条都抓不住，只有数值求积抓住"。
**两次的教训一致：退化极限验的是端点，端点上的重合廉价得很。**

反过来：`ratio_inverted`/`two_over_pi_flipped`/`branches_swapped`
三条**完全不碰`b`**，所以`b`的两条门对它们一格都不响；
抓它们的是分布表、电流守恒与结构判据。

**结论：五条门没有一条是多余的，也没有一条能单独成立。**
`front_limits`那一列**全绿**——它在本矩阵里一格都没抓住，
但它守的是另一件事（`b`公式的**形式**由这两个极限反推出来，见第一节），
所以留着，并且在模块docstring与案例页里都写明了它抓不住什么。

另外两条不在矩阵里但一并验了红：
公开签名出现裸参数名（无单位后缀又未声明无量纲）当场红；
公开函数名不带返回值单位后缀当场红。

## 四、材料记录装不下`Jc`/`Ic`——**实测、拒收点、以及规则1今天成不成立**

### 4.1 我需要哪些材料属性

### 4.3 顺带实测出来的一个**洞**（不在任务范围内，但必须报）

尝试2与尝试4是**同一个物理量的两种写法**（体电流密度与片电流密度），
判决却相反：

- `..._a_per_m`（`per_m`）→ 被长度制隔离**拒收**（正确）；
- `..._a_per_m2`（`per_m2`）→ **放行**（错误）。

原因：`materials._SYSTEM_SUFFIXES["m"]`只枚举了`{m, m2, m3, per_m}`，
**没有`per_m2`**，于是米制的`per_m2`字段能悄悄进一条mm制记录。
这正是spec/14第五节要防的那类静默——**而且它是2026-08-05修`per_`那个1e12方向错
时没有一并补上的同一处**（那次修的是`unit_suffix_of`的判定，
`_SYSTEM_SUFFIXES`的枚举没跟着补）。

尝试5还暴露了第二个形状：`resistivity_ohm_m`能通过单位后缀检查，
**是因为它以`_m`结尾被当成了长度**，然后又因为"是米制"被长度制隔离拒掉。
**拒得对，但理由是错的**——`Ω·m`不是长度。换个名字（`resistivity_ohm_metre`）
它会因为"没有单位后缀"被拒；写成mm制（`resistivity_ohm_mm`）它会被放行，
而那个换算因子`1e3`与电阻率的正确换算恰好一致纯属巧合。

`converted_to`那一条（尝试7）也是**对得偶然**：换算表里
`("per_m","mm") → ("per_mm", 1e-3)`是为`长度⁻¹`写的，
对`A/m`恰好也对——因为安培不随长度制变。**换成`A/m²`它就没有登记项、会拒**
（那是`per_m2`，表里没有），**而拒是对的**；但如果哪天有人顺手补上
`("per_m2","mm") → ("per_mm2", 1e-6)`，那对`A/m²`是对的、对`Ω·m²`是错的。
**这条边界上"猜因子"的风险是真的，spec/14第五节不猜的原则应当保住。**

### 4.4 我怎么处理的——**是临时避开，不是长期方案**

本轨道的处理：`Jc`、`d`、`Kc`、`Ic`是**案例的输入常数**
（写在`generate_oracle.py`的模块级常量与`oracle.json`的`inputs`里），
模块把`Kc`/`Ic`收成**显式函数参数**。

**我没有做的三件事**（总指挥点名禁止的三条，逐条对照）：
- 没有把`Jc`/`Ic`硬编码进案例**并假装不需要材料记录**——
  案例页第一节与第四节都写明它们本该进记录、今天进不去；
- 没有另起平行的电磁材料通道——`electromagnetics/`里**一行材料读写代码都没有**；
- 没有改隔离规则、没有改`BASE_UNIT_SUFFIXES`、没有改`_SYSTEM_SUFFIXES`。

**定性：临时避开。** 它只在本案例这种"输入是构型不是物性"的场合站得住——
本案例算的是一个闭式，`Jc`取多少不影响判据成立与否（判据全是无量纲的
或按`Kc`归一化的）。**一旦有第二个消费方要问"这卷带材的`Ic`是多少"，

**绊线已经埋好**（`tests/test_superconductor.py`两条门）：

  断言`critical_current_a`仍被拒。缺口补上那天它红，**红了就回来改本节**；
- `test_the_length_system_check_still_lets_an_area_denominator_through`：
  断言4.3那个洞仍在。补上那天它红。

### 4.5 **spec/14规则1那条设计意图今天成立不成立？**

**不成立。** 而且比research/07记的更彻底。

规则1写的是"一份记录聚合多域字段，域是属性的标签不是记录的分块"，
理由是`thickness_mm`同时进力学与光学，分块形制下要写两遍、两遍就会漂移。
**这个理由在力学↔光学之间成立**（两者都在长度量纲上，
且光学域显式走`converted_to("m")`那条安全带）。

**它在力学↔电磁之间整条断掉**，两个独立的原因：

1. **单位后缀集里没有电学单位**。这不是"某个字段名不好听"，
   是**整个域的所有物性字段一个都进不来**：`Ic`(A)、`Jc`(A/m²)、
   `ρ`(Ω·m)、`σ`(S/m)、`Br`(T)、`μr`(无量纲，得显式声明)。
   今天能混进去的只有那些**恰好以已登记后缀结尾**的名字，
   而它们进得去是靠误判（4.3那两条）不是靠支持。
2. **长度制隔离把它挡在门外**。电磁量天然米制，力学记录是mm制，
   `_check_length_system`按设计拒收。这一条**是对的**——
   它防的正是silent 1000。但它的后果是：
   **同一块铜的杨氏模量与电阻率永远进不了同一条记录**，
   除非整条记录改成米制（那力学侧就得全改）或者电阻率改成mm制
   （那是个没人写的单位）。

**所以规则1今天的状态是：一条写在规范里、有理由、但没有任何实现能满足的规则。**
按总指挥的话——**这比没有这条规则更糟，它让人以为这件事已经解决了。**
research/07审计时判的是"同一块铜的杨氏模量与电导率放不进同一条记录"，
本轮把它推进了一步：**不是放不进同一条，是电磁属性根本进不了任何一条**
（除非撒谎说它无量纲，尝试6实测可行）。

**我没有硬做。** 三条选法与后果列在第六节交给用户裁。

## 五、三条边界（任务书要求如实写进案例页与本页，不许软化）

1. **本案例不进0040的成功标准分母。** 它验公式不验引擎——
   今天`shapes`里没有"带材"、`state`里没有电流自由度、`solve`里没有电磁求解器，
   这条案例算的是一个独立闭式，不经过引擎的状态与求解器。
   **这一条写在案例页最顶上的引用块里**，就在标题下面第一眼能看见的位置，
   免得将来被当成"引擎能算超导了"。
   research/12第4.1节A4已先写下这一句，案例页原样重复。
2. **幂律指数`n`"典型20—30"标《未核实》。** research/12核不到权威出处；
   核到的是Pardo等取`n = 1000`模拟临界态、扫描`n = 5…200`、以及一份实测`n = 15`。
   本模块与本案例**都不使用`n`**（临界态是`n → ∞`的极限）。
   `tests/test_superconductor.py::test_the_unverified_n_value_never_appears_without_its_marker`
   按字符窗扫本轨道全部产物，**任何一处"20—30"附近500字符内没有《未核实》就红**——
   research/09价格条那次"未核实的数脱离标记被转述"的事故，这次用门堵。
3. **临界态（Bean）模型本身是理想化。** 它假设`Jc`与局部磁场无关
   （真实REBCO的`Jc(B, θ)`随场显著下降、各向异性可达数倍）、忽略磁通蠕动、
   带材无限薄无限长、无邻近导体、无外加磁场、只有单调加载的传输电流。
   **本案例不检验这些假设中的任何一条**，只检验"在这些假设下那条闭式算得对"。
   适用边界写在模块docstring最前面与案例页第六节。

## 六、要用户裁的四件事
