## 一、过阻尼分支`ζ ≥ 1`的恢复系数

### 1.1 接触段的解：三段

接触段（重叠`δ > 0`期间）的方程与初条件：

    m·δ'' + c·δ' + k·δ = 0,   δ(0) = 0,  δ'(0) = v0 > 0
    ω0 = sqrt(k/m),  ζ = c/(2·sqrt(mk)),  β = ζ·ω0

（任务书写的是`x(0) = 0, x'(0) = −v_in`。两者差一个整体符号`x = −δ`，
而`e = |x'(t_end)|/v_in`对整体符号不敏感，故两种写法同解。
`v0`只出现在整体因子上，所以纯LSD、无重力时`e`与入射速度无关——research/13第4.1节。）

特征根`s = −β ± sqrt(β² − ω0²) = ω0·(−ζ ± sqrt(ζ²−1))`，三段：

**（a）`ζ < 1`欠阻尼**，`ωd = ω0·sqrt(1−ζ²)`：

    δ(t)  = (v0/ωd)·e^(−βt)·sin(ωd·t)
    δ'(t) = v0·e^(−βt)·[cos(ωd·t) − (β/ωd)·sin(ωd·t)]

**（b）`ζ = 1`临界阻尼**，重根`−ω0`：

    δ(t)  = v0·t·e^(−ω0·t)
    δ'(t) = v0·e^(−ω0·t)·(1 − ω0·t)

**（c）`ζ > 1`过阻尼**，`ωh = ω0·sqrt(ζ²−1)`（双实根`−β ± ωh`）：

    δ(t)  = (v0/ωh)·e^(−βt)·sinh(ωh·t)
    δ'(t) = v0·e^(−βt)·[cosh(ωh·t) − (β/ωh)·sinh(ωh·t)]

**一条随手可查、后面要反复用的不等式**：`β² − ωh² = ω0²ζ² − ω0²(ζ²−1) = ω0²`，
故`β > ωh > 0`恒成立。两个实根都是负的，且慢根是`−(β − ωh)`。

### 1.2 约定A（重叠归零）：`ζ ≥ 1`根本没有有限的接触结束时刻

`ζ > 1`时`δ(t) = (v0/ωh)·e^(−βt)·sinh(ωh·t)`，而`t > 0`上`sinh > 0`、`e^(−βt) > 0`，
**故`δ(t) > 0`恒成立——重叠再也回不到零**。`ζ = 1`时`δ = v0·t·e^(−ω0t) > 0`同理。

而速度按两个模态拆开：

    δ'(t) = v0·[ ½(1 − β/ωh)·e^(−(β−ωh)t) + ½(1 + β/ωh)·e^(−(β+ωh)t) ]

因`β > ωh`，两个指数都是负的，故`δ'(t) → 0`（从负侧趋近，因为`1 − β/ωh < 0`）。

**结论：约定A在`ζ ≥ 1`上`t_end = ∞`、`e = 0`。**
这不是"恢复系数很小"，是**物体粘住了**——接触段末尾整段靠拉力（吸引）把它拽着，
而拉力永远不消失。**约定A的过阻尼分支不可用**，这本身就是
0052第一节选截断约定的理由在极端参数下的加强版。

**实测**（RK4积到`t = 60/ω0`，见1.5节）：`ζ = 1.5`时`δ`一直为正、`δ'`一直为负，
两者按`e^(−(β−ωh)t)`同步衰减；`δ'/δ`实测`−0.381966`，
而`−(β−ωh)/ω0 = −(1.5 − sqrt(1.25)) = −0.3819660`。

### 1.3 约定B（力归零，本仓采用）：闭式

合力`F = k·δ + c·δ' = m·(ω0²·δ + 2β·δ')`。令`F = 0`，除掉`v0·e^(−βt)/ωh`：

    (ω0² − 2β²)·sinh(ωh·t) + 2β·ωh·cosh(ωh·t) = 0
    ⟹ tanh(ωh·t_c) = 2β·ωh / (2β² − ω0²) = 2ζ·sqrt(ζ²−1) / (2ζ² − 1)

**根的存在性不是"看着像"，是一个恒等式**：

    (2ζ² − 1)² − [2ζ·sqrt(ζ²−1)]² = (4ζ⁴ − 4ζ² + 1) − (4ζ⁴ − 4ζ²) = 1

差**恰为1**，故右端严格小于1，`tanh`有唯一正根。（`ζ > 1`时`2ζ² − 1 > 1 > 0`，
分母恒正，不存在换支问题。）而且`ω0² − 2β² < 0`、`tanh`单调，
括号里的量从`+2βωh`单调降到`ω0² − 2β² + 2βωh`，**符号只翻一次**——
所以这个根就是接触段里的第一个、也是唯一一个。

同一个恒等式还给出`1 − tanh² = 1/(2ζ²−1)²`，于是

    cosh(ωh·t_c) = 2ζ² − 1,    sinh(ωh·t_c) = 2ζ·sqrt(ζ²−1)

（互相验证：`cosh² − sinh² = (2ζ²−1)² − 4ζ²(ζ²−1) = 1` ✓）

代回速度的括号因子：

    cosh − (β/ωh)·sinh = (2ζ²−1) − [ζ/sqrt(ζ²−1)]·2ζ·sqrt(ζ²−1) = 2ζ² − 1 − 2ζ² = −1

**括号因子恰为`−1`**，故`|δ'(t_c)| = v0·e^(−β·t_c)`——分离速度**就落在包络线上**。

最后化简`ωh·t_c`。令`p = ζ + sqrt(ζ²−1)`，则`1/p = ζ − sqrt(ζ²−1)`、
`p² = 2ζ²−1 + 2ζ·sqrt(ζ²−1)`。由`tanh u = T`得`e^(2u) = (1+T)/(1−T) = p²/p^(−2) = p⁴`，故

    ωh·t_c = 2·ln p = 2·arcosh ζ

于是**过阻尼分支的闭式**：

$$
e = \exp\left[-\frac{2\zeta\,\operatorname{arcosh}\zeta}{\sqrt{\zeta^{2}-1}}\right]
= \exp\left[-\frac{2\zeta\,\ln\!\left(\zeta+\sqrt{\zeta^{2}-1}\right)}{\sqrt{\zeta^{2}-1}}\right]
\qquad (\zeta>1)
$$

**临界阻尼`ζ = 1`单独推一遍**（不靠取极限）：

    F/m = ω0²·v0·t·e^(−ω0t) + 2ω0·v0·e^(−ω0t)·(1 − ω0t)
        = v0·ω0·e^(−ω0t)·(2 − ω0·t)
    ⟹ ω0·t_c = 2,   δ'(t_c) = v0·e^(−2)·(1 − 2) = −v0·e^(−2)

$$
e\big|_{\zeta=1} = \exp(-2) = 0.135335283236612691
$$

括号因子`(1 − ω0 t_c) = −1`，**与另外两段一样**。

### 1.4 三段其实是同一条：连接

先把欠阻尼那条写法统一。由`arcsin ζ + arccos ζ = π/2`：

    π − 2·arcsin ζ = 2·arccos ζ

于是三段的**无量纲接触时长**排成一列，形状完全平行：

| 分支 | 无量纲接触时长 | 恢复系数（约定B） |
|---|---|---|
| `ζ < 1` | `ωd·t_c = 2·arccos ζ` | `exp[−2ζ·arccos(ζ)/sqrt(1−ζ²)]` |
| `ζ = 1` | `ω0·t_c = 2` | `exp(−2)` |
| `ζ > 1` | `ωh·t_c = 2·arcosh ζ` | `exp[−2ζ·arcosh(ζ)/sqrt(ζ²−1)]` |

**这三行不是拼接，是一条实解析函数。** 令

$$
f(\zeta)=\frac{\arccos\zeta}{\sqrt{1-\zeta^{2}}},\qquad e=\exp\left[-2\zeta f(\zeta)\right]
$$

换元`ζ = cos θ`得`f = θ/sin θ`，是`θ²`的解析函数；而`1 − ζ = θ²/2 − θ⁴/24 + …`
可逆解出`θ²`是`(1−ζ)`的解析函数。故`f`在`ζ = 1`处解析，`f(1) = 1`。
`ζ > 1`只是`θ`变成纯虚数，`arccos → i·arcosh`、`sqrt(1−ζ²) → i·sqrt(ζ²−1)`，
两个`i`约掉。**`ζ = 1`处没有折点、没有分支切换的痕迹**——
这与research/13第4.3节订正过的那件事同源：调研报告说的`ζ = 1/sqrt(2)`"分支边界"
是`arctan`主值的人为产物；这里的`ζ = 1`同样不是真的边界。

还有一条比三条闭式更好记、也更好验的写法。**三段的括号因子都恰为`−1`**，所以

$$
\left|\delta'(t_{\text{end}})\right| = v_{0}\cdot\exp\left(-\zeta\,\omega_{0}\,t_{\text{end}}\right)
$$

**分离速度永远落在包络线`v0·e^(−βt)`上**——约定A的`ζ < 1`也满足
（那里`ωd·t_c = π`，括号因子`= cos π = −1`）。两个约定的差别**全部**在`t_end`里，
一点都不在别处。实测`|δ'(t_end)| / exp(−ζ·t_end)`在两个约定、七个采样点上
**偏差≤5.4e-12**（残余来自二分定`t_end`的精度经`exp`放大，不是这条式子本身）。

### 1.6 `ζ → ∞`时`e`去哪：**截断约定下恢复系数的绝对下界**

把闭式在大`ζ`处展开。`ζ/sqrt(ζ²−1) = 1 + 1/(2ζ²) + O(ζ⁻⁴)`，
`arcosh ζ = ln(2ζ) − 1/(4ζ²) + O(ζ⁻⁴)`，故指数

    2ζ·arcosh(ζ)/sqrt(ζ²−1) = 2·ln(2ζ) + ln(2ζ)/ζ² − 1/(2ζ²) + O(ζ⁻⁴·ln ζ)

$$
e \;\longrightarrow\; \frac{1}{4\zeta^{2}} \qquad (\zeta\to\infty)
$$

**实测`e·4ζ²`**：`ζ = 10`给0.975174、`ζ = 100`给0.999520、`ζ = 10⁴`给1.000000、
`ζ = 10⁸`给1.000000。**一阶收敛到1，二次衰减律成立。**

**于是本节要回答的那个问题**：

> **截断约定下恢复系数的下确界是`0`，不可达，没有正的下界。**
> 全`ζ`轴（`ζ ∈ (0, ∞)`）上的值域是**开区间`(0, 1)`**，两端都取不到。

单调性：对数网格20万点扫`ζ ∈ [1e−6, 1e4]`（**跨越`ζ = 1`**），
**非单调点0个**；`e(1e−6) = 0.999996858414281`、`e(1e4) = 2.500000e−09`。

**`exp(−2) = 0.1353352832`是什么**：它是`ζ < 1`分支的下界，
也是`ζ = 1`处的取值，**不是绝对下界**。0052第一节"代价二"写的
"截断式在`ζ ∈ (0,1)`上的值域是`(0.135335, 1)`"**是对的**，
0052第九节第2条也已声明"下界0.1353只在`ζ < 1`内成立"。
**本页做的是把那个限定摘掉，不是推翻它。**

2. 落在`ζ ≥ 1`时**约定A完全不可用**（`e = 0`且接触永不结束），

   那个档在`ζ ≥ 1`上是没有定义的，必须失败关闭**；
3. `ζ`大意味着接触时长短、系统更刚：`ωh·t_c = 2·arcosh ζ`而`ωh ≈ ζ·ω0`，

```python
"""三段闭式 vs RK4独立积分。"""
import math

def tau(zeta):  # 无量纲接触时长（约定B：力归零）
    if zeta < 1.0:
        return 2.0 * math.acos(zeta) / math.sqrt(1.0 - zeta * zeta)
    if zeta == 1.0:
        return 2.0
    return 2.0 * math.acosh(zeta) / math.sqrt(zeta * zeta - 1.0)

def e_closed(zeta):
    return math.exp(-zeta * tau(zeta))

# 独立数值积分：m=1, k=1 => x'' = -2*zeta*x' - x, x(0)=0, x'(0)=1
def rk4(x, v, h, z):
    def f(x_, v_):
        return v_, -2.0 * z * v_ - x_
    a1, b1 = f(x, v)
    a2, b2 = f(x + 0.5 * h * a1, v + 0.5 * h * b1)
    a3, b3 = f(x + 0.5 * h * a2, v + 0.5 * h * b2)
    a4, b4 = f(x + h * a3, v + h * b3)
    return (x + h * (a1 + 2 * a2 + 2 * a3 + a4) / 6,
            v + h * (b1 + 2 * b2 + 2 * b3 + b4) / 6)

def e_numeric(z, convention="B", n=3000, t_max=4000.0):
    g = (lambda x, v: x) if convention == "A" else (lambda x, v: x + 2.0 * z * v)
    h = 1.0 / ((z + math.sqrt(abs(z * z - 1.0)) + 1.0) * n)  # 步长只由特征根量级定
    x, v = rk4(0.0, 1.0, h, z)
    t = h
    while t < t_max:
        xn, vn = rk4(x, v, h, z)
        if g(x, v) > 0.0 >= g(xn, vn):
            lo, hi = 0.0, h
            for _ in range(200):
                mid = 0.5 * (lo + hi)
                xm, vm = rk4(x, v, mid, z)
                lo, hi = (mid, hi) if g(xm, vm) > 0.0 else (lo, mid)
            xe, ve = rk4(x, v, 0.5 * (lo + hi), z)
            return abs(ve), t + 0.5 * (lo + hi)
        x, v, t = xn, vn, t + h
    return None, None  # 没有有限根

if __name__ == "__main__":
    print(f"{'zeta':>10} {'e闭式':>22} {'e数值RK4':>22} {'|偏差|':>10} {'t_end偏差':>10}")
    for z in [0.05, 0.5, 0.9, 0.999, 1.0, 1.001, 1.1, 1.5, 3.0, 10.0, 100.0, 1000.0]:
        ec, (en, tn) = e_closed(z), e_numeric(z)
        print(f"{z:>10g} {ec:>22.15e} {en:>22.15e} "
              f"{abs(en - ec):>10.2e} {abs(tn - tau(z)):>10.2e}")
    print("约定A在 zeta>=1 无有限根：",
          [e_numeric(z, "A", n=800, t_max=400.0) for z in (1.0, 1.5, 3.0)])
    print("zeta->inf: e*4*zeta^2 = " + " ".join(
        f"{z:g}:{e_closed(z) * 4 * z * z:.6f}" for z in (10, 1e2, 1e4, 1e8)))
```

## 二、research/13第五节那张表：带重力重做

**结论**：原表三行**全错**，真值是表中值的**2.398倍、1.104倍、1.010倍**。
错因就是那一节自己登记的第②条——**表里没有重力，而接触段一直有重力**。
含重力的接触段是`δ'' + ω0²·δ = g`，解是绕`δ_eq = mg/k`的简谐，故

$$
\delta_{\max} = \delta_{\text{eq}} + \sqrt{\delta_{\text{eq}}^{2} + \left(v_{0}/\omega_{0}\right)^{2}}
$$

**这条修正对"比值"是加性的`≈ +1`**：令`R = v0·ω0/g`（原表那一列给的正是`R`），
则真比值`= 1 + sqrt(1 + R²) → R + 1 + 1/(2R)`。
所以它**只在`R = O(1)`的低刚度档要命**（`k = 1e2`那行`R = 1.01`，错2.4倍），
高刚度档自动消失（`k = 1e6`那行`R = 101`，只错1%）。
**而那正是原表用来展示"比值≈1"的那一行。**

```python
"""带重力的瞬态穿透，独立RK4。参数从原表反解：m=1 kg, g=9.81, 落高0.05 m。"""
import math

M, G = 1.0, 9.81
V0 = math.sqrt(2.0 * G * 0.05)

def closed(k, gravity):        # 闭式（被验对象）
    w = math.sqrt(k / M)
    d_eq = M * gravity / k
    return d_eq + math.hypot(d_eq, V0 / w)

def rk4_dmax(k, gravity, n=400_000):   # 独立积分 d'' = gravity - (k/M)*d，二分定 d'=0
    def step(d, u, h):
        def f(d_, u_):
            return u_, gravity - (k / M) * d_
        a1, b1 = f(d, u)
        a2, b2 = f(d + 0.5 * h * a1, u + 0.5 * h * b1)
        a3, b3 = f(d + 0.5 * h * a2, u + 0.5 * h * b2)
        a4, b4 = f(d + h * a3, u + h * b3)
        return (d + h * (a1 + 2 * a2 + 2 * a3 + a4) / 6,
                u + h * (b1 + 2 * b2 + 2 * b3 + b4) / 6)
    h, d, u = (2 * math.pi / math.sqrt(k / M)) / n, 0.0, V0
    for _ in range(n):
        dn, un = step(d, u, h)
        if un <= 0.0 < u:
            lo, hi = 0.0, h
            for _ in range(200):
                mid = 0.5 * (lo + hi)
                lo, hi = (mid, hi) if step(d, u, mid)[1] > 0.0 else (lo, mid)
            return step(d, u, 0.5 * (lo + hi))[0]
        d, u = dn, un
    raise RuntimeError

if __name__ == "__main__":
    old = {1.0e2: (9.905e-02, 9.810e-02), 1.0e4: (9.905e-03, 9.810e-04),
           1.0e6: (9.905e-04, 9.810e-06)}
    for k, (d_old, nk) in old.items():

        print(f"k={k:.0e} 原={d_old:.3e} 真闭式={c:.9e} 真RK4={n:.9e} "
```

## 三、三球金字塔：`μc = 2−√3`的独立复核

**本节没有读`cases/three_sphere_pyramid/`的实现再复述它**——那不叫复核。
下面从几何与静力学重推，最后才把结果拿去和`oracle.json`对拍。

### 3.1 设定与未知量

等径`r`、等质量（自重`W`）的三个球，平面（`x`-`z`）问题：

    顶球  T  = (0, r(1+√3))
    底球  BR = (r, r)          BL = (−r, r)
    球-球接触点  (±r/2, r(2+√3)/2)      球-地接触点  (±r, 0)
    单位法向（底球指向顶球）  n_R = (−1/2, √3/2)   n_L = (1/2, √3/2)

**先查两件几何**（精确有理算术，不是"约等于"）：
连心距的平方`= r² + 3r² = 4r²`，**恰好相切**；
且**两底球心距的平方也是`4r²`——它们互相也相切**。
（后一条是本节比research/13第二节多出来的一个必须处理的接触，见3.3节前提三。）

未知量**8个**（不预设对称）：两个球-球接触各`(F_n, f_t)`、两个球-地接触各`(N, T)`。
方程**9条**：三个刚体各`ΣFx = 0`、`ΣFz = 0`、`ΣM = 0`（**含力矩平衡**，
这正是research/13第二节无摩擦变体丢掉的那三条）。

### 3.2 精确解

**符号级核验**：在`Q(√3)`（形如`a + b√3`，`a`、`b`是`Fraction`）上做精确高斯消元，
**全程没有浮点**。

    9方程 / 8未知   精确秩 = 8   相容 = True

**秩8 = 未知数个数 ⟹ 解唯一，问题静定。**（第9条方程是冗余的：
构型镜像对称，而顶球在对称面上，它的`ΣFx`与`ΣM`自动满足。）
**"加摩擦后静定"这句话本身也被复核了**——research/13第二节说
"我没有独立复核那个秩分析本身"，现在复核了。

精确解（以`W`为单位）：

| 量 | 精确值 | 数值 |
|---|---|---|
| 球-球法向`F_n` | `1/2` | 0.500000000000000·W |
| 球-球切向`f_t` | `1 − (1/2)√3` | 0.133974596215561·W |
| 球-地法向`N` | `3/2` | 1.500000000000000·W |
| 球-地切向`T` | `−1 + (1/2)√3` | −0.133974596215561·W |

`F_n = W/2`与`N = 3W/2`都是**有理数**，一眼可查：
`N = 3W/2`就是"三个球的总重`3W`由两个地面接触对半分"。

**对称性是解出来的不是假设的**：`F1 − F2 = 0`、`f1 − f2 = 0`、
`N1 − N2 = 0`、`T1 − T2 = 0`，四个差**精确为0**。
（research/13第二节与`case.md`第四节第7条都记过"对称性没有被独立验证"——
这里对**带摩擦**那一支验了；无摩擦变体同法可验，见3.4节。）

**两个摩擦需求**（精确）：

$$
\frac{|f_t|}{F_n} = 2-\sqrt{3},\qquad
\frac{|T|}{N} = \frac{2-\sqrt{3}}{3}
$$

两条都是**精确相等**（`Q(√3)`上逐位相同，不是"差很小"）。故取统一的`μ`时

$$
\mu_c=\max\left\{2-\sqrt{3},\ \frac{2-\sqrt{3}}{3}\right\}=2-\sqrt{3}\approx 0.26794919243112281
$$

**浮点差 = 0.0e+00。** **卡住的是球-球接触，不是地面**——地面只需要`0.0893`，
比球-球宽松3倍。（这一条推导之前没人写过：如果将来有人给两处接触配**不同**的`μ`，
判据要拆成两条，`μc`这一个数就不够用了。）

**与无摩擦变体的比**：`0.26794919 / 0.19245009 = 1.392305`，
与research/13第二节记的"1.392倍"一致。

**浮点独立复核**（不同算术、不同实现）：把同一个9×8矩阵交给`numpy`，
`matrix_rank = 8`、最小奇异值`0.354`（离奇异很远，秩不是数值巧合）、
最小二乘残差`max|A·u − b| = 6.66e-16`（**非零就说明9条方程不相容**）、
与精确解的最大差`8.88e-16`。

### 3.3 三个必须写明的前提

**前提一：点接触不传力偶。** 球-球与球-地都只传法向力与切向力，
没有滚动阻力、没有自旋摩擦力偶。这是标准假定，但它是`ΣM = 0`那三条方程的形状来源。

**前提二：平面问题。** 面外的切向分量与自旋按对称性为零。三维下要另算。

**前提三（本节自己发现、原推导没提的）：两底球之间的接触必须是不传力的。**
3.1节查出两底球**恰好相切**，所以那是一个**真实存在的接触点**。
如果它传力，未知数变成10、方程仍是9，**问题立刻变超静定，`μc`这个闭式就没了**。
它不传力的理由要算出来：解中顶球给右底球的水平分量是

    F_n·(−n_Rx) + f_t·(−t_Rx) = +0.133975·W  > 0（指向 +x，即向外）

**顶球把两个底球往外推 ⟹ 它们之间的间隙张开 ⟹ 单边接触分离 ⟹ 不传力。**
（`case.md`第四节第6条写了"底球之间的接触被略去"，理由记的是数值奇异；
**这里补上的是静力学理由**——它不是被略去，它是真的不传力。
两条理由都成立，但只有后一条能支撑"静定"这个结论。）

**三个量里`N`两个模型完全相同**（`3W/2`，竖直平衡不经过接触角），
`F`与`T`不同：**加摩擦改的是力怎么分，不改总的竖直承载**。

**顺带把无摩擦变体那条未平衡力矩也算了**：该解下右底球对球心的合力矩
精确为`−(1/6)√3·W·r = −0.288675134594813·W·r`，
而`√3/6 = 0.288675134594813`——**与`case.md`第四节第1条登记的
`M_y = −(√3/6)·W·r`逐位相同（差0.00e+00）**。
即：**无摩擦变体对可转动的刚体球确实不是平衡态**，那条已登记的失效声明成立。

## 五、方法上的两条

**第一条：这一页有一个结论是靠"把值域算全"才出现的。**

**第二条：第三节那个"两底球也相切"是几何自检查出来的，不是读出来的。**

```python
"""三球金字塔 mu_c 的精确复核：Q(sqrt3)精确算术 + 9方程/8未知完整刚体平衡。"""
from fractions import Fraction as F


class Q3:  # a + b*sqrt(3)
    def __init__(s, a=0, b=0):
        s.a, s.b = F(a), F(b)

    def __add__(s, o):
        o = q(o)
        return Q3(s.a + o.a, s.b + o.b)

    __radd__ = __add__

    def __neg__(s):
        return Q3(-s.a, -s.b)

    def __sub__(s, o):
        return s + (-q(o))

    def __rsub__(s, o):
        return q(o) + (-s)

    def __mul__(s, o):
        o = q(o)
        return Q3(s.a * o.a + 3 * s.b * o.b, s.a * o.b + s.b * o.a)

    __rmul__ = __mul__

    def inv(s):
        d = s.a * s.a - 3 * s.b * s.b
        return Q3(s.a / d, -s.b / d)

    def __truediv__(s, o):
        return s * q(o).inv()

    def __eq__(s, o):
        o = q(o)
        return s.a == o.a and s.b == o.b

    def z(s):
        return s.a == 0 and s.b == 0

    def f(s):
        return float(s.a) + float(s.b) * 3.0 ** 0.5

    def __repr__(s):
        return f"{s.a}" if s.b == 0 else (f"{s.b}√3" if s.a == 0 else f"({s.a}+{s.b}√3)")


def q(v):
    return v if isinstance(v, Q3) else Q3(v)


S, H = Q3(0, 1), Q3(F(1, 2))            # sqrt(3), 1/2  （取 r = 1, W = 1）
T_C, BR, BL = (Q3(0), Q3(1) + S), (Q3(1), Q3(1)), (Q3(-1), Q3(1))   # 三个球心
P_R, P_L = (H, Q3(1) + S * H), (-H, Q3(1) + S * H)                  # 球-球接触点
G_R, G_L = (Q3(1), Q3(0)), (Q3(-1), Q3(0))                          # 球-地接触点
nR, nL = (-H, S * H), (H, S * H)        # 单位法向：底球 -> 顶球
tR, tL = (S * H, H), (-S * H, H)        # 单位切向（镜像对）
eR, eL = (Q3(1), Q3(0)), (Q3(-1), Q3(0))  # 地面摩擦方向（镜像对）
U = ["F1", "f1", "F2", "f2", "N1", "T1", "N2", "T2"]


def M(c, p, fx, fz):                    # 对球心 c 的力矩，力(fx,fz)作用在 p
    return (p[0] - c[0]) * fz - (p[1] - c[1]) * fx


def build():
    rows, rhs = [], []

    def add(d, r):
        row = [Q3(0)] * 8
        for k, v in d.items():
            row[U.index(k)] = q(v)
        rows.append(row)
        rhs.append(q(r))

    add({"F1": nR[0], "f1": tR[0], "F2": nL[0], "f2": tL[0]}, 0)          # 顶球 Fx
    add({"F1": nR[1], "f1": tR[1], "F2": nL[1], "f2": tL[1]}, 1)          # 顶球 Fz = W
    add({"F1": M(T_C, P_R, *nR), "f1": M(T_C, P_R, *tR),
         "F2": M(T_C, P_L, *nL), "f2": M(T_C, P_L, *tL)}, 0)             # 顶球 M
    for i, (c, p, n, t, g, e) in enumerate(
        ((BR, P_R, nR, tR, G_R, eR), (BL, P_L, nL, tL, G_L, eL)), start=1
    ):
        fn, ft, nn, tt = f"F{i}", f"f{i}", f"N{i}", f"T{i}"
        add({fn: -n[0], ft: -t[0], tt: e[0]}, 0)                          # 底球 Fx
        add({fn: -n[1], ft: -t[1], nn: 1}, 1)                             # 底球 Fz = W
        add({fn: -M(c, p, *n), ft: -M(c, p, *t),
             nn: M(c, g, Q3(0), Q3(1)), tt: M(c, g, *e)}, 0)              # 底球 M
    return rows, rhs


def solve(rows, rhs, n):
    aug = [list(r) + [rhs[i]] for i, r in enumerate(rows)]
    piv, row = [], 0
    for col in range(n):
        p = next((r for r in range(row, len(aug)) if not aug[r][col].z()), None)
        if p is None:
            continue
        aug[row], aug[p] = aug[p], aug[row]
        inv = aug[row][col].inv()
        aug[row] = [v * inv for v in aug[row]]
        for r in range(len(aug)):
            if r != row and not aug[r][col].z():
                fac = aug[r][col]
                aug[r] = [aug[r][k] - fac * aug[row][k] for k in range(n + 1)]
        piv.append(col)
        row += 1
    bad = [r for r in range(len(piv), len(aug))
           if all(aug[r][k].z() for k in range(n)) and not aug[r][n].z()]
    sol = [Q3(0)] * n
    for i, c in enumerate(piv):
        sol[c] = aug[i][n]
    return sol, len(piv), not bad


if __name__ == "__main__":
    rows, rhs = build()
    sol, rank, ok = solve(rows, rhs, 8)
    s = dict(zip(U, sol))
    print(f"9方程/8未知  精确秩={rank}  相容={ok}")
    for k in U:
        print(f"  {k:>3} = {str(s[k]):>14} = {s[k].f(): .15f}·W")
    mu_s, mu_g = s["f1"] / s["F1"], s["T1"] / s["N1"]
    print(f"球-球 |f|/F = {mu_s}  精确等于 2−√3 ? {mu_s == Q3(2, -1)}")
    print(f"球-地 |T|/N = {-mu_g}  精确等于 (2−√3)/3 ? {-mu_g == Q3(2, -1) / 3}")
    print(f"mu_c = {max(abs(mu_s.f()), abs(mu_g.f())):.17f}   "
          f"2−√3 = {2 - 3 ** 0.5:.17f}   差 = {abs(abs(mu_s.f()) - (2 - 3 ** 0.5)):.1e}")
    fx = s["F1"] * (-nR[0]) + s["f1"] * (-tR[0])
    print(f"顶球给右底球的水平分量 = {fx.f():+.6f}·W > 0 ⟹ 两底球互相分离、该接触不传力")
```
