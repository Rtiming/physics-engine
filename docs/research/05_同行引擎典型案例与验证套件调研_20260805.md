# 同行引擎的典型案例与验证套件调研（2026-08-05）

目的：给decisions/0015第二条（案例是一等交付物、允许复用同行、下载同行库做对比实验）
提供证据。三问：同行把什么当标准案例、判据强度如何、验证套件这件工程本身怎么组织。

## 一、最重要的一条结论：同行的"案例"绝大多数没有硬判据

调研覆盖MuJoCo（含MJX/Menagerie）、Bullet/PyBullet、PhysX、Project Chrono、Drake、
Genesis、Warp/Newton、ODE、PyElastica、SOFA、FEBio、libuipc、HCIPy/POPPY/prysm。
**"随仓库发布的案例"与"能当门用的案例"是两回事**，判据强度差三个量级：

| 强度 | 判据 | 代表 |
|---|---|---|
| 1 最强 | **解析闭式解** | Drake `multibody/benchmarks/`——唯一把解析解做成独立库的一家：无力矩轴对称刚体（Kane 1983 §1.13/§3.1）、质量-阻尼-弹簧、斜面、acrobot、摆 |
| 2 | **跨实现参考数据对拍** | Chrono `data/testing/joints/` 264个文件的ADAMS参考数据，每案例八通道（Pos/Vel/Acc/Quat/Avel/Aacc/Rforce/Rtorque），**且把生成金标的`.adm`输入卡一起入库**；Genesis `tests/rigid/test_mujoco_parity.py`直接拿MuJoCo当oracle |
| 3 | **守恒量漂移** | MuJoCo的`dzhanibekov.xml`、`pendulum.xml`；Newton的`example_basic_dzhanibekov.py` |
| 4 | **自洽性** | MuJoCo `ForwardInverseMatch`正逆动力学往返；ODE `demo_I.cpp`多质点等效惯量对单刚体 |
| 5 最弱 | **定性观察/不炸** | PhysX snippets、Bullet ExampleBrowser、Havok/Unity样例——绝大多数属这一类 |

**反面教材要记住**：PyElastica的`examples/`只判"脚本退出码为0"
（`run_all_examples.sh`），25个案例目录的README全是0字节。案例目录不等于验证套件。

## 二、可直接复用的案例（按我们的三档划分）

### 2.1 只需碰撞查询、不需要积分器的（A档，本仓今天就能跑）

来源FCL、libccd、Ericson《Real-Time Collision Detection》、Arvo《Graphics Gems》：

- **球/胶囊解析距离与穿透**：`d = segdist − (r1+r2)`，闭式，机器精度；
  FCL `test_fcl_sphere_capsule.cpp`是同一件事的C++版；
- **线段-线段五条退化分支**：两段退化为点、单段退化为点、平行、`t<0`钳制、`t>1`钳制；
- **闭式解对暴力网格最小值**：独立代码路径，误差随网格`N`二阶下降；
- **旋转AABB闭式对拍**（Arvo）：对**中心-半边长分解**成立——
  `c' = R·c + t`、`h'_i = Σ_j |R_ij|·h_j`，其中`c=(lo+hi)/2`、`h=(hi−lo)/2`。
  注意：局部AABB不居中时不能直接对`hi`用该式，这是易错点；
- **broad ⊇ narrow超集不变量**：可证命题（AABB是保守外包），
  `separation < 0 ⟹ AABB相交`，反例必须为零。这是换SAP/BVH那天唯一不能破的承诺；
- **球-盒解析距离**：`d = |p − clamp(p, lo, hi)| − r`，覆盖面/棱/角三类最近特征；
- **SAT十五轴OBB**（Gottschalk-Lin-Manocha SIGGRAPH 1996）：3+3面法向+9边叉积，一条不能少；
- **naive broad phase冻结为金标**：FCL把六种broadphase manager塞进同一列表逐个对拍，
  暴力实现就是金标——本仓`collision.py`的O(n²)天然就是这个角色。

### 2.2 加一个积分器就能跑的（B档）

- **弹道自由飞行**：velocity Verlet对常加速度**精确**；半隐式Euler误差**恰为**`a·T·h/2`
  ——判据可以钉到误差常数本身，比"误差随h线性下降"强得多；
- **无阻尼谐振子**：阶数（Verlet误差随h减半降4倍）+ 漂移排序
  （MuJoCo `engine_forward_test.cc`形制：判据是积分器之间的**相对优劣**，
  不随机器/编译器漂移，并先断言`drift != 0`防"全零假通过"）；
- **复合刚体惯量自洽**（ODE `demo_I.cpp`）：离散质点求和张量对解析张量，纯代数不需积分器；
- **无力矩轴对称自由刚体**（Drake `free_body`）：进动率`λ = ω3·(Ia−It)/It`，
  三维转动**唯一有闭式解**的案例；
- **Dzhanibekov中间轴翻转**：MuJoCo/Bullet/PhysX/Newton四家独立实现，
  是区分"游戏引擎"与"机器人引擎"最便宜的单体测试
  （PhysX与Havok都忽略陀螺项，Erez 2015据此判PhysX不适合精度敏感的机器人应用）；
- **扫掠隧穿与TOI**：`v·h > t + 2r`必穿透，球-平面TOI闭式。

### 2.3 需要真求解器的（C档，判据来自杆/梁族与光学族）

杆梁族（与WDS的DER带材同族，PyElastica/Gazzola 2018/Bergou 2008）：
Timoshenko悬臂（`αc=4/3`，L∞与L1一阶收敛）、大挠度悬臂对椭圆积分（Bisshopp-Drucker 1945）、
自重悬臂`δ_tip = qL⁴/(8EI)`、Euler屈曲`Fc = π²EI/(bL)²`、
Michell失稳临界扭转`Φc = 2√3·π·α/β`、局部螺旋屈曲包络。
接触族：三球金字塔双向摩擦判据（Chrono `utest_DEM_pyramid.cpp`——
同一模型只改摩擦系数，一边必须撑住、一边必须塌，本次调研里判据设计最好的一条）、
斜面滑动阈值`θc = arctan(μs)`与无滑滚球`a = (5/7)g·sinθ`、恢复系数弹跳。
光学族：艾里斑`E(x) = 2·J1(x)/x`首零`x = 3.8317059702`、
FTS仪器线型`FWHM = 1.20671/(2·OPD_max)`、Norton-Beer切趾系数各组`Σ Ci = 1`、
变换层自洽三件套（通量守恒/MFT-FFT等价/往返可逆）。

**重要提醒**：C档的判据本仓大半已经在消费方仓里跑着了——WDS有B1—B6、C1绞盘、
C1-d横漂、X2各向异性摩擦、free_rod六道门、自重悬臂闭式解与跨求解器对拍。
引擎仓要做的不是重新发明这些案例，是给它们一个版本化的oracle清单面（轴7至今零代码）。

## 三、验证套件这件工程本身：五条可照抄的形制

1. **布局（Chrono）**：验证案例收编回主仓，`src/tests/unit_tests/<域>/`与
   `src/tests/benchmark_tests/<域>/`平级，参考数据进`data/testing/`，
   **并把生成金标的输入卡一起入库**——金标因此可重生成、可审计。
   `chrono-validation`独立仓已被官方标注Obsolete，独立仓路线是被同行走过又放弃的。
2. **测试组织（MuJoCo）**：`test/`镜像`src/`，每个子目录自带`testdata/`，
   benchmark与test平级但独立文件名后缀；skip名单每条带一行理由。
3. **金标形制（FEBio TestSuite）**：**只比确定性整数**（时间步数、迭代总数、
   RHS求值次数、刚度重构次数、plot文件字节数），零容差，跨平台靠三份表分家
   而不是靠放宽容差，子进程锁`OMP_NUM_THREADS=1`。这是浮点跨平台问题的
   主流答案：**换比较对象，不是放大容差**。
4. **容差声明（GROMACS）**：按物理量成对声明rel/abs**并写理由**，
   参考数据按单双精度分`reference_s/_d`，留一个全局`tolerance_factor`总开关。
5. **金标更新闭环（FEBio `acceptChanges.py` + GROMACS `-ref-data update-changed`）**：
   只覆盖失配项、保留仍在容差内的旧值（避免金文件被浮点噪声搅动）、
   打印Old/New对照、固定提交message。这正是把轴7规则5（重生成金标须走决策记录）
   从口号变成机制的现成实现。

## 四、性能门：同行的答案是"不进CI"

这一节直接关系0014与spec/13。量化事实：

- GitHub托管runner的墙钟变异系数**CV = 2.66%**；配2%阈值假阳率**45%**；
  压到1%假阳需要约7%的门——**等于测不到小回退**。
- **Drake**在`multibody/benchmarking/README.md`里明写该基准
  "不作为性能回退测试"；**MuJoCo的CI干脆不跑benchmark**。

三条替代路：①受控本机实验脚本（Drake `benchmark_tool.py`：关turbo+绑核，
实测把6%波动压到0.5%）；②**确定性代理量**（指令数计数噪声约1e-6%，
或FEBio式的整数计数器）；③时间序列变点检测（MongoDB E-Divisive，AUC 95.8%）。

**对本仓的含义**：spec/13声明的延迟预算（import 110ms、`pe-scene validate` 0.22s、
wheel 30KB）应由受控本机脚本测量并产报告，门里放**确定性整数计数器**。
本仓恰好有天然的整数计数器：AABB测试次数、narrow调用次数、事件分类计数、
规范化产物字节长度、run package文件数——其中AABB测试次数就是算法工作量的直接代理，
换SAP/BVH那天它必变。

## 五、守恒量当自动断言的三种写法

- **无参考自洽断言（Chrono）**：能量漂移RMS ≤ 1e-2、约束违背RMS ≤ 1e-5；
- **排序断言（MuJoCo）**：`|E_RK4| < |E_implicit| < |E_Euler|`，配`EXPECT_NE`防全零假通过；
  以及单调不增断言：每步`E < 1.01·E₀`并**报出破的步号**；
- **正逆往返（MuJoCo fwdinv）**：每步自比。

## 六、Erez/Tassa/Todorov 2015的口径（引擎对比论文，全文核实）

ICRA 2015 pp.4397-4404。四个主模型：Grasping（35-DOF仿Shadow Hand抓胶囊）、
Humanoid（25-DOF）、Planar Chain（5刚体5铰，**守恒动能与角动量**）、
27 Capsules（162 DOF堆叠）。衍生：Astronaut（去重力去地面→守恒动量）。

**准确性判据不是解析解而是"自洽性"**：用`h = 1/64 ms`积分得参考轨迹，
再把`h`按2的幂增到32 ms，测位置相对参考的偏差，在10段轨迹片段上平均。
论文明说这么做是因为"典型机器人系统不保守能量、动量、辛形式或任何已知量"。

**模型限制值得抄**：只允许hinge关节（外加free joint）；碰撞几何**只有球、胶囊、
固定地面**（明确排除box与mesh，理由是"mesh碰撞是需要自己一套对比框架的复杂话题"）；
接触只有库仑摩擦。——一个严肃的跨引擎对比，其几何词汇比我们现在的还窄。

## 七、同行库对比实验的合规与可复现（0015张力B的落实）

- **许可证要先查**：WDS已有先例并已立边界——GPL类来源（dismech-python、
  discrete-elastic-ribbon）只作对拍**不得复制代码**，可复制来源限MIT/Apache。
  PyElastica（MIT）是WDS唯一真正的第三方库oracle（其B6、X2）。
- **版本必须钉死**：对拍产物的manifest要携带同行库版本、安装方式、平台与BLAS实现
  （spec/13第三节`runtime_environment`的自然延伸）。
- **入库素材**一律附来源URL+版本+SHA；照Chrono形制，生成金标的输入卡与脚本一起入库。
