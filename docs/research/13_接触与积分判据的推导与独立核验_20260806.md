## 一、斜面滑动阈值：θc = arctan(μs)

### 推导

面法向`n = (sinθ, 0, cosθ)`，下坡切向`d = (cosθ, 0, −sinθ)`，`n·d = 0`。
重力`F = (0, 0, −W)`，`W = mg`：

    法向分量  N = −F·n = W·cosθ
    切向分量  T =  F·d = W·sinθ

库仑粘着条件`T ≤ μs·N`：

    W·sinθ ≤ μs·W·cosθ   ⟺   tanθ ≤ μs   ⟺   θ ≤ θc = arctan(μs)

### 核验（符号级）

`W`在不等式两边**恒等约掉**，`T/N = tanθ`是精确有理数（取`tanθ`有理时）。
**这是符号级结论，不是数值巧合**：阈值与`m`、`g`、以及罚刚度`k`全部无关——
`k`的约掉发生在平衡条件`k·δ = 力`里。

**本仓实测**（三个自由度全放开，走完`state→energies→solve`）：
五档倾角的`N`、`T`对闭式偏差**≤3.3e-16（1—2 ulp）**；
阈值扫描`θc ± 1e-7°`两侧判别相反。

## 二、三球金字塔临界摩擦：μc = 1/(3√3) = √3/9

### 几何（精确）

等径`r`，两底球贴地相切、球心`(±r, 0, r)`；顶球卧槽、球心`(0, 0, r + √3·r)`。
连心距`sqrt(r² + 3r²) = 2r` ✓（恰好相切）。
连心线单位方向`(1/2, 0, √3/2)`，模长精确为1，与水平成**60°**。

### 静力（球-球无摩擦，只沿连心线传力）

顶球竖直平衡（两个对称接触，竖直分量`√3/2`）：

    2·F·(√3/2) = W    ⟹   F = W/√3

底球（受顶球反作用`F`、自重`W`、地面法向`N`与摩擦`T`）：

    竖直：N = W + F·(√3/2) = W + (W/√3)(√3/2) = W + W/2 = 3W/2
    水平：T = F·(1/2) = W/(2√3)

粘住条件`T ≤ μ·N`：

    W/(2√3) ≤ μ·(3W/2)   ⟹   μ ≥ 1/(3√3) = √3/9 ≈ 0.19245008972987526

### 核验

**符号级**：`N/W`算得**恰为1.5**（差0.00e+00）；`μc`对`1/(3√3)`差**2.78e-17**、
对`√3/9`差5.55e-17（两者互差1 ulp，是同一个数的两种写法）。
`W`在`T/N`里精确约掉 ⟹ **μc只由几何定**。

**本仓实测**：`T/N`在`k=2e7`时对闭式相对偏差5.4e-08，
且**该偏差随`k`一阶消失**（刚度涨10倍偏差降10.00/10.50倍——**订正：其中10.50整个是浮点噪声**，对抗审核用40位精度独立解非线性平衡得到精确比值恒为10.000，而`k=2e7`档的实测5.394e-08已被污染4.8%）——
**那是罚柔度不是实现错误**（穿透改变接触几何本身——**理由在`case.md`第二节，不在本页第五节**；本页初稿这个交叉引用指错了，第五节讲的是瞬态与准静态穿透律，与接触几何无关）。

### 边界（必须写明）

**这条推导有两个前提，缺一条`μc = 1/(3√3)`就不成立。**

**前提一：球-球接触无摩擦。**

**前提二：转动不参与。** 这一条是2026-08-06对抗审核抓到的——**本页初稿漏了它**。
对底球球心取矩，重力与球-球力都过心，只有地面摩擦有矩：

**即这个构型对可转动的刚体球根本不是平衡态。**

## 三、库仑摩擦迟滞回线的耗散：W = 4·T_max·(u_max − u_y)

### 推导

弹性-理想塑性滑块（切向刚度`k_t`串联库仑滑块，限`T_max = μN`），
屈服位移`u_y = T_max/k_t`。稳态回线是平行四边形：

    卸载支：u 从 u_max 到 u_max−2u_y，T 从 +T_max 线性降到 −T_max（跨度恰 2u_y）
            其后 T ≡ −T_max 直到 −u_max
    加载支：对称

上支积分（从`−u_max`到`+u_max`）：线性段均值为零，其余段恒为`+T_max`：

    ∫上 = 0 + T_max·(2u_max − 2u_y)
    ∫下 = 0 + (−T_max)·(2u_max − 2u_y)
    面积 = ∫上 − ∫下 = 4·T_max·(u_max − u_y)

### 核验（符号级）

用`Fraction`做精确有理算术，三个幅值（2/5/20倍`u_y`）的分段积分与闭式
**逐位相等**（`精确相等 = True`，不是"差很小"）。

**本仓实测**：三个幅值的数值梯形积分对闭式偏差**0.00e+00**，
而那个零有解释——回线分段线性、梯形在线性段上精确，且步数取5的倍数让拐点
**恰落在步长边界**；用不整除的步数复验给1.0e-06—1.35e-05，**机械是真的**。

## 四、线性弹簧-阻尼器的恢复系数：**两个约定，两条闭式**

**这是本页最要紧的一节。** plans/08初稿把其中一条当成无条件成立写进了判据。

### 4.1 接触段的解

    m·δ'' + c·δ' + k·δ = 0,   δ(0) = 0,  δ'(0) = v0
    ω0 = sqrt(k/m),  ζ = c/(2·sqrt(mk)),  β = ζ·ω0,  ωd = ω0·sqrt(1−ζ²)

    δ(t)  = (v0/ωd)·e^(−βt)·sin(ωd·t)
    δ'(t) = v0·e^(−βt)·[cos(ωd·t) − (β/ωd)·sin(ωd·t)]

`v0`只出现在整体因子上 ⟹ **`e`与入射速度无关**（对纯LSD、无重力）。

### 4.2 约定①：接触结束 = **重叠归零**

`δ = 0`的首个正根是半周期：`ωd·t_c = π`，故`t_c = π/ωd`。代入：

    |δ'(t_c)| = v0·e^(−β·t_c)
    e = exp(−β·π/ωd) = exp( −ζ·π / sqrt(1−ζ²) )

### 4.3 约定②：接触结束 = **合力归零**

**这一条是Schwager & Pöschel（2007）的订正**：在重叠归零那一瞬，
阻尼项让合力`F = kδ + cδ'`已经变成**拉力**（吸引），
所以按重叠定义碰撞时长"**定性地不正确**"。

    F = m·[ω0²·δ + 2β·δ'] = 0
    ⟹ ((ω0²−2β²)/ωd)·sin(ωd·t) + 2β·cos(ωd·t) = 0
    ⟹ tan(ωd·t_c) = −2β·ωd/(ω0²−2β²)

关键的一步代换（**本页自己做的，不引用**）：

    ω0² − 2β² = ω0²(1−2ζ²) = ω0²·cos(2·arcsin ζ)
    2β·ωd     = 2ζ·sqrt(1−ζ²)·ω0² = ω0²·sin(2·arcsin ζ)

    ⟹ tan(ωd·t_c) = −tan(2·arcsin ζ)  ⟹  ωd·t_c = π − 2·arcsin ζ

    ⟹ e = exp[ −(ζ/sqrt(1−ζ²))·(π − 2·arcsin ζ) ]

**一处订正**：调研报告说这条在`ζ = 1/√2`处有"分支边界"。
**没有**——那是用`arctan`主值带来的人为分支。写成`2·arcsin ζ`
（等价于用`atan2`）在`ζ ∈ (0,1)`上**处处连续**，实测在`ζ = 1/√2`处也光滑。

**临界阻尼极限**（本页自己求的）：令`ζ = cos ε`，则`sqrt(1−ζ²) = sin ε`、
`π − 2·arcsin ζ = 2ε`，故指数 → `(cos ε/sin ε)·2ε → 2`：

    ζ → 1 时  e → exp(−2) ≈ 0.1353352832

**即临界阻尼下恢复系数不是0。** 这是两个约定的**定性**分歧，不是精度差别。

### 4.5 这对判据的含义（**必须在写案例前裁**）

- **不截断拉力** ⟹ 约定①的闭式精确成立，但分离前有一小段拉力（物理上是吸引）；
- **截断拉力**（LIGGGHTS的`limitForce`、LAMMPS的`limit_damping`）⟹ 约定①**不再成立**，
  两家文档都警告"**声明的恢复系数只是近似的，低`e`时尤甚**"。

**两条都对，钉错了会把一个正确实现判红。**

### 4.5b 本节整节只覆盖`ζ < 1`——过阻尼分支2026-08-12已补

**上面4.1—4.4的每一条都带着一个没写出来的前提：`ζ < 1`**
（`ωd = ω0·sqrt(1−ζ²)`在`ζ ≥ 1`是虚的）。
[0052](../decisions/0052_阶段1至3开工前的七条裁决_20260812.md)第一节把它列为阻塞项。

**已补，见[research/15](15_过阻尼分支与推导补全_20260812.md)第一节。** 三句摘要：

1. **约定②（截断）三段的接触结束时刻形状完全平行**：
   `ωd·t_c = 2·arccos ζ`（`ζ<1`，与4.3节的`π − 2arcsin ζ`是同一个数）、
   `ω0·t_c = 2`（`ζ=1`）、`ωh·t_c = 2·arcosh ζ`（`ζ>1`），
   而三段的**括号因子都恰为`−1`**，故统一有`|δ'(t_end)| = v0·exp(−ζ·ω0·t_end)`；
2. **约定①（重叠归零）在`ζ ≥ 1`上根本没有有限根**——`sinh > 0`使重叠再也回不到零，
   `t_end = ∞`、`e = 0`，**物体被拉力粘住**。该分支在约定①下不可用；
3. **约定②下`e`没有正的下界**：`ζ → ∞`时`e ~ 1/(4ζ²) → 0`，
   全轴值域是开区间`(0, 1)`。`exp(−2) = 0.1353`是**`ζ<1`分支**的下界，不是绝对下界。

### 4.6 反解式（生产代码实际实现的那一条）

使用者声明的是`e`不是`ζ`。反解约定①：

    ζ = (−ln e)/sqrt(π² + ln²e)
    c = 2·sqrt(m_eff·k)·(−ln e)/sqrt(π² + ln²e)

**核验**：`e → c → ζ → e`往返，四个目标值偏差**≤2.8e-17**（三个恰为0）。

### 4.7 接触时长的第二种写法

    t_c = π/ωd = sqrt( m·(π² + ln²e)/k )

**核验**：三档ζ两式差**0.0e+00**（逐位相同）。

## 五、瞬态穿透 vs 准静态穿透：**两条不同的律**

### 推导

**准静态**（平衡）：`k·δ = N = mg` ⟹ `δ = mg/k`，即`O(1/k)`。

**瞬态冲击**（无阻尼，入射速度`v0`）：接触段`δ(t) = (v0/ω0)·sin(ω0·t)`，故

    δ_max = v0/ω0 = v0·sqrt(m/k)，即 O(k^(−1/2))

两者之比`= v0·sqrt(k/m)/g`，**随`k`按sqrt发散**。

## 六、总弹跳时间与总路程

### 推导（等比级数）

首落时间`t0 = sqrt(2h/g)`。第n次弹跳的往返时间`2·e^n·t0`，故

    T = t0 + Σ(n≥1) 2·e^n·t0 = t0·(1 + 2e/(1−e)) = t0·(1+e)/(1−e)
    S = h + Σ(n≥1) 2·h·e^(2n)  = h·(1 + 2e²/(1−e²)) = h·(1+e²)/(1−e²)

**弹跳次数无穷而总时间有限**——这是等比级数收敛的直接结果。

### 核验

闭式对4000项级数求和：`e=0.5`与`e=0.8`两组，`T`差**0.0e+00**、`S`差≤2.2e-16。
文献算例（h=1 m、e=0.5、g=9.8）：本页闭式给**1.3553 s / 1.6667 m**，
文献给"1.36 s / 1.67 m" ✓。

## 七、Newmark与HHT-α：稳定性与阶

### 7.1 放大矩阵（本页自己构造）

无阻尼SDOF`x'' + ω²x = 0`，`Ω = ωh`，状态`(x, hv, h²a)`。Newmark：

    x1  = x + hv + h²(1/2−β)a + h²β·a1
    hv1 = hv + h²(1−γ)a + h²γ·a1
    h²a1 = −Ω²·x1

消去`a1`得`3×3`放大矩阵，谱半径由特征多项式求根。

### 7.2 核验结果

| 格式 | ρ(Ω=0.1) | ρ(Ω=10) | ρ(Ω=1e4) | 实测阶 |
|---|---|---|---|---|
| 平均加速度 γ=1/2 β=1/4 | 1.000000 | 1.000000 | **1.000000** | 2 |
| 线性加速度 γ=1/2 β=1/6 | 1.000000 | 3.363026 | **3.732050（发散）** | 2 |
| 带耗散 γ=0.6 β=0.3025 | 0.999501 | 0.824621 | 0.818182 | **1.0092** |
| 后向Euler型 γ=3/2 β=1 | 0.995037 | 0.099504 | 0.000100 | 1 |

**第二行推翻一句常见的话**："隐式 ⟹ 无条件稳定"是假的。
线性加速度Newmark是隐式而**只条件稳定**。

### 7.3 无条件稳定的**锐**条件是 2β ≥ γ ≥ 1/2

对每个`γ`二分求最小`β`（判据：`ρ ≤ 1`在`Ω = 1…1e5`六档同时成立）：

| γ | 实测最小β | γ/2 | (γ+½)²/4 |
|---|---|---|---|
| 0.5 | 0.250000000 | 0.250000000 | 0.250000 |
| 0.6 | 0.300000000 | 0.300000000 | 0.302500 |
| 0.7 | 0.350000000 | 0.350000000 | 0.360000 |
| 1.0 | 0.500000000 | 0.500000000 | 0.562500 |

**实测最小β恰为γ/2**（二分精度1e-10）。
`β ≥ (γ+½)²/4`是**充分不必要**——它标的是特征根重合（`ρ_∞`取最小）的那个`β`，
两者只在`γ = 1/2`时重合。

### 7.4 线性加速度的临界Ω

二分求`ρ ≤ 1`的上界：**实测 Ω_c = 3.464101615138**，
而`2√3 = 3.464101615138`，**差 4.4e-16**（机器精度）。

### 7.5 HHT-α

`γ = 1/2 − α`、`β = (1−α)²/4`，运动方程`M·a1 + (1+α)·K·x1 − α·K·x0 = 0`。
**放大矩阵由数值构造**（对三个基向量各走一步），不引用任何公式：

| α | ρ(Ω=10) | ρ(Ω=1e6) | (1+α)/(1−α) | 实测阶 |
|---|---|---|---|---|
| 0 | 1.0000000 | 1.0000000 | 1.000000000 | 2.0000 |
| −0.05 | 0.9131683 | 0.9047628 | 0.904761905 | 2.0000 |
| −0.10 | 0.8378028 | 0.8181840 | 0.818181818 | 2.0000 |
| −1/3 | 0.6825284 | 0.5000780 | 0.500000000 | 1.9999 |

`ρ_∞ = (1+α)/(1−α)`**在`Ω = 1e6`处吻合到6—7位**（趋于极限，未完全收敛属正常）。

**一处值得记的反差**（本页核验的）：`γ=0.6, β=0.3025`**就是**HHT `α=−0.1`的参数。
配上`α=−0.1`时阶是**2.0000**；当**纯Newmark**用（`α=0`）时阶掉到**1.0092**。
**同一组数，差一个量级的行为**——这解释了为什么"带耗散的Newmark掉到一阶"
与"HHT带耗散仍是二阶"两句话可以同时为真。
