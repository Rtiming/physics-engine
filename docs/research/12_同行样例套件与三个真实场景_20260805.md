# 同行样例套件与三个真实场景（2026-08-05）

用户问的是两件事，本页分开答：

1. **"其他的那种像英伟达的、还有那个soft的那种，他们用的是什么样的样例？"**
   ——同行随产品发布的**样例套件**（sample/demo/example suite）长什么样；
2. **"给我们也加一点样例，必须确保这种案例能跑通。"**
   ——按plans/04那三个真实场景，我们今天能立哪些**真跑得通**的案例。

## 零、本页与research/05的分工（先说清，免得两页打架）

research/05调研的是"**验证案例**"——有硬判据、能当门用的那批。
本页调研的是"**样例套件**"——同行发给用户看"这个引擎能干什么"的那批。

两者形制不同：research/05第一节已判定样例的典型判据是最弱一档
（"定性观察/不炸"）。本轮**逐条读代码核实了这一判断，并把它量化了**：

| 产品 | 样例条数 | 有数值判据的 | 最强判据 |
|---|---|---|---|
| PhysX 5 snippets | 73 | **0** | 无 |
| Warp（1.15） | 57 | **0**（`fem/`全部无assert） | 无 |
| Newton | 107 | **1条是真解析对拍**，另约十余条是包络断言 | 角度RMS 0.02° |
| SOFA | 474个`.scn` | 87个有回归阈值（**自产金标**），1个目录叫`Validation` | 状态阈值1e-4 |

所以本页多回答一问，这一问research/05没答：
**哪些同行样例值得升格成有判据的案例，怎么升**（第四节第三小节）。

## 一、NVIDIA系：四个产品，形制完全不同

### 1.1 最要紧的一条结构变化：Warp的物理已经整块搬走了

`warp.sim`在**Warp 1.10.0（2025-11）被删除**，CHANGELOG原文：
"Remove `warp.sim` module and related examples. This module has been superseded
by the Newton library, a separate package with a new API."

后果是**今天`warp/examples/`下已经没有`sim/`目录**（本轮用GitHub API核实：
`warp/examples/`只剩`core`、`fem`、`optim`、`tile`、`benchmarks`、
`distributed`、`interop`、`cpp`）。
**凡是引"Warp的刚体/布料样例"的资料都已过期**——那些样例现在叫Newton。

这条对我们有直接含义：NVIDIA把"GPU编程与PDE内核"（Warp）和
"物理引擎"（Newton）拆成了两个产品，**样例套件也跟着拆**。
这与本仓spec/15"域边界靠依赖图守"的做法是同一类动作，只是切在更高一层。

### 1.2 PhysX 5 SDK snippets：73条，碰撞查询占最大头，判据为零

目录79个，除`compiler`/`graphics`/`media`三个非样例目录与
`snippetcommon`/`snippetutils`/`snippetrender`三个共用件，实际样例73条。
主题分布（本轮逐目录点名统计）：

**颗粒堆积／料斗／漏斗：0条。** **带数值判据的：0条。**

它是PhysX 5相对PhysX 4最实的一条几何新路，**也正是场景三"不规则模型"的答案**
（见第三节3.3）。

**最有信息量的一条：`snippetgyroscopic`**。
research/05第2.2节引Erez 2015：PhysX与Havok都忽略陀螺项，
论文据此判PhysX不适合精度敏感的机器人应用。**PhysX 5现在专门给陀螺项配了一条snippet。**
——同行被一篇对比论文点名之后十年，把那一条补上并做成了样例。
这说明**一条设计得好的对比案例真的会改变别人的产品**，不只是打分。

### 1.3 Warp：57条，全是PDE与GPU编程，零刚体、零判据

| 子目录 | 条数 | 内容 |
|---|---|---|
| `core` | 20 | GPU编程范式为主：内存分配器、CUDA图捕获、自旋锁、工作队列、torch/cupy互操作；物理只有DEM 1条、SPH 1条、波动1条、二维流体2条 |
| `fem` | 23 | 有限元：扩散3、对流扩散2、Navier-Stokes 3（含Taylor-Green、Kelvin-Helmholtz）、Stokes 2、Burgers 1、浅水1、APIC流体2、Darcy 1、**静磁1**、混合弹性1、形状优化2、其余网格与后处理 |

**刚体堆叠0、关节机器人0、布料0、接触密集0**——全部在1.10.0搬去了Newton。
Warp剩下的物理是**连续介质PDE**。

**最独特的一条：`fem/example_magnetostatics.py`**。
它解的是"铜线圈绕圆柱铁芯、径向电流"的三维静磁，
方程写在文件头：`1/mu Curl B + j = 0`、`Div B = 0`，
用**磁矢势A的H(curl)协调空间、Nédélec一类棱边元**。

这一条对我们特别重要，因为：
- 它**同时命中用户的场景一与场景二**（线圈、铁芯、静磁）；
- 它用的正是research/08第1.3节说的棱边元（节点元产生伪模态、棱边元不会）；
- **它没有任何assert、没有任何参考值、没有任何容差**（本轮读源核实）。

也就是说：**同行手里离我们两个电磁场景最近的那条样例，判据是零。**
这条事实值得记住——它说明"同行有样例"不等于"同行给了我们oracle"。

#### Newton的判据强度：分三层，逐条读过

**底层（覆盖全部107条）**：`newton/tests/test_examples.py`只断言子进程退出码为0，
外加少数几条用正则匹配stdout里的loss值。
——与research/05点名的PyElastica反面教材**同型**。

**中层（约十余条）**：`test_final()`里的**包络断言**。实例：

- `contacts/example_pyramid.py`：顶块位移 `< 0.5 m`。
  注释写明"In test mode the wrecking ball is omitted"——
  **测试模式下把撞球去掉了**，于是这条案例只验"金字塔在重力下不自己塌"。
- `contacts/example_newton_cradle.py`：`abs(q[0])<1.25 and abs(q[1])<1e-3 and abs(q[2])<1.1`
  ——只判"摆球留在平面工作区内"。
  牛顿摆这个题目**天然带动量与恢复系数判据**，同行一条都没用。
- `mpm/example_mpm_granular.py`（`--collider concave`是一个**V形漏斗**，
  两块倾斜45°的板）：判据三条——所有粒子在地面以上、所有粒子在碰撞体外、
  `max_z > 0.8`（消息是"All particles have collapsed"）。
  ——**非穿透＋防全塌**。第三条正是spec/12第6.2节要的"先断参照量非零"那种反假通过守卫，
  形制可抄；但没有质量守恒、没有流出率、没有堆积角。

**顶层（1条）**：`vbd/example_cable_bend_twist_analytic.py`是本轮唯一读到的
带定量容差的NVIDIA样例，六条assert：

    max(bend_tip_errors)       < math.radians(0.005)
    max(bend_angle_rms_errors) < math.radians(0.02)
    max(bend_shape_errors)     < 2.0e-5
    max(twist_tip_errors)      < math.radians(0.02)
    max(twist_linear_errors)   < math.radians(0.02)
    max(twist_transverse)      < 1.0e-5

注释里给了CPU基线（弯曲角RMS约0.0008°、形状RMS约3.4e-6）。
**但它的"解析解"是离散边值问题的精确解**（`theta_i = i/(N-1)·theta_tip`均匀分布），
不是连续体闭式解。按research/05的分档它落在**第4档自洽**，不是第1档。
最后一条`twist_transverse < 1e-5`是真正好的一条：**纯扭转不得产生横向运动**——
这是对称性判据，不需要任何参考解，我们可以直接照抄这个思路。

**最独特的一条：`vbd/example_cable_michell_threshold.py`**。
它是同行里**唯一**把杆的失稳阈值做成样例的，而Michell失稳正是决策0040的C档第5条。
但读完源码有两条必须记下：

1. **亚临界那几行不是算出来的，是钉死的**。
   `_make_bodies_kinematic()`把`body_mass`、`body_inv_mass`、`body_inertia`、
   `body_inv_inertia`全部置零，文件头也写明"Rows at or below the threshold are
   **fixed planar references**"。断言是
   `max_stable_coplanarity < 5.0e-3`（对着被冻住的那几行）与
   `max_above_threshold_coplanarity > 5.0e-2`（对着真在算的那几行）。
   ——**这不是Chrono三球金字塔那种双向判据**。Chrono是同一模型只改摩擦系数、
   两侧都真算、一边必须撑住一边必须塌；Newton这条只有"塌"那一半是物理。
2. **它用的临界扭转式与文献不同**。Newton的实现是

       critical_twist = 2*pi*sqrt(3*bend_stiffness/twist_stiffness)

   而Goriely 2006与Gazzola 2018（决策0040引的那条）的形式是
   `Φc = 2·sqrt(3)·π·α/β`（α为弯曲刚度、β为扭转刚度）。
   两式只在`α/β = 1`时相等：记`x = α/β`，前者是`2π·sqrt(3x)`，后者是`2·sqrt(3)·π·x`。
   Newton那七行的比值标签（0.71x…1.41x）是按前者算的；按后者算，
   同样的七组刚度会变成0.87x…3.46x，**只有一行仍是亚临界**。

   **本页不断言Newton错**——有可能他们的`bend_stiffness`/`twist_stiffness`
   与文献的α/β不是同一个量（离散每边刚度 vs 连续体刚度）。
   **但对我们有直接后果**：0040第5条立案例时，
   **必须以Goriely/Gazzola的式子为准**，并在案例页第四节"已知失效清单"里
   写明这条与Newton实现的分歧，否则将来对拍必然打架。

`newton/tests/`有176个测试文件，但`golden_data/`只有1项
（`test_sensor_tiled_camera`）——**Newton基本不用金标文件**，
判据全写在断言里。这与Chrono的264份ADAMS参考数据是两条完全不同的路。

## 二、SOFA系：用户说的"soft"

### 2.1 我判断"soft"指SOFA Framework，依据与不确定性一并写出

**支持的依据**：

1. 用户把它与"英伟达"并列点名，且问的是"**他们**用的是什么样例"——
   主语是一个**组织或产品**，不是一类物理现象（"soft body"是现象不是"他们"）。
2. 在物理引擎语境里，与NVIDIA同级、开源、名字读音与拼写最接近"soft"的同行只有
   **SOFA**（Simulation Open Framework Architecture，Inria）。
3. SOFA的招牌恰好是**软组织**（soft tissue）实时仿真——两条线索指向同一处。
4. research/05已经把SOFA列进同行名单，本仓语境里它本来就是"同行"。

**次高可能**：`SoftRobots`插件（Inria，专做软体机器人：腱驱动、气动执行器、
软段接刚性关节）。但**它是SOFA的插件**，覆盖SOFA即覆盖它。

**明确排除**：Softimage（已停产的DCC，不是物理引擎）。

**这一条是推断不是事实。** 列入第六节待裁清单第1条。

### 2.2 SOFA的样例形制：按组件排，不按应用排

`sofa-framework/sofa`的`examples/`下474个`.scn`场景文件（本轮用git tree API统计），
顶层结构是：

    Component/      按组件排：AnimationLoop, Collision, Constraint, Diffusion,
                    LinearSolver, Mapping, Mass, MechanicalLoad, ODESolver,
                    SolidMechanics, Topology, Visual …
    Demos/          40个演示场景（liver.scn、caduceus.scn、chainAll.scn、
                    SofaWasher.scn、Coil.scn、fallingBeamLagrangianCollision.scn …）
    Tutorials/      Basic / Collision / ForceFields / Mappings / Solvers /
                    StepByStep / Topologies
    Benchmark/      Accuracy / Analysis / Performance / Render / TopologicalChanges
    Validation/     **只有一个目录：cantilever_beam**
    SimpleAPI/  Objects/

**这个布局本身就是SOFA最独特的地方**：
它的样例主体不是"这个引擎能做什么应用"，而是"**每个组件长什么样**"——
`Component/SolidMechanics/FEM/`下就有37个场景，一个力场一个场景
（`TetrahedronFEMForceField.scn`、`HexahedralFEMForceField.scn`、
`TriangularFEMForceFieldOptim.scn`、`TetrahedronHyperelasticityFEMForceField.scn`…）。

对比NVIDIA：PhysX/Newton的样例是**按场景**排的（金字塔、多米诺、牛顿摆），
SOFA是**按组件**排的（每个ForceField一条）。
**两种组织法回答的是不同的问题**：
NVIDIA的样例回答"能不能做这件事"，SOFA的样例回答"这个部件怎么接"。

本仓今天15个案例是**按判据**排的（第三种），三种都不一样，值得记一笔。

### 2.3 "同一对象三模型"怎么在样例里体现

SOFA的核心形制是每个对象有三套表示——**behavior（力学）／collision（碰撞）／
visual（视觉）**，三者之间用**Mapping**连起来：mapping把位置与速度从主到从传播，
把力从从到主反向传播。

样例里的体现有三处，逐处对上文件：

1. **`Tutorials/Mappings/`整个目录就是干这件事的**
   （`TutorialMappingBarycentric`、`TutorialMappingLiverBarycentric`）：
   一个节点放behavior模型（`MeshLoader` + `TetrahedronSetTopology`），
   下面挂两个子节点——visual子节点与collision子节点，
   **各自用BarycentricMapping映回同一个behavior模型**。
2. **`Component/Mapping/`分Linear与NonLinear两族**，
   每个mapping一个场景——mapping在SOFA里是与力场平级的一等组件。
3. **`Demos/chainAll.scn`、`chainHybrid.scn`、`chainHybridNoGroup.scn`**：
   同一条链，不同段用不同的behavior模型（刚体段／FEM段／弹簧段），
   靠mapping拼在一起。这是"三模型"形制的最强展示——
   **它让同一个物体的不同部分用不同的物理**。

**对本仓的含义（这一条比样例本身重要）**：
用户说"我们是三维模型，而且是带厚度的那种"。

## 三、三个真实场景，同行是怎么算的（本页最要紧的一节）

### 3.1 场景一：超导带绕一圈的电流分布

#### 主流数值形式：三条路，代价差一个数量级

| 形式 | 未知量 | 怎么绕开长细比 | 代价 |
|---|---|---|---|
| **H-formulation** | 磁场H（棱边元） | **不绕**，超导层要真网格 | 最贵。文献记载CORC电缆的三维H模型"could have taken up to months" |
| **H-φ / 薄壳** | 超导区H，非导电区标量势φ | **薄壳近似**：带材退化成一张面 | 中。arXiv 2108.08828是这条路 |
| **T-A formulation** | 超导区电流矢势T，全域磁矢势A | **薄带近似**：带材退化成一条线/一张面，T在其上 | 最便宜。"decreasing both the mesh complexity and the computing time" |
| **积分方程／变分（Brandt、MMEV）** | 电流密度J | 只离散超导体本身，**不要空气网格** | 矩阵稠密但自由度最少 |

**这条对我们最有用的一句**：T-A与薄壳都是**把"带厚度"这件事显式地近似掉**——
同行面对"数微米超导层压在数十微米基带、宽度毫米级"的长细比，
**给出的主流答案不是把厚度画进网格，而是把厚度降维成一个面/线上的量**。
用户说"我们是三维模型，带厚度的那种"，但**超导带这个场景里，
同行的主流做法恰恰是不画那个厚度**。这一条要提前说破。

积分方程法有一条额外好处与本仓相关：
它**只离散超导体本身，不要空气网格**——
research/08门槛2（缺体网格与关联表）在这条路上可以少一大半。

#### 幂律与n值

    E = Ec·(J/Jc)^n     等价写法  J = Jc·(E/Ec)^(1/n)

`Ec`是特征电场，**通常取1e-4 V/m（＝1 μV/cm）**，它定义了`Jc`。
`n`刻画I-V曲线的陡度，`n → ∞`时退化到临界态模型。

n的取值：本轮**没有核到一份权威的"典型20—30"表**。
核到的具体数字有两个：
- Pardo等（arXiv:1410.0772）做数值对拍时**取`n = 1000`来模拟临界态模型**，
  并给出一组扫描`n = 5, 10, 20, 40, 80, 200`的交流损耗曲线；
- 一份REBCO弱点分析里实测到`n = 15`。

**结论：`n`是20—30这一说本页标"未核实"。**
能确证的是：工程REBCO带材的n在**十几到几十**的量级，
数值上常用n=100—1000逼近临界态。
对我们的含义不变：**这是幂次二三十的非线性**，牛顿法的全局化行为与力学问题完全不同
（0029登记的信赖域/载荷步自适应缺口在这里会被顶到极限）。

#### **解析基准：有，而且很强。这是本页对场景一最重要的答案**

**存在三条第1档（解析闭式）判据，全部可用，本轮已逐条数值验证过。**

**(a) Norris薄带电流分布（Norris 1970，conformal mapping）**

半宽`a = w/2`的薄带、厚度`d`、临界片电流密度`Kc = Jc·d`、
临界电流`Ic = w·Kc`，通传输电流`I`时的片电流密度：

    K(x) = (2·Kc/π)·arctan( sqrt( ((w/2)^2 − b^2) / (b^2 − x^2) ) )    |x| < b
    K(x) = Kc                                                            b ≤ |x| ≤ w/2
    b    = (w/2)·sqrt( 1 − (I/Ic)^2 )

出处：Pardo等arXiv:1410.0772式(69)（原文把`b`的分母记作`I_m`，
按`I=0`给`b=w/2`、`I=Ic`给`b=0`两个极限反推应为`Ic`，本页按`Ic`写）。
原始文献是W. T. Norris, *J. Phys. D* **3** (1970) 489。

**本轮实测的自洽判据**：`∫K(x)dx`必须恰等于`I`。
Simpson 4e5点、`I/Ic`从0.1扫到0.99，相对偏差**5e-10到1.3e-7**
（`I/Ic`小时被arctan在`|x|→b`处的竖直斜率拖慢，收敛阶下降，符合预期）。

Pardo等的对拍结论直接可引：数值解取`n = 1000`时与该闭式**重合**，
而且他们说了一句我们该抄的话——
"checking the current density is more strict than the AC loss,
since the current density that produces a given AC loss is not unique"。
**验电流分布比验交流损耗严。**

**(b) Brandt-Indenbom / Zeldov薄带在垂直外场中的解析解**（1993）
Phys. Rev. B **48**, 12893 与 Europhys. Lett. **22**, 735。
电流密度、磁场、穿透磁通、磁矩全部解析给出，恒定`Jc`。
**适用限制必须写进案例页**：只在临界区**单调穿透**时成立，
高电流低场区（`I ≥ Ic·tanh(Ha/Hc)`，`Hc = Jc·d/π`）有保证。

**(c) Norris交流损耗闭式**（记`i = Im/Ic`，`Ql`为每周期每单位长度损耗）

薄带（矩形薄带）：

    2π·Ql/(μ0·Ic^2) = 2·[ (1+i)·ln(1+i) + (1−i)·ln(1−i) − i^2 ]    → i^4/3   (i ≪ 1)

椭圆截面（Norris证明对任意半轴的椭圆线材成立，`Ic = π·a·b·Jc`）：

    2π·Ql/(μ0·Ic^2) = (2−i)·i + 2·(1−i)·ln(1−i)                     → i^3/3   (i ≪ 1)

本轮已数值验证两条渐近：`i=1e-3`时薄带式给3.331e-13对`i^4/3 = 3.333e-13`，
椭圆式给3.335e-10对`i^3/3 = 3.333e-10`。**三次方与四次方的差别是这两条判据的招牌**
（Norris 1970的原始发现），一条案例同时验形状与幂次。

**(d) Bean临界态**：厚板的经典解，可作退化校验；
但对"带"这个几何，Bean的均匀穿透深度假设**不成立**——
上引综述明说薄膜不能当成板来简化，这一点必须写进案例页第六节"本案例不是什么"。

**结论（回答任务第3问）：超导带有可用的解析基准，而且是第1档。**
但——**有oracle不等于今天能跑通**：这些闭式要拿来当门用，
必须有一个我们自己的求解结果去对。今天引擎的电磁是零，
所以它们只能先入库当oracle，进不了C档分母。详见第四节。

### 3.2 场景二：多线圈之间的互感与电容

#### 互感：闭式解，而且本仓的椭圆积分已经够用（本轮实跑核实）

**Maxwell同轴圆环闭式**：半径`r1`、`r2`，轴向间距`h`，

    k^2 = 4·r1·r2 / ( (r1+r2)^2 + h^2 )
    M   = μ0·sqrt(r1·r2)·( (2/k − k)·K(k) − (2/k)·E(k) )

`K`、`E`是第一、二类完全椭圆积分。
**注意参数约定**：本仓`cases/large_deflection_cantilever/generate_oracle.py`里的
`complete_k(m)`、`complete_e(m)`收的是**参数`m = k^2`**（与scipy一致），不是模`k`。
这一条不写清楚，将来必错。

**Neumann双回路公式**（任意位形，来自Wikipedia Inductance条目的标准写法）：

    M = (μ0/4π)·∮∮ (dx1 · dx2) / |x1 − x2|

对同轴圆环，按轴对称把双积分降到一维：

    M = μ0·r1·r2·∫_0^π cos(φ) / sqrt( r1^2 + r2^2 − 2·r1·r2·cos(φ) + h^2 ) dφ

**本轮实测（用本仓已有的Carlson实现，纯标准库，不装任何依赖）**：

| 检查 | 结果 |
|---|---|
| `complete_k`/`complete_e` 对 mpmath，`m`从0扫到0.999999 | 相对偏差 **≤4.4e-16**（机器精度） |
| Maxwell闭式 对 Neumann一维求积（独立代码路径），`m ∈ [3e-2, 0.9999]` | 相对偏差 **1.3e-14 到 1.5e-12** |
| 同上，`m = 2.0e-3` | 2.7e-10 |
| 同上，`m = 5.0e-4` | 6.3e-9 |
| 同上，`m = 1.25e-4` | 1.0e-7 |
| 同上，`m = 7.8e-6` | 1.0e-5 |
| 远场偶极极限 `M → μ0·π·r1^2·r2^2/(2·h^3)`，`h=10`（r1=1, r2=0.2） | 1.5e-2（几何误差，正常） |
| 同上，`h=100` | 1.6e-4（**不再随h下降——说明此处闭式本身已失精**） |

**这张表是本页给场景二最实的东西**：
Maxwell闭式在`m`很小（两环相距远）时会**灾难性相消**——
`(2/k − k)·K`与`(2/k)·E`两项都是`O(1/k)`量级而`M`是`O(k^3)`量级。
精度大致按`1/m^2`退化：`m ≥ 1e-2`可给1e-11的容差，
`m < 1e-3`必须换级数或偶极展开。
**这条边界要写进案例页的"已知失效清单"，并且它就是这条案例的红。**

**自感的经典近似**：Wheeler公式（单层螺线管）及其修正式，
用来给互感做数量级交叉校验；已知缺陷是**不含导线直径**，
线径一变精度就掉。可作第4档自洽用，不能当oracle。

#### 电容：闭式构型很少，工业上靠专用工具

闭式的只有同轴（`C' = 2πε/ln(b/a)`）、平行板、球形电容器几种
（research/08第六节已列，本页不重复）。**线圈之间的匝间/层间电容没有闭式。**

**工业界用什么**（回答任务的"工业上用什么工具"）：

- **FastHenry / FastHenry2**（MIT）：算三维导体结构的**磁准静态频变自感、互感与电阻**，
  多极加速把内存与时间压到近似`O(n)`，"can reduce required computation time and
  memory by more than an order of magnitude"。**这是互感这一侧的工业标准开源件。**
- **FastCap / FasterCap**：三维与二维**电容提取**，
  FasterCap加了有损介质与自动网格加密。
- 两者都是矩量法/积分方程路线——**与3.1节说的"只离散导体不离散空气"同一族**。
  这一点很值得注意：**互感与电容的工业工具，走的都不是有限元。**

**对我们的含义**：场景二的互感一半可以完全不碰网格；
电容一半即使做，也应该走积分方程而不是先建FEM——
这与research/08默认"电磁＝FEM棱边元"的预设**不一致**，
是本页推翻的第三条（见第五节）。

### 3.3 场景三：不规则模型自由落体落进漏斗

#### 同行的等价样例叫什么

- **料斗/漏斗（hopper／funnel）是DEM圈的标准演示**，不是游戏引擎圈的。
  Chrono的GRANULAR/GPU模块有二维料斗基准（5万球）；
  Chrono `DEM-Engine`论文（arXiv:2311.04648）的验证节里有斜面滚球、球堆叠、
  球冲击、**转鼓与料斗流动敏感性**、颗粒破碎、11M单元的巡视车共仿真。
  平底料斗的验证构型：高0.40 m、宽0.20 m、深0.04 m、下表面孔径0.04 m，
  比对量是**单组分与双组分的质量流出率**。
- **Newton的等价物是`mpm/example_mpm_granular.py --collider concave`**：
  两块倾斜45°的板围成V形漏斗，MPM颗粒落进去。
- **PhysX、Isaac Sim、Isaac Lab、MuJoCo、Bullet都没有颗粒漏斗样例。**
  （注意术语陷阱：RL圈的"Hopper"是**单腿跳跃机器人**，
  `pybullet-gym/.../mjcf/hopper.xml`是那个，不是料斗。）

#### 碰撞表示：三条路，同行都在用，用途分工明确

| 路 | 谁在用 | 适用 |
|---|---|---|
| **凸分解**（V-HACD／CoACD） | 通用资产管线 | 离线把非凸网格切成若干凸包。V-HACD体素化后合并，快（每资产数秒）但凸包多、运行时接触解算慢；CoACD（SIGGRAPH 2022）用"碰撞感知的凹度度量"，凸包少、跑得快但分解慢，且**保细节不填洞**（V-HACD即使阈值很小也会把洞填掉） |
| **GJK＋EPA** | 凸-凸窄相的默认解 | Newton有`tests/test_gjk.py` |
| **SDF（符号距离场）** | **PhysX 5 `snippetsdf`；Newton `contacts/example_nut_bolt_sdf.py`；Isaac Lab的Factory与AutoMate的接触建模** | 直接吃非凸网格，不用分解。**这是同行对"不规则模型"给出的当代答案** |

另有**hydroelastic**一路（Newton有`example_nut_bolt_hydro.py`、
`example_robot_panda_hydro.py`；Drake的irrotational contact fields是同族）——
把点接触换成压力场，接触力连续可微。

#### 接触模型：三族

- **罚函数/DEM**（Hertz-Mindlin带切向历史）：Chrono DEM-Engine、LAMMPS用这个。
  上引DEM验证用的参数：`E = 7.1e7 Pa`、`ν = 0.33`、`Δt = 1e-6 s`；
- **LCP/互补**：Bullet、PhysX的主路；
- **IPC（Incremental Potential Contact）**：对数障碍加CCD线搜索，
  **保证每一步都无穿透**；有刚体版（Rigid-IPC）、有颗粒冲击扩展、
  有与IsaacSim/Lab桥接的libuipc（IsaacIPC）。

#### **可判据化的量：五条，从最硬到最软**

**这是回答任务第5问的直接答案。**

1. **质量/粒子数守恒（零容差）**。落进去多少出来多少，
   一个粒子都不许穿墙消失。Newton的做法是逐粒子断言"在地面以上、在碰撞体之外"
   ——**非穿透断言是这一族里唯一可以零容差的**。
2. **单体自由落体与弹跳的闭式**。落进漏斗之前那段是弹道，
   本仓`ballistic_free_flight`已经在跑；碰底那一下有恢复系数闭式
   （`e' == e`、总弹跳时间闭式，0040第9条）。
3. **Beverloo流出率**（三维圆孔）：

       Q = C·ρ·sqrt(g)·(D − k·d)^(5/2)

   `Q`质量流率、`ρ`堆积密度、`D`孔径、`d`颗粒直径、
   `C`无量纲流出系数（实测拟合约**0.56—0.57**）、`k`形状因子
   （文献给的零流截距外推到**2.6—2.9**）、指数`5/2`是三维值。
   **适用区间必须声明**：`D/d`要够大（`D/d = 10`时吻合良好），
   `D/d`小于约5会**结拱堵死**（球珠的临界半径实测`R_c = 4.94 ± 0.03`，
   对应`D/d ≈ 5`），且料床要够高否则压头随排空变化。
   **这是一条经验律不是解析解**——按轴7规则1，
   **它只能当对拍源不能当oracle**，与TEAM同型（research/08第六节强度2的裁法照搬）。
4. **堆积角（angle of repose）**。Chrono的官方演示就是"料流过漏斗形成稳定堆、
   展示堆积角"。它与摩擦系数有确定关系，但**关系式依赖接触模型**，
   所以只能作跨参数的**排序判据**（μ大则角大），不能当绝对值判据。
5. **斜面阈值与无滑滚球**（`θc = arctan(μs)`、`a = (5/7)·g·sinθ`，0040第8条）。
   严格说这不是漏斗案例，但它是**摩擦系数标定的入口**——
   漏斗里的任何定量结论都要先过这一条。

**一条要提前说破的**：上面5条里，
**第1、2、5条是解析或零容差的，第3、4条不是。**
所以"漏斗案例"能不能算跑通，取决于我们把判据钉在哪一条上。
钉1、2、5可以；钉3、4只能算对拍。

## 四、给我们的样例建议（落点）

本仓对"跑通"的定义（plans/04第六节，本页沿用，一个字不放宽）：

### 4.1 A档：今天就能立成可跑通案例的

**先说一条纪律**：0040第四节把案例分成"计入C档分母的"与"引擎自己的门"。
下面A1、A2两条**都属于后者**——它们验的是公式与oracle，不是引擎的物理求解。
**给了不加分**，但它们是场景一、场景二将来唯一的第1档判据来源，

#### A1. `coaxial_loop_mutual_inductance`（同轴圆环互感）

## 五、本页推翻的三条（我自己先前或已有文档的假设）

### 第一条：我以为"同行样例多说明验证强"，474 : 1把这条打掉了

SOFA有474个`.scn`场景，`Validation/`目录里**只有一个案例**。
NVIDIA四个产品237条样例，**带定量数值容差的只有1条**，
而且那一条对的是离散自洽不是物理闭式。
research/05已经定性说过"样例目录不等于验证套件"，
**本轮把它变成了数字**：样例数与判据数之间没有相关性，甚至可能是负的
（样例最多的SOFA与PhysX，判据最少）。

### 第二条：plans/04说"刚体自由飞行今天就能开工"——**开工可以，但它不是A档**

`integrate.py`三个积分器全是平动签名，`StateLayout`是固定布局，
姿态与角速度都不存在。惯量张量已有是真的，但那只是被积的量，
不是积分器。**这一条我按代码核实后推翻了plans/04第五节的隐含定级**，
把它移到B档第一位。

### 第三条：research/08默认"电磁＝有限元棱边元"——**互感与电容的工业主路不是FEM**

research/08第1.2节把离散手段列全了，但整页的重心在FEM棱边元
（门槛1的拓扑实体声明、门槛2的体网格、门槛3的复数不定系统，
全是FEM路线的门槛）。
本轮发现：**互感（FastHenry）与电容（FasterCap）的工业标准工具走的都是积分方程/矩量法**，
超导带的Brandt方法与变分法也**只离散导体不离散空气**。

含义很实：**如果场景一、二走积分方程而不是FEM，
research/08的门槛2（体网格与关联表）可以整块绕开，门槛1也大半绕开。**
代价是稠密矩阵（自由度少但矩阵满），而这恰好落在
research/06把`solve.py`稠密LU排成"全仓最陡复杂度"的那条线上——
**同一个欠账，两条路径都指向它，排期权重应该再抬一级。**
这一条列入待裁。
