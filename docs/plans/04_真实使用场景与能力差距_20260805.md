# 真实使用场景与能力差距（2026-08-05，用户给出）

用户2026-08-05给出**三维带厚度**的定位与三个具体使用场景。
本页把它们钉成正本，并逐个量出与今天能力的差距。**这是本仓第一次拿到
"引擎要用来算什么"的具体问题**——此前的路线都是从消费方仓的既有实现倒推的。

## 零、两条定位信息（比场景本身更要紧）

1. **我们是三维模型，而且是带厚度的那种。**
   今天的力学内核是**中心线杆**（DER，`κ=2·tan(θ/2)`，节点是三维点）——
   它是"三维空间里的一维物体"，**不是带厚度的三维体**。
   截面上的分布（应力、电流、温度）在这个表示里**根本没有自由度可放**。
2. **三个场景里两个是电磁主导的。** 而引擎的电磁是零（research/08 只做了预研）。
   这意味着 plans/02 的轨道排序（力学搬迁为主线）**与真实需求不一致**。

## 一、场景一：超导带绕一圈，电流怎么分布

### 这是什么问题

高温超导（HTS）带材的**电流分布**问题。它在文献里是成熟问题类，
但对数值方法的要求很特别：

- **极端长细比**：HTS 带材典型是数微米的超导层压在数十微米的基带上、
  宽度毫米级——厚度与宽度差三到四个数量级。这正是用户说"带厚度"的地方，
  而且是**最难画网格的那种厚度**。
- **强非线性本构**：`E = Ec·(J/Jc)^n`，`n` 典型 20—30。
  这不是"有点非线性"，是幂次二三十的非线性——牛顿法在这里的收敛行为
  与我们今天做过的任何问题都不同。
- **屏蔽电流与磁滞**：电流分布**依赖历史**（外场怎么加上去的），
  与决策0033 裁的摩擦锚点是**同一类问题**：历史相关的内变量。

### 差距（逐条，不含糊）

> **订正（research/12）**：本节原判场景一"最远"——**过悲观了两处**。
> ①**它有第1档解析基准**：**Norris 1970 薄带电流分布**的 conformal mapping 闭式
> `K(x) = (2·Kc/π)·arctan(sqrt(((w/2)²−b²)/(b²−x²)))`（|x|<b），`b = (w/2)·sqrt(1−(I/Ic)²)`；
> 实测自洽 `∫K dx = I` 在 I/Ic 从0.1到0.99 上 rel **5e-10到1.3e-7**。
> 另有 **Norris 交流损耗两式**与 **Brandt-Indenbom 1993** 的完整解析解。
> ②**`n` 典型20—30 这个数核不到权威出处，标未核实**（核到的是取n=1000模拟临界态、
> 扫描5…200、以及一份实测n=15）。
> ③同行绕开极端长细比的主流手段是 **T-A薄带与H-φ薄壳——把厚度降维掉、不画进网格**，
> **这与用户"我们是带厚度的三维"直接相抵**，是一处必须让用户知道的张力。

| 缺什么 | 今天的状态 |
|---|---|
| 电磁域 | **零**。research/08 已做预研并列出门槛（**但其"电磁=FEM棱边元"的默认前提已被research/12推翻，见下**） |
| 截面自由度 | **零**。中心线杆的状态里没有截面上的位置 |
| 复数/不定系统求解 | **零**。`_solve_dense` 遇奇异失败关闭 |
| 强非线性的全局化 | 无信赖域、无载荷步自适应（0029 登记的脆点） |
| 历史相关内变量 | 0033 裁了归属（进状态），但**状态布局是固定的**，那条未解 |

**判断：这是三个场景里最远的一个。** 不是"再加一块"，是要先有电磁域 + 截面表示。

## 二、场景二：多线圈之间的干扰（互感、电容）

### 这是什么问题

线圈之间的**互感**与**电容**提取。

### 与场景一的关键差别：**它有解析解，而且不需要网格**

这一条是本页最有用的发现：

- **互感**有闭式解——同轴圆环之间的互感由**第一、二类完全椭圆积分**给出
  （Maxwell 公式），而**我们刚在大挠度悬臂里实现过椭圆积分**
  （`large_deflection_cantilever` 的 Carlson 对称形式，零依赖）。
- 一般位形的互感有 **Neumann 公式**（双回路线积分），
  可以用**细丝（filament）离散**算，不需要体网格。
- 自感有经典的近似闭式（Wheeler、Maxwell），可作交叉校验。

**这意味着场景二是三个里最便宜的电磁入口**：
- 判据强度是**解析闭式解**（research/05 的第1档，最强）；
- 不需要网格、不需要单元库、不需要复数求解；
- 纯 Python 可算，**不破零依赖承诺**。

**电容那一半更贵**：需要静电场求解（Laplace 方程），
除了同轴、平行板、球形这几个闭式构型之外要网格。
**建议拆开：互感先做，电容等网格。**

### 差距

| 缺什么 | 备注 |
|---|---|
| 细丝几何与回路表示 | `shapes` 里没有"回路/曲线"这个词汇 |
| Neumann 双回路积分 | 纯数值积分，零依赖可写 |
| 椭圆积分 | **已有**（大挠度悬臂案例里的 Carlson 形式） |
| 电容 | 需静电求解，除少数闭式构型外要网格 |

## 三、场景三：不规则模型自由落体落进漏斗

### 这是什么问题

**刚体动力学 + 网格碰撞 + 摩擦接触**。这是三个场景里最"经典引擎"的一个——
MuJoCo/Bullet/PhysX/Isaac 的标准演示就是这类。

### 差距

| 缺什么 | 今天的状态 |
|---|---|
| **刚体（6自由度）** | **零**。我们只有质点（三自由度），没有转动惯量参与的姿态积分 |
| 网格碰撞窄相 | **零**。`collision.py` 只有球/胶囊族的窄相 |
| 接触与摩擦 | **零**。T5 最大一块，且卡在 0033 的状态布局问题 |
| 恢复系数 | **零** |

> **订正（research/12 按代码核实）**：本页原判"刚体自由飞行今天就能做、属A档"——
> **不成立**。`integrate.py` 三个积分器签名全是 `(x, v, t, h, acceleration, ops)`，
> **纯平动**；`StateLayout` 是固定布局，**装不下四元数**。
> 它是**最小的B档**（要先加姿态状态与转动积分器），不是A档。
> 惯量张量确实已有，那部分判断是对的。
> 派出的轨道R简报已按"要新建姿态状态+转动积分器"写，故未受影响。

**但它有一条捷径**：`geometry.py` 已有四种解析原语的**惯量张量**（0022），
而刚体自由飞行的判据（Drake 的 `free_body` 无力矩轴对称闭式、
Dzhanibekov 中间轴翻转）在 research/05 里已经调研过，属 B 档。
**"刚体自由飞行"可以先于接触落地**，它只要转动积分不要接触。

## 四、三个场景合起来说明了什么

**plans/02 的轨道排序与真实需求不一致。**

此前的排序是"力学搬迁为主线"（T5：能量项→弯曲→扭转→接触），
理由是消费方 WDS 有成熟的 DER 内核可搬。但三个真实场景里：

- 场景一、二要的是**电磁**，力学搬迁一条都用不上；
- 场景三要的是**刚体 + 网格碰撞 + 接触**，DER 杆内核也用不上。

**结论：搬迁 WDS 的 DER 内核服务的是 WDS 自己，不服务这三个场景。**
这不是说搬迁错了——WDS 是真实消费方，那条路仍然成立——
但**它不该继续被当作唯一主线**。

# 补充场景（同日，用户续给）

用户在给出前三个场景后补了三类，**其中最后一类几乎就是完整的绕线机数字孪生**。
本节按同一口径逐个量差距。

## 七、场景四：光学的散射、干涉、衍射

用户原话："**光学的场景，散射的场景，干涉衍射的场景……最复杂的那种，
各个学科的都有的。**"

### 我们有什么

`optics/` 子包（决策0031）：圆孔远场艾里斑闭式、FTS仪器线型与Norton-Beer切趾。
**都是闭式标量解，没有场传播。**

### 差距与可用的解析判据

| 子场景 | 缺什么 | **有没有解析oracle** |
|---|---|---|
| **衍射（近场/一般孔径）** | 二维复数场网格 + FFT（角谱／菲涅耳／夫琅禾费传播） | 有：单缝、双缝、矩孔、菲涅耳数极限退化到艾里斑 |
| **干涉** | 同上（两束叠加即可） | **有且很强**：双光束 `I = I1+I2+2√(I1I2)cos Δφ`，条纹间距闭式；迈克尔逊/杨氏双缝都是教科书闭式 |
| **散射** | 复数场 + 球谐/贝塞尔级数 | **有且是精确解**：**Mie理论**对均匀球是**严格级数解**（不是近似）；瑞利散射是其小球极限，可作退化校验 |

**Mie 散射值得单独说**：它是本仓能拿到的**判据强度最高的光学案例之一**——
严格级数解、参数扫描下可逐点对拍、且**小球极限退化到瑞利** `∝ 1/λ⁴`
是一条独立的自洽门。代价是要复数与球贝塞尔函数（`j_n`、`y_n`、`h_n^(1)`），
纯Python可写但要小心小宗量的相消（0031 已在 `J1` 上处理过同类问题）。

**共同前置：二维复数场 + FFT。** 0031 已把它声明为光学下一块。
纯Python 的 Cooley-Tukey 可写（约30行），但 512² 网格上会很慢——
这正是 0016 的加速档该出场的地方。

## 八、场景五：平面带材（有厚度）绕上线圈盘，十几匝

用户原话："**一个平面的带有一定的厚度，然后一点一点地绕到我们的线圈盘里面，
多绕个几圈，比如说绕个十几圈。**"

### 这是什么问题

多匝卷绕。与场景一（超导带电流）共用同一个几何，但问的是**力学**：
匝与匝之间怎么叠、张力怎么传递、半径怎么长。

### 差距

| 缺什么 | 说明 |
|---|---|
| **自接触**（匝碰匝） | 这是本场景的核心难点：新绕上去的一匝要压在已绕的匝上。`collision.py` 连网格窄相都没有 |
| **接触与摩擦** | T5 最大一块，卡在 0033 的状态布局问题 |
| **半径随匝数生长** | WDS 有 `WindingSurface`（有效半径随层数长），**引擎侧零**；`modelgen.generate_spool` 只做了静态几何 |
| **带材的宽与厚** | 中心线杆表示不了。至少要"带宽方向"的自由度或截面 |
| **喂料/生长** | WDS 有 `feed_turn`（移动前沿喂料），引擎侧零 |

**判断：这是 WDS 那条搬迁路真正的终点**，也是 T5 全部做完之后才谈得上的。

## 九、场景六：完整放线—导向—张力—收线（用户说"这个特别复杂"，确实）

用户原话（拆解）：
> 一个缠好的盘子慢慢**转动放线** → 经过**两个导向轮** → 一个**张力轮**
> → 缠到**另一个三维盘**上 → 同时给这个盘**加偏移**，
> 模拟实际**蹭边**的情况，以及盘子在**各个轮子上偏移**的情况。

### 这一条最要紧的一点：**它验证了我们刚建的接口不是空想**

逐项对上：

| 场景要素 | 引擎里对应什么 | 状态 |
|---|---|---|
| 放线盘转动 | **`MotionSource`** —— 位姿时间线喂进来 | ✅ 刚落地（0038）；`SampledPoseTimeline` 与 `AnalyticPose` |
| 两个导向轮 | `modelgen.generate_roller` + `CollisionQuery` | 🔶 几何有，**接触无** |
| 张力轮 | **`Actuator`** —— 带时延的控制量 | 🔶 **声明层刚落地（0038），`apply` 的物理没实现** |
| 收线盘 + 偏移（排线） | `MotionSource`（横动时间线）+ 半径生长 | 🔶 运动源有，生长无 |
| **蹭边**（带材碰法兰） | 接触 + 法兰几何 | ❌ 接触无；**法兰轴向尺寸还是 spec/11 的已知缺口**（0034 维持失败关闭） |
| 各轮上的偏移/未对中 | 多体场景装配 | ❌ **`Scene` 装配容器没有**——今天的 `scene.py` 是文件加载器，spec/10 第一节要的 `declare_contact_between` + `finalize` 一个都没有 |

**这条场景把 spec/10 六接口里的五个同时用上了**（Scene / MotionSource /
Actuator / Sensor / CollisionQuery）——而那六个接口是从 WDS design/24 蒸馏来的，
**不是我们想象的**。今天回头看，它们的设计动机得到了独立印证。

### 差距总账（按阻塞顺序）

1. **`Scene` 装配容器** —— 多体、按对声明接触、finalize 统一校验。**今天就能做，无阻塞**；
2. **接触与摩擦** —— 卡在 0033 的状态布局（接触点数随构型变而布局固定）；
3. **`Actuator.apply` 的物理** —— 要接能量项与求解器；
4. **半径生长与喂料** —— WDS 有实现可搬；
5. **法兰轴向尺寸** —— spec/11 已知缺口，**这条场景就是 0034 写的那个"触发条件"**：
   蹭边要算，就必须知道法兰的轴向尺寸。**本场景一旦真做，0034 第四节自动重开。**
