### 甲1（2026-08-17）：圆柱侧面接触＋多槽位步进器＋绞盘案例

**代码**：`contact.PenaltyCylinderContact`（有限长圆柱侧面罚法向；活动条件**两条**——
穿透且轴向仍在筒宽内；几何刚度**只出现在周向**，`H·a`恰为0）；
`contact.advance_contacts_quasistatic`＋`ContactPoint`/`MultiContactStep`
（多槽位同时迭代，兑现0050第一节欠账与S3.6的`missing`）；
`energies.AxialStretch.axial_force_n`（逐边轴向力，绞盘判据要判的量）。

**案例**：`cases/capstan_tension_ratio`，真机导轮尺寸（R=50mm、半宽8.5mm，
2026-07-07现场确认），8个接触同时滑移。四条判据：

| 判据 | 实测 | 精度由什么定 |
|---|---|---|
| `\|T_i\|/(μN_i) = 1` | **2.22e-16** | return-map的**定义性质**，与载荷步无关 |
| `N_i` ＝两侧张力的法向合量 | **2.44e-07** | 残差容差1e-6 N ÷ 法向力≈4 N |
| 逐节点比对精确离散绞盘式 | 4.26e-03 | 载荷步一阶误差 |
| 收敛阶 | 比**2.10 / 2.06** | 同上 |

**三条量出来的界**（都进了门或清册，不留在散文里）：

1. **圆柱上罚接触的残差地板是`0.5·k·ulp(R)`**——`g = ρ − R`是两个`O(R)`量相减，
   半空间那条"力精确"在这里不成立。两半径×五档刚度10组实测，比值全在`[0.15,0.48]`；
2. **判别翻转那一趟走9459次回溯、残差高一个量级**（`C¹`非`C²`，0050第四节）；
3. **求解容差由能量分辨率定而非刚度地板**——`PointLoad`把总能量顶到`−550 N·mm`，
   线搜索在残差`4e-8`处再也分辨不出下降。

**必红实测**：圆柱项9条注错全抓到（最低1条）；多槽位7条全抓到，
**其中"试探力错位"第一轮红0条活了下来**，补门的第一版判据也抓不住，判对量才行。

**不能声称的**：带材在接触里仍是中心线上的点、**没有宽度**，所以碰不到法兰；
轮固定不自旋；接触对是声明的不是检测的。S6.5只进partial不进done。
