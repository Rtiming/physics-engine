## 一、八个模块与各自的验收标准

### M1 路径B核心：转动块进动态积分
`rigidbody`今天文件头明写"无接触、无约束"。要开的口子是：接触力对质心取矩 → 进Euler方程。
**与0079的准静态那一半必须语义对齐**（0074第四节：同一个群的两种参数化，
准静态用指数映射局部图、动态用四元数，**不许出现两套互不认识的转动状态**）。

**验收**：① 无力矩时`integrate_free_flight`产物**逐位不变**（`float.hex()`）；
② 有接触时角动量与能量的账各判一条；③ 有限差分：力矩对姿态的导数（若引入解析导数）。

### M2 无滑滚球 `a = (5/7)·g·sinθ`
**验收**：① 与闭式的偏差 + 随时间步的**收敛阶**；
② **"无滑"本身要被判**——接触点相对速度给个数，不是假定；
③ 0081第三节第4条那条布尔判据：`a = αR`成立与否。

### M3 滑与不滑的分界 `tanθ ≤ (7/2)·μ`
**注意这个数**：0081第二节记着派活方（我）一度写成`3μ`，那是实心圆盘的数。
**验收**：两侧各判 + 临界角与闭式的偏差；滑那一支要判`a = g(sinθ − μcosθ)`与`α = 5μg cosθ/(2R)`
**且`a ≠ αR`**。

### M4 翻倒

### M5 同行深读（"深度学习一下别人怎么做的"）
不是列清单，是**回答本仓下一步的具体问题**：刚体接触动力学里，
转动与摩擦怎么耦合（把摩擦冲量作用在接触点上会不会破角动量守恒）、
滚动阻力是独立模型还是摩擦的副产品、接触点相对速度怎么算才不引入伪滑移、
以及**它们各自的门是怎么写的**。
**验收**：每条结论带URL或仓内路径:行号；查不到写"没查到"；**产出要能改变M1—M4的写法**，
否则算没读懂。
