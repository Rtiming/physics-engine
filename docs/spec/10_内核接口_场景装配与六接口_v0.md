## 一、场景装配 `Scene`

**解决"要算什么"与"怎么算"的分离。** 四家同行（PyElastica/Chrono/SOFA/libuipc）
与FTS收敛出的同一形状：

1. 场景是带类型的系统容器：组件/端口/连接用稳定版本化ID声明（FTS聚合根形制）；
2. 交互**按对声明**，不设全局表：`declare_contact_between(A, B)`只记账；
3. **延迟实例化**：组装期只登记，`finalize()`统一实例化并做类型校验——
   整个场景在跑第一步之前被完整校验，配错当场炸（PyElastica形制）；
4. 数量与拓扑全部来自声明（轴2规则4）；
5. 物理律是可换组件，与几何分离（libuipc的Geometry/Constitution正交）。

首个落地候选：WDS design/23的多体接触方案（`penalty_context`单数改元组）——
方案已定、故意未实施，等其第3段需求开工。

## 二、运动来源 `MotionSource`

**"路径从哪来"与"物理怎么算"解耦。** 外部只写位姿、不写力
（MuJoCo mocap形制）：

    pose_at(t_s) -> Pose
    horizon_s() -> float
    is_replayable() -> bool   # 不可重放的来源禁止进入需要确定性的运行

WII位姿时间线是第一个实现候选；解析轨迹是第二个；将来的控制器是第三个。
`is_replayable`与轴3规则5（复现指纹）联动：不可重放来源的运行不得声称指纹。

## 三、驱动器 `Actuator`

**把控制量变成物理作用。** 张力机放线端是第一个实现候选（WDS用途4）：

    command_space() -> Space
    apply(command, state, dt_s) -> ActuationResult
    delay_s() -> float

时延不是可选项——真实控制回路有延迟，没有时延训练出的策略上真机会翻车
（MuJoCo环形缓冲形制）。FTS侧对应物：`ComponentKind.ACTUATOR`（其scene.py:84），
参数经Quantity声明——两域的驱动器将来同名同义。

## 四、传感器 `Sensor`

    observation_space() -> Space
    read(state) -> ndarray
    delay_s() -> float

**硬约束：传感器只能读物理上真测得到的量。** 带材每个节点的精确位置不是
传感器——真机上没有这个量；把它塞进观测空间训练出的策略无法迁移。
这条要写成门（首个"必须红"用例：声明一个读全场状态的传感器，校验必须拒）。

## 五、碰撞查询 `CollisionQuery`

    check_path(source: MotionSource) -> tuple[CollisionEvent, ...]
    check_state(state) -> tuple[CollisionEvent, ...]

`CollisionEvent`至少带：发生在哪（弧长/时刻）、谁和谁、侵入多深、**可信度**。
可信度不是修饰——broad phase命中与narrow phase确认是两回事，混报即缺陷。
（WDS用途3；其上游只给路径，撞不撞由引擎判。）

> **首个实现已落地（v0.2，决策0009）**：`collision.py`的broad-phase AABB查询——
> 全部事件`confidence="broad_phase"`且`penetration_mm=None`，narrow phase落地前
> 谁也读不出侵入深度；装配期校验重复body与未知白名单对（当场炸）；
> 白名单按对声明沿WII相邻连杆忽略的形制。真实参数示例场景
> （R45/60导轮+R50带盘+真SHA连杆网格）见`tests/test_shapes_and_collision.py`。
> `check_path`（沿MotionSource扫掠）未实现。

## 六、步进契约 `Episode`

    reset(*, seed) -> (Obs, Info)
    step(action) -> (Obs, reward, terminated, truncated, Info)

形状对齐Gymnasium；`terminated`与`truncated`必须分开（RL自举算法靠此区分）。
**优先级已降**：数据集先行裁决（WDS design/24七之四）下，本接口等交互式
环境需求真到来再实现。`reset(seed)`与轴3规则5联动。
