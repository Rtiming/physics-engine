# angular_spectrum_propagation 角谱：**不做傍轴近似**的那一条传播

`case/angular_spectrum_propagation`。C档，spec/15（光学域）+ `optics/field.py` +
`optics/propagation.py`（决策0086落地、决策0091冻结判据）。

**它与`cases/double_slit_propagated`的分别是本案例存在的全部理由**：
那一条走的是**单次FFT的夫琅禾费形制**——傍轴、丢掉孔径二次相位、输出网格随z张开。
这一条走**角谱**——标量精确、不做任何傍轴展开、输出网格与入射面同间距。
0086自己在第八节把这件事登记成了GAP，原文：
"**角谱那一侧没有任何案例冻结金标**——平面波本征函数、倏逝波衰减、`z→0`退化、
半群四条今天只有`tests/`里的门，没有进`cases/`"。
按本仓的分档，`tests/`守的是实现、**案例冻结的才是判据**，
能力位S4.5因此一直是`partial`。本页把那四条冻下来，并另加两条更硬的。

**四条oracle里有两条是任何傍轴形制都给不出的**，它们是本案例的分辨力所在：

1. **平面波本征值**里的根号是精确的``sqrt(1 − (λf)²)``，傍轴把它展成``1 − (λf)²/2``；
2. **倏逝功率损失**：倏逝分量按``exp(−kz·sqrt(q−1))``衰减，于是含倏逝内容的场
   传过去**掉能量**；而傍轴传递函数的模**恒为1**，同一个构型上给**恰好1.0**。
   **这一条只是一个数**，验它不需要复述任何公式。

顺带把**矩孔**（两个方向都有界）的三个整数零容差冻下来——能力位S4.6的label里
"矩孔"那一格此前只有构件没有判据，因为仓里每一处`rectangular_aperture`调用的
`half_width_y_m`都取`1e9 × pitch`（y方向占满窗口），**那是缝不是孔**。

## 一、物理/几何设定

标量传播，均匀平面波垂直照明，观察面在`z`处。**两个网格，两套物理**：

### 网格甲｜宏观网格，所有分量都在光锥内

| 量 | 值 |
|---|---|
| 波长λ | 632.8e-9 m（HeNe，与`scalar_diffraction_airy`、`double_slit_propagated`同一个） |
| 入射面网格 | 32行×32列（行=y，列=x），**方阵** |
| 采样间距dx=dy | 5.0e-6 m（**是波长的7.90倍**） |
| 角谱适用域上界`z_c = N·dx²/λ` | 1.2642225031605564e-3 m |
| 传播距离z | 0.5·`z_c` = 6.321112515802782e-4 m |
| 最大`|λf|` | `λ/(2dx)` = 0.0633 ⟹ **32×32格全部是传播分量，0格倏逝** |
| 矩孔 | x方向8个采样、y方向4个采样（**两个方向都有界**） |
| 孔径半宽（几何） | x：((8−1)/2+0.25)·dx = 3.75·dx；y：((4−1)/2+0.25)·dy = 1.75·dy |
| 孔径中心 | (0.5·dx, 0.5·dy)——**偏半格** |
| 孔内采样 | 32个（4行×8列），亮行`{31,0,1,2}`、亮列`{29,30,31,0,1,2,3,4}` |
| `k·z` | 6.2763e+3 弧度 |

### 网格乙｜亚波长网格，倏逝波真的出现

| 量 | 值 |
|---|---|
| 波长λ | 632.8e-9 m |
| 入射面网格 | 1行×32列（y方向只有一个采样，本网格是一维问题） |
| 采样间距dx | 1.0e-7 m（**只有波长的0.158倍**） |
| 角谱适用域上界`z_c` | 5.056890012642224e-7 m |
| 传播距离z | 0.4·`z_c` = 2.0227560050568898e-7 m |
| 最大`|λf|` | `λ/(2dx)` = 3.164 ⟹ **32格里只有11格是传播的，21格倏逝** |
| 缝宽 | 4个采样，半宽((4−1)/2+0.25)·dx = 1.75·dx，中心偏半格 |
| 冻结本征值的bin | 传播：0、1、3、5；倏逝：6、8、12、16 |

五条设定是**有理由的，不是随手取的**：

1. **网格甲取方阵**。角谱的输出网格与入射面同间距，两个方向都必须真的有频率内容；
   方阵还让两个轴的`z_c`相等，适用域上界没有歧义（0086第四节记的
   "两轴不等长时两个域之间会张开一条缝"在这里不出现，那条缝由
   `tests/test_optics_propagation.py`单独守）。
2. **矩孔两个方向取不同的采样数**（8与4）。取成一样的话，
   行列搞混的实现在方形孔上完全看不出来；亮行4 ≠ 亮列8 ≠ 网格32 这三个数
   一起把"这真的是个孔"钉死。
3. **中心偏半格、半宽再偏四分之一格**。以采样点为中心的对称孔覆盖的采样数
   必然是奇数（`2p+1`），要取到2的幂中心就得偏半格；边界恰好落在采样点上时
   "那个点在孔内还是孔外"由浮点最后一位决定——引擎侧对这种规格**失败关闭**
   （0086第5.1节抓到的真缺陷，实测把32个采样的缝算成31个）。
4. **网格乙的间距只有波长的0.158倍**。这不是为了好看：`|λf| > 1`的分量才是
   倏逝波，而`|λf|`的上限是`λ/(2dx)`——间距不小于半波长时**一个倏逝分量都没有**，
   那条最硬的判据就无从谈起。
5. **两个距离都取`z_c`的分数（0.5与0.4）而不是踩在边界上**。
   适用域两端那一格由`tests/test_optics_propagation.py`的采样判据门守着，
   不是本案例的题；本案例守的是**域内的答案对不对**。

## 二、参考解出处

Goodman,《Introduction to Fourier Optics》第3.10节：角谱与传递函数
`H = exp(i k z sqrt(1 − (λfx)² − (λfy)²))`、倏逝分量（根号变虚）与它的指数衰减；
第4.2节：菲涅耳傍轴近似正是把该根号展到二阶，
**即本案例前两条oracle分开的那两件事**。

**生成器走的是另一条算法**（脚本入库：`cases/angular_spectrum_propagation/generate_oracle.py`，
SHA-256钉在`oracle.json`的`generator.sha256`字段）：
被验内核是基2 Cooley-Tukey（位反转重排、log2(N)级蝶形、缓存的旋转因子表）
正变换 → 乘传递函数 → 同一条路逆变换；生成器是**二维直接求和**

```
S(v,u) = Σ_{(r,c)∈孔内} exp(−2πi(rv + cu)/N)
U(r,c) = (1/N²) Σ_v Σ_u S(v,u)·H(u,v)·exp(+2πi(rv + cu)/N)
```

**没有行列分解、没有位反转、没有旋转因子表**——两条路唯一共用的是
"二维DFT是什么"这条定义本身。生成器不import `physics_engine.optics`，
孔径的采样位置、传递函数、频率序号全部自己按几何与定义算。

生成器里有一处**从教训抄来的写法**：相位先按整数`(rv + cu) mod N`约化再进`exp`。
`tests/test_optics_field.py`实测过，直接写大幅角的`exp`时误差被幅角约化主导——
N=1024上比整数约化差**65倍**。**参照自己的误差盖过被验对象时，
那条判据测的就不再是引擎。**

倏逝功率损失那一条的金标走的是**频域Parseval**
（`Σ|H|²|S|² / Σ|S|²`，`S`是定义式直接求和），
而被验实现是在**实空间**逐点求`|U|²`再乘`dx·dy`——两条路只共用Parseval恒等式本身。

复数按决策0086的字节形制落盘：**一个复数是长度2的浮点数组，次序`(实部, 虚部)`**。

**必须红（实测）**：

- **把精确根号换成傍轴展开**（`sqrt(1−q)` → `1−q/2`）：`paraxial_eigenvalue_gap`
  那一行把差量逐bin冻住了；`paraxial_power_ratio_would_be`那一行更直接——
  conformance里正面构造了一个傍轴传播器，实测它在网格乙上给**恰好1.0**，
  而精确角谱给0.8955。两条必红都在`tests/cases/test_angular_spectrum_propagation.py`里，
  与判据写在同一条测试内，因为它们是同一句话的两半。
- **把矩孔写成缝**（`half_width_y_m = 1e9×pitch`）：`aperture_lit_row_count`
  当场从4变成32。`field_components`那12个数也全变，但**那一行的红说不清是哪里错了**，
  三个整数那三行才说得清。
- **z越界**：`test_the_case_setup_really_sits_inside_the_declared_domain_and_the_engine_refuses_outside`
  正面把距离调到`1.0001·z_c`并断言引擎拒答。它守的是**案例自己的设定**——
  越界之后那些冻结值就不再是"角谱在适用域内的答案"，而是混叠区里的一堆数。
- **`z=0`把`+0.0`写成`−0.0`**：清单那条只判最大偏差是0.0，这种错在偏差上照样是0。
  另有一条不靠清单的结构判据逐个比`float.hex()`。

## 四、已知失效清单

- **只验角谱，不验菲涅耳与夫琅禾费**。那两个形制由`cases/double_slit_propagated`
  与`tests/test_optics_propagation.py`守。两条案例**互不覆盖**：
  一条傍轴一条精确，判据表里没有一个量是重的。
- **只验标量近似**。矢量衍射、偏振、界面的菲涅耳系数都不在本案例。
  倏逝波在这里只是标量角谱里根号变虚的那一支，**不是**近场光学里的表面波。
- **只验一个分辨率、两个距离**。判据冻在32×32与1×32两个网格上；
  分辨率相关的收敛阶不在本案例（它在
  `tests/test_optics_rectangular_aperture.py::test_the_two_dimensional_pattern_converges_to_the_continuous_product_at_second_order`
  与`tests/test_optics_propagation.py`里，且那两条走的都是夫琅禾费）。
- **半群那条依赖平台的三角函数幅角约化**。本案例的`k·z = 6.28e3`弧度，
  比`tests/test_optics_propagation.py`那条门的`1e5`小一个多数量级，
  所以本案例对平台的敏感度**低于**那一条；但原理不变——
  若某平台的libm只做简单取模，`cos`的误差会按`eps·kz`放大。
  **红了先查平台，不要先放宽**。
- **网格乙是一维问题**（1行）。倏逝那条判据因此只验了x方向的倏逝。
  二维的倏逝（`(λfx)² + (λfy)² > 1`）没有被单独冻——
  引擎侧那一条式子是两轴对称的（`propagation.py`里`square`同时减两项），
  但"对称"是读代码得到的推断不是实测，如实记在这里。
- **不验反向传播**（`z < 0`）。倏逝分量会按`exp(+k|z|sqrt(...))`爆炸，
  在浮点上那不是"病态"是"没有意义"；引擎侧对`z < 0`失败关闭。
- **`paraxial_power_ratio_would_be`这一行不是被验实现的输出**，
  是被验实现必须与之**不同**的那个数。它冻在清单里是为了让"傍轴给不出这个"
  这句话有一个可执行的形态，而不是一句案例页里的散文。
- 未在Windows/Linux复核。

## 五、档位与负载级

C档，**interactive**（<1s），与`oracle.json`的`load_tier`逐字一致（`interactive`），
无pytest marker。

实测（本机，中位数）：conformance六条测试共**0.05 s**；生成器一次**0.06 s**。

**规模与墙钟的关系**（本机，**只报这个规模下是多少，不下任何跨机结论**——
plans/16的M8立的口径就是本机墙钟不作数）：

| 环节 | 规模 | 一次（三次中位数） |
|---|---|---|
| 生成器的二维直接求和（正+逆） | 32×32格×32个亮采样 ＋ 12个采样×1024格 | 0.0071 s |
| 引擎的角谱传播（基2蝶形正逆各一次） | 32×32 | 0.0023 s |

**这个规模是挑出来的，理由写在这里以免下一个人照抄**：金标那一侧是
`O(N²·亮采样数)`加`O(冻结点数·N²)`，纯Python；32×32上是毫秒级，
**128×128上正变换那一步就要32倍**（`N²`翻16倍、亮采样数翻4倍）。
本案例只需要"角谱在适用域内算对了"这一件事，不需要大网格——
大网格上多出来的信息是收敛阶，而那一条在别处已经有了。

## 六、本案例不是什么

- **不是"引擎能做近场传播了"的证据**。它算的是二值掩模在一个距离上的复振幅，
  没有透镜、没有多元件、没有介质界面、没有部分相干、没有偏振。
- **不是`double_slit_propagated`的替代**。那一条验的是夫琅禾费远场
  （傍轴、单次FFT、输出网格随z张开），本条验的是角谱（精确、同间距）。
  **两条案例的判据表里没有一个量是重的。**
- **不是近场光学的证据**。网格乙里的倏逝波是标量角谱中根号变虚的那一支，
  它不是表面等离激元、不是SNOM探针耦合，也没有任何界面。
- **不是通用FFT库的证明**。`fft`只做2的幂，非2幂**失败关闭**（决策0086第二节）。
- **不是性能证明**。第五节那张表是**本机单点**，按0018只判量级不立门。
- **不验适用域的边界那一格**。`z = z_c`上两个形制交接的那一条门在
  `tests/test_optics_propagation.py`；本案例只在域内取点，
  越界只作为一条必红出现。
