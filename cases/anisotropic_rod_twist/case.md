# anisotropic_rod_twist 整杆各向异性弯曲与扭转

**这一条回答的是"带材在非平面槽里往哪个轴弯、扭多少"。**

plans/14第二节量出来：这批工件**没有一个是平面件**（最小二乘拟合平面后的最大离面
距离18.4—116.9 mm），整匝帧扭转`∫|τ|ds`跨236°—657°，而带材`EI_hard/GJ ≈ 1040`。
**带材一定优先扭而不是硬弯**——而各向同性`EI`连"往哪个轴弯"都表达不了，
这不是精度问题。本案例是决策0065的验收面。

判据值的正本是同目录的`oracle.json`，`case_id`为`case/anisotropic_rod_twist`。
**本案例的材料参数标`hypothesis_only`**：带材`E`、`EI`、`GJ`全是假设输入
（`research/05`把它们列为"只有现场实测能补"的五项之一）；
**但四条判据没有一条依赖那些数的真值**——它们判的是比值、闭式关系与结构零。

## 一、物理/几何设定

四个算例，各自最小：

| 算例 | 设定 | 出处 |
|---|---|---|
| 螺旋线 | `R = 40 mm`、`p = 12 mm`、扫过2 rad，N=21/41/81/161 | **设定**。`p/R = 0.3`让`τ`与`κ`同量级，否则"验挠率"名不副实 |
| 悬臂 | `L = 50 mm`、端载`F = −0.05 N`、N=11/21/41/81 | **设定**。载荷小到挠度/跨长≈5e-4（线性区） |
| 扭转 | `L = 200 mm`、N=21、端扭矩`M = 0.5 N·mm` | **设定** |
| holonomy | 四条10 mm边，切向`x̂ → ŷ → ẑ → x̂` | **构造**：三个直角的球面测地三角形 |

| 材料 | 取值 | 出处 |
|---|---|---|
| `EI_easy`（朝厚度方向弯，中性轴沿带宽） | 8.0×10⁴ N·mm² | **设定** |
| `EI_hard`（在带宽面内弯，edgewise） | 8.0×10⁷ N·mm² | **设定**，取比值1000让判据一眼可读 |
| `GJ` | 77 N·mm² | plans/14第2.3节`G·(1/3)·w·t³`，4 mm×0.1 mm带材、ν=0.3 |
| `EA`（悬臂用，只为让问题适定） | 4.0×10⁴ N | **设定** |
| 真实带材的两个数 | `EI_hard = E·t·w³/12 = 8.0e4`、`EI_hard/EI_easy = (w/h)² = 1600` | plans/14第2.3节 |

**帧约定**（接反是本案例第一位要防的事）：`d1`是**穿厚**方向、`d2`是**带宽**方向，
`d2 = t × d1`；`κ1 = 0.5(m2_l+m2_r)·κb`配`EI_easy`、`κ2 = −0.5(m1_l+m1_r)·κb`配`EI_hard`。
`κ1`/`κ2`是**离散**曲率（无量纲、已在对偶元上积分过），物理曲率是它除以`l̄`。

## 二、参考解出处

四条闭式，全部独立于被验内核；生成器`generate_oracle.py`只写这四条，
**不调`solve_equilibrium`、不调`physics_engine.rod`、不引任何力学模块**（有一条门判它）。

1. **螺旋线运动学**（教科书）：`x(θ) = (R cos θ, R sin θ, p θ)`给
   `κ = R/(R²+p²)`、`τ = p/(R²+p²)`。
   **第三个数是零，而且是结构零**：`m1`取解析主法线时，
   两条边中点法线之和`= 2cos(Δ/2)·n(θ_v)`严格平行于顶点法线，
   而顶点副法线与它正交，于是`κ2 ≡ 0`，**与离散步长无关**。
2. **端载悬臂**：`δ = F·L³/(3·EI)`。矩形截面两个主轴的二阶矩差`(w/h)²`倍，
   所以**同一根杆、同一个载荷、只把参考`d1`绕轴转90°**，挠度比必须恰是`EI_hard/EI_easy`。
3. **端扭矩杆**：`θ = M·L/GJ`。`L`是**端边中点之间的距离**`Σ l̄_i`，见第四节第2条。
4. **Gauss-Bonnet**：切向序列`x̂ → ŷ → ẑ → x̂`围出的球面测地三角形三个角都是直角，
   面积（＝立体角）`= 3·π/2 − π = π/2 = 4π/8`。
   **沿这条闭合切向路径平行输运一周的holonomy恰是这个立体角。**
   两端材料帧夹持、中间自由时串联扭簧能量`0.5·GJ·Θ²/Σl̄`。

同行（WDS）那边这一套**没有任何测试验证各向异性弯曲的行为**，
其验证协议因为没有oracle而**明确拒绝**建各向异性对比算例
（`tests/validation/test_c1_criteria_frozen.py`第77行断言这会抛`ValueError`）。
第2、3、4条是本仓自己立的，同行没有。

| 挠度落点`δ_easy`、`δ_hard` | rel 1e-3 | 含**固支半格柔度**订正后二阶（N=11/21/41/81实测2.350e-2/6.063e-3/1.539e-3/3.880e-4，比值3.876/3.939/3.968）。判N=81那一档，1e-3是2.6倍余量 |

## 四、已知失效清单

1. **`m_ref`冻结 ⟹ 扭转项对位置没有任何依赖。**
   这意味着**单次`solve_equilibrium`调用里弯曲与扭转的交换根本不存在**——
   `RodTwist.gradient`在位置块上恒为零（`tests/test_rod.py`有一条断言直接判它）。
   交换只能靠载荷步之间重新输运参考帧找回来，即`solve_rod_with_retransport`。
   **抄了公式不抄外循环，得到的杆弯不出扭，而且不报任何错。**

2. **`θ = M·L/GJ`里的`L`是`Σ l̄_i = 190 mm`，杆长是200 mm。**
   扭转弹簧住在**内顶点**上，`n_edges`条边之间只有`n_edges − 1`段，
   等分时`Σ l̄ = (n_edges−1)·h`，**比杆长少一个`h`**。
   拿杆长去对会得到一个5%的"偏差"，然后被当成精度问题去调——**那10 mm是形制**。
   连续极限里它对应"第一条边中点到最后一条边中点"的距离，`h → 0`时差别消失。

3. **固支悬臂不加半格订正只有一阶收敛。**
   被钉死的第一条边吞掉了钳口到第一条边中点那半格的柔度，正确的等效对偶长度是`3h/2`。
   实测不订正时偏差0.145/0.0738/0.0372/0.0187（比值≈2，**一阶**），
   订正后是干净的二阶。推导在`energies.clamped_chain_bending_vertices`
   （静态凝聚：`min_{φ0} (EI/h)φ0² + (EI/2h)(φ1−φ0)² ⟹ φ0 = φ1/3`）。
   这是决策0027那条教训的**第三例**——0027警告过归因错就会去改边界条件，而那改不动它。

4. **绝对残差容差取1e-9 N，比`solve.py`推荐的"总载荷的1e-9到1e-10"（=5e-11）松。**
   不是放水：**本问题的可达残差地板实测是2.5e-10 N**，取5e-11时60次迭代、
   399次回溯仍不收敛。这正是`solve.py`docstring里"绝对残差的可达地板随问题规模上升"。

5. **易/难轴门把γ全钉住。** 不钉，杆会自己转过去用软轴——那是**另一件事**
   （由holonomy那两条门验）。本门量的是**纯弯曲**的各向异性。

6. **挠度比的2.79e-7偏差是几何非线性，不是数值噪声。**
   载荷降10倍它降100倍（2.79e-7 → 2.79e-9 → 2.65e-11），是干净的`O(F²)`。
   判据取1e-6而不是1e-12，就是给这一项留的。

7. **holonomy那道门刻意把`EI`压到`1e-3 N·mm²`（GJ的1e-5量级）。**
   球面三角的90°折角给出很大的离散曲率（`|κb| = 2`），弯曲项对γ的耦合会把扭转
   分布拉歪。**本门单独验扭转通道**；弯曲通道由前两组门各自验过。
   这条是判据的适用范围声明，不是掩盖——`EI`不压时holonomy本身（`γ₃−γ₀ = −π/2`）
   照样成立，变的只是γ在链上的分布。

8. **本案例不含塑性、不含轴向`N`、不含槽壁接触。** 见第六节。

9. 无skip。

## 五、档位与负载级

## 六、本案例不是什么

* **不是"抄了公式就算数"的案例。** 最后一条判据期望的是一个**错误答案**
  （`twist_energy_without_retransport_n_mm = 0.0`，零容差），
  记的是不抄retransport外层循环会拿到什么。**那是这道门唯一的分辨力**：
  若哪天有人改了形制使单次求解也能出扭转，这一条会红——而那时该红的，
  正是"这道门还在不在区分两条路"这个问题本身。

* **不是弹塑性。** 纯弹性双轴弯曲＋扭转两项，没有纤维塑性、没有材料历史。
  `sections`/`section_beam`那一片有塑性但只有一个站点，
  **两片今天没有接口**，合并要另走决策。

* **不含轴向`N`进全局装配。** 悬臂算例里的`AxialStretch`是既有的独立能量项，
  不是杆自己的轴向本构。

* **不含槽壁接触。** plans/14第2.3节说的"双轴弯曲＋扭转＋槽壁接触三件一起算"，
  本案例交了前两件。**所以那个5.9%仍然定位不到区间里的哪一点**——
  它是上界，真值在它与0之间。

* **不是真实工件的复现。** 四个算例都是最小构造（螺旋线、直悬臂、直杆、四段折线），
  没有一个读了`centerline.csv`。真实槽的曲率与扭率分布见plans/14第2.2节，
  **把它跑进来需要接触**。

* **不解锁任何能力位。** 按决策0064第二节，本波次四条轨道没有一条让某位从
  `partial`进`done`；本案例也不例外——它是单元级的闭式门，不是端到端场景。

* **不判性能。** 决策0065第三、四节的墙钟与带宽数是**在那里报的**，
  不进本案例的判据表：它们随机器负载变（实测那批数是在1分钟负载7.35时量的），
  拿它们当门会得到一个随机红。
