# fts_instrument_line_shape FTS仪器线型与Norton-Beer切趾

`case/fts_instrument_line_shape`。B档，spec/15（光学域进引擎）+ `optics/fts.py`。
同行案例复用（research/05第2.3节光学族的另外两条：无切趾ILS的
`FWHM = 1.20671/(2·OPD_max)`、Norton-Beer三组各自`Σ Ci = 1`）。
消费方fts-digital-twin的`assessment/instrument_line_shape.py`用同一约定，
本案例是引擎侧与它对得上的那个闭式参照。

## 一、物理/几何设定

一条单色谱线经有限扫描后被摊成一个固定核（仪器线型）。无切趾时该核是
`ILS(dσ) = sinc(2·L·dσ)`（归一化sinc）；切趾窗为
`A(Δ) = Σ_i Ci·(1 − (Δ/L)²)^i`。

| 量 | 值 |
|---|---|
| 单边最大光程差L | 0.05 m（对应分辨率1/(2L)=10周/米=0.1 cm⁻¹） |
| 波数口径 | **谱学波数**σ=1/λ，周/米（`per_m`），不是角波数k=2π/λ |
| sinc约定 | **归一化** `sinc(z)=sin(πz)/(πz)`，首零在z=1 |
| Norton-Beer弱 | C=(0.384093, −0.087577, 0.703484, 0) |
| Norton-Beer中 | C=(0.152442, −0.136176, 0.983734, 0) |
| Norton-Beer强 | C=(0.045335, 0, 0.554883, 0.399782) |
| 窗最小值扫描点数 | 4096（含两端） |
| Simpson节点 | 20000（两档自校验，地板1e-15） |
| 越界取样点 | 1.5·L |

**`L`是单边不是全程**：干涉图录在`−L..+L`上，所以分辨率公式的分母是`2L`。
把两者弄反是2倍的分辨率错，而2倍"看起来完全合理"——这是本案例守的第一道单位边界。

## 二、参考解出处

- **无切趾ILS与1.20671**：FTS教科书通用结论。**生成器不抄这个数**，
  它对`sin(πz)/(πz) = 1/2`直接二分求根（100次，区间压到浮点地板），
  得1.2067091288032286；教科书的1.20671是它四舍五入到第五位小数的结果，
  实测差8.712e-7，落在末位半宽5e-6内。
- **Norton-Beer系数**：Norton & Beer 1976（JOSA 66, 259）及其1977勘误
  （JOSA 67, 419）的标准三组；同值见Naylor & Tahic 2007（JOSA A 24, 3644）表1。
  生成器**另抄一份**，与内核那份互为对拍——抄错一位，`coefficient_sums`或
  `window_at_scan_end`当场红。
- **通量代价**：内核走求和闭式`Σ Ci·2^(2i)(i!)²/(2i+1)!`（每阶积分比1、2/3、8/15、16/35），
  生成器走复合Simpson数值积分。**两条不同的路**，所以这条验的是那个闭式推导本身。

生成器不调`normalised_sinc`、不调`norton_beer_*`、不import `physics_engine.optics`。

## 三、判据表

| 量 | rel/abs | 理由 |
|---|---|---|
| `fwhm_in_sinc_units` | abs 1e-15 | 内核里是写死的常量，金标是**独立二分求根**——所以这条真的在验那个常量。二分残差只剩sinc求值的1eps量级；1e-15约4.5eps |
| `fwhm_matches_textbook_quote` | abs 0 | 布尔：`|因子 − 1.20671| ≤ 5e-6`（教科书末位1e-5的四舍五入半宽）。实测8.712e-7。与上一条分工：上一条验精度，这条验没写错数 |
| `first_zero_per_m` | rel 1e-15 | `1/(2L)`，一次乘一次除。**这条同时是L与2L的捕手** |
| `fwhm_per_m` | rel 1e-15 | 因子`/(2L)`，两次乘除 |
| `line_shape_at_peak` | abs 0 | `sinc(0)=1`是极限的精确值，实现直接返回1.0不走除法——零容差 |
| `line_shape_at_first_zero` | abs 1e-16 | `sinc(1)`在float64上不是0而是`sin(π的浮点表示)/π`=3.898e-17。**容差是算出来的**：1e-16是这个必然残值的2.6倍 |
| `line_shape_at_plus_half_fwhm` | abs 1e-15 | 半高点上ILS必须恰为0.5——**这条才是那个半宽常量的物理门**。实测0.4999999999999999，偏差1.11e-16即0.5eps |
| `line_shape_at_minus_half_fwhm` | abs 1e-15 | 负侧同值（偶函数）。两侧都验：只验一侧的话，把偏移取了绝对值的实现与真正对称的实现分不开 |
| `coefficient_sums`（3组） | abs 1e-6 | **`Σ Ci = 1`是一条门**。物理必要条件：`A(0)=Σ Ci`，零光程差点承载全部通量，`Σ≠1`会把整条谱线整体缩放。1e-6是文献系数的申报位数（六位小数）。**本仓三组实测残差恰为0** |
| `window_at_zero_opd`（3组） | abs 1e-6 | `A(0)=Σ Ci`的另一面：上一条验系数表，这条验窗函数真的在Δ=0取到那个和（幂次写错、区间判断写反都在这里露出） |
| `window_at_scan_end`（3组） | abs 0 | `A(L)=C0`**逐位相等**：x=1时`(1−x²)=0`，高阶项全灭，没有任何算术发生。残值越小切趾越强：弱0.384 > 中0.152 > 强0.045 |
| `window_beyond_scan`（3组） | abs 0 | 扫描区间外**是0不是延拓**。不写这条的话，一个把`(1−x²)^i`在`|x|>1`上继续算的实现会给出正负乱跳的"窗"，且在别的判据上全绿 |
| `throughput`（3组） | rel 1e-15 | 闭式 对 Simpson。Simpson对三次以下精确、窗是六次多项式，h=5e-5时截断约3e-18，远低于浮点地板；两条路实测差≤1.11e-16 |
| `throughput_strictly_decreasing` | abs 0 | 布尔排序判据（spec/12第6.2节写法2）：弱0.7009 > 中0.5863 > 强0.5240，**越强的切趾扔掉越多信号**。假通过口子是三者全零，堵法是先各自断言落在(0,1)开区间 |
| `window_minimum_reduced_opd`（3组） | abs 3e-4 | 读侧在4096个等距点上取最小，位置误差上界是网格半间距1.221e-4，取值是它的2.5倍。**weak与medium的极小落在端点内侧**（x*≈0.9684与0.9648），strong落在端点上（x*=1）——这个差别只由C1的符号决定，是C1抄错的直接捕手 |
| `window_minimum_value`（3组） | abs 1e-7 | 网格取最小的值误差是`½·|A''|·δ²`，三组最大界5.460e-8，取值约1.8倍 |

**必须红（实测）**：

- 第一版把"窗在扫描区间内单调不增"写成判据，**当场红**：
  `weak的窗在0.049218750000000006 m处回升了：0.38136774267196655→0.3820539035642147`。
  红得对——见第四节第一条。这条失败直接催生了`window_minimum_*`两条判据。
- `tests/test_optics.py`里有一条把弱组C2扰动1e-5的用例，验的正是
  `Σ Ci = 1`那条门在1e-6容差下抓得住这种量级的抄错。

## 四、已知失效清单

- **weak与medium的切趾窗在扫描端点附近不单调**：C1为负，窗先跌到一个内部极小
  （弱：x*=0.9684、A=0.381367，比`A(L)=0.384093`低2.726e-3；
  中：x*=0.9648、A=0.147729，低4.713e-3）再回升到C0。strong的C1=0，它是单调的。
  **这不是bug，是这两组已发表系数的性质**——Norton-Beer从未要求切趾窗单调。
  写在这里是因为它反直觉，且第一版的单调判据正因此红过。
- **本仓没有重新推导那三组系数**。`Σ Ci = 1`是它们的**必要**自洽条件，
  不是数值正确性的证明。真要验证它们，得复现Norton-Beer的优化问题
  （在给定主瓣展宽下最小化边瓣），那不在本块。
- **不做带切趾的ILS本身**。Norton-Beer窗的傅里叶变换要球贝塞尔`j_i(u)/u^i`
  与它的小自变量级数（直接用sin/cos写会在`u→0`处相消到失去全部有效位）。
  本案例只验窗本身与它的通量代价。
- **不做自切趾**（有限接收立体角把条纹对比度吃掉的那一项）。FTS一侧有成熟实现，
  引擎侧按spec/12第七节的切换门搬迁，不在本块预支。
- **不做相位误差、采样与混叠**。
- **通量代价的判据只在L=0.05 m上跑过**。它是L无关的比值（量纲上就是），
  但"量纲上无关"是推断不是实测。
- 未在Windows/Linux复核。

## 五、档位与负载级

B档，**interactive**（<1s）。实测：三条测试共**0.03 s**（最贵的是4096点的窗最小值
扫描×3组）。生成器一次**0.23 s**（两档Simpson各20000/10000节点×3组）。

## 六、本案例不是什么

- **不是"引擎能做FTS了"的证据**。它算的是两条闭式与一族窗函数，
  没有干涉图、没有变换、没有一条真实的谱。
- **不是切趾窗质量的评价**。边瓣压低多少、主瓣展宽多少都没验——
  那要带切趾的ILS，见第四节。
- **不是第二套FTS**。物理正本在fts-digital-twin；本案例是引擎侧的闭式参照，
  它的价值是让两边**对得上**，不是取代。
- **不验衍射那一侧**——那是`cases/scalar_diffraction_airy`。
- **不是性能证明**：每次调用几十个浮点运算。
