# free_span_tension_step 自由跨段的张力：由线速度差与带材弹性生成

**本案例把``T = M/R``换掉了。** `drives.SpoolTension`把张力写成扭矩除以卷径——
那条式子里没有时间、没有速度、没有带材，**于是控制器没有任何东西可控**：
一个必须抑制线速度扰动的控制律，在那个模型里连扰动都不存在。

本案例的链路是：**上游喂料长度时间线 → 线速度 → 跨段材料长度账 →
带材弹性 → 张力 → 放线盘力矩平衡 → 放线速度**，闭成一个环。
守plans/14第3.2节登记的二号缺口（线速度与输运），决策0066。

判据值的正本是同目录的`oracle.json`（本页只解释，不重复声明），
`case_id`为`case/free_span_tension_step`。

**本案例永久标`hypothesis_only`**：带材EA、跨段长度、放线盘转动惯量、
轴承阻力矩、线速度**一条实测都没有**，出处见第一节与0062第二节裁决2。

## 一、物理/几何设定

跨段一端固定在R1（最后一只实体导轮，世界系里不动），另一端是落位点。
放线盘由磁粉离合器**制动**，转速由带材拉着走；收线端速度由伺服给定。

| 项 | 取值 | 出处 |
|---|---|---|
| 带材``EA`` | 60 000 N（4 mm×0.1 mm、``E ≈ 150 GPa``） | **假设输入**，与`cases/capstan_tension_ratio`同一个数 |
| 跨段几何长度``L_geo`` | 300.0 mm | **假设输入**。plans/14第二节量出工件包络432×270×224 mm，几百mm是对的量级；**这一段的实际长度没有实测**，且真机上它每个样点都在变（见第四节第1条） |
| 放线盘半径``R`` | 60.0 mm | **假设输入** |
| 放线盘转动惯量``J`` | 5 000 kg·mm² | **假设输入**。满卷/空卷差几倍，本案例取定值 |
| 制动力矩``M`` | 1 200 N·mm | **假设输入**。取``M/R = 20 N``落在真机张力区间10—30 N的中段；POC-050L的L后缀线圈参数厂家资料没有（0062第二节裁决3） |
| 线速度``v`` | 20.0 mm/s | **假设输入**，真机线速度没有实测记录 |
| 速度阶跃``Δv`` | 2.0 mm/s（10%）／0.2 mm/s（1%） | 10%判超调，1%判收敛阶（理由见第四节第3条） |
| 轴承阻力矩``c`` | 0 ／ 50 ／ 1 000 N·mm·s | **三档全是假设输入**：0是无阻尼极限；**50是真实量级**（``ζ = 0.0132``）；**1 000是为了把阶跃响应放进良态区调出来的**，比真实轴承大二十倍 |
| 步长``dt`` | 1e-6 ／ 1e-5 ／ 收敛四档1.6e-5→2e-6 | 峰值那条判据的分辨率就是步长 |
| 积分格式 | 半隐式Euler（长度账用**新**转速） | 见第四节第4条 |
| 重力、接触、导轮 | **全无** | 本案例只有一段自由跨与一只放线盘，见第六节 |

模型三条：

    输运账     dL_mat/dt = v_放线 − v_收线
    带材弹性   ε = (L_geo − L_mat)/L_mat 、 T = EA·ε （ε ≤ 0 时 T = 0）
    力矩平衡   J·dω/dt = T·R − M − c·ω          （ω > 0，制动不是驱动）

**``ω·R``被当作放线端的未拉伸（材料）吞吐率**——这是一条声明：真机上盘上的带材
也带着张力，误差是``O(ε)``，本工况``ε = 3.33e-4``。

## 二、参考解出处

**没有可引的文献式号，参考解是本案例自己推的**，推导逐步写在
`generate_oracle.py`的docstring里，脚本入库、SHA进清单
（`algorithm:oracle/free_span_tension_step` v1.0.0）。
生成器**只import``math``与`physics_engine.oracles`**，
不import`transport`、不import`drives`、不import任何力学模块（轴7规则3）。

三条闭式：

1. **稳态**：``T = M/R + c·v/R²``（力矩平衡取``dω/dt = 0``）。
   ``c = 0``时它恰是``T = M/R``——**旧模型是本模型在零轴承阻力矩下的稳态特例**，
   案例有一道门判两边给出**同一个浮点数**；
2. **二阶参数**：``ω_n = sqrt(1000·R²·K/J)``、``ζ = (1000·c/J)/(2ω_n)``，
   其中``K = −dT/dL_mat = EA·L_geo/L_mat²``。
   那个``1000``是``1 N = 1000 kg·mm/s²``；
3. **阶跃响应**：张力连续而速度差当场跳``−Δv``，初值带斜率冲击
   ``y'(0) = ω_n/(2ζ)``，等价于传递函数多一个零点。于是

       y(t) = 1 − e^{−ζω_n t}·[cos(ω_d t) − ((1−2ζ²)/(2ζ√(1−ζ²)))·sin(ω_d t)]
       t_p  = (π − acos ζ)/ω_d                            ← 标准二阶是 π/ω_d
       超调 = exp(−ζ(π − acos ζ)/√(1−ζ²)) / (2ζ)

``ζ → 0``时相对超调发散（稳态变化趋零而振荡幅值不趋零），
绝对幅值仍是闭式``K·Δv/ω_n``、峰值落在四分之一周期``(π/2)/ω_n``。

## 三、判据表

| 量 | rel / abs | 理由 |
|---|---|---|
| ``c = 0``的``T_ss``对`drives.SpoolTension.tension_n` | **零容差（`==`）** | **恒等式**：这句"旧模型是本模型的特例"要么逐位成立要么就不该说。实测两边都是`20.0` |
| 闭式稳态起点在推进下的漂移 | abs 1e-10 N | **恒等式**：半隐式Euler的离散不动点＝连续不动点。实测20000步（0.2 s）漂移**恰为0.0**；容差按``T → L_mat → T``往返舍入给（四档最坏3.908e-12） |
| 跨段刚度``K`` | rel 1e-14 | 纯代数。**它与``EA/L_geo``差``(1+ε)² = 1+6.67e-4``**，比超调容差还大一倍——拿``EA/L_geo``当K会把正确实现判红 |

| 阶跃相对超调 | rel 3e-4 | **收敛结果**：半隐式Euler一阶误差。``dt = 1e-6``实测``c = 50``给9.03e-6、``c = 1000``给7.35e-5，取1000档的4倍余量 |
| 阶跃峰值时刻 | rel 1e-4 | **容差由采样栅格定不由模型精度定**：``dt = 1e-6``对``t_p ≈ 4.2e-3``是2.4e-4的栅格；实测两档都是1.76e-5（峰附近是二次的），但换``dt``它立刻退回栅格量级 |
| 阶跃峰值幅值 | rel 2e-4 | 实测8.8e-6／3.93e-5，取5倍余量。**必须与相对超调并判**：``ΔT_ss``在``c → 0``时趋零，只判相对量时把它算错照样过 |
| 无阻尼幅值``K·Δv/ω_n``与四分之一周期 | rel 1e-4 | 实测1.17e-5／7.84e-6 |
| 无阻尼包络（末周期/首周期） | abs 1e-6 于 1.0 | **辛格式在无阻尼极限守幅值**。实测跑满12.08个周期后比值**0.99999998** |
| 时间步收敛比 | 落在``[1.9, 2.1]`` | **一阶收敛**：四档``dt``实测误差``3.605e-5/1.803e-5/9.021e-6/4.513e-6``，比值**1.99906/1.99911/1.99868**。**不写死为2**——与`harmonic_oscillator`那条"不写死为4"同源 |
| 三个方向符号 | 符号，零容差 | 收线端加速⟹张力升、减速⟹降、制动力矩加大⟹升。实测收线端``±2 mm/s``给``+0.72620``/``−0.72618 N``（反对称到0.002%） |
| ``ζ = 0.5``处本式与恢复系数式 | rel 1e-15（相等）；其余``ζ``差>10% | **盲区门**，见第四节第2条 |
| 时间线逐段速率与驱动等价 | rel 1e-15；驱动**逐位相同** | 段内恒速语义要有确定含义。实测8000步全部样点`==`、末态`26.708364419146104`一个字节不差 |

**恒等式、收敛结果、符号必须分开**，因为它们红了说明的事完全不同：
第一类红说明两个模型的关系断了，第二类红说明步长不够或线性化参考点用错了，
第三类红说明**符号反了**——而符号反了的症状不是一个错的数。

## 四、已知失效清单

1. **跨段几何长度是常数，而真机上它每个样点都在变。**
   plans/14第一节：张力机不动、机器人搬着工件走，所以自由跨一端固定在R1、
   一端随机械臂运动，跨长与入射角逐样点变。那是plans/14第3.3节登记的
   **三号缺口**（落位点几何层），不在本案例。
   本案例因此**算不了"臂动作为扰动源"**，只能算"收线端速度作为扰动源"。

2. **``ζ = 0.5``是一个盲区，而它正是写测试时最顺手的那个值。**
   ``exp(−ζΦ/√(1−ζ²))``这个形状在本仓出现了三次：
   `contact.restitution_from_damping_ratio`取``Φ = 2·acos ζ``、
   `drives.step_response_overshoot`取``Φ = π``、本案例取``Φ = π − acos ζ``
   并多一个前因子``1/(2ζ)``。
   ``π − acos ζ = 2·acos ζ`` ⟺ ``ζ = 0.5``，而``1/(2ζ)``在同一点**恰为1**——
   **两处退化撞在同一个点上**。实测``ζ = 0.5``时本式给`0.29843605919227484`、
   恢复系数给`0.2984360591922749`，**差一个ulp，是同一个实数**。
   只在``ζ = 0.5``上判，判不出这两件事是两件事。判据因此在**五个**``ζ``上扫。

3. **金标是线性化解，它给误差垫了一条floor。**
   与`capstan_tension_ratio`那条"拿``e^{μΔφ}``当逐节点判据"同形。
   线性化偏差``∝ Δv²``而响应``∝ Δv``，所以相对floor``∝ Δv``。
   同一批``dt``、同一终点，实测：

   | ``Δv`` | 收敛比 |
   |---|---|
   | 0.2 mm/s | 1.99906 / 1.99911 / 1.99868 |
   | 2.0 mm/s | 1.99652 / 1.99404 / **1.98863** |

   再往细里走（``Δv = 2``、``dt`` 到 2.5e-7）实测掉到**1.9168**。
   **症状看起来像"收敛阶坏了"，而病根是判据本身。**
   有一条门专记这件事，收敛阶那条门因此跑在``Δv = 0.2``上。

4. **积分格式是半隐式Euler，一阶，且没有自适应、没有回退。**
   步长是写死的档。改成显式Euler（长度账用旧转速）时**五条门同时红**，
   所以这条选择是被守着的，但**它不是最优的**：要更高阶就要另裁。

5. **``ω ≤ 0``当场失败关闭。**
   放线盘停转时磁粉制动器进入静摩擦保持段（``|T·R| ≤ M``时盘不转），
   那是一条互补条件、要一套return-map。本案例**不假装能算它**。
   实测这条门真的会开火：把两端对调之后第**7595**步（7.595 ms）转速穿零被它接住。

6. **松弛（``ε ≤ 0``）时``L_geo``不再是跨段的长度。**
   带材垂成一条悬链线，此后模型给出的一切都不再有意义。
   原语取``T = 0``并给出``is_slack``，容不容忍由`SpanTransportLoop.forbid_slack`
   **显式声明**——本案例一律取``True``。**本案例不判松弛工况的任何数值。**

7. **无阻尼那一档的"不衰减"是辛格式的性质，不是无阻尼的证明。**
   判据判的是"幅值比落在1附近"，它挡得住多出来的耗散，
   **挡不住"格式恰好也守住了一个错的幅值"**——所以幅值本身另有一条闭式判据。

8. **一条实测输入都没有，全部产物永久`hypothesis_only`。**
   摘除要按项写行（0062第八节）。

9. 无skip。

## 六、本案例不是什么

* **不是场景⑥端到端**。只有一段自由跨与一只放线盘：导轮、蹭边、排线横动、
  传感器、控制器全都不在。要看那些去`cases/winding_line_endtoend`。
* **不是控制器**。本案例只把扰动**建出来**并量清楚它有多大、衰减得多慢；
  抑制它是控制器的事，而控制器要接在哪一路（制动力矩还是收线速度）
  是使用者的选择，本案例不替他选。
* **不是`drives.TensionLoop`的替代**。那条链路建的是电流→扭矩→时延→PID；
  本案例建的是扭矩→速度→长度→张力。**两条链路今天没有被接在一起**——
  接起来要一条把``brake_torque_nmm``交给`MagneticParticleClutch`的装配层，
  那是下一片。
* **不是材料注入**。`feed.py`的docstring自陈那是"带材从轮面流过、边界随材料移动"。
  本案例的长度账是**欧拉**的（跨段是一个控制体），`feed.py`是**拉格朗日**的
  节点账，两者互不覆盖。跨段里没有节点、没有弯曲、没有杆。
* **不是带材的横向行为**。这里的带材是**一根一维弹簧**：只有轴向刚度``EA``，
  没有宽度、没有弯曲、没有扭转、没有横漂。横漂在
  `cases/roller_skew_lateral_drift`，各向异性弯曲是另一条轨道。
* **不判定量**。EA、跨长、惯量、轴承阻力矩、线速度全是假设输入。
  它证明的是**机制**：速度差怎么变成张力、张力怎么反过来改速度、
  以及**这个环开环几乎不衰减**。
* **不判松弛工况**。见第四节第6条。
