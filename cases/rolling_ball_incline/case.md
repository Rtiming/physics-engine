# rolling_ball_incline — 无滑滚球与滑动滚球

plans/16的M2与M3，开工前置见[0081](../../docs/decisions/0081_路径B开工前的两件_判据出处与我自己写错的那个数_20260818.md)，
同行依据见[research/17](../../docs/research/17_同行的刚体接触动力学_六问与它们各自改了什么_20260818.md)。

**本案例是本仓第一条让转动自由度参与动态接触的案例。**

## 一、物理/几何设定

实心刚体球在无限大斜面上由静止释放。全部量：长度mm、力N、质量kg、时间s。

| 量 | 值 | 出处 |
|---|---|---|
| 半径`R` | 10.000 mm | 设定 |
| 质量`m` | 1.000 kg | 设定 |
| 惯量 | `I = (2/5)mR² = 40.000 kg·mm²` | 实心球，**用`Fraction`精确算**（生成器） |
| 重力`g` | 9810.000 mm/s² | 设定；重量`W = m·g/1000 = 9.810 N`（`1 N = 1000 kg·mm/s²`） |
| 倾角`θ` | 20.000° | 设定 |
| 法向罚刚度`k_n` | 5.000e5 N/mm | 与`winding_line_endtoend`同档 |
| 切向系数`k_t` | **50.000 N·s/mm** | **被实测逼出来的，见第四节第1条** |
| 摩擦`μ` | 滚动支0.300、滑动支0.050 | 分界`μc = tan20°/3.5 = 0.10399` |
| 步长／步数 | `1e-6` s ／ 20000（共0.02 s） | 见第四节第2条 |
| 积分器 | `RK4_BODY` | `rigidbody`已有的四阶显式 |

初始球心高度扣掉静态压缩量`W·cosθ/k_n`，**免得第一帧是一次撞击**。

## 二、参考解出处

**教科书闭式，不是对同行测试的转述。** research/17第四节实测过这件事：
Chrono／Bullet／MuJoCo**没有一家为`a = (5/7)g sinθ`立过数值门**
（Chrono那两条是终态阈值、Bullet那条压根没断言、MuJoCo那条是隐式积分的能量上界）。
`docs/research/05`第2.3节那一行也**只给金字塔那一项点了同行文件名**，
这两条是裸公式——**所以0081第一节把推导补齐了，本页照抄**。

设`I = k·mR²`（实心球`k = 2/5`）：

| 量 | 闭式 | 实心球 |
|---|---|---|
| 无滑质心加速度 | `a = g·sinθ/(1+k)` | `(5/7)·g·sinθ` |
| 维持无滑所需摩擦 | `f = k/(1+k)·m·g·sinθ` | `(2/7)·m·g·sinθ` |
| 无滑与滑的分界 | `tanθ ≤ (1+k)/k·μ` | `tanθ ≤ (7/2)·μ` |
| 滑动支 | `a = g(sinθ − μcosθ)`、`α = μ·g·cosθ/(kR)` | `α = 5μg cosθ/(2R)` |

**一次真正独立的交叉验证**：Fang & Negrut 2021附录D解析推出
`α ≤ tan⁻¹(3.5μs − 5ηr μk)`，**令滚阻项`ηr = 0`恰是第三行**。
两条独立路径（本仓的`Fraction`、他们的解析推导）同一个数。

## 三、判据表

| 量 | rel | abs | 理由 |
|---|---|---|---|
| 三条系数（5/7、2/7、7/2）与`μc` | 0 | 0 | **代数恒等式不是测量值**。容差留一点就等于允许它变成别的数——而"变成别的数"正是把实心球写成球壳会发生的事 |
| 滚动支`a`、所需摩擦、`a/(αR)` | 5e-3 | 0 | 罚接触穿透是`O(1/k_n)`的模型自带量，速度型摩擦另有`O(μN/k_t)`残余滑移，**两者都进这条判据**。实测偏差1.1e-04，**余量约45倍**。零容差在这里是错的：它会把模型自带量当成实现缺陷 |
| 滑动支`a`、`α`、`a/(αR)` | 5e-3 | 0 | 同上两项模型自带量。实测偏差1.3e-05（`a`）与8.4e-05（`α`），**余量两个数量级以上** |
| `sliding_flag` | 0 | 0 | **布尔量**编码成1/0。"滑没滑"是判据本身不是被测量（0081第三节第4条） |
| 法向力产生的力矩 | 0 | 0 | 球的杆臂沿`n̂`、法向力也沿`n̂`，叉积**必须是逐位的零**。这条不判物理，判**实现里有没有多出一项** |

## 四、已知失效清单

1. **`k_t`不能取大。** 实测：`k_t = 5e5`与`5e3`时模型进入**颤振区**——
   平均加速度仍对（偏差1e-4量级），但**瞬时切向力被钉在摩擦锥上、`sliding`恒为真**，
   于是"无滑"那条判据**失去分辨力**。`k_t = 50`时`k_t·|v_t| = 0.959 N`，
   **恰是闭式所需摩擦`(2/7)W sinθ = 0.9585 N`**（第三条独立对拍）。
   **本案例因此把`k_t`定在50并写明理由**；`k_t`的上限判据本身**未做**，登记在plans/07；
2. **步长没有做收敛阶。** 0.02 s、`dt = 1e-6`是一档，**没有扫多档给阶**。
   理由：接触刚度`k_n = 5e5`下稳定步长本身很紧，扫描要上master跑，
   **本轮先把两支的物理立住**。收敛阶登记为GAP；
3. **不是滚动阻力。** research/17第三节逐家核过：滚动阻力在所有主流同行那里
   都是**显式声明的第二套力偶**，本仓"点接触不传力偶"与它们的默认一致——
   **因此本案例不覆盖滚动阻力，也不许被读成覆盖了**；
4. **只有一个球对一个静止平面。** 多体、动平面、非球形都不在内；
5. **速度型摩擦不是锚点型。** 它在真正的静止粘着上有`O(μN/k_t)`的残余滑移，
   **不是零**——所以"无滑"判的是比值不是绝对零，见判据表。

## 五、档位与负载级

A档、`local_batch`（本机批级，`batch` marker）。清单`case_id`是`case/rolling_ball_incline`。
顺序基线曾对滚动支重算3次、滑动支重算2次，五条门合计约27.5秒；0102改为
同一pytest worker内两支各算一次、共享只读module fixture。这是运行内缓存，
每轮验收都重算，不跨提交沿用结果。单次积分仍明显超过1秒，因此不再冒充交互级。

## 六、本案例不是什么

1. **不是C档第8条的完整兑现。** 那一条的前半（`θc = arctan μs`静置阈值）
   由`incline_slide_threshold`守着，本案例是后半。**两条合起来才是一条**；
2. **不是"无滑"的证明，是"无滑"的判据。** 判的是`a/(αR)`这个比值——
   **一个"永远按滚动公式算"的错误实现会让两支的比值都等于1**，
   而那正是第四条门（两支必须被比值分开）关掉的那扇门；
3. **不是长期稳定性的声明。** `rigidbody`文件头自陈RK4**不是辛的**，
   research/17第五节实测DEM同行为此刻意选一阶半隐式。
   本案例只跑0.02秒，**长时程漂移一个字都没验**；
4. **不是接触检测。** 接触对是声明的，与`contact/`同纪律；
5. **`sliding`这个标志不等于"物理上在滑"。** 它是"切向力已饱和在摩擦锥上"。
   第四节第1条那个颤振区正是两者分开的地方——**本案例把`k_t`选在它们一致的那一档**。
