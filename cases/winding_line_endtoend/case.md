# winding_line_endtoend 放线—导向—张力—收线端到端

**本仓第一次把四件事装在一条链路上跑**：放线端的张力（力边界条件）、
导向轮上的罚接触与库仑摩擦（多槽位同时滑移）、收线端的位移控制（卷走带材）、
排线横动把带材边缘顶上法兰内环面。

判据值的正本是同目录的`oracle.json`（本页只解释，不重复声明），
`case_id`为`case/winding_line_endtoend`。

**本案例永久标`hypothesis_only`**，且**它不让主分母动**——理由见第六节。

## 一、物理/几何设定

```
放线端(张力30N) ──自由段── [导向轮 R=50mm, 包角90°] ──自由段── 落位点(收线盘, 两片法兰)
```

| 项 | 取值 | 出处 |
|---|---|---|
| 导轮半径 | 50.0 mm | **真机实测**：外径100 mm（`HARDWARE_TOPOLOGY.md`，2026-07-07现场确认） |
| 导轮轴向半宽 | 8.5 mm | **真机实测**：有效宽度17 mm，同上 |
| 收线盘槽半宽 | 8.5 mm | 同上口径 |
| 带材半宽 | 2.0 mm | 4 mm宽REBCO带材 |
| **半间隙** | **6.5 mm** | 两者之差——蹭边阈值 |
| 收线盘筒半径 / 法兰外径 | 60.0 / 75.0 mm | **假设** |
| 包角``θ`` | 90°，8段 | **设定**，非实测 |
| 摩擦``μ`` | 0.30 | **假设输入** |
| 带材``EA`` | 60 000 N | **假设输入** |
| 放线端张力 | 30.0 N | 真机张力区间10—30 N的上端 |
| 罚刚度 | 1.0×10⁴ N/mm | 法向、切向、法兰同取 |
| 重力 | **0** | 整匝自重比张力小三个量级 |
| 收线距离 / 步数 | 0.02 mm / 480步 | 见第四节第2条 |
| 求解器残差容差 | 1.0×10⁻⁶ N | 与`capstan_tension_ratio`同源（能量分辨率地板） |

**混合控制，照真机来**：力在**放线端**（磁粉离合器给制动张力），
位移在**收线端**（伺服卷走带材）。落位点的``x``/``y``位移控制、
**``z``自由**——它由张力的横向分量与法兰限位平衡决定。

## 二、参考解出处

四条闭式，全在`generate_oracle.py`里，**不调引擎任何一层**：

1. **放线端张力 = 外载**。力边界条件，不是解出来的量；
2. **落位点张力 = 放线端 × exp(μθ)**。Euler-Eytelwein，与
   `cases/capstan_tension_ratio`是同一条式子。**方向由带材走向定**：
   带材朝收线端滑，摩擦朝放线端，张力沿走向递增；
3. **半间隙 = (槽宽 − 带宽)/2**。两个声明尺寸的差；
4. **蹭边力 = T_落位 × (|横动| − 半间隙) / L**。最后一段自由段长``L``、
   受张力``T``，落位点被顶偏``δ``时张力的横向分量是``T·δ/L``（小角）。

## 三、判据表

| 量 | rel / abs | 理由 |
|---|---|---|
| 放线端轴力 | rel 1e-9 | **力边界条件**：外载多大第一段轴力就多大。1e-9只留给准静态残差，**不留给建模误差**——红了说明装配里有一段力丢了或乘错了 |
| 落位点/放线端 之比 对 `exp(μθ)` | rel 6e-3 | 位移控制的收线连续化到全滑移，**误差随收线步数下降**。480步实测比值1.604693、相对偏差1.695e-3，取约3.5倍余量 |
| 每个导轮接触的`\|T\|/(μN)` | abs 1e-12 | 全滑移的**定义性质**，是上一条成立的前提 |
| 半间隙阈值两侧 | **零容差** | 6.5 mm以内一点蹭边力都没有，超过就有——定性相反，与`incline_slide_threshold`同口径 |
| 蹭边力 对 `T·δ/L` | rel 2e-3 | 7 mm与8 mm两档实测差**0.11%**，那是`sin θ ≈ θ`的`O((δ/L)²)` |
| ±横动的蹭边力 | **逐位相同** | 镜像反对称。**哪一片被顶住与单元门相反**——那里动带材、这里动槽 |

## 四、已知失效清单

1. **控制回路与准静态平衡是分离处理的，不做同步耦合。**
   离合器时滞``τ = 50 ms``、PID闭环settle约0.5 s，而带材的准静态平衡没有时间尺度。
   本案例取**控制回路已稳态**的张力当作力边界条件。
   真机上两者在卷径突变或断带时会真耦合，**那时本案例的分离处理不再成立**。

2. **收线0.02 mm/480步是实测选出来的，不是随手取的。**
   0.05 mm起内层牛顿在同一构型里走不完（判别翻转叠加大位移）。
   0.02 mm在120/240/480步给出比值1.658805/1.629820/1.604693，
   **收敛不是干净的一阶**——它同时在收敛两件事（步长与趋近稳态滑移）。
   判据因此只判落点不判阶，与`capstan_tension_ratio`那条判阶的门分工。

3. **起点必须已经接触但穿透很浅。** 落位点从``z = 0``起步时法兰一上来就穿透
   ``|横动| − 半间隙``，罚力``k·δ``把节点甩飞、牛顿走不动。
   这与"分离态切线刚度奇异"是同一族的另一面：**那边刚度为零迈不出第一步，
   这边刚度过大第一步就飞了**。

4. **第一版把混合控制装反了。** 在放线端加力、把落位点钉死，
   结果张力**沿走向递减**（比值0.5587）——那是带材被从收线盘上往回拽。
   **方向不是判据挑出来的，是构型定的。**

5. **第一版把落位点的``z``钉住了**，算出5000 N的"蹭边力"。
   那是**规定穿透量的反力**，不是物理接触力。``z``必须自由。

6. **带材没有弯曲刚度**：只有`AxialStretch`。横向刚度全部来自张力×曲率，
   所以落位点的横向平衡是一根张紧的弦，不是一根梁。真实带材有``EI``。

7. 无skip。

## 六、本案例不是什么

* **不是场景⑥完成，也不让主分母动。** 场景⑥七位里S6.3/S6.4/S6.5/S6.6都是
  partial，**全done才算端到端完成**。本案例让S6.7从todo进partial，
  **主分母仍是0/6**——这不是谦虚，是清单的算法。
* **不是整机**。一只导轮，不是R4→R3→R2→R1加两只活动小导轮；
  没有放线盘的转动、没有伺服、没有KUKA。
* **不含控制回路**。张力是`drives`算好的一个稳态值，
  控制器的动态不在这次求解里（第四节第1条）。
* **不是多匝**。带材是固定长度的一段，没有喂料、没有匝数增长、没有半径生长、
  没有匝间接触。那是S5.4与S5.2。
* **不判定量**。摩擦、包角、EA、法兰尺寸全是假设输入；
  `research/05`第三节把五项列为"只有现场实测能补"。**产物永久`hypothesis_only`**。
* **蹭边只给上界**。杆模型原理上看不见边缘载荷下的板屈曲，
  真定量必须过壳FE交叉裁决——那不在本仓。
* **带材没有宽度方向的力学**，只有一个用于定位边缘的半宽偏移；
  也没有扭转，边缘点假定材料标架不绕切线转。
