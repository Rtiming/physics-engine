# narrow_phase_signed_distance 窄相：解析原语闭式 + 距离场查询的偏差声明

承接[decisions/0090](../../docs/decisions/0090_网格碰撞窄相_EPA与MPR与距离场查询的三选一_20260818.md)。
它裁的是"EPA、MPR、距离场查询三选一"，而本案例是那份裁决的**可测出口**：
落地的那条路给出的数，逐点对得上闭式；给不出精确数的地方，**它自己说出来带多大偏差**。

判据的正本是同目录的`oracle.json`（本页只解释，不重复声明；两处冲突以清单为准），
清单由`generate_oracle.py`产出——那个脚本**一行都不import`physics_engine.collision`**。

## 一、物理/几何设定

纯几何、无时间演化。两族构型。

### 1.1 解析五族（各带分离支与穿透支）

| 族 | 参数 | 分离支 | 穿透支 |
|---|---|---|---|
| 球-球 | r₁=3mm、r₂=4mm，沿x摆开 | 间距12mm ⟹ `+5` | 间距5mm ⟹ `−2` |
| 球-半空间 | 平面过(0,0,1)、外法向(0,0,1)；球r=2mm在轴上 | 球心z=4mm ⟹ `+1` | 球心z=2mm ⟹ `−1` |
| 盒-盒轴对齐 | A半宽(10,20,30)mm、B半宽(5,5,5)mm，圆角均0，沿x摆开 | Δx=20mm ⟹ `+5` | Δx=12mm ⟹ `−3` |
| 球-圆柱（无法兰） | 圆柱R=9mm、半宽4mm，轴向z；球r=1mm | 侧面(12,0,0) ⟹ `+2`；端面(0,0,6) ⟹ `+1` | 轴心(0,0,0) ⟹ `−5` |
| 球-旋转盒 | 盒半宽10mm绕z转45°；球r=2mm在x轴上 | x=18mm ⟹ `+1.857864…` | x=14mm ⟹ `−2.100505…` |

**最后一格是本案例最要紧的一格。** 点(14,0,0)看着在"半宽10"之外，其实在**转过来的盒里面**
——沿x轴到顶点是10√2=14.142mm。体内的最近面是**侧面**而不是顶点，距离是10−14/√2=0.1005mm。
把"沿轴到顶点"当成"到表面"是旋转凸体上最容易犯的一个错，**写这个案例时第一版真错过**。

### 1.2 距离场四族（三种曲率符号各一条，外加一条非凸的阶）

场按`sample_narrow_band`烘（窄带块稀疏＋三次B样条，决策0085），探针是球型（点＋半径0）。

| 族 | 场 | 曲率 | 分辨率档 | 探针 |
|---|---|---|---|---|
| 半空间 | `φ = z` | `∇²φ ≡ 0` | h = 2.0 / 1.0 / 0.5mm | (0.3, −1.1, 2.5) |
| 球（凸） | `φ = ρ − 10` | `∇²φ = 2/ρ > 0` | h = 1.0 / 0.5 / 0.25mm | ρ = 11.5mm |
| 圆柱孔（**凹、非凸**） | `φ = 12 − ρ` | `∇²φ = −1/ρ < 0` | h = 0.5 / 0.25mm | ρ = 10.5mm |
| 环面（**非凸**） | `φ = sqrt((ρ−12)² + z²) − 3.5` | 两向都有 | h = 0.8 / 0.4 / 0.2mm | 四个探针取max范数 |

窄带宽度一律取`max(基准, 2h√3 + 余量)`：查询点的4×4×4支撑每轴要往外伸2h，
**带比支撑窄就会在带里也查不了**（`sample_narrow_band`自己拒这种参数）。

## 二、参考解出处

**②无闭式解则生成脚本入库**那一档，但要说清楚：本案例的九条闭式全是初等代数
与一次泰勒展开，本可以直接写在页上；入库脚本是为了让那些数**有一个被SHA-256钉住的出处**。

| 项 | 值 |
|---|---|
| 生成器 | `cases/narrow_phase_signed_distance/generate_oracle.py` |
| 身份 | `algorithm:oracle/narrow_phase_signed_distance` v1.0.0 |
| SHA-256 | 钉在`oracle.json`的`generator.sha256`，另由`tests/test_case_generators_reproduce.py`**重跑核对逐字节复现** |
| 依赖 | 标准库（`math`）＋`physics_engine.oracles`的写清单器；**不import`collision`** |

九条闭式逐条：

1. 球-球：`|c₂ − c₁| − (r₁ + r₂)`。**分离支与穿透支是同一条式子**——这正是本仓既有窄相
   "一个数两用"的形制，也正是EPA给不了的（它只答穿透那一半，0090第2.1节）；
2. 球-半空间：`(c − p)·n − r`（内核走的是支撑函数那条路，两串不同的运算）；
3. 盒-盒轴对齐：逐轴间隙`g_i`，分离时`sqrt(Σ max(g_i,0)²)`、全轴重叠时`max_i g_i`。
   **第二支就是最小平移穿透深度**——轴对齐盒对上EPA给的是同一个数，
   于是本案例顺带回答了"不做EPA会不会少一个量"：**在这一对上不会**；
4. 球-圆柱：径向与轴向各自clamp；
5. 球-旋转盒：球心转进盒的局部系再套盒的SDF；
6. 场的偏差主项：`S(x) = φ(x) + (h²/6)·∇²φ(x) + O(h⁴)`（`contact/field.py`模块docstring，
   决策0085第三节），于是
   * 半空间`∇²φ ≡ 0` ⟹ 偏差**恒为零、与h无关**；
   * 球`∇²φ = 2/ρ` ⟹ 偏差`+h²/(3ρ)`，**正的＝场报的距离偏大＝偏松**；
   * 圆柱孔`∇²φ = −1/ρ` ⟹ 偏差`−h²/(6ρ)`，**负的＝场报的距离偏小＝偏紧**。

**第三条是本案例最值钱的一行**：0074第二节第4条只说了"系统性偏保守或偏松"，
0085第三节把凸那一侧钉到"偏松"，**本案例把凹那一侧钉到"偏紧"**——两侧各有一条闭式。

## 三、判据表

清单里每条`expected`都带`rel`/`abs`与理由（全文见`oracle.json`）。摘要：

| 量 | rel | abs | 理由（摘要） |
|---|---|---|---|
| 解析五族的11个分离量 | 0 | 1e-12 mm | **不写零容差**，理由是本案例自己量出来的两条：`segment_segment_distance_mm`开方用`x ** 0.5`而不是`math.sqrt`（`**`走libm的`pow`，IEEE不要求正确舍入，本机20万个正数里277个差1 ulp）；以及CPython 3.12起`sum()`对float走Neumaier补偿求和（本机20万组三维点积里44972组与手写`a+b+c`不同）。坐标量级50mm上两条合起来约1.4e-14mm，1e-12留两个量级 |
| 半空间场的分离量（三档h） | 0 | 1e-13 mm | 仿射函数被三次B样条**精确重构**，场与闭式解的是同一个方程，差别只有求和次序。实测最差2 ulp（4.441e-16mm）。**不写零**：两条路求和次序不同，逐位相等是没验过的性质 |
| 半空间场的偏差估计（三档h） | 0 | 1e-15 mm | **本案例唯一一条接近零容差的**，理由是代数事实：`∇²φ ≡ 0` ⟹ 估计恒零。实测7.401e-17 / 1.850e-17 / **0.0** |
| 球场的偏差估计（三档h） | 5e-3 | 0 | 闭式给的是**主项**，实测带`O(h⁴)`余项。实测相对偏差1.889e-3 / 4.709e-4 / 1.180e-4，**自身随h二阶缩小**，5e-3覆盖最粗档并留一档。不按绝对判：绝对容差会让粗档松细档紧，量不出"主项抓对了没有" |
| 孔场的偏差估计（两档h） | 5e-3 | 0 | 同上。实测9.437e-4 / 2.361e-4 |
| 环面场值误差的收敛比（两条） | 1e-1 | 0 | 收敛比是**区间**不是恒等于4。这里比本仓其余二阶门的`[3.9,4.1]`宽一档，理由要说清楚：**量的是四个探针上的max范数**，而max范数对"哪个点最差"敏感（0085第9.3节腿A记过同一形状：max比3.2411而mean比3.8299）。实测4.0459 / 4.0127 |

### 实测结果（2026-08-18，本机，CPython 3.13.12 / macOS arm64）

| 格 | 实测 |
|---|---|
| 球-球（200组随机） | max\|Δ\| = **1.421e-14 mm** |
| 球-半空间（200组随机） | max\|Δ\| = **7.105e-15 mm** |
| 盒-盒轴对齐（400组随机，分离/穿透两支都过50组） | max\|Δ\| = **7.105e-15 mm** |
| 球-旋转盒 外侧 / 内侧 | Δ = **1.332e-15 mm** / **0.0**（逐位） |
| 半空间场 h=2.0/1.0/0.5 | max\|Δ\| = **1.110e-16 / 4.441e-16 / 4.441e-16 mm** |
| 半空间场的偏差估计 | **7.401e-17 / 1.850e-17 / 0.0** |
| 球场偏差估计 对 `h²/(3ρ)` | rel **1.889e-3 / 4.709e-4 / 1.180e-4**；**实际偏差/估计 = 0.999992 / 1.000000 / 1.000000** |
| 孔场偏差估计 对 `−h²/(6ρ)` | rel **9.437e-4 / 2.361e-4**；实际/估计 = **1.000189 / 1.000047** |
| 环面场值误差 | **3.193e-2 / 7.893e-3 / 1.967e-3 mm**，比 **4.0459 / 4.0127** |
| 既有球/胶囊窄相（120对语料里34对相交） | `penetration_mm.hex()` **34/34逐位不变** |

"实际偏差/估计"那两行是本案例最强的一组数：**闭式主项不只是量级对，它把实际偏差抓到了
小数点后第五位**（球那一族最细两档是1.000000）。这说明`(h²/6)·tr(∇²φ)`不是一个安慰性的
声明，而是真的能拿去修正的量——**但本仓不拿它去修正**，理由在第六节第4条。

## 四、已知失效清单

每条一行理由，禁止静默skip。**本案例没有一条skip**，下面记的是**判据覆盖不到**的东西。

1. **不覆盖胶囊对盒/圆柱、旋转盒对旋转盒、圆柱对圆柱。** 这些对今天没有闭式，
   而本仓不做迭代（决策0090第七节GAP第二行）。它们在场景查询里保持`broad_phase`，
   在直查面上抛`CollisionQueryError`——两条各有一个门在`tests/test_narrow_phase_shapes.py`；
2. **不覆盖带法兰的圆柱。** `FiniteCylinder.flange_outer_radius_mm`在全仓只用来撑AABB，
   **没有实体语义**，所以精确窄相当场拒（决策0090第4.1节）。**按无法兰算会少报15mm**
   （真实导轮R45/法兰R60），那条量化在`tests/test_narrow_phase_shapes.py`里；
3. **不覆盖真实网格。** `MeshAsset`带的是路径＋SHA-256＋声明的AABB，**一个顶点都没有**；
   内核不读网格字节（0074第二节）。网格那一侧只能由外部烘好的场经协议进来，
   而**烘焙要pcu那个独立venv**（`tools/model/sdf_bake/`），本案例的场全部是解析函数烘的；
4. **场只验过球型探针。** 非球探针对场当场拒——`min φ`会静默漏接触（0090第2.3节第一行）。
   于是"一根杆碰一个真实件"这件事本案例一个字都没说；
5. **窄带外没有验"深在体内"与"远在体外"分得开**，因为**它们在稀疏块表里分不开**
   （0085第四节实测两种点的信号都是`None`）。本案例只验了"窄带外会抛/会降级"，
   没有验任何窄带外的数值；
6. **只跑了macOS/arm64一个平台**，而第三节那两条容差理由（`pow`与`sum()`）**都是平台相关的**：
   `x ** 0.5`是否等于`math.sqrt(x)`由libm决定，`sum()`的补偿求和由CPython版本决定
   （3.12起）。**没测过就是没测过**——判据留的两个量级余量是给这件事的，不是给精度的；
7. **不覆盖`GeneratedShape`包裹之外的形状扩展。** 形状层今天六种，本案例覆盖四种
   （球/胶囊隐含在既有那条路里、圆角盒、无法兰圆柱），`MeshAsset`见第3条。

## 五、档位与负载级

* **档位**：A档（只用`shapes`/`collision`/`contact.field`三个已有模块，**零新增依赖**）；
* **清单身份**：`case_id` = `case/narrow_phase_signed_distance`；
* **负载级**：**交互级**（pytest无marker，与`oracle.json`的`load_tier: "interactive"`逐字一致）。
  实测：`pytest tests/cases/test_narrow_phase_signed_distance.py -q`共11条、**0.95秒**；
  `tests/test_narrow_phase_shapes.py`共31条、**1.74秒**。
  两份合起来不到3秒，全部落在交互档预算内；
* **场那一族的成本在哪**：烘焙（`sample_narrow_band`）而不是查询。
  环面那一格h=0.2的一档是本案例最贵的单点，因为窄带节点数按**表面积**长（0074第5.1节）。

## 六、本案例不是什么（Drake形制）

1. **不是"EPA/MPR不如距离场"的证明。** 三条路的取舍写在决策0090第二节，
   而那份裁决的依据是**前置**（要凸体、要内点、要真实几何），不是精度对比。
   本案例一个EPA的数都没有量过，因为**本仓没有EPA的实现**；
2. **不是网格窄相。** 场是由**解析函数**烘的，不是由三角网格烘的。
   S3.2 label里的"网格"两个字在本案例里没有出现——那件事的拦路虎是
   "内核不读网格字节"，不是算法选型（决策0090第一节）；
3. **不是接触力。** 本案例算的全是几何量（分离量、穿透深度、偏差估计），
   一条力都没有。0074第一节："几何判定与接触力学是两道题，谁也不能替谁"——
   力那一侧归`cases/sdf_contact_convergence`；
4. **不是"偏差可以被修正掉"的许可。** 第三节实测偏差估计把实际偏差抓到了1.000000，
   于是很容易得出"那就把它减掉"。**本仓不减**，理由是两条：
   估计只是主项（`O(h⁴)`余项没被覆盖），以及**减掉之后那个数就不再是任何一个场的读数**，
   而调用方分辨不出"读数"与"读数减一个模型"。要修正就要先裁"修正后的数算哪一档可信度"；
5. **不是性能对比。** 场那条路一次查询要做两次`evaluate`（值一次、Hessian一次），
   拿它的墙钟去比"闭式快还是场快"是错的口径；
6. **不是broad phase的判据。** 本案例全部走直查面或单对场景查询，
   没有量AABB剔除率。broad⊇narrow那条超集不变量归`cases/broadphase_superset`；
7. **不覆盖非凸体上的"两个一般形状之间的穿透深度"。** 那个量在非凸上**没有良定义**，
   本案例给的全部是"球型探针到表面的距离减半径"——那是良定义的，
   而且对球型探针**就是**穿透深度（球的Minkowski和还是球）。
   **两者的区别正是决策0090第2.3节第一行那条限制的理由。**
