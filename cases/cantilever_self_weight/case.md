# cantilever_self_weight 自重悬臂梁：引擎第一次把教科书闭式解算对

`case/cantilever_self_weight`。B档，spec/12第三节（能量项）+第4.1节（准静态求解）。
**这是能量项→装配→牛顿求解→与解析解对拍的第一条完整链路。**
同行案例复用（research/05第2.3节：PyElastica与Gazzola 2018的自重悬臂族；
WDS有自己的`test_gravity_cantilever.py`）。

## 一、物理/几何设定

小挠度Euler-Bernoulli梁，固支端在`s=0`、自由端在`s=L`，均布自重。

| 量 | 值 |
|---|---|
| 长度 L | 1000.0 mm |
| 弯曲刚度 EI | 2.0e7 N·mm² |
| 单位长度载荷 q | 0.5 N/mm（总载荷500 N） |
| 重力 g | 9806.65 mm/s² |
| 加密阶梯 | 10 / 20 / 40 / 80 段 |
| 牛顿绝对残差容差 | 1.0e-7 N |

离散：等分链，节点载荷按梯形权（端点半权），由力反推质量因为重力项吃的是质量。
固支由弯曲模板的幽灵节点承担（`(−2,2)`配偏置`2h·t̂`、**权1/2**），
不靠再钉一个节点。轴向与面外自由度钉住——本案例是平面小挠度问题。

## 二、参考解出处

教科书闭式解：**`δ_tip = q·L⁴ / (8·EI)` = 3125.000000000 mm**。
生成器只写这个闭式与收敛判据，不调`solve_equilibrium`、不调任何能量项。

## 三、判据表

| 量 | rel/abs | 理由 |
|---|---|---|
| `tip_deflection_mm` | rel 1e-15 | `qL⁴/(8EI)`，四次幂一次除法 |
| 收敛比区间 `[3.9, 4.1]` | abs 0 | **不写死为4**。实测四档全为**4.000**，但写死会让任何合理实现在粗档上红（spec/12第4.3节：比阶不比单点） |
| `all_refinements_converged` | abs 0 | 布尔前置断言：**不收敛的解不许参与收敛阶比较**——那会拿一个没解出来的数去算阶 |
| `newton_iterations_within_bound` | abs 0 | 总能量是位置的二次型（线性弯曲+均匀重力），**牛顿一步即达精确解**。迭代数变多是「能量不再是二次型」的信号，是有效判据不是装饰 |

**牛顿绝对残差容差1e-7 N是声明的绝对量**（spec/12第4.3节要求不许含糊）：
它是总载荷500 N的2e-10。**实测残差地板随加密上升**——n=10时2.4e-10 N、
n=160时5.6e-8 N，因为弯曲刚度标度`EI/h³`按`h⁻³`增长。
这正是spec/12第4.3节说的"绝对残差门在细化时会被污染"，本案例是它的一个实例。

## 四、已知失效清单

- **只验小挠度**。实测端点挠度3125 mm对长度1000 mm是**大挠度**，
  几何非线性在真实梁上早已显著——本案例验的是**这套离散对它自己那个线性方程的收敛性**，
  不是"这根梁真会这样弯"。要验大挠度得用椭圆积分闭式（research/05的C2），
  那需要几何精确的DER弯曲，不在本块。
- **`LinearBending`不是DER的几何精确弯曲**（`κ = 2·tan(θ/2)`）。真正的DER随杆内核搬迁进来。
- **求积权错了会从二阶掉到一阶**：实测全权时收敛比1.895/1.949/1.975，半权时4.000。
  症状与WDS登记的"固支只有一阶"一模一样，**但病根不同**——那不是边界条件阶次，
  是求积权重。归因错一次就会去改边界条件，而那改不动它。
- **只在平面内**：轴向与面外自由度被钉住。三维弯扭耦合不在本案例。
- 未在Windows/Linux复核。

## 五、档位与负载级

B档，**interactive**（<1s）。实测：两条测试含四档求解共0.26s。

## 六、本案例不是什么

- **不是"引擎能算梁了"的证据**。它算的是线性小挠度方程，且只在一种边界条件、
  一种载荷下验过。
- **不是大挠度验证**（见第四节第一条）。
- **不是求解器的性能证明**：稠密LU，规模是几百自由度。
- **不验证接触、摩擦、约束、动力学**——那些一个都还没有。
