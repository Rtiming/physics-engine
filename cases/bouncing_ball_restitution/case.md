# bouncing_ball_restitution — 瞬态罚接触的三条闭式

案例ID：`case/bouncing_ball_restitution`

**这条案例第一次让"瞬态接触"从既成事实变成被声明的能力。**
在它之前，罚接触+显式积分跑得通是plans/08在调研里顺手测出来的，
仓里**没有一条判据守着它**。

## 一、物理/几何设定

单个质点撞一个半空间，**无重力、无阻尼**。

| 量 | 值 | 单位 |
|---|---|---|
| 罚刚度`k` | 1.0e4（扫描档1e3 / 1e4 / 1e5） | N/mm |
| 质量`m` | 1.0e-3 | kg |
| 入射速率`v_in` | 500.0 | mm/s |
| 节点半径`r` | 0.0（质点） | mm |
| 半空间：面上一点 | (0, 0, 0) | mm |
| 半空间：外法向 | (0, 0, 1) | — |
| 初位置 | (0, 0, 0) | mm |
| 初速度 | (0, 0, −500) | mm/s |
| 重力 | (0, 0, 0)——**刻意为零**，见第六节 | mm/s² |
| 积分器 | `velocity_verlet` | — |
| 步长 | **由`advise_step()`算**，不是魔数 | s |
| 每次接触步数 | 20 / 200 / 2000（判据各取所需） | — |

**单位链**：`k`是N/mm、间隙是mm，故力是N；`N/kg = m/s²`是米制，
而状态是mm制，所以加速度桥要乘1000，`ω = sqrt(1000·k/m)`。
那个1000不是凑的——`energies.EnergyRegistry.acceleration`的docstring里
记着一个静默1000倍真的发生过一次，**而有限差分门对它完全失明**。

## 二、参考解出处

**① 闭式解。** 三条全部来自同一个事实：**罚接触期间的运动是简谐半周期**。
无重力无阻尼时接触段满足`m·ẍ = −1000·k·x`，故：

- 接触时长`t_c = π/ω`（半周期，**与入射速度无关**）；
- 最大穿透`δ_max = v_in/ω`（简谐振幅）；
- 恢复系数`e = 1`（保守力场）。

生成脚本入库：`cases/bouncing_ball_restitution/generate_oracle.py`，
SHA-256钉在`oracle.json`的`generator.sha256`。
**该脚本不import积分器也不跑接触**——它只把闭式算出来，
所以它是独立路径而不是实测复述（spec/08规则1）。

同行的第三条腿：O'Sullivan & Bray 2004给的`Δt ≤ 0.17·sqrt(m/K)`
换算约18.5步/接触，**与本仓实测的20步落在同一格**（plans/08第1.4节）。

## 三、判据表

| 量 | rel | abs | 理由 |
|---|---|---|---|
| `omega_rad_per_s` | 1e-14 | 0 | 闭式对闭式，只留浮点噪声：sqrt与除法各一次舍入 |
| `contact_duration_s` | 1e-6 | 0 | 接触起止落在步长格点上，分辨误差本应约`1/N`（N=200时5e-3）。**取1e-6是因为实测比值恒为1.000000**——接触时长对称，格点误差首阶相消 |
| `max_penetration_mm` | 5e-3 | 0 | N=20时实测比值1.003097，N=200时1.000031。**按最粗档定**，留约1.6倍余量 |
| `restitution` | 0 | 3e-4 | 理论值恰为1。**用abs不用rel**：两者数值相同，但abs表达的是"离1有多远"这个物理量。按N=20实测2.5e-4留约1.2倍余量 |
| `penetration_ratio_per_decade` | 1e-2 | 0 | **必红的判据本体**：瞬态律给`sqrt(10)≈3.162`、准静态律给`10`，**差3.16倍**，远在1%之外。1%同时容得下最粗档的离散误差 |
| `monotonically_decreasing` | 0 | 0 | 非数值量（单调性）零容差，判相对优劣不判绝对值 |
| `all_errors_positive` | 0 | 0 | 前置断言防三档全零假通过（MuJoCo `EXPECT_NE`形制）；**同时它本身是物理断言**——实测`e`恒大于1 |
| `quasistatic_formula_is_wrong_here` | 0 | 0 | 布尔声明：`δ = N/k`在本案例域外 |

**实测收敛（2026-08-12）**：

| 步/接触 | `t_c`比 | `δ_max`比 | `e` |
|---|---|---|---|
| 20 | 1.000000 | 1.003097 | 1.000249919 |
| 200 | 1.000000 | 1.000031 | 1.000000253 |
| 2000 | 1.000000 | 1.000000 | 1.000000000 |

`δ`误差随N每×10降**约100倍**（二阶，与`velocity_verlet`的形式阶一致）；
`e`误差降**约1000倍**。**后者比形式阶更快，本仓未解释这一条，登记为待查。**

## 四、已知失效清单

1. **罚接触下存在临界入射速度，低于它接触不结束**（research/13第六节）。
   本案例的驱动函数对此**失败关闭**：`4·N`步内接触没结束就抛断言，
   消息里写明这是那件事的兜底。**不是静默skip。**
2. **`explicit_euler`不在本案例的可选积分器里**。理由不是"精度差"——
   是**实测它在任何步长下都发散**（`h·ω=0.1`跑40周期能量涨7.2e10倍），
   步长顾问对它失败关闭。见`integrate.py`的`step_bound`。
3. **过阻尼`ζ ≥ 1`不在本案例范围**。那条闭式两个约定都没被推过
   （0052第一节登记的阻塞项），阻尼本身属阶段2。
4. **`e`误差的收敛比形式阶快**（约`N³`而非`N²`），**未解释**。
   登记为待查，触发条件：阶段2加阻尼后若该现象消失或反转，回来查。

## 五、档位与负载级

**A档**（走`state`→`energies`→`acceleration`桥→`integrate`整条路，
不是在测试里手写弹簧）。

**交互级**：无pytest marker，与`oracle.json`的`load_tier: "interactive"`一致。

实测耗时：6条判据合计**0.08秒**。

## 六、本案例不是什么

**（一）它不是"弹跳球"，它是"一次撞击"。** 重力刻意设为零。
带重力的完整弹跳要用总弹跳时间级数`sqrt(2h/g)·(1+e)/(1−e)`，
那属**阶段2**——而且带重力时"`e`与入射速度无关"这条**不再成立**
（plans/08第五节明写）。**从本案例推不出任何关于连续多次弹跳的结论。**

**（二）它不验阻尼、不验恢复系数小于1的任何情形。**
`e = 1`是保守力场的必然，**没有验证任何耗散机制**。
0052第一节裁定的截断约定、以及可声明`e`的下界`exp(−2) = 0.1353`，
本案例**一个字都没验**。

**（三）它不验多体、不验摩擦、不验转动。**
接触体是质点，**质点没有力矩**——`max_points > 1`在今天的自由度下
不多算任何物理（决策0051）。

**（四）`δ_max = N/k`这条看似相近的判据在这里是错的。**
那是准静态律（`O(1/k)`），瞬态是`O(k^(−1/2))`。
plans/08第零节实测`k=1e5`时准静态式差**1010倍**。
本案例的必红用例专防这一条：注入准静态律后实测比值3.1623对上要求的10.0000，**当场红**。

**（五）本案例的绿不代表`velocity_verlet`可以上生产。**
`production_ready`仍是`False`。四条翻转条件见`integrate.PRODUCTION_READY_CONDITIONS`——
本案例只兑现了其中两条（可计算的步长界、一个第1档解析判据案例）。
**剩下两条没中，所以那个标志不翻。**
