# double_slit_propagated 双缝：引擎第一次把衍射图样**传出去算**

`case/double_slit_propagated`。C档，spec/15（光学域）+ `optics/field.py` + `optics/propagation.py`
（决策0086）。

**它与`cases/scalar_diffraction_airy`的分别是本案例存在的全部理由**：
那一条把一个自变量代进闭式`E(x)=2J1(x)/x`，**没有任何场、没有任何传播**；
这一条建一个孔径掩模、做二维复数变换、乘传播因子、在观察面上读图样，
**闭式只出现在判据的右边**。能力位S4.6要的正是这件事——原文：
"一般孔径的衍射（单缝／双缝／矩孔，**由传播算出而非闭式代入**）"。

它同时把research/05第2.3节光学族第13条的三件套一次跑齐：
**MFT-FFT等价**（定义式直接求和 对 基2蝶形）、**通量守恒**、**往返可逆**。

## 一、物理/几何设定

标量夫琅禾费衍射，均匀平面波垂直照明双缝，观察面在`z`处。

| 量 | 值 |
|---|---|
| 波长λ | 632.8e-9 m（HeNe，与`scalar_diffraction_airy`同一个） |
| 入射面网格 | 8行×256列（行=y，列=x） |
| 采样间距dx=dy | 10.0e-6 m |
| 观察距离z | 2.0 m |
| 单缝宽w | 4个采样 = 40.0e-6 m |
| 双缝中心距d | 32个采样 = 320.0e-6 m |
| 孔径半宽（几何） | ((4−1)/2 + 0.25)·dx = 1.75·dx = 17.5e-6 m |
| 两缝中心 | (0.5 ∓ 16)·dx，即 −155.0e-6 m 与 +165.0e-6 m |
| 孔内采样点（有符号序号） | −17、−16、−15、−14、+15、+16、+17、+18（共8个） |
| 观察面间距 | λz/(N·dx) = 4.945e-4 m |
| 菲涅耳数（整孔半宽180e-6 m） | 0.0256，边缘相位0.0804弧度（申报上界0.1） |

三条设定是**有理由的、不是随手取的**：

1. **缝宽与中心距都取2的幂**（4与32）。离散孔径的变换是Dirichlet核，
   其零点在`k = m·N/M`；`M`是2的幂时那正好是整数bin，
   于是条纹极大与包络零点**都落在采样格上**，可以零容差地判。
   取非2幂的宽度，零点就掉在两个bin之间，判据只能退化成插值。
2. **缝的中心偏半格**（`0.5·dx`）。以采样点为中心的对称孔覆盖的采样数
   **必然是奇数**（`2p+1`）；要取到偶数（更要2的幂），中心就得偏半格。
   这不是技巧，是采样与对称性的一条硬事实。
3. **半宽再偏四分之一格**。边界恰好落在采样点上时，"那个点在孔内还是孔外"
   由浮点最后一位决定——引擎侧对这种规格**失败关闭**（见第四节）。
4. **行数取8而不是1**。一行N列的场会让二维路径退化成一维，
   行列混淆一类的错就测不出来。缝在y方向占满窗口，于是谱只落在`fy=0`那一行，
   **其余7行的强度和实测恰为0**（常值列的长度8 DFT在非零bin上成对相消，是精确的）。

`d/w = 8`，所以**第8级条纹缺级**：单缝包络的第一个零点恰好压在第8级条纹极大上。

## 二、参考解出处

Born & Wolf,《Principles of Optics》第8.5.1节（矩孔与多缝的夫琅禾费衍射）：
单缝包络`sinc²(w·sinθ/λ)`、双缝因子`cos²(π·d·sinθ/λ)`、
条纹极大`sinθ = m·λ/d`、包络首零`sinθ = λ/w`、`d/w`为整数时的缺级。

**生成器走的是另一条算法**（脚本入库：`cases/double_slit_propagated/generate_oracle.py`，
SHA-256钉在`oracle.json`的`generator.sha256`字段）：
被验内核是基2 Cooley-Tukey（位反转重排、log2(N)级蝶形、缓存的旋转因子表），
生成器是**定义式直接求和**`U(k) = Σ_n exp(−2πi·n·k/N)`，孔内只有8个采样所以逐bin直算。
两条路没有任何共用代码，也不共用旋转因子表。孔径的采样位置由生成器
**自己按几何算**，不调`rectangular_aperture`；生成器不import `physics_engine.optics`。

生成器里有一处**从教训抄来的写法**：相位先按整数`(n·k) mod N`约化再进`exp`。
`tests/test_optics_field.py`实测过，直接写`exp(−2πi·k·m/N)`时误差被`exp`的
大幅角约化主导——N=1024上比整数约化差**65倍**（120.6·eps·Σ|x| 对 1.85·eps·Σ|x|）。
**参照自己的误差盖过被验对象时，那条判据测的就不再是引擎。**

冻结的是**复振幅比**`U(k)/U(0)`而不是绝对复振幅：绝对值里含一个`exp(ikz)`，
`kz ≈ 1.99e7`弧度，两侧都只是在调`cmath.exp`同一个大幅角——冻结它测的是libm不是引擎。
比值把它精确消掉，留下变换、观察面二次相位与坐标映射三样。
复数按决策0086的字节形制落盘：**一个复数是长度2的浮点数组，次序`(实部, 虚部)`**。

## 三、判据表

| 量 | rel | abs | 理由 |
|---|---|---|---|
| `relative_amplitude_components`（11个bin×2分量） | 0 | 4e-15 | 定义式直接求和 对 基2蝶形。直接求和是8项累加（~8eps）、蝶形是log2(256)=8级（~8eps）、比值再除一次、观察面二次相位两侧同式不同幅角，合起来约30eps=6.7e-15量级。**实测最坏2.7756e-16，余量14.4倍**。判绝对不判相对：条纹极小处比值近零，相对误差没有意义 |
| `aperture_sample_count` | 0 | 0 | 孔内采样数是整数。它锁的是**采样缝宽**——边界落在采样点上时这个数整差一格（本轨道实测踩过：期望32个采样、实得31个），而图样照样是漂亮的sinc平方 |
| `fringe_sines`（7级） | 4e-16 | 0 | 观察面坐标是`k·λz/(N·dx)`，在`k = m·N/P`处约掉z与N，**恒等地**落回`m·λ/(P·dx)`——一条单位边界的往返，理论偏差为0，容差只留约2eps给两侧不同的乘除次序。**实测最坏1.7347e-18（第6级），余量2.7倍** |
| `normalised_intensity`（7级） | 0 | 4e-15 | 强度是复振幅比的模平方，相对误差是振幅的2倍，而振幅比量级≤1，与第一行同量级。**实测最坏2.2204e-16，余量18倍** |
| `missing_order_intensity` | 0 | 0 | `d/w = 8`时第8级恰好压在单缝包络首零上。**零容差不是乐观是结构性的**：缝宽4是2的幂、该bin是`N/4`，蝶形最后一级配对的两项相位差恰为π（精确取负），IEEE下逐位抵消。**实测返回`0.0`**；直接求和那一侧的残值4.0276e-17，两条路都到地板 |
| `envelope_first_zero_sine` | 4e-16 | 0 | 包络首零在`sinθ = λ/w`，`w`是**缝宽**不是中心距。把两者搞反的实现在前6级条纹上全绿，只有缺级与这一条会红。**实测偏差恰为0** |
| `power_ratio_after_propagation` | 0 | 1e-14 | 菲涅耳单次FFT的前因子`dx·dy/(iλz)`与观察面间距`λz/(N·dx)`在总能量上恰好互相抵消，期望是精确的1。**这条是前因子唯一的捕手**——前因子写错时归一化图样一个字都不变。**实测偏差6.0e-16，余量17倍** |
| `round_trip_max_deviation` | 0 | 1e-15 | `ifft2(fft2(U0))`对`U0`的最大偏差，期望是精确的0（往返是恒等）。误差模型`16·eps·max|U0| = 3.6e-15`（掩模max|U0|=1）。**实测1.4016e-16，余量7.1倍** |

**必须红（实测）**：

- **孔径边界落在采样点上时`aperture_sample_count`会整差一格**。这是本轨道抓到的
  **真缺陷**：第一版把半宽写成`(M/2 − 0.5)·dx`，边界恰在第`M/2`个采样上，
  于是`dx = 10e-6`时得到8个采样、`dx = 2.5e-6`时得到31个（期望32）。
  后果不是精度差一点：采样缝宽整差一格、衍射零点随之挪位，
  而**"收敛阶"实测从2.106变成−4.222**，图样却仍然是漂亮的sinc平方。
  现在这种规格由`propagation.py`**失败关闭**，必红用例在
  `tests/test_optics_propagation.py::test_an_aperture_edge_that_lands_on_a_sample_fails_closed`。
- **把缝宽与中心距搞反**：前6级条纹判据全绿，`missing_order_intensity`与
  `envelope_first_zero_sine`两条当场红。
- **前因子漏掉`dx·dy`**：八条判据里只有`power_ratio_after_propagation`会红，
  `tests/test_optics_propagation.py`里有一条正面构造了这个错误并断言它被抓。
- **条纹极大的位置**另有一条不靠清单的结构判据（前6级必须是局部极大），
  它抓的是"整幅图样平移半个条纹"这类错——余弦是偶的，只比数值的判据抓不住它。

## 四、已知失效清单

- **只验夫琅禾费（远场）**。本案例的菲涅耳数0.0256、边缘相位0.0804弧度，
  在申报上界0.1之内。近场（边缘相位>0.1）请用`propagate_fresnel`，
  引擎在越界时**拒答**而不是给一个看起来合理的图样。
- **只验标量近似**。矢量衍射、偏振、近场倏逝耦合都不在本案例；
  倏逝波的衰减由`tests/test_optics_propagation.py`单独守（角谱那一侧）。
- **只验一个分辨率**。判据冻结在256列上；分辨率相关的收敛阶
  （Dirichlet核→连续sinc，实测阶2.474→2.106→**2.026**）在
  `tests/test_optics_propagation.py::test_the_discrete_pattern_converges_to_the_continuous_sinc_at_second_order`，
  不在本案例。
- **零容差的两条依赖"缝宽是2的幂"这个设定**。换一个非2幂的缝宽，
  `missing_order_intensity`就不再恰为0（零点掉在两个bin之间）——
  那时要改的是判据形制不是容差。
- **不验圆孔**。圆孔在笛卡尔格上是阶梯边，误差是**振荡的不是单调的**
  （Gauss圆问题那一类，实测R=16→1.5101e-3、R=32→1.4691e-3、R=64→1.9796e-4，
  "阶"是0.040与2.892）。那条对比放在`tests/test_optics_propagation.py`里，
  并且**明写它不是`O(h²)`**——假装是会得到一条随机红的门。
- **半群那条判据依赖平台的三角函数幅角约化**。传递函数相位在那些构型里是
  `k·z ~ 1e5`弧度；本机（macOS/arm64/CPython 3.13）的libm做精确约化，
  残差停在eps量级（实测比值2.14）。若某平台的libm只做简单取模，
  那条门会红——**红了先查平台，不要先放宽**。
- 未在Windows/Linux复核。

## 五、档位与负载级

C档，**interactive**（<1s），与`oracle.json`的`load_tier`逐字一致（`interactive`），
无pytest marker。

实测（本机，中位数）：conformance四条测试共**0.04 s**；生成器一次**0.03 s**。

**规模与墙钟的关系**（本机三次中位数，**只报这个规模下是多少，不下任何跨机结论**——
plans/16的M8立的口径就是本机墙钟不作数）：

| 网格 | `fft2`一次 | 菲涅耳传播一次 | 秒/(N²·log₂N) |
|---|---|---|---|
| 64×64 | 0.0039 s | 0.0045 s | 1.83e-7 |
| 128×128 | 0.0167 s | 0.0187 s | 1.63e-7 |
| 256×256 | 0.0718 s | 0.0783 s | 1.49e-7 |
| 512×512 | 0.3331 s | 0.4166 s | 1.77e-7 |

最后一列在四档上只在1.49e-7到1.83e-7之间浮动，即**实现真的是`O(N² log N)`**，
没有隐藏的二次项。本案例取8×256（**不是**方阵）正是因为它只需要一维图样，
`8×256`的工作量只有`256²`的1/32。**512²以上的规模纯Python会进本机批级**，
真要用请先量再申报，不要照抄本页的数。

## 六、本案例不是什么

- **不是"引擎能做衍射了"的证据**。它算的是一个二值掩模在远场的图样，
  没有透镜、没有像差、没有多元件、没有部分相干、没有偏振。
- **不是`scalar_diffraction_airy`的替代**。那一条验的是`J1`与艾里闭式本身的精度
  （申报`|ΔJ1| ≤ 1e-12`），本条一个贝塞尔函数都不调。两条案例**互不覆盖**。
- **不是通用FFT库的证明**。`fft`只做2的幂，非2幂**失败关闭**（决策0086第二节）；
  精度只在`N ≤ 1024`上实测过。
- **不是性能证明**。第五节那张表是**本机单点**，按0018只判量级不立门。
- **不验角谱**。本案例全程走单次FFT形制（夫琅禾费）；角谱的平面波本征函数、
  倏逝波衰减、`z→0`退化与半群性质在`tests/test_optics_propagation.py`，
  它们**不在任何案例的冻结金标里**——这是一条如实登记的欠账。
