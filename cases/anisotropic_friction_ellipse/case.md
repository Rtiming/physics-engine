# anisotropic_friction_ellipse 各向异性摩擦椭圆：径向缩为什么是错的

**本案例验的是一条本构的物理正确性，而它替换的那条曾经看起来完全正常**
（决策0068）。

`coulomb_return_map`是各向同性径向返回。在圆上，**沿径向缩回去**、
**欧氏最近点投影**、**最大耗散原理要求的外法向流动**这三件事恰好重合，
于是"径向返回"这个名字看起来像是算法本身。**椭圆上这三件互不相同，
而只有第三件是物理。**

判据值的正本是同目录的`oracle.json`（本页只解释，不重复声明）。
清单身份`case/anisotropic_friction_ellipse`。

## 一、物理/几何设定

切平面里的摩擦椭圆，位移控制、法向力由声明给定。

| 项 | 取值 |
|---|---|
| 纵向摩擦系数``μ_∥`` | 0.50 |
| 横向摩擦系数``μ_⊥`` | 0.10 |
| 比值``μ_∥:μ_⊥`` | **5:1**（消费方WDS给的那个比） |
| 法向力``N`` | 4.0 N（**声明的输入**，不由求解器出） |
| 切向粘着刚度``k_t`` | 3.0×10⁴ N/mm |
| 面法向``n`` | ``(0, 0, 1)`` |
| 纵向轴``d_∥`` | ``(1, 0, 0)``（**显式字段**，见第六节） |
| 椭圆半轴``a = μ_∥N`` / ``b = μ_⊥N`` | 2.0 N / 0.4 N |
| 屈服位移``u_y = a/k_t`` | 6.6667×10⁻⁵ mm |
| 回线幅值 | 2、5、20倍``u_y``；每段500步 |
| 混合角回线 | 45°、20``u_y``、每段2000步、跑4圈 |

屈服面：

    (f_∥/(μ_∥·N))² + (f_⊥/(μ_⊥·N))² ≤ 1

## 二、参考解出处

四条互相独立的闭式，**全部不含离散化**，推导写在`generate_oracle.py`的模块docstring里。

1. **支撑函数**``h(ψ) = √(a²cos²ψ + b²sin²ψ)``——凸集沿给定方向的最大投影。
   最大耗散原理（Hill）说实际切向力在容许集上使``f·Δu``最大，
   故它就是关联流动下沿``ψ``稳态滑移的耗散/单位距离；
2. **椭圆半径**``ρ(ψ) = 1/√(cos²ψ/a² + sin²ψ/b²)``——径向返回把力钉在``f ∥ m̂``上，
   故它的耗散是这个；
3. **最高短缺**``(a − b)²/(a² + b²)``，在**ψ = 45°**取到。5:1给``8/13 = 61.538%``；
4. **径向返回违反外法向的最大正弦**``(a² − b²)/(a² + b²) = 12/13 = 0.923077``，
   即**67.38°**。

主轴上椭圆退化成1维理想塑性，回线面积用与`friction_hysteresis_loop`
逐字相同的闭式``W = 4·a·(U − u_y)``（弹性-理想塑性滑块，任一本塑性力学教材；
同行出处见research/05第2.3节C档接触族）。

### 混合角回线**没有闭式，本案例也不编一个**

卸载支的力从支撑点沿``−m̂``走直线，**再屈服点不落在**``−f_sup``**上**，
之后力沿椭圆弯着走到另一端——回线不是平行四边形。
所以混合角上判的是两条**不需要闭式**的东西：外功``∮f·du``与塑性功``Σf·Δu_slip``
两条独立记账必须相等，且稳态圈必须**逐位周期**。

## 三、判据表

| 量 | rel | abs | 理由 |
|---|---|---|---|
| ``μ_∥ = μ_⊥``时与`coulomb_return_map`逐位相同 | 0 | 0 | **定性判据零容差**。相同是**构造出来的**——两系数逐位相等时映射把参数原样转交，连报错都是它的。判的是IEEE-754位型（`float.hex()`）不是``==``：``-0.0 == 0.0``为真而位型不同 |
| 通用椭圆路径在``μ_∥ = μ_⊥``上与圆的闭式 | 0 | 4e-16 | **不许零容差**：通用路径解的是标量方程，退化时只能到舍入。**没有它，上一条的"逐位"就只是转交本身的同义反复**——转交可以掩盖通用路径写错 |
| 滑移增量与屈服面外法向的``\|sin\|``（λ ≥ 1.1） | 0 | 1e-14 | 最大耗散原理的KKT条件，真值是**0**。实测最坏4.9e-15 |
| 同上，刚屈服档（λ = 1.001） | 0 | 1e-12 | **同一条判据、单独一档**，因为它的容差不是求解精度而是**消去误差**：``(f_trial − f)/k_t``在``λ → 1``时两数相减，方向误差按``eps/(λ−1)``放大。λ=1.0001/1.001/1.01/1.1实测3.59e-12/4.19e-13/3.31e-14/4.86e-15，**四档各差一个数量级** |
| ``f·m̂``与支撑函数``h(m̂)``的相对差 | 0 | 1e-14 | 同一条原理的另一半：上一条判方向，这条判大小。**它对方向误差是二阶不敏感的**（``h``的梯度恰是``f``，两边一阶变化相消），故实测在全部λ上平在1.5—1.9e-15。**两条一起才把方向与大小都钉住** |
| 对照组：径向返回的同一个``\|sin\|`` | 1e-14 | 0 | **这是对照不是被验对象**。闭式``(a²−b²)/(a²+b²)``。它必须**显著非零**，否则"两条映射不同"这句话本身没被验过 |
| 七个角上的关联/径向稳态耗散 | 1e-12 | 0 | 引擎侧是位移控制稳态滑移的实测力投影，闭式一侧是支撑函数与椭圆半径。留1e-12给稳态迭代余量（实测1e-15量级） |
| 最高短缺``8/13`` | 1e-12 | 0 | **本案例的中心数字**：WDS报"混合角耗散最高短缺60%"，本仓量到**61.538%** |
| 最高短缺出现的角 | 0 | 0 | **零容差**：峰值角从1°格点argmax选出，格点含45°，**要么恰是45.0要么是别的格点值，没有中间态**。峰值跑到别处即椭圆朝向接错 |
| 45°处横向力被高估的倍数``μ_∥/μ_⊥`` | 1e-12 | 0 | **"系统性偏置横向落位"这句话的定量形状**。耗散短缺只说少了多少功，这条说方向错到哪去了 |
| 各向同性顶替口径的逐角短缺 | 1e-12 | 0 | **另一个口径，不许与上面混起来**：这条比"拿单个``μ_∥``顶上去"，峰值0.8在**主轴**上；那条比"椭圆上径向缩 vs 最近点"，峰值0.615在**45°**上 |
| 主轴回线耗散 | 1e-13 | 0 | 拐点对齐步长边界⟹梯形积分**离散误差为0**；剩下的是1500项累加的浮点求和误差，实测2.0e-14(K=500)/2.2e-14(K=1000)/2.1e-15(K=2000)——**不随K单调，正是求和舍入的指纹**。不对齐时(K=250)实测4.2e-05，高九个数量级 |
| 主轴加载全程的横向力 | 0 | 1e-15 | **实测恰为0.0**。它非零就说明面内轴接错了——那正是`PenaltyAnnulusLimit`把朝向藏进坐标符号时单元门抓不到的那一类错 |
| 稳态圈的锚点净漂与力净变 | 0 | 1e-15 | **回线闭合**。实测恰为0（映射确定，状态一旦重复就永远重复） |
| 第3圈与第4圈耗散之差 | 0 | 1e-15 | **顺手补上`friction_hysteresis_loop`第六条已知失效**（那里明写"多圈的稳态性没验"） |

## 四、已知失效清单

每条一行理由，**禁止静默skip**。本案例无skip。

1. **不走`solve_equilibrium`。** 装置是"给定法向力 + 位移控制"，直接驱动
   `anisotropic_return_map`，与`incline_slide_threshold`调`coulomb_return_map`同形制。
   原因是**步进器今天接不上椭圆映射**：`advance_contact_quasistatic`与
   `advance_contacts_quasistatic`把``friction_coefficient``当标量写死，
   而决策0068裁定不改它们的既有行为。**已登记，触发条件**：步进器加上可选的
   屈服面参数那一次——那时本案例要补一条"走整条路"的门。
2. **法向力是声明的常数，不随位形变。** 真实的带材-导轮接触里法向随包角变，
   而那会让椭圆的两个半轴逐点变。本案例的椭圆是固定的。
   **已登记，触发条件**：第一个把椭圆接进多槽位步进器的消费方。
3. **切向弹性刚度是各向同性的``k_t·I``。** 第二节"欧氏最近点投影等价于关联流动"
   **这一步依赖它**。若哪天切向刚度也各向异性（纤维方向的剪切刚度本就更大），
   最近点投影要改用能量范数下的投影，这条等价关系要重推。**本案例不验那种情形。**
4. **没有硬化、没有率相关。** ``μ_∥``、``μ_⊥``是常数，不随滑移速率或累计滑移变。
   静摩擦与动摩擦不分。与`friction_hysteresis_loop`同一条边界。
5. **``μ = 0``被拒收，不是被支持。** ``μ_⊥ = 0``把椭圆压成线段，
   那是一次**不同的**投影（往线段上夹紧）。本仓今天没有消费方要它，
   故`FrictionEllipse`当场报错而不是静默给一个除零的nan。
   **已登记，触发条件**：第一个真要"某方向完全无摩擦"的消费方。
6. **耗散仍然是案例自己积分出来的，不是引擎报的。** 与`friction_hysteresis_loop`
   第五条**同一条缺口**：`EnergyRegistry`只报势能，本仓今天没有耗散记账通道。
   本案例把这条缺口又用了一次，**没有关掉它**。
7. **没有横向落位（``e_lat``）的端到端数**。本案例量到的是"横向摩擦力被高估5倍"，
   **而从力到落位偏差要过带材的弯曲与输运**，那是另外两条轨道的东西。
   **本案例不声称任何毫米级的落位结论。**
8. **`coulomb_return_map`仍可能输出``-0.0``。** 各向异性那条把负零收成正零
   （理由见`_positive_zero`：`canonical_bytes`把两者写成不同字节，
   于是`State.fingerprint()`不同），**各向同性那条没加，因为加了就改既有产物指纹**。
   两条路径在这一点上的差别只出现在精确为零的分量上。**已登记，未修。**

## 五、档位与负载级

- **清单身份**：`case/anisotropic_friction_ellipse`；
- **档位**：B档（对四条独立闭式，穿过引擎的接触层但不进`energies`/`solve`）；
- **负载级**：本机批级（`local_batch`，与`oracle.json`的`load_tier`一致）。
  六道门共**0.36秒**（2026-08-17实测，1分钟负载6.7，三次一致）。
  **同一份代码在负载19时是1.09秒**——三倍差全部来自机器负载（四条轨道并行占机），
  这条注在这里是因为0053那笔教训：**拿不合格读数去改台账会把正确的数改错**。
  申报批级而非交互级的**理由是扫描规模不是单步成本**：
  退化对拍1440次、外法向扫描1440次、耗散扫描91角×2映射×120步、
  回线3幅值×3圈＋45°4圈×2000步，合计约十万次return-map。

## 六、本案例不是什么

- **不是摩擦系数的标定**。``μ_∥``、``μ_⊥``、``N``、``k_t``全是**声明的输入**。
  5:1这个比来自消费方WDS的声明，本仓没有独立测过它。
- **不是"η-return"那条捷径的实现**。派活书把η-return描述成
  "把椭圆拉成圆、径向返回、再变回来"，而**那条捷径展开之后就是径向缩**
  （``f = f_trial/|S·f_trial|``，一个纯标量乘在``f_trial``上，方向一个字没变；
  逐分量实测两条差8.88e-16）。本案例判的是**最近点投影**，
  η是那条标量方程里的**塑性乘子**，不是任何一次坐标缩放。详见决策0068第二节。
- **不是各向异性弯曲、不是各向异性输运**。椭圆只管切向本构。
- **不是多点接触、不是多轮路由**。单点、单个椭圆。
- **不进0040分母**。同行C档接触族要的是多体与恢复系数；
  本案例验的是本仓自己的切向本构对不对。
- **不是横漂案例的替代**。`roller_skew_lateral_drift`第六节说"不含摩擦，
  真做各向异性要补摩擦椭圆"——**本案例补的是椭圆本身，不是把它接进那个案例**。
