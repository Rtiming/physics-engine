# euler_buckling Euler屈曲：引擎第一次算对一个**失稳载荷**

`case/euler_buckling`。C档（research/05第2.3节"需要真求解器"的那批），
spec/12第三节（能量项）+第4.1节（准静态求解）。
**这是`PointLoad`与切线刚度正定性判别的进仓门**，也是决策0040那张
C档13条表里的**第3条**——它点名要的正是`PointLoad`。

同行案例复用（research/05第2.3节C3；PyElastica／Gazzola 2018同族）。
与本仓另外两条杆梁案例的分工：`cantilever_self_weight`验小挠度线性方程、
`large_deflection_cantilever`验几何非线性的**位移**，
**本案例验的是一个特征值**——"载荷加到多大它撑不住"。
前两条问"变形多少"，这一条问"还稳不稳"，是两类不同的判据。

## 一、物理/几何设定

轴向受压的细长直柱，载荷是**方向固定的死载**（dead load，沿`−x`），
施加在受载端节点上。三种边界条件各跑一遍。

| 量 | 值 |
|---|---|
| 长度 L | 100.0 mm |
| 弯曲刚度 EI | 100.0 N·mm² |
| 轴向刚度 EA | 1.0e5 N |
| 细长比 EI/(EA·L²) | 1.0e-6 |
| 加密阶梯 | 10 / 20 / 40 / 80 段 |
| 取值用的加密档 | 80 段 |
| 模态层与定性层的加密档 | 20 段 |
| 牛顿绝对残差容差 | 1.0e-8 N |
| 载荷二分次数 | 40（区间`[0.1·Fc, 6.0·Fc]`，压到 5.4e-12·Fc） |
| 保长扰动的链节转角幅值 | 0.003 rad |
| 亚临界／超临界采样 | 0.7·Fc ／ 1.3·Fc |
| 固支顶点的Voronoi长度系数 | 1.5（即`3h/2`） |

离散：等分链，轴向由`AxialStretch`承担、弯曲由`DiscreteElasticBending`承担、
轴向压载由**`PointLoad`**施加（决策0046；在它之前引擎没有点载荷项，
端载荷只能用集中质量凑，那条路做不了这个案例）。
面外（z）自由度全钉：本案例是平面问题。
节点质量全取1.0 kg，**不参与任何能量项**（无重力项），`EnergyContext`要求为正。

**边界条件就是钉法**，逐条写死：

| 边界条件 | 钉住的自由度 | 有效长度因子 b |
|---|---|---|
| 两端铰支 | 节点0的x与y；节点n的y（x自由，载荷在那里） | 1 |
| 一端固支一端自由 | 节点0的x与y；节点1的y（**只钉方向，第一条边的长度仍自由**——柱子必须能轴向缩短） | 2 |
| 两端固支 | 两端各钉两个节点的y；节点0的x；受载端x自由（标准的"两端固支、一端可轴向滑动"） | 1/2 |

**求解分两步，这一点是本案例的形制而不是取巧**：

1. **预屈曲**：把所有横向自由度钉住，解直链的轴向平衡。直链在任何载荷下都
   **恰好**是平衡态（直链上弯曲梯度为零、轴向力沿x），钉住横向只是把这个已知事实
   用上，换来一个恒正定的一维问题；实测牛顿一步收敛、每段缩短恰为`F/EA`。
2. **稳定性**：放开横向自由度，问约化切线刚度还正不正定
   （`solve.tangent_stiffness_is_positive_definite`，带状Cholesky，
   全部主元为正 ⟺ 正定）。对载荷二分这个真假翻转点，即得离散临界载荷。

**这条路径不需要牛顿法穿过分岔点**——它问的是"直链在这个载荷下还是不是极小"。
直接穿越会发生什么，第四节有量化记录。

## 二、参考解出处

### 连续解：`Fc = π²·EI/(b·L)²`

控制方程`EI·y'''' + F·y'' = 0`，通解`y = A + B·s + C·sin(k·s) + D·cos(k·s)`
（`k² = F/EI`）。四个边界条件给出齐次系统，行列式为零即特征方程；
最小正根`u = k·L`给出`Fc = (u/L)²·EI`，即**`b = π/u`**。

| 边界条件 | 特征方程 | 最小正根 u | b = π/u |
|---|---|---|---|
| 两端铰支 | `sin u = 0` | π | 1 |
| 一端固支一端自由 | `cos u = 0` | π/2 | 2 |
| 两端固支 | `4·sin(u/2)·[(u/2)cos(u/2) − sin(u/2)] = 0` | 2π | 1/2 |

**生成器不抄b的表，它对每条特征方程求根。** 两端固支那条有**两支**根：
`sin(u/2)=0`给`u=2π`、`tan v = v`（`v=u/2`）给`u = 8.9868…`；取小的那个。
自校验把这条比较写进去了，因为"b用错"最常见的形态就是拿了大的那一支。
文献值（**Timoshenko & Gere, *Theory of Elastic Stability*, 2nd ed., 1961,
§2.1／§2.2／§2.4**；AISC钢结构规范附录的"理论K值"表同为1.0/2.0/0.5）
只作交叉验证，**写进金标的是求根结果**。

### 离散解：铰接刚性链的**精确**特征值（第二条参考路线）

引擎把杆离散成n段、在n−1个内部顶点上放弯曲能`(EI/(2h))·(Δφ)²`。
线性化后这正是铰接刚性链模型，其刚度矩阵是三对角Toeplitz阵`tridiag(−1,2,−1)`，
特征值有闭式`2(1−cos(kπ/n))`，于是（两端铰支）

    Fc_n = (4·EI/h²)·sin²(k·π/(2n))     k = 1, 2, …

**这条路线把离散误差与实现误差分开**：引擎的实测值应当命中`Fc_n`
而不是命中连续解，二者之差是纯粹的离散误差`−π²/(12n²)`。
它同时给出二阶模态比`sin²(2π/2n)/sin²(π/2n)`（连续极限4=2²，n=20时3.9753766812）。

**生成器只算这两条闭式**：不import `physics_engine`的任何力学模块。
四条自校验在生成时跑，任何一条不过就不出金标：

1. 求根得到的b与文献表逐项相对偏差 < 1e-12，且两端固支的另一支根确实更大；
2. **离散特征对是恒等式**：把`v_j = sin(jkπ/n)`代回差分方程，残差 < 1e-14
   （n=10与n=17、全部k）。这验的是闭式本身而不是它的某一个值；
3. **离散→连续的第一修正恰为`−π²/(12n²)`**：断言"n翻倍则余项降4倍"
   （实测3.9987/4.0000/4.0000），比只断言"趋近π²EI/L²"强得多，
   且校验里不需要写下任何系数；
4. 单调性：`Fc_n`随n单调增且恒小于连续值；二阶模态比随n单调增且恒小于4。

## 四、已知失效清单

- **牛顿法穿不过分岔点，本案例绕开了它，绕开的方式写在这里。**
  实测（两端铰支，n=20，从带横向扰动的初值出发，全部横向自由度放开）：

  | F | 初始扰动幅值 | 结果 |
  |---|---|---|
  | 0.8Fc | 1e-4 / 1e-2 / 1.0 mm | ✅ 收敛回直链（y_mid ≤ 1.0e-10），4—25次迭代 |
  | 1.05Fc | 1e-4 mm | ⚠️ "收敛"但只跑了0迭代——**初值的残差本来就在容差内**（扰动几乎落在零空间里），这是一次**假收敛** |
  | 1.05Fc | 1e-2 / 1.0 mm | ❌ 不收敛，回溯345 / 77次 |
  | 1.2Fc — 2.0Fc | 全部三档 | ❌ 全部不收敛，回溯40—389次，理由恒为"线搜索40次回溯后仍无法降低能量——牛顿方向不再是下降方向（可能已在鞍点或Hessian非正定）" |

  **这正是decisions/0029第八节登记的那条缺陷**（无信赖域、无载荷步自适应、
  Hessian非正定时无修正），而屈曲恰恰就是Hessian失去正定性的那一点。
  **本案例没有靠调参绕过去**：参数（载荷步、容差、初值）改了也一样红。
  绕开的方式是**换判据**——问"直链还是不是极小"而不是"屈曲后长什么样"，
  于是求解器只需要解一个恒正定的一维预屈曲问题。
  代价是明确的：**本案例不给后屈曲平衡路径，一条都不给**。
  要那条路径得给`solve.py`加弧长法或信赖域，那是另一块。
- **求解器报告的`converged=True`在超临界处是真的，但那是个鞍点**。
  从**精确的直链**出发，1.3Fc下牛顿一步收敛、残差达标、返回的解逐位仍是直的。
  求解器没有错——`∇U = 0`确实成立。分辨这件事的是本批新增的
  `tangent_stiffness_is_positive_definite`；**在它之前本仓没有任何办法查这一条**，
  `solve.py`开头"适用域：Hessian在解附近正定"因此一直是个不可验证的申报。
- **可伸长性是引擎的必然，不是本案例的选择**。Euler理论假定杆不可伸长；
  引擎只有弹簧。该效应把离散临界载荷抬高恰好`+Fc/EA = 9.87e-7`，
  已进判据表并留了2倍余量。**它不随n下降**，所以在最细档占离散误差的0.8%，
  是收敛比上界取4.1（而不是更紧）的原因。
- **固支顶点的Voronoi长度取`h`会把收敛阶从二阶打到一阶**，且误差大两个数量级。
  扫描（一端固支一端自由，四档网格的相对误差与比值）：

  | 系数 | n=10 | n=20 | n=40 | n=80 | 比值 |
  |---|---|---|---|---|---|
  | 1.00 | +1.0551e-01 | +5.1371e-02 | +2.5342e-02 | +1.2585e-02 | 2.054 / 2.027 / 2.014 |
  | 1.25 | +5.0100e-02 | +2.4988e-02 | +1.2493e-02 | +6.2479e-03 | 2.005 / 2.000 / 2.000 |
  | **1.50** | **−8.3796e-04** | **−3.6007e-04** | **−1.0900e-04** | **−2.9470e-05** | 2.327 / 3.303 / 3.699 |
  | 1.75 | −4.7706e-02 | −2.4712e-02 | −1.2468e-02 | −6.2471e-03 | 1.930 / 1.982 / 1.996 |
  | 2.00 | −9.0886e-02 | −4.8110e-02 | −2.4589e-02 | −1.2406e-02 | 1.889 / 1.957 / 1.982 |

  **1.5是唯一那个点**，其余全是干净一阶。更强的一条旁证：按上表反解"误差恰为零"
  的最优系数，四档分别是1.4957 / 1.4964 / 1.4978 / 1.4988——**它随h线性趋近1.5**，
  于是`3h/2`处的残余误差是`(斜率∝h)×(偏移∝h) = O(h²)`，与观察到的比值
  正在趋近4一致。这是decisions/0027、0029那条教训的**第三例，而且换了物理问题**：
  前两次验静挠度，这次验特征值。同一个系数在两类问题上同时把阶次抬起来，
  那不像配出来的数。
  **但要如实说**：`3h/2`处的比值2.327/3.303/3.699还没进渐近区，
  本案例的收敛阶断言因此只加在**两端铰支**（无固支顶点，实测3.9916/4.0033/4.0226）；
  固支的两条只断言误差量级与"退回h必须掉到一阶"。
- **两端固支那一档的误差在n=10与n=20之间变号**（+2.451e-04 → −3.529e-03），
  即两个误差项在n≈10附近互相抵消。本案例的取值档是n=80，不受影响；
  但**任何人拿这个模型做两端固支的粗网格估算都必须知道这条**——
  n=10那一档"准得可疑"是抵消而不是精度。
- **只在平面内、只在一阶模态附近**。面外自由度被钉住；扭转屈曲、弯扭耦合屈曲、
  局部螺旋屈曲（research/05的C6）都不在本案例。二阶模态只经Rayleigh商验了一个比值，
  没有解出它的模态形状。
- **没有非线性后屈曲、没有缺陷敏感性、没有塑性铰**。Euler屈曲是理想直柱的
  分岔载荷；真实柱子的初弯曲、偏心、残余应力都会把它压低，本案例一个都不涉及。
- **没有特征值求解器**。`tangent_stiffness_is_positive_definite`只回答
  "是不是正定"，不给最小特征值，所以临界载荷是**二分**出来的而不是解出来的。
  40次二分的代价是本案例总耗时的大头。真正的特征求解器（连同它能给的模态向量）
  本仓今天没有，**不假装有**。
- 未在Windows/Linux复核。

## 五、档位与负载级

C档（research/05第2.3节"需要真求解器"的那批），**local_batch**（本机批级，<2分钟）。
实测（本机空载）：八条测试共约 **5.3秒**。
慢的原因是可申报的：三种边界条件 × 最多四档网格 × 40次载荷二分，
每次二分含一个预屈曲牛顿解与一次带状Cholesky；
加上四个试验形状各40次能量二分。**不是可以靠调参省掉的慢。**

带状Cholesky是这个案例负担得起的原因：稳定性判别的复杂度是`O(m·b²)`
而不是`O(m³)`（链式Hessian的半带宽与规模无关，见`tests/test_energies.py`
里那条带宽门）。n=80的稳定性矩阵有159个自由自由度，二分40次仍在秒级。

## 六、本案例不是什么

- **不是"引擎能做屈曲分析"的证据**。它算的是单根、平面、各向同性、
  无缺陷、无接触的理想直柱在三种教科书边界条件下的**分岔载荷**。
  工程意义上的屈曲分析还差：初始缺陷、非线性后屈曲路径、多柱体系的整体稳定、
  扭转与弯扭耦合、塑性。
- **不是求解器的稳健性证明**——恰恰相反，第四节量化登记了它穿不过分岔点。
  本案例的可行是靠**换判据**换来的，不是靠求解器变强。
- **不是`tangent_stiffness_is_positive_definite`能替代特征值分解的证据**。
  它只给一个布尔；临界载荷靠二分逼近，模态靠Rayleigh-Ritz的试验形状比较。
  两者都够用于本案例的判据，都不等于有特征求解器。
- **不是`PointLoad`全部形制的门**。本案例只用了单点、恒定方向、恒定大小的死载。
  多点载荷、随构型转动的随动载荷（follower load，会破坏Hessian的对称性）
  一个都没验——后者甚至会改变屈曲载荷本身（Beck柱是发散失稳变颤振失稳的经典例子）。
- **不验证连续极限下的模态形状本身**。第四层验的是"正弦半波在所有试验形状中
  给出最低的临界载荷，且与真值的间隙 ≤ 5.9e-7"，那是Rayleigh-Ritz意义上的模态判据；
  它**没有**逐节点比较模态向量，因为本仓没有特征向量可比。
- **不是`b`表的证据来源**。b由特征方程求根得到，文献表只作交叉验证；
  反过来说，如果特征方程写错了，本案例会与文献表一起红——
  自校验第1条就是为这件事立的。
- **它验`energy()`，但只验一个符号。** 第四层的能量差判据能抓住`E = −F·x`
  写成`+F·x`（超临界处扰动不再降能，门立刻红），
  但抓不住把`E`整体乘一个正的常数因子——那种错由`tests/test_energies.py`
  的手算数门与量纲门守。**三条门缺一不可**，理由见decisions/0029第六节：
  求解器只用梯度与Hessian，只活在`energy()`里的错误能从闭式案例底下溜过去。
