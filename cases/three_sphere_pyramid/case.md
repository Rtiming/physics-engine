# three_sphere_pyramid 三球金字塔临界摩擦：μc = 1/(3√3)

**引擎第一个多体接触案例**——此前接触都发生在节点与**固定**半空间之间，
而固定面不参与自由度。本案例的球-球接触**两端都是自由度**，
于是切线刚度里第一次出现**跨节点的耦合块**，那才是多体接触与单体接触的真正分界。

判据形制取自Chrono `utest_DEM_pyramid.cpp`：**同一模型只改摩擦系数，
一边必须撑住、一边必须塌**。research/05称它是那次调研里判据设计最好的一条。

判据值的正本是同目录的`oracle.json`（本页只解释，不重复声明）。

## 一、物理/几何设定

三个等径球。两个底球贴地并相切，球心``(±r, 0, r)``；顶球卧在凹槽里，
球心``(0, 0, r + √3·r)``。连心线与水平成**60°**。

| 项 | 取值 |
|---|---|
| 半径``r`` | 10.0 mm |
| 质量（每个球） | 1.5 kg |
| 重力 | 9810 mm/s²（沿``−z``） |
| 罚刚度（三处统一``k``） | 力判据用2×10⁷ N/mm；收敛阶扫2×10⁵、2×10⁶、2×10⁷ |
| 自由度 | 三个球心的``x``与``z``共6个；``y``全部钉住（问题在平面内） |
| **球-球接触** | **无摩擦**，只沿连心线传力 |
| **球-地接触** | 法向罚 + 粘着弹簧 + 库仑锥 |

**"球-球无摩擦"是本案例最要紧的一条设定，也是它与Chrono原版的差别**——
理由见第六节。

## 二、参考解出处

静力学分解（任一本静力学教材）。顶球竖直平衡：

    2·F·(√3/2) = W        →   F = W/√3

底球（受顶球反作用``F``、自重``W``、地面法向``N``与摩擦``T``）：

    竖直：N = W + F·(√3/2) = 3W/2
    水平：T = F·(1/2)      = W/(2√3)

粘住条件``T ≤ μN``：

    W/(2√3) ≤ μ·(3W/2)    →   μ ≥ 1/(3√3) = √3/9 ≈ 0.19245008972987526

**``W``两边约掉——临界摩擦系数与质量、重力加速度、罚刚度全部无关，只由几何决定。**

### 与斜面案例的关键差别：这里的比值**不是精确的**

`incline_slide_threshold`里法向是固定的，穿透不改变力的分解，所以``N``与``T``
精确到1 ulp。**这里不同**：穿透改变**接触几何本身**——球心距变了，
连心线角度跟着变——于是``T/N``带一个``O(δ/R) = O(1/k)``的偏差。

**因此本案例多一条判据：那个偏差必须是一阶的。** 实测：

| ``k`` (N/mm) | ``T/N``相对偏差 | 前档/本档 |
|---|---|---|
| 2×10⁵ | 5.664e-06 | — |
| 2×10⁶ | 5.661e-07 | **10.00** |
| 2×10⁷ | 5.394e-08 | **10.50** |
| 2×10⁸ | 2.370e-08 | 2.28（已入浮点地板） |
| 2×10⁹ | 2.554e-07 | 0.09（地板以下，开始变差） |

**前三档比值≈10即一阶收敛**，这条比"偏差很小"强得多——
它证明那个偏差**是模型的柔度而不是实现的错误**。
后两档的退化是相消：``k = 2×10⁹``时穿透约4×10⁻⁹ mm而心距20 mm，
相对量2×10⁻¹⁰，双精度只剩约6位有效数字。**地板的位置是算得出来的，不是玄学。**

## 三、判据表

| 量 | rel | abs | 理由 |
|---|---|---|---|
| ``μc``（由实测``T/N``给出） | 2e-7 | 0 | 闭式``1/(3√3)``由几何决定，但罚柔度带``O(1/k)``偏差。``k=2e7``实测5.4e-08，取2e-7约3.7倍余量。**这个容差是模型的柔度，不是实现的余量**——收敛阶那条门专门验这一点 |
| ``μ/μc = 1.00001``撑住 | 0 | 0 | **定性判据零容差**（Chrono形制）：同一模型只改``μ`` |
| ``μ/μc = 0.99999``塌 | 0 | 0 | 同上，另一边。**两侧都断言才叫临界值** |
| ``F = W/√3`` | 2e-7 | 0 | 同上，柔度偏差 |
| ``N = 3W/2`` | 2e-7 | 0 | **它比另外两个准得多**（实测7e-12量级）——竖直平衡不依赖接触角，柔度不进这一条。容差仍取统一值，判据表的可读性优先于逐条压紧 |
| ``T = W/(2√3)`` | 2e-7 | 0 | 经接触角进来，带柔度偏差 |
| 偏差比落在``[8, 12]`` | 0 | 0 | 一阶是**渐近**性质，**不写死为10**——写死会让正确实现在别的构型上红（与`harmonic_oscillator`那条"不写死为4"同源） |
| 偏差逐档单调减小 | 0 | 0 | **前置断言**：不减小时比值区间那条门是在拿噪声算阶 |

## 四、已知失效清单

每条一行理由，**禁止静默skip**。

1. **球-球接触无摩擦。** 加上摩擦后问题**静不定**（未知数多于方程），
   ``μc``不再有与柔度无关的闭式解——它会依赖三处刚度的比值。
   **本案例刻意取静定的那一支**，因为一个依赖罚参数的"临界值"不是判据。
2. **需要延拓才能扫刚度。** 高刚度下直接从刚性几何起步会撞上"接触恰好为零"
   的奇异（切线刚度在那里没有法向刚度）。本案例用低刚度的解当高刚度的初值。
   **这是求解策略不是物理**，但它必须被写下来——否则下一个人会以为高刚度"跑不了"。
3. **残差容差必须随刚度缩放。** 残差地板来自``length − 2r``的相消，
   量级随``k``涨。固定容差在高刚度档会永远不收敛
   （起草时正是这样卡了200次迭代）。
4. **不给塌之后的运动。** ``μ < μc``时底球滑开，那是瞬态问题，
   要隐式积分族——本仓一个都没有。本案例只断言"判别为滑"。
5. **顶球的转动不参与。** 球被当成质点+半径；无滑滚动、力矩平衡都不在内。
   C档第8条的后半（无滑滚球）同样卡在这里。
6. **底球之间的接触被略去。** 平衡时顶球把它们推开，该接触分离；
   声明它反而会在起步时引入一个``g = 0``的奇异点（起草时实测撞上）。
7. **对称性没有被独立验证。** 左右两侧的力实测相同，但那是同一段代码算的，
   **不构成独立证据**。

## 六、本案例不是什么

- **不是C档第7条的完整兑现。** Chrono的`utest_DEM_pyramid.cpp`**所有接触都有摩擦**，
  那是静不定问题；本案例的球-球接触无摩擦，是**静定变体**。
  **定性判据（同一模型只改``μ``、一边撑住一边塌）复现了，闭式``μc``是本变体的。**
  故`cases/README.md`的分母按**半条**记，**不进位**。
- **不是DEM。** Chrono那条是离散元的单元测试；本仓这里是准静态能量求解，
  没有时间推进、没有阻尼、没有碰撞检测流水线。
- **不是"三个球的碰撞"。** 接触对是**声明**的（`ContactDeclaration`），
  不是搜出来的——`collision.py`的broad/narrow phase没有参与本案例。
- **不是稳定性分析。** 只断言静平衡的力与摩擦锥，不判这个平衡是不是极小
  （`tangent_stiffness_is_positive_definite`没有用在这里，因为罚接触的
  几何刚度在接触处为负，那条判据的含义要先重新裁一次）。
