# 三球金字塔（含力矩平衡）：`μc = 2 − √3`

本案例是`three_sphere_pyramid`的**另一支**，不是它的替代。
那一条做的是**球-球无摩擦、且不写力矩平衡**的6方程6未知变体，闭式`μc = 1/(3√3)`；
本条做的是三个刚体各含`ΣM = 0`的**全粘着支**，9方程8未知、精确秩8，闭式`μc = 2 − √3`。

**两支差1.392305倍**——决策0063第二节量的那个"转动自由度缺席时接触问题的答案
系统性地偏约四成"，就落在这两个数之间。

## 一、物理/几何设定

三个等径等质量球，平面（`x`-`z`）问题，`y`方向与面外转动全部钉住。

- 半径：`radius_mm = 10.0`
- 质量：`mass_kg = 1.5`（每球）
- 重力：`gravity_mm_s2 = 9810.0`，方向`(0, 0, −1)`
- 自重：`weight_n = 14.715`（`= mass_kg × gravity_mm_s2 / 1000`）
- 罚刚度（法向与切向同取）：判据档`2.0e6 N/mm`；收敛阶档`2.0e4`、`2.0e5`、`2.0e6`
- 初始构型（球心）：顶球`(0, 0, r(1+√3))`、右底球`(r, 0, r)`、左底球`(−r, 0, r)`
- 地面：过原点、外法向`(0, 0, 1)`的半空间
- 球-球单位法向（底球指向顶球）：`n_R = (−1/2, 0, √3/2)`、`n_L = (1/2, 0, √3/2)`

自由度：三体各`x`、`z`、`θ_y`共9个。布局是`rotation.build_rigid_body_layout`
产出的"质心块 + 转动块"，转动块挂在节点块之后，故`node_dof_count`仍是9。

边界条件（`fixed_indices`）：三体的`y`、`θ_x`、`θ_z`，**外加顶球的`θ_y`**。
最后那一条是**规范固定**，理由与它的代价见第四节第2条。

能量项与求和次序（次序即形制）：
`UniformGravity` → `PenaltySphereContact`（两个球-球法向）→
`PenaltyNormalContact`（两个球-地法向）→ `MaterialPointStickSpring`（四根粘着弹簧）→
`RotationStickCoupling`（四根弹簧的转动增量）。

### 一之二、"两侧"那一支的装置（2026-08-18加，决策0080）

上面那套是**全粘着支**：粘着弹簧是调用方装配的能量项，锚点是常量、永不改变。
两侧判据换一套装置，差别只有一条但它是整件事的要害：
**锚点住在状态里，由`contact.stepper.advance_contacts_quasistatic`改写。**

- 布局：`contact.layout.build_contact_layout(node_count=3,
  declarations=四对, rotating_bodies=(0,1,2))`——
  节点块(9) + **四个锚点槽**(20) + 转动块(9)，共38个标量。
  转动块排在锚点槽**之后**，理由见决策0080第三节（插中间会顶掉每个既有槽的`base`）。
- 接触对声明次序（**次序即形制**，它定了每个锚点落在哪一格）：
  `sphere_right` → `sphere_left` → `ground_right` → `ground_left`。
- 四个`ContactPoint`：球-球那两个**两端都是可转的`MaterialPoint`**
  （`counterpart`给对边），球-地那两个对世界锚点。
  杠杆臂取参考构型下的`∓R·n`——球面上接触点就在连心线上。
- 零应力锚点：球-球是**相对**位移，参考构型下恰为零矢量；
  球-地在接触点正下方，即`x = ±R`。
- `registry_without_stick`只含`UniformGravity` → `PenaltySphereContact` →
  `PenaltyNormalContact`。粘着弹簧由步进器每趟按当前锚点自己造（那是它的契约）。
- 法向与杠杆臂**全程固定在参考构型上**。前提的成立条件是实测的：60步末
  `max|θ| = 5.79e-07 rad`、位形漂移微米级（第四节第8条）。
- `max_passes = 1`（法向固定时一趟精确）。

## 二、参考解出处

**闭式解，`Q(√3)`上的精确有理算术**，生成脚本入库：

- 路径：`cases/three_sphere_pyramid_rotational/generate_oracle.py`
- SHA-256：钉在`oracle.json`的`generator.sha256`字段（改了脚本不重跑，读侧当场红）
- 算法：9×8装配 + 精确高斯消元，全程`Fraction`与`a + b√3`，**没有一处浮点**

脚本在**生成期**就断言了六件事，抄错一个符号当场炸：精确秩必须是8、
第9条方程必须冗余（剩余行整行为零）、四组对称差必须精确为零、
`F = W/2`、`N = 3W/2`、`|f|/F`必须**精确等于**`2 − √3`。

独立证人：[`docs/research/15`](../../docs/research/15_过阻尼分支与推导补全_20260812.md)第三节
用另一份实现做过同一件事。本案例的生成器与它的四个数**逐位相同**
（`test_the_generator_reproduces_the_independently_recomputed_solution`）。
**两份实现逐位相同才叫复核**——照抄它的数不叫。

精确解（以`W`为单位）：

| 量 | 精确值 | 数值 |
|---|---|---|
| 球-球法向`F` | `1/2` | 0.500000000000000·W |
| 球-球切向`f` | `1 − (1/2)√3` | 0.133974596215561·W |
| 球-地法向`N` | `3/2` | 1.500000000000000·W |
| 球-地切向`T` | `−1 + (1/2)√3` | −0.133974596215561·W |

`|f|/F = 2 − √3 = 0.26794919243112281`，`|T|/N = (2−√3)/3 = 0.0893163974770409`。
**卡住的是球-球接触，不是地面**——地面宽松3倍。

## 四、已知失效清单

1. ~~**滑移没有接上转动。**~~ **2026-08-18解封（决策0080）。**
   本案例此前只有**纯粘着**支：四根弹簧全程stick、锚点从不动，
   于是Chrono形制的"只改`μ`、一边撑住一边塌"那条两侧判据给不了。
   `contact/stepper.py`接上转动块之后，第三节下半张表那八行是**塌那一边**的判据，
   **C档第7条因此进位**（见第六节）。
   本条留在这里不删：它是"欠账登记了触发条件、触发条件到了就兑现"的一次完整闭环。
2. **顶球自旋被钉住。** 不钉时约化Hessian有一维零空间（整座金字塔沿地面
   **整体侧滚**），实测条件数7.86e17。零模上重力不做功，所以**平衡解存在但不唯一**
   ——它是一条平衡线。钉住顶球`θ_y`挑掉线上一个点；**这不改问题**由
   "约束反力矩恰为0.0"那条逐位门证明。
   **不许把它读成"金字塔会散架"**：起草时按那个猜想写过一条门，实测零模是侧滚
   不是外滚，猜想被否掉了。
3. **`k ≥ 2e7`不进收敛阶扫描。** 那一档起实测偏差进浮点地板（力的绝对噪声
   约`7e-15·k`，而力本身是`O(W)`），拿它算阶就是在算噪声：实测`2e6→2e7`
   的比值是33.08而不是10。**地板的位置是算得出来的，不是玄学**。
4. **`tangent_stiffness_is_positive_definite`在近奇异构型上会给假绿。**
   零模的主元被舍入抬成`O(eps·k)`的正数，带状Cholesky于是返回`True`。
   这不是本案例引入的缺陷，是那个函数自己docstring里写明的边界
   （"它只回答是不是正定，不给最小特征值"）。本案例因此**不拿它判零模**，
   改判能量沿零模是平的、梯度在零模上的投影为零。
5. **无滑滚球`a = (5/7)g·sinα`不做。** 那是0063第五节**第3步**（路径B、
   时间积分、`rigidbody`接接触）的判据，准静态路径给不了它。本案例的斜面那一组
   给的是**约束反力矩**`W·R·sinα`——同一条物理（接触力对质心取矩）的准静态投影。
6. **三维一般转动没有案例。** 本案例与斜面组都是平面问题（只有`θ_y`自由）。
   `rotation.py`的指数映射、雅可比与二阶导按三维写并按三维验（`tests/test_rotation.py`
   走到`|θ| = 2.69`与`φ = π`分支），但**没有一个案例把三个转动分量同时放开**。
   解封条件：第一个真正三维的接触构型进来时。
7. **近阈值有一条行进不收敛带。** `|μ − μc|`小到一定程度时，**行进**（不是单步）
   会在若干步之后报`达到最大迭代次数60仍未收敛`。边界实测：`k = 2e6`时约
   `|μ − μc| ≲ 4e-4`（`μ = 0.2679`第12步、`0.26794`第3步），`k = 2e5`只在`0.26794`出现，
   `k = 2e4`二十步内不出现。
   **已排除三条**：不是残差容差地板（容差从8e-8放到1e-2，停住的残差**一模一样**
   是2.86e-4 N）；不是零模或病态（失败点的约化Hessian与健康点**谱完全相同**，
   条件数4853）；不是"一趟不够"（加趟数**更早**失败，即预测-修正在这一带不是压缩的）。
   **定位到的那一半**：残差落在转动块上（`body1_theta_y`与`body2_theta_y`等大反号，
   2.86e-4 N·mm），而1 ulp抖动引起的梯度跳变是4.03e-8——**高7000倍，是真实的
   不平衡力矩不是舍入**。**根因没定位到，不编一个。**
   **它不参与任何判据**：撑住跑`μ = 0.30`、塌跑`μ = 0.20`，阈值二分只走**一步**
   （单步在`μ = μc`上也不失败）。解封条件：第一个需要在这一带做行进的消费方。
8. **杠杆臂与法向全程固定在参考构型上。** 两侧那一组不重取几何、也不重输运。
   前提的成立条件是**实测的**：60步末`max|θ| = 5.79e-07 rad`，比指数映射的
   级数/闭式切换阈值`0.2`小五个数量级；位形漂移是微米级而杠杆臂是10 mm。
   **因此本案例给不了`rotation.retransport_levers`第一个真实调用方**
   （0079第六节与plans/07登记的那笔欠账仍然挂着，原样不动）。
   有限位移的接触（球滚过去、贴地的换成另一个物质点）**不在本案例范围内**。
   解封条件：第一个真正走出局部图的接触构型——今天最可能是盒/网格族的角接触，
   那里杠杆臂是真材料点，球面上"接触点永远在连心线上"这条便利没有了。

## 五、档位与负载级

C档、交互级。清单身份：`case_id = case/three_sphere_pyramid_rotational`，
`load_tier = "interactive"`（与`oracle.json`逐字一致）。无pytest marker。

C档的理由与`three_sphere_pyramid`同源：它是同行套件里点名的构型
（Chrono `utest_DEM_pyramid.cpp`形制），且判据来自独立推导的闭式而非实测。
交互级的理由是实测：五档刚度全部**1到2次牛顿迭代、零回溯**，
全组**38条**测试合计**0.33秒**（2026-08-18加两侧那一组之后重测；
其中塌那一边60步、撑住25步、阈值二分38次求解）。

## 六、本案例不是什么

- **不是`three_sphere_pyramid`的替代。** 那一条仍然有效，它验的是另一个模型
  （球-球无摩擦、不写力矩平衡）。两条案例的`ground_normal_n`都是`3W/2`且必须保持一致
  ——**加力矩平衡改的是力怎么分，不改总的竖直承载**。
- **~~不是~~ 是C档第7条的兑现（2026-08-18改写，决策0080）。** 第7条要的是
  "同一模型只改`μ`、一边撑住一边塌"。0079那一轮兑现了`missing`的前半句
  （`μc = 2−√3`由转动接触自由度与本案例算出来），后半句"两侧判据"由本轮兑现：
  撑住那一边是**不动点**（滑距逐位`0x0.0p+0`、状态向量25步逐位不变），
  塌那一边是**恒速率的不可逆滑移**（球-球判别`SLIP`、两底球逐步分开、
  顶球逐步下降、滑距不衰减，且滑距有闭式`(μc−μ)·F/k_t`）。
  第7条`missing`因此清干净，状态`partial → done`。
  **注意它没有连带解锁S3.7**：那一位的label还写着"翻倒"与"无滑滚动"，
  两件都要时间积分（0063的路径B），准静态给不了。
- **不是刚体动力学。** 没有惯量张量、没有角速度、没有时间。转动自由度在这里是
  能量极小化的三个无约束标量参数（SO(3)指数映射的局部图），
  与`rigidbody.py`的四元数是同一个群的两种坐标（决策0074第四节）。
- **不是滚动阻力模型。** 点接触不传力偶（research/15第3.3节前提一）。
  金字塔的零模是侧滚，正因为没有任何东西阻止滚动——**那是模型的声明，不是遗漏**。
- **不判位置。** 罚接触的位置有`O(1/k)`误差、力没有误差
  （`PenaltyNormalContact`类docstring）。本案例的判据全部是力、力矩与比值。
