# incline_slide_threshold 斜面滑动阈值：θc = arctan(μs)

**引擎第一个带接触的案例**（决策0050）。它同时是`cases/README.md`第一节之二
那张表里**第一条既走完`state`→`energies`→`solve`整条路、又不是梁**的案例。

判据值的正本是同目录的`oracle.json`（本页只解释，不重复声明）。

## 一、物理/几何设定

单质点静置于倾角``θ``的斜面上，库仑摩擦系数``μs``。

| 项 | 取值 |
|---|---|
| 质量 | 2.0 kg |
| 重力 | 9810 mm/s²（沿``−z``） |
| 摩擦系数``μs`` | 0.30 |
| 面法向``n`` | ``(sin θ, 0, cos θ)``，单位矢量；面过原点 |
| 下坡切向``d`` | ``(cos θ, 0, −sin θ)``，与``n``正交 |
| 法向罚刚度``k_n`` | 5.0×10⁴ N/mm |
| 切向粘着刚度``k_t`` | 3.0×10⁴ N/mm |
| 自由度 | 节点三个分量**全部放开**（不是只放开一个方向） |
| 分解判据扫的倾角 | 5°、10°、16.699244°、25°、40° |
| 阈值两侧偏移 | ±1×10⁻⁴°、±1×10⁻⁷° |

**"三个自由度全部放开"是这份设定里最要紧的一行。** 起草本案例时先试过
"只放开``z``"，实测法向力给出``W/cos θ``而不是``W·cos θ``——
差的正是``1/cos²θ``。原因不是接触项错了，是**把节点约束在竖直线上就不再是
斜面问题**。它同时暴露了当时缺的那一块：切向没有刚度，所以不能放开。
**粘着弹簧就是那块缺的刚度**，而它在物理上本来就该在（见第二节）。

## 二、参考解出处

沿面法向与切向分解重力（任一本静力学教材；同行出处见research/05第2.3节
C档接触族第8条，判据来自Chrono与Drake）：

    N = W·cos θ      T = W·sin θ      W = m·g

粘住条件即切向驱动力不超过摩擦锥``T ≤ μs·N``：

    W·sin θ ≤ μs·W·cos θ   ⟺   tan θ ≤ μs   ⟺   θ ≤ θc = arctan(μs)

**θc与质量、重力加速度、两个罚刚度全部无关**——``W``两边约掉、``k``在平衡条件
``k·δ = 力``里约掉。这是本案例判据强度的来源：**它是一个定性翻转的阈值，
不是一个能靠调参凑近的数值**。

金标生成器`generate_oracle.py`只写这两条闭式，**不调`solve_equilibrium`、
不调任何接触项**。

### 模型与理论的分界：粘着是势能，滑移不是

决策0050第二节裁的"接触是**半个能量项**"在本案例第一次有了具体形状：

- **法向**（`PenaltyNormalContact`）与**粘着**（`TangentialStickSpring`）是能量项，
  进`EnergyRegistry`、进牛顿的切线刚度；
- **滑移**（`coulomb_return_map`）不是——库仑摩擦耗散、非associative，
  写不成任何位置的势函数。

这条分界不是实现选择，是0033调研的结论：带粘着的库仑摩擦把切向位移
**分解成可逆的"粘"与不可逆的"滑"**，与塑性力学同构。

## 三、判据表

| 量 | rel | abs | 理由 |
|---|---|---|---|
| ``θc``（度） | 1e-12 | 0 | ``arctan(μs)``是闭式值，本仓只做一次``atan``与一次弧度转角度；1e-12是两次浮点运算的余量，**不是给实现留的空间** |
| 阈值下方粘住 | 0 | 0 | **定性判据零容差**。布尔量没有"差不多" |
| 阈值上方滑动 | 0 | 0 | 同上，反向。**两侧都断言才叫阈值**——只断一侧的话，一个"永远粘住"的实现能过一半 |
| ``N``（5档倾角） | 4e-16 | 0 | 罚函数模型的**法向力是精确的**：平衡时``k·δ = N``，``k``被约掉。实测五档偏差≤2.2e-16（1 ulp），取4e-16≈2 ulp |
| ``T``（5档倾角） | 4e-16 | 0 | 粘着弹簧同构：``k_t·|Δ| = T``，与``k_t``无关。实测≤3.3e-16 |

**位置不在判据表里**，这是刻意的：罚函数的穿透``δ = N/k``是**模型自带的**，
不是误差。本案例判力与阈值，**不判位置**——判位置等于把模型参数当成物理。

## 四、已知失效清单

每条一行理由，**禁止静默skip**。

1. **摩擦不在牛顿迭代内。** 本案例先解法向与粘着的平衡（`solve_equilibrium`），
   再拿解出来的``N``与``T``过一次return-map判粘/滑。
   **这不是完整的摩擦求解器**——活动集在迭代中翻转的情形（滑移改变锚点、
   锚点改变切向力、切向力再影响活动集）本案例碰不到，因为它是**静置**问题：
   阈值下方锚点不动，阈值上方本来就没有静平衡。**下一片才做迭代内的摩擦。**
2. **阈值上方不给运动。** ``θ > θc``时块会加速下滑，那是瞬态问题，
   要隐式积分族——本仓一个都没有。本案例在阈值上方只断言"判别为滑"，
   **不声称能算它滑多快**。
3. **无滑滚球（C档第8条的后半）不做。** 它要转动自由度参与接触，
   而`rigidbody`的姿态与接触今天没有接缝。
4. **分离态起步会奇异。** 节点悬在面上方时法向项对切线刚度零贡献，牛顿迈不出第一步
   （`tests/test_contact_normal.py`有正向的门钉着）。本案例的初值**刻意压在面内**。
5. **单点接触。** 真实的块是有面的，多点接触的分布本案例不涉及；
   槽位形制支持多点（`max_points`），但窄相今天只有球/胶囊族。
6. **静摩擦与动摩擦不分。** 本案例只有一个``μs``。两者分开要在return-map里
   按滑移速率切换，而速率是瞬态量。

## 五、档位与负载级

- **清单身份**：`case/incline_slide_threshold`；
- **档位**：C档（research/05第2.3节的"需要真求解器"那批；本案例走完
  `state`→`energies`→`solve`并新增两个能量项）；
- **负载级**：交互级（`interactive`，与`oracle.json`的`load_tier`一致）。
  九次求解各自1—3步牛顿，实测总耗时在毫秒量级。

## 六、本案例不是什么

- **不是摩擦求解器的验收**。它验的是"分解、摩擦锥、阈值"三件事在静置问题上
  是否与理论一致，**不验迭代内的活动集策略**（那还不存在）。
- **不是罚函数刚度的标定**。两个``k``是**声明的输入**；判据刻意选了与``k``无关的量，
  **换一组``k``判据必须照样过**——这一条本身就是一道门。
- **不是C档第8条的完整兑现**。第8条含无滑滚球，本案例只做滑动阈值那一半，
  故`cases/README.md`的分母按**半条**记，不按一条记。
- **不是三维块的接触**。它是单质点对半空间，没有翻倒、没有面接触、没有力矩平衡。
