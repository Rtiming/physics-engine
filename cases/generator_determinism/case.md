# generator_determinism 参数化生成器：确定性、齐次性，与"产的形是真形"

`case/generator_determinism`。A档，spec/11规则2**第二类**（参数化生成器）。
**这是引擎第一次有真实的"参数→形状"纯函数**——在此之前`modelgen`只有一个引用壳
（`shapes.GeneratedShape`有身份与参数元组，却没有任何一个生成器）。

被验内核：`src/physics_engine/modelgen.py`的三个生成器
（带盘`generate_spool`、导轮`generate_roller`、骨架`generate_former`），
外加`geometry.mass_properties`——第三条判据是**跨模块**的：
它拿另一个模块的解析质量属性去对一个教材闭式解，回答"生成器产的形是不是真形"。

## 一、物理/几何设定

三次生成器调用。**除`characteristic_length_mm`外全部入参是无量纲比值**
（case2 `src/robot_links.py`§J1的形制：一切长度来自特征长度，生成器不写毫米字面量）。
参数刻意取二进制精确值（2的幂之和），于是"比值×L"这一步无舍入。

### 1.1 带盘 spool（3件：`barrel` + `flange_low` + `flange_high`）

| 量 | 值 | 推出的毫米尺寸 |
|---|---|---|
| `characteristic_length_mm` | 256.0 mm | — |
| `barrel_radius_ratio` | 0.25 | 空盘筒半径 64.0 mm |
| `barrel_width_ratio` | 0.375 | 筒全宽 W = 96.0 mm（半宽48.0） |
| `flange_outer_radius_ratio` | 0.4375 | 法兰外半径 R_f = 112.0 mm |
| `flange_width_ratio` | 0.0625 | 单片法兰厚 w = 16.0 mm（半宽8.0） |
| `wound_layers` | 8 | — |
| `layer_thickness_ratio` | 0.001953125（=1/512） | 单层厚 0.5 mm |
| 绕满后筒半径 | (0.25+8×0.001953125)×256 | R_eff = 68.0 mm |
| 法兰盘心轴向偏移 | W/2 + w/2 | d = ±56.0 mm |
| 密度 | 7850.0 kg/m³ | 通用碳钢名义值，**是输入不是被验量** |

**法兰是两件独立的形**，不是`FiniteCylinder.flange_outer_radius_mm`——
理由见第二节与`docs/decisions/0032`。三件的轴向区间互不重叠
（筒占`|z|≤48`，两片盘占`48≤|z|≤64`），所以体积可直接相加。

### 1.2 导轮 roller（1件：`face`）

`characteristic_length_mm` = 128.0 mm、`radius_ratio` = 0.375（R = 48.0 mm）、
`face_width_ratio` = 0.125（面全宽 16.0 mm，半宽 8.0 mm）。密度同上。
形制取自WDS `dynamic/cylinder_contact.py::CylinderSurface`的参数面。

### 1.3 骨架 former（2件：`link_0` + `link_1`）

`characteristic_length_mm` = 512.0 mm；骨架点列（**无量纲比值**）
`(0,0,0)`、`(0.5,0,0)`、`(0.5,0.25,0)` → 毫米坐标`(0,0,0)`、`(256,0,0)`、`(256,128,0)`，
两段轴长 256.0 与 128.0 mm。`root_radius_ratio` = 0.0625、
`tip_radius_ratio` = 0.03125，锥度按段中点插值（t = 0.25 与 0.75）：

    r_0 = (0.0625 + (0.03125 − 0.0625)×0.25)×512 = 0.0546875×512 = 28.0 mm
    r_1 = (0.0625 + (0.03125 − 0.0625)×0.75)×512 = 0.0390625×512 = 20.0 mm

密度同上。

### 1.4 确定性与齐次性实验的设定

- **一位扰动**：每个入参各扰一位（浮点走`math.nextafter(v, +inf)`，
  `wound_layers`走`+1`，骨架点逐分量扰）。共 6+1（带盘）+3（导轮）+3+9（骨架）
  = **22条**。
- **跨进程**：以`PYTHONHASHSEED`分别为`"0"`与`"1"`起子进程，
  各自复现同一次调用并打印`declaration_sha256`。
- **齐次性**：`characteristic_length_mm`乘 **2.0**，比较产出中的每一个长度
  （偏移3个分量 + 形的半径/半宽/胶囊端点），共 15+5+20 = **40个**。

## 二、参考解出处

三类判据三个出处，**没有一处来自被验内核**：

1. **确定性/一位变化/齐次性**——关系型判据（"两次调用的字节相等"、
   "22条扰动全部改变声明"、"40个长度全部逐位翻倍"），布尔与计数，
   由`generate_oracle.py`直接写死。**刻意不冻结任何一份具体哈希**：
   声明指纹的形制不是已登记的面（`engine_facets.py`里没有它），
   把它的哈希冻进金标等于让一个未登记的字节形制长出依赖者。
2. **圆柱质量属性**——教科书闭式解：`V = πR²W`、`I_zz = ½mR²`、
   `I_xx = I_yy = m(3R²+W²)/12`（Beer & Johnston, *Vector Mechanics for
   Engineers*, 附录B"均质体的质量惯性矩"表；任一本刚体动力学教材同式）。
   装配合并走平行轴定理`I_P = I_cm + m(|d|²E − d⊗d)`。
3. **胶囊体积**——`V = πr²h + (4/3)πr³`（圆柱段+两个半球帽，初等几何）。
   胶囊的**惯量张量**本案例不给数值金标，只验两条普适律（见第四节）。

金标生成脚本入库：`cases/generator_determinism/generate_oracle.py`，
其SHA-256钉在`oracle.json`的`generator.sha256`字段（改了脚本不重跑，读侧当场红）。
生成脚本**不import`modelgen`也不import`geometry`**。

### 二之二、法兰怎么处理，为什么

spec/11第二之二节登记了一条缺口：`FiniteCylinder`声明了`flange_outer_radius_mm`
却**没有法兰的轴向尺寸**，于是"带法兰的圆柱"的体积与惯量不由声明决定，
`geometry.mass_properties`对它**失败关闭**。
**决策0034第四节已裁：本轮不动形状词汇，维持失败关闭**，并点名
"`modelgen`的带盘生成器按同一纪律处理"。

本案例的生成器按那条纪律办：**不改词汇，在生成器层用既有原语组合表达**——
筒一件、两片法兰盘各一件，全是既有的`FiniteCylinder`，
`flange_outer_radius_mm`恒为`None`。三条理由：

1. **组合表达不需要新词汇**。加字段那条要改spec/11规则2、还会让WDS导轮的既有
   声明形制变，是0034明确压住的；把一个形拆成三件既有原语则落在生成器里，
   词汇一个字没动，`shapes.py`与`geometry.py`也都没动。
2. **分解是精确的，不是近似**：真实带盘实体
   `{r≤R_b, |z|≤W/2+w} ∪ {r≤R_f, W/2≤|z|≤W/2+w}`
   与"筒(R_b,W) + 两片盘(R_f,w)贴在筒两端外侧"是**同一个点集**，三件互不重叠。
   不损失任何几何，只是把一个形拆成三件。
3. **不这么办，第三条判据就不可达**：带法兰的圆柱在`geometry`那头永远算不出质量属性，
   "生成器产的形是真形"这条独立判据会从"红"退化成"不可达"——那比红更坏。
   `oracle:modelgen/spool_mass_properties`里的`any_flanged_cylinder_produced: False`
   就是这条纪律的门。

0034的触发条件（WDS碰撞预演批次或case2给出带法兰导轮的书面需求）真到来时，
本案例是"独立第二个形"那条候选修法的一份**可用实现与一条精确分解的证明**，
是那场裁决的材料，不是对它的抢先。

法兰的两个尺寸不是本仓发明的：WDS的`CylinderSurface`给法兰**两个**尺寸——
`flange_channel_width_mm`（两壁内侧面的轴向间距）与`flange_height_mm`
（壁高出接触面的径向高度）。本案例的`barrel_width_ratio`就是前者、
`flange_outer_radius_ratio − barrel_radius_ratio`就是后者。
**"法兰没有轴向尺寸"是引擎侧的缺口，不是消费方侧的。**

## 三、判据表

| 量 | rel | abs | 理由 |
|---|---|---|---|
| `repeat_calls_identical` | 0 | 0 | 同进程两次调用的`declaration_bytes`逐字节相等。纯函数的最低门 |
| `cross_process_identical` | 0 | 0 | 换`PYTHONHASHSEED`起两个子进程，SHA与本进程相同。**进程内比两次抓不到集合/字典哈希序**——同一进程里种子是同一个，两次会一起错；跨种子子进程是唯一抓得到它的口径 |
| `negative_zero_normalised` | 0 | 0 | 骨架坐标写`-0.0`与写`0.0`产同一份字节。`-0.0 == 0.0`为真而`json.dumps`给`"-0.0"`与`"0.0"`——真实隐患不是理论顾虑 |
| `perturbation_count` | 0 | 0 | **防判据变空**：扰动条数（22）冻进金标，少扰几条时"全部改变"会自动成立 |
| `perturbations_changing_declaration` | 0 | 0 | 22条一位扰动全部改变声明字节。与上一个数相等才算通过；两数分开写是为了红时能一眼分辨"漏扰"与"扰了没变" |
| `absorbed_perturbation_labels` | 0 | 0 | 只改参数表、不改形几何的扰动**名单**（不是个数）。名单变长意味着有参数不再影响几何，是参数面该重审的信号 |
| `compared_length_count` | 0 | 0 | 同样防判据变空：参与齐次性比较的长度个数（40） |
| `lengths_scaling_exactly` | 0 | 0 | L乘2后每个长度**逐位**等于2倍。零容差是算出来的：2的幂缩放在IEEE-754下无舍入（尾数不变、指数加1），所以这是位判据不是数值判据。**任何写死的毫米量当场破它** |
| `part_ids`（三条） | 0 | 0 | 件名与件序逐字相等。带盘3件是"法兰走独立形"那条路的直接体现 |
| `any_flanged_cylinder_produced` | 0 | 0 | 产出的圆柱`flange_outer_radius_mm`恒为`None`（见第二之二节第3条） |
| `radius_mm` / `half_width_mm`（导轮） | 0 | 0 | `0.375×128 = 48.0`、`0.5×0.125×128 = 8.0`，二进制精确。全宽与半宽写在两处，把最容易差2倍的口径钉死 |
| `link_radii_mm` | 0 | 0 | 锥度插值的**手推值**28.0/20.0，两步都无舍入 |
| `link_centroids_mm` / `assembly_centroid_mm` | 0 | 0 | 胶囊质心在端点中点、带盘质心在原点。`(−56m)+(+56m)`在IEEE-754下精确为0（同幅反号相加无舍入） |
| `inertia_offdiag_max_kg_mm2`（三条） | 0 | 0 | 局部轴下惯量对角，`geometry._diagonal`写的是字面`0.0`；胶囊两段轴向是`(1,0,0)`与`(0,1,0)`，`Δ·n_i·n_j`含因子0。位判据 |
| `inertia_symmetric` | 0 | 0 | `I_ij = I_ji`。**普适律**，与胶囊闭式无关 |
| `inertia_triangle_inequality_holds` | 0 | 0 | 主矩三角不等式`I_i + I_j ≥ I_k`。任何真实质量分布必满足；本案例不独立验证胶囊惯量数值，这两条普适律是那个空缺处唯一诚实的判据 |
| 全部体积/质量/惯量对角元 | **1e-15** | 0 | 见下 |

**那条1e-15是算出来的，不是放宽到能过为止**（decisions/0024第三节先例）。
两条路径只差乘法结合次序：`geometry.mass_properties`先算体积、
再用`scale = m/V`把质量乘回形状矩；oracle直接把质量乘进闭式。
多出一次除法与一次乘法，误差界约`3×(eps/2) = 3.3e-16`。逐条实测：

| 量 | 实测相对偏差 |
|---|---|
| 筒 体积 / 质量 / I_zz | 1.67e-16 / 1.62e-16 / 1.44e-16 |
| 筒 I_xx = I_yy | **恰为0**（两边乘法次序碰巧一致） |
| 法兰 体积 / 质量 | **均恰为0** |
| 法兰 I_xx=I_yy / I_zz | 1.16e-16 / **2.34e-16（本案例最大值）** |
| 装配 体积 / 质量 / I_xx / I_zz | 0 / 1.70e-16 / 1.75e-16 / 1.67e-16 |
| 导轮 体积 / I_zz | **均恰为0** |
| 导轮 I_xx=I_yy | 2.09e-16 |
| 骨架 两段体积 | **均恰为0** |

1e-15 = 实测最大值的4.3倍、解析界的3倍。**收到2e-16实测即红**：带盘的
`assembly_inertia_diag_kg_mm2[2]`与导轮的`inertia_diag_kg_mm2[0]`同时破
（`check_all`按字母序比，带盘那边先报到装配那条）。实测输出见decisions/0032第四节。

## 四、已知失效清单

- **不独立验证胶囊惯量张量的数值**。`geometry._capsule_shape_mm5`按
  "圆柱段+两个半球帽"分解推导，在oracle里把同一个分解再写一遍不构成独立见证
  （共同的概念错误会一起过）。本案例因此只对胶囊验体积、质心，
  加两条与闭式无关的普适律（对称性、主矩三角不等式）。
  要真正独立地验它，得用数值体积分或同行库对拍，属`peer_*`轨道，不在本案例。
- **导轮不验轮缘圆角与凹套**。WDS `CylinderSurface`还有`edge_radius_mm`
  与`concave_depth_mm`/`concave_half_width_mm`，`shapes.FiniteCylinder`
  **没有对应字段**，所以生成器既不吃也不产。这不是"暂未支持"式的含糊：
  带这两样的导轮，本模块产不出忠实声明。词汇长出对应原语之前解不了封。
- **齐次性只测了λ=2一个点**。选它是因为2的幂缩放无舍入、判据可以是逐位的；
  λ取3或0.1时会有一两个ulp的偏差，需要另一条数值容差。逐位那条更强，
  先要它；有需要时再补一条数值档的。
- **确定性只在本机macOS/CPython实测**。跨解释器版本、跨平台（Windows/Linux）
  未复核。浮点`repr`的最短往返在CPython 3.1+是稳定的，但那是**引擎的假设**
  而不是本案例证过的事。
- **不验单位换算之外的物理**。密度7850 kg/m³只是把体积换成质量的输入，
  不是对任何真实零件的材料声明；本案例不检查它是否合适。
- **"绕满超出法兰"只验拒收，不验绕层的物理**。带盘半径随层数生长是
  WDS `WindingSurface`的形制搬迁，层厚随张力/带材变化的那部分不在本模块。

## 五、档位与负载级

A档，**interactive**（<1s）。实测：6条conformance测试共**0.15s**
（含两个子进程启动）；`tests/test_modelgen.py`的44条拒收/形制测试共**0.06s**。
`load_tier: interactive`，无pytest marker。

## 六、本案例不是什么

- **不是"引擎能生成机械模型了"的证据**。三个生成器各只产一到三件解析原语；
  case2那个骨架驱动壳体是build123d的B-Rep实体、上千行系数，本模块产的是它的
  **胶囊链最小版**，两者不在一个量级。
- **不是"声明指纹是一个面"**。`declaration_bytes`只是进程内的比较基准，
  不落盘、不跨边界、不进`engine_facets.py`。哪天它要被消费方读或写进文件，
  必须先进面清册——那时本案例的判据也要跟着重写（现在的判据刻意只比关系，
  不冻结字节，正是为了那一天不必推翻金标）。
- **不是碰撞形的正确性**。本案例不声明任何`CollisionShape`，
  也不碰保守方向（envelope/fitted，spec/11规则5）——生成器产的是形，
  用它做包络还是贴合是调用方的声明。
- **不是"参数化生成器规范可以冻结"**。spec/11整页仍是草案；本案例是它规则2
  第二类的**首个**实现，一个消费方都还没采纳（进仓门的消费方位由本仓案例暂代）。
- **不是性能证据**。三个生成器都是几十次浮点乘法，没有做过任何profile，
  也没有进`tests/perf`的预算表。
