# two_beam_interference 双光束干涉：一条余弦定律，两种光程差机制

`case/two_beam_interference`。B档，spec/15（光学域）+ `optics/interference.py`（决策0044）。
**引擎第一次算干涉。** 判据分四层，每层的失效原因互不重叠：
定律本身、条纹几何、**能量守恒**、高条纹级次与FTS的桥。

## 一、物理/几何设定

双光束叠加强度 `I(Δφ) = I1 + I2 + 2·√(I1·I2)·|γ|·cos(Δφ)`，
`|γ|`是复相干度的模。可见度 `V = (Imax−Imin)/(Imax+Imin) = 2√(I1I2)|γ|/(I1+I2)`。

| 量 | 值 |
|---|---|
| 波长λ | 632.8e-9 m（HeNe，**与`scalar_diffraction_airy`同一条谱线**） |
| 主强度对 | I1=3.0、I2=0.75（比4:1，`V`=0.8） |
| 等强对 | I1=I2=2.0（**不取1.0**，见第三节必须红第一条） |
| 部分相干 | \|γ\|=0.4；另有\|γ\|=0（非相干）与\|γ\|=1（完全相干） |
| 极不等强对 | I1=1.0、I2=1e-12（`V`=2e-6，放大因子`1/V`=5e5） |
| 近等强对 | I1=1.0、I2=1+1e-7（暗纹相消，放大因子2.0e7） |
| 负强度标本 | I1=6.887858857269796、I2=6.887858857237471（朴素式返回−1.78e-15） |
| 相位取样 | 0、π/3、π/2、2π/3、π、4π/3、3π/2、2π（8点） |
| 双缝缝间距d | 0.25e-3 m |
| 屏距L | 1.20 m |
| 条纹间距Δx | λL/d = 3.0374399999999998e-3 m |
| 屏上取样x/Δx | 0、0.25、0.5、1、1.5、5（6点） |
| 傍轴偏差取样x/Δx | 0.25、1、5、**40**（最后一点故意不傍轴，x/L≈0.10） |
| 平均取样点数 | 720（整周期） |
| 迈克尔逊动镜位移 | 5.0e-3 m → 光程差10 mm → **条纹级次15802.78** |
| FTS最大光程差L | 0.05 m（单边），ILS首零1/(2L)=10 周/米 |

## 二、参考解出处

Born & Wolf《Principles of Optics》第7.2节（双光束干涉与可见度，
式7.2.13的`V = 2√(I1I2)/(I1+I2)`）与第10.3节（部分相干，等强时`V = |γ|`）；
Hecht《Optics》第9.3节（杨氏双缝`Δx = λL/d`）与第9.4节（迈克尔逊`OPD = 2d`）。

**生成器走三条与被验实现不同的路**（`generate_oracle.py`，SHA钉在清单里）：

1. **相位精确约化**：`OPD/λ`用`Fraction`在有理数上精确算（两个float64本来就是
   精确有理数），取小数部分再乘2π。内核走`(2π/λ)·OPD`，相位误差随条纹级次线性
   增长——**这个差正是第四层要量的东西**；
2. **余弦用`Decimal`的Taylor级数（60位）**，不调libm。金标因此不继承平台实现；
3. **精确光程差按定义式**`√A − √B`在60位上直接相减（丢10位仍剩50位），
   而内核走恒等变形`2xd/(√A+√B)`——两条不同的代数路。

第一亮纹的位置由生成器**二分它自己的精确光程差**求出（200次），不用任何闭式；
测量侧在float64上二分内核的精确光程差。生成器不import `physics_engine.optics`。

## 四、已知失效清单

- **调用点的角度单位无人守**。上一节末尾那条：传进来的度数就是一个有限浮点数，
  本模块无从判别。唯一的防线是参数名带`_rad`。**这是本轨道唯一一条没有门的错法。**
- **两束光强度的单位一致性无人守**。I1按W/m²、I2按mW/m²传进来不会报错，
  与上一条同类（跨调用点的单位约定）。
- **不做`arg(γ)`**。本模块只吃复相干度的**模**。`arg(γ)`会整体平移条纹图样，
  它要么由光源谱经Wiener-Khinchin算出（那是傅里叶变换，0031已声明为下一块），
  要么由消费方测量后传入——今天没有消费方需要。准单色、谱型对称时`arg(γ) = 0`，
  本案例覆盖的正是这一档。
- **`|γ|`是申报输入不是算出来的**。本案例验的是"给定`|γ|`，公式是否照定义用它"，
  **不验"这束光的`|γ|`到底是多少"**——后者要谱与相干时间，不在本块。
- **暗纹的相对精度在`I1 ≈ I2`时天然受限**。放大因子`√I2/|√I1−√I2|`：
  1+1e-7那对是2.0e7（内核剩9位有效数字），负强度标本那对是4.3e11（只剩4位）。
  不相消的写法把误差从"相对6.6%"降到"相对1.15e-9"，**但降不到eps**。
- **傍轴偏差的实测值在近轴处判别力受限**。`1/dev`放大因子在x=0.25Δx处是4.86e6，
  容差因此只能压到rel 2e-9。更近轴的取样点会更松——**这是判据的边界不是实现的**。
- **只验双光束**。多光束（法布里-珀罗的`1/(1+F·sin²)`）不在本案例。
- **只验干涉因子，不验衍射包络**。真实双缝图样是干涉因子乘单缝衍射因子，
  本案例只有前者。
- **不验偏振**。两束正交偏振不干涉（Fresnel-Arago），本案例默认同偏振态。
- **迈克尔逊只验一个动镜位置**。没有扫描、没有干涉图、没有变换——那是下一块。
- **`michelson_phase_rad`的容差已到该值的2.3 ulp**，这个量级上再收紧没有意义；
  相位判别力止步于`2.1e-15 × 条纹级次`。
- 未在Windows/Linux复核。

## 六、本案例不是什么

- **不是"引擎能做干涉了"的证据**。它算的是两束标量光的闭式叠加，
  没有场、没有传播、没有孔径。
- **不是衍射**。双缝的衍射包络不在这里；`scalar_diffraction_airy`才是衍射那一侧，
  而它也只有一维闭式。
- **不是相干性理论**。`|γ|`是输入不是输出；从光源谱算相干度要傅里叶变换。
- **不是FTS**。本案例与`fts_instrument_line_shape`只在一条判据上握手
  （ILS首零=整个扫描程上滑过一个整条纹），**不复算ILS、不做任何变换**。
- **不是干涉仪仿真**。没有分束比、没有镜面误差、没有光源尺寸、没有自切趾。
- **不计入决策0040的成功标准分母**。0040把分母定为research/05第2.3节的
  C档13条同行标准案例，光学族那四条是艾里斑、FTS半宽、Norton-Beer系数和、
  变换层自洽三件套——**双光束干涉不在其中**。本案例验的是一项新能力，
