# mie_sphere_scattering 均匀球的Mie散射：**严格级数解，不是近似**

`case/mie_sphere_scattering`。C档，spec/15（光学域）+ `optics/mie.py` +
`optics/spherical_bessel.py`（决策0091）。

**全仓第一条散射案例。** 能力位S4.7的`why`原文写着plans/05对场景④的判词是
"**散射零**"——本案例补那个零。此前光学域有闭式衍射（`scalar_diffraction_airy`）、
有场传播（`double_slit_propagated`、`angular_spectrum_propagation`），
**一条散射都没有**。

Mie解是Maxwell方程组对**均匀各向同性球**在平面波照明下的**严格解**：
不是小球近似、不是几何光学近似、不是任何一种微扰。
数值上唯一的近似是级数在第`n_max`阶截断，而那一条在引擎侧**显式声明并失败关闭**。

**四条oracle的金标来路各不相同**，这是本案例分辨力的来源：

| oracle | 金标从哪来 | 与被验实现共用什么 |
|---|---|---|
| 逐阶系数与两条效率 | **50位十进制的独立实现** | 只有"Mie系数是什么"这条定义 |
| 幺正性与能量守恒 | **解析的0**（无损球的幺正性） | 什么都不共用 |
| 小球极限 | 一半50位参照、一半**静电偶极子**闭式 | 无 |
| 大球极限 | **解析标度律**`2^(−2/3)` | 无 |

## 一、物理/几何设定

标量参数化的电磁严格解。三个构型：

### 构型甲｜无吸收球（主构型）

| 量 | 值 |
|---|---|
| 尺度参数x = 2πa/λ | 5.213（**吃的是半径不是直径**） |
| 折射率m | 1.55 + 0i（**无吸收**，玻璃量级） |
| 截断阶n_max | 15（Wiscombe判据`ceil(x + 4x^⅓ + 2)`） |
| 内部宗量mx | 8.08015 |
| 时间约定 | `exp(−iωt)`，于是吸收对应`Im m ≥ 0`（引擎侧`MIE_TIME_CONVENTION`） |

**为什么冻的是无吸收球**：`m`实 ⟹ `mx`实 ⟹ 高精度参照那一侧全部是实数运算，
`Decimal`直接能做（Python的`Decimal`没有复数）。系数`a_n`/`b_n`仍然是复的
（`ξ_n = ψ_n − iχ_n`），但那一步只是"实数除以复数"，两个分量手写十行就够，
**不需要一整套复数十进制算术**。有吸收那一侧由构型丙与瑞利吸收闭式去盖，
它们的金标都是解析的、不需要高精度参照。

**x与m都不特殊**：选5.213与1.55只是为了**不是**一个会让某一阶恰好为零的
巧合构型——那种构型会让判据看起来比实际更强。

### 构型乙｜小球极限（退化到瑞利）

| 量 | 值 |
|---|---|
| 折射率m | 1.5 + 0i |
| 尺度参数梯子 | 0.1 → 0.05 → 0.025（**逐档减半**） |
| Clausius-Mossotti因子`(m²−1)/(m²+2)` | 0.29411764705882354 |

梯子逐档减半，于是`O(x²)`的修正应当逐档掉到四分之一——
**"偏差小"是软判据，"偏差按x²掉"不是**。

### 构型丙｜大球极限（消光佯谬）

| 量 | 值 |
|---|---|
| 折射率m | 1.5 + 0.1i（**有吸收**） |
| 尺度参数梯子 | 50 → 100 → 200 → 400 → 800（**逐档翻倍**） |
| 最大截断阶 | 840（x=800） |

**用吸收球是有理由的**：吸收把共振ripple压掉，`Q_ext`才真的单调趋近2；
无吸收球在大`x`上振荡得很厉害，**那条曲线不适合用来验"趋近"**。
如实写在这里，不假装无吸收也单调。

## 二、参考解出处

Bohren & Huffman,《Absorption and Scattering of Light by Small Particles》
第4.4节（球矢量波函数展开与系数`a_n`/`b_n`，式4.53）、
第4.4.2节（效率因子，式4.61—4.62）、第5.1—5.2节（瑞利极限与Clausius-Mossotti因子）；
van de Hulst,《Light Scattering by Small Particles》第8章
（消光佯谬`Q_ext → 2`与边缘衍射的`x^(−2/3)`修正）；
Wiscombe 1980, Appl. Opt. 19, 1505（级数截断阶判据）。

**生成器走的是另一条算法**（脚本入库：`cases/mie_sphere_scattering/generate_oracle.py`，
SHA-256钉在`oracle.json`的`generator.sha256`字段）：

| | 被验实现（`float`） | 生成器（`Decimal`，50位） |
|---|---|---|
| `ψ_n(x)` | Miller**向下**递推 + 三角种子归一 | **上升级数**，无递推无锚点 |
| `D_n(mx)` | 连分式**向下**递推`D_{n−1} = n/z − 1/(D_n + n/z)` | `j_{n−1}(z)/j_n(z) − n/z`，**两阶直接相除** |
| `χ_n(x)` | 向上递推，种子来自libm的`sin`/`cos` | 向上递推，种子来自**自己的泰勒级数** |

**连libm都不共用。** 50位远超`float`的16位，所以参照本身的误差在这些判据里
不参与——0086第5.2节那条教训（判据自己的参照可能比被验对象更差）
在这里被这条位数直接消掉。

复数按决策0086的字节形制落盘：**一个复数是长度2的浮点数组，次序`(实部, 虚部)`**。

## 三、判据表

| 量 | rel | abs | 理由 |
|---|---|---|---|
| `coefficient_a_components`（15阶×2分量） | 0 | 4e-15 | 50位上升级数 对 `float`Miller向下递推，两侧连`sin`/`cos`都不共用。被验侧误差模型：`ψ`与`χ`各几个eps、`D_n`一条连分式、再一次复数除法，约`16 eps = 3.6e-15`。**实测最坏5.5511e-16，余量7.2倍**。判绝对不判相对：高阶系数的实部小到1e-20量级，那里的相对误差没有意义 |
| `coefficient_b_components`（15阶×2分量） | 0 | 4e-15 | 同上。`b_n`与`a_n`只差分子分母里那个公共因子（`m·D_n`对`D_n/m`），走同一条数值路径 |
| `extinction_efficiency` | 0 | 8e-15 | `Q_ext = (2/x²)Σ(2n+1)Re(a_n+b_n)`，15项累加，容差取系数那条的2倍。**实测1.3323e-15，余量6.0倍**。金标`3.1049959150801856` |
| `scattering_efficiency` | 0 | 8e-15 | `Q_sca = (2/x²)Σ(2n+1)(|a_n|²+|b_n|²)`。**它与上一行是两条不同的式子**——一条取实部、一条取模平方——所以下一行的"两者相等"是真判据 |
| `extinction_minus_scattering` | 0 | 8e-15 | **无吸收 ⟹ 消光恰等于散射**。只有系数落在幺正圆上时才成立，不是恒等变形。**实测恰为`0.0`**。**注意`Q_abs`按定义就是这个差，所以"消光=散射+吸收"本身不是判据**，本页不假装它是 |
| `unitarity_max_residual` | 0 | 1e-14 | **逐阶**`| |a_n|² − Re(a_n) |`，比上一行更硬：上一行是两条求和相等，可以靠不同阶的误差互相抵消而蒙混，逐阶看抵消不掉。**实测最坏1.1102e-16，余量90倍**（50位参照侧是2.0e-50） |
| `scattering_efficiency`（小球三档） | 4e-14 | 0 | 严格级数在x=0.1/0.05/0.025上的`Q_sca`，50位参照。**这一行判相对不判绝对**：三个数从2.3e-5降到9.0e-8，绝对容差会让最小的那一档形同虚设。**实测最坏相对偏差1.5543e-15，余量26倍** |
| `rayleigh_closed_form_efficiency`（三档） | 4e-15 | 0 | 瑞利闭式本身。只有一次乘方与一次模平方，**实测最坏2.2204e-16（1 eps）**，容差取18 eps。**它冻在这里是因为"退化到瑞利"这条门有两半**：一半是严格级数算对了，另一半是闭式本身算对了 |
| `relative_departure`（三档） | 0 | 2e-14 | 两者之比减一，即**严格解比瑞利多出来的那一项**：6.9546e-4 → 1.7582e-4 → 4.4077e-5，逐档掉到约四分之一（x减半、修正是`O(x²)`）。**冻住它等于冻住"这条极限是怎么收敛的"而不只是"它收敛了"**。实测最坏1.4082e-15，余量14倍 |
| `extinction_gap_ratio`（4个比值） | 0 | 1e-2 | **解析标度律**`2^(−2/3) = 0.629961`。实测0.634430／0.634339／0.633527／0.632662，**从上方单调趋近**，最大偏离4.4695e-3（余量2.2倍）。**"接近2"是软判据**（任何缓慢下降的曲线都满足），"按`x^(−2/3)`接近2"不是——本行判的是**指数** |
| `extinction_at_largest_size` | 0 | 3e-2 | x=800处的`Q_ext`对2。实测`2.022837075358014`，差2.2837e-2（余量1.3倍）。**容差不是收敛误差是物理**：有限x上`Q_ext`本来就不等于2，差的正是那条`x^(−2/3)`修正，所以容差必须比它大一点点而不是更多——写松了这条门就只是在断"Q_ext是个O(1)的数" |

**必须红（实测）**：

- **Bohren & Huffman那条`+15`起点规则**（`n_start = max(n_max, ceil|mx|) + 15`）。
  这是本轨抓到的**真缺陷，而且它在教科书算法里**：x=500、m=1.33（无吸收）上
  它给`Q_ext = 2.031189119014`，收敛值是`2.030373894631`——**相对差4.0e-4**，
  对一个自称"严格级数解"的实现来说这不是舍入而是错，**一个字都不报**。
  x=50、m=1.5上同样形态是6.7e-8。必红在
  `tests/test_optics_mie.py::test_must_be_red_the_textbook_plus_fifteen_start_rule_is_not_enough`。
- **`BHMIE`那条`ψ_n`向上递推**。`j_n`是它的极小解。对50位参照实测相对误差：
  x=1e-3时n=1→1.134e-10、n=2→1.700e-3、**n=3→5.952e+04**（答案比真值大六万倍），
  而n=3恰是`mie_max_order(1e-3)`。必红在
  `tests/test_optics_spherical_bessel.py::test_must_be_red_the_textbook_upward_recurrence_loses_the_small_argument`。
- **级数截到第2阶的x=20**：末项占比远超申报，引擎**当场炸**
  （`tests/test_optics_mie.py::test_a_series_truncated_too_early_fails_closed`）。
- **时间约定翻了**（`Im m < 0`）：引擎失败关闭并在报错里点名约定，
  而不是让一个"发光的球"静静地算下去。
- **有吸收球的幺正性**：`mie_unitarity_residual`对复折射率**拒答**——
  有吸收时`|a_n|² < Re(a_n)`，那个差正是被吸收掉的部分，**不是残差**。
  必红实测那个差是`O(0.1)`不是噪声。
- **把消光当成"挡住的几何截面"会给1不是2**（`Q_ext → 2`就是消光佯谬本身）。
- **`|Q_ext − 2|`的方向**：清单那条判的是相邻比值落在`2^(−2/3)`附近，
  **一条整体上升但比值恰好也是0.63的曲线在那条判据上照样绿**（比值是正的，
  它不管方向）。本案例另有一条不靠清单的结构判据正面断单调下降。

## 四、已知失效清单

- **只验效率因子，不验角分布**。散射相函数`S_1(θ)`/`S_2(θ)`、
  不对称因子`g`、后向散射效率`Q_back`**一个都不在本案例，引擎侧也没有实现**。
  它们要连带Legendre函数`π_n`/`τ_n`那一层，是另一块。
- **只验均匀各向同性球**。核壳球、椭球、团簇、粗糙表面、双折射球全部不在。
  "均匀"是Mie严格解成立的**前提**而不是本实现的限制。
- **只验一个无吸收构型的逐阶系数**。高精度参照那一侧要求`m`是实数
  （`Decimal`没有复数），所以有吸收球的逐阶系数**没有对过高精度参照**——
  它们由瑞利吸收闭式（小球端）与消光佯谬标度律（大球端）两头夹住，
  中间那一段**只有自洽门没有外部参照**。如实登记为GAP，触发条件写在决策0091第八节。
- **域外拒答而不是外推**：`x`只在`[1e-6, 1e3]`、`|m|`只在`(0, 10]`上测过。
  域外是"未测"不是"成立"，引擎侧对越界**失败关闭**。
- **截断判据是经验的**。`n_max = ceil(x + 4x^⅓ + 2)`是Wiscombe的经验判据，
  引擎另量末项占比并在超标时炸。那条"末项占比盖住截断误差"的关系
  是128个构型上**实测**的经验关系，**不是定理**——
  本轨的第一版判据只看末项，而末项**可以恰好落在近零点上**
  （实测x=50、m=1.5上末项占比2.065e-18而真正的截断误差6.2e-8）。
- **单阶球贝塞尔出口与整串出口不是逐位相同的**（Miller起点按`order_max`定），
  实测差最后一位。不是缺陷是递推的性质，但0001第三条那道字节门在，
  所以写进了`spherical_bessel.py`的docstring并有一条门正面断言。
- 未在Windows/Linux复核。

## 五、档位与负载级

C档，**interactive**（<1s），与`oracle.json`的`load_tier`逐字一致（`interactive`），
无pytest marker。

实测（本机，中位数）：conformance五条测试共**0.03 s**；生成器一次**0.05 s**。

**规模与墙钟的关系**（本机，**只报这个规模下是多少，不下任何跨机结论**——
plans/16的M8立的口径就是本机墙钟不作数）：

| 尺度参数x | 截断阶n_max | 一次`mie_efficiencies`（五次中位数） |
|---|---|---|
| 5.213 | 15 | 2.91e-5 s |
| 50 | 67 | 7.80e-5 s |
| 100 | 121 | 1.30e-4 s |
| 400 | 432 | 4.58e-4 s |
| 800 | 840 | 8.85e-4 s |
| 1000 | 1042 | 1.10e-3 s |

**它是`O(x)`的**：项数按`x`长，每项是常数次复数运算。
纯Python在申报上界`x = 1000`处仍是毫秒级，**所以本块没有加速档的理由**
（spec/13第一节"优化先profile"）。

## 六、本案例不是什么

- **不是"引擎能做散射了"的证据**。它算的是一个均匀球的三个效率因子，
  没有角分布、没有偏振、没有多球、没有近场。
- **不是米氏理论的完整实现**。角函数那一层（`π_n`/`τ_n`、`S_1`/`S_2`）
  一行都没有。
- **不是`scalar_diffraction_airy`或两条传播案例的替代**。
  那三条是**标量衍射**（Kirchhoff/角谱），本条是**矢量电磁的严格解**。
  两者在物理上不同层：标量衍射把光当成一个复标量场，
  Mie解的是完整的Maxwell边值问题。判据表里没有一个量是重的。
- **不是"1/λ⁴解释了天空为什么是蓝的"的完整论证**。本案例验的是
  `C_sca ∝ 1/λ⁴`这条标度律在严格级数上成立，
  大气分子的极化率、多次散射、偏振与太阳谱一个都没有。
- **不是性能证明**。第五节那张表是**本机单点**，按0018只判量级不立门。
- **不验非2幂、不验GPU、不验并行**——本块与那些无关。
