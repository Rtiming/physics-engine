# two_body_spring 两体弹簧：能量项协议的第一块搬迁与它的三层判据

`case/two_body_spring`。B档，spec/12第三节（能量项协议）与第6.1节（有限差分验不了物理）。
**T5搬迁轨第一块**——能量项四方法协议在引擎里第一次有实现。

## 一、物理/几何设定

两个自由质点，一根轴向弹簧连接，无重力、无接触、无约束。

| 量 | 值 |
|---|---|
| 质量 A / B | 0.3 / 0.5 kg |
| 静止长度 l0 | 10.0 mm |
| 轴向刚度 EA | 45.0 N |
| 初始伸长 δ | 0.05 mm |
| 积分器 / 每周期步数 | velocity Verlet / 20000 |
| 重力（另一条判据用） | −9806.65 mm/s² |

轴向刚度 `k = EA/l0 = 4.5 N/mm`；约化质量 `μ = m_A·m_B/(m_A+m_B) = 0.1875 kg`。

## 二、参考解出处

三条都是闭式，写在`generate_oracle.py`里，生成器不调被验内核：

- 拉伸能 `U = ½·(EA/l0)·δ²`（线弹性轴向单元，教科书）；
- 重力势能 `U = −m·g·y`；
- 两体振动角频率 `ω = sqrt(k/μ)`——**单位换算在这里露头**：`k`是N/mm、`μ`是kg，
  而`N/kg = m/s²`，状态是mm制，所以`k/μ`要乘1000才是`1/s²`。

## 三、判据表

| 量 | rel/abs | 理由 |
|---|---|---|
| `energy_nmm`（拉伸） | rel 2e-13 | oracle由δ直接算；**内核走另一条路**——先求`|x_j−x_i|`再减`l0`，`10.05−10.0`是相消，相对误差被放大约`L/δ=200`倍（eps 2.2e-16×200≈4.4e-14）。实测2.7e-14，留约七倍余量。**容差不是放宽到能过为止，是把两条路径的数值差异算出来** |
| `energy_nmm`（重力） | rel 1e-15 | `−m·g·y`，一次乘法一次除法 |
| `omega_per_s` | rel 1e-15 | `sqrt(k/μ·1000)`，闭式 |
| 整周期后伸长 | abs 1e-9 mm | 每周期20000步，实测偏差1.0e-13mm。**这一条是那个1000倍单位bug的捕手** |
| 半周期后伸长 | abs 1e-9 mm | 必须反相。只看整周期分不出「频率对」与「频率差整数倍」 |
| 质心漂移 | abs 1e-9 mm | 无外力则质心不动。它验的是「两端受力等大反向」，与频率对错**正交**；实测1.2e-14mm |

## 四、已知失效清单

- **只有两个节点、一条边**。装配的正确性（多边求和、索引散射）在这个规模上只被弱验证；
  真正的考验随多节点杆内核进来。
- **无重力参与振动判据**。重力项与拉伸项的耦合（下垂后频率变化）本案例不测。
- **δ/l0 = 0.5%，是小变形**。大变形下`k`不再是常数，本案例的闭式频率不成立。
- ~~**Hessian只在有限差分门里被验**~~ **已闭合（2026-08-05，决策0030）**：
  见[`cases/axial_stretch_hessian`](../axial_stretch_hessian/case.md)——
  金标走两条**精确有理算术**独立路径（`Fraction`二阶前向jet照定义求导 +
  手推闭式），两条逐位相等，生成器不import被验模块。
  那条案例还顺带把spec/12第6.1节做成了实验：同一个改错的静止长度，
  **有限差分全绿、解析金标红**。
- 未在Windows/Linux复核。

## 五、档位与负载级

B档，**interactive**（<1s）。实测：4条测试含两次20000步积分共0.42s。

## 六、本案例不是什么

- **不是"能量项协议已经验完了"的证据**。它验的是两个最简单的项；
  弯曲、扭转、接触摩擦一个都没有。
- **有限差分门不是物理判据**。本案例把这件事做成了活标本：写这一块时
  能量→加速度的接缝漏了mm与m的换算、加速度小了1000倍，而FD门**全绿**——
  因为换算因子不在能量里，FD看不见它。抓住它的是第三节的频率门。
  **两类门必须并存，任何一类都不能替代另一类。**
- **不是性能基准**。加速档尚未实现（本块纯Python），对拍义务随批量实现附着。
