# 张力闭环对线速度阶跃（`closed_loop_tension_step`）

决策[0070](../../docs/decisions/0070_张力闭环装配_控制器可插拔与两条时钟_20260817.md)，
守[plans/15](../../docs/plans/15_从这里到真机介入的分阶段计划_20260817.md)第三节阶段一的1.2与1.5。

`free_span_tension_step`证明了**扰动是真的**——一次10%的线速度阶跃让张力摆
1.05 N且12.08个周期不衰减。本案例把控制器接上去，回答**那个扰动压不压得住**。

答案取决于一个无量纲数：`ω_n·τ = 18.98`，**执行器比对象慢19倍**。

## 一、物理/几何设定

### 1.1 被控对象（**逐条与`free_span_tension_step`同一个数**）

带材轴向刚度：`axial_stiffness_n = 60000.0 N`（4 mm宽×0.1 mm厚、E≈150 GPa，**假设输入**）
自由跨几何长度：`geometric_length_mm = 300.0 mm`（**假设输入**，实际长度没有实测）
放线盘半径：`radius_mm = 60.0 mm`（**假设输入**）
放线盘转动惯量：`inertia_kg_mm2 = 5000.0 kg·mm²`（**假设输入**，满卷/空卷差几倍）
轴承粘性阻力矩：`bearing_damping_nmm_s = 50.0 N·mm/(rad/s)`（**假设输入**，本模型唯一的阻尼通道）
稳态制动力矩：`brake_torque_nmm = 1200.0 N·mm`（给`T = M/R = 20 N`，落在真机张力区间10—30 N中段）
线速度：`line_speed_mm_s = 20.0 mm/s`（**假设输入**）
阶跃幅度：`step_mm_s = 2.0 mm/s`（10%，与`free_span_tension_step`同一次阶跃）

导出的工作点：设定张力`20.27777777777778 N`、跨段刚度`200.13520802897804 N/mm`、
`ω_n = 379.6015671475346 rad/s`（60.41547 Hz）、`ζ = 0.013171705368794534`。

### 1.2 执行链

电流-扭矩增益：`torque_per_ampere_nmm = 23256.0 N·mm/A`（POC-050基型样本外推，**L后缀参数厂家资料没有**）
额定扭矩：`rated_torque_nmm = 50000.0 N·mm`
磁滞时滞：**两档**——
　`lag_s = 0.05 s`（`nominal`档，POC-050L的假设值，`tests/test_drives.py`一直用它）
　`lag_s = 0.0005 s`（`fast`档，**一次数值实验，不是一台机器**——见第六节）
前馈电流：`M₀/k_M = 0.05159958720330237 A`（由稳态制动力矩反解）

### 1.3 控制器与两条时钟

推进步长：`plant_dt_s = 1e-6 s`（阶跃判据）／`1e-5 s`（稳态与稳定界判据）
控制周期：`control_decimation × plant_dt_s`，抽取比逐档给
增益（`fast`档，由`ω_目标 = 2ω_n`、`ζ_目标 = 0.7`、`Ki = 0.3×Routh界`反解）：
　`proportional = 0.007739938080495356 A/N`
　`integral_gain = 2.3909045882870474 A/(N·s)`
　`derivative = 1.7561293801847282e-05 A·s/N`
增益（`nominal`档）：`proportional = 0`、`integral_gain = 1.2443872530174083`、`derivative = 0`
　——**这一档只能纯积分**：把`fast`那套设计放上去时Routh第一列是`−16525.92`，
　负的，**任何正的积分增益都不稳**。

### 1.4 绞盘（1.5那一条）

摩擦系数：`friction_coefficient = 0.3`（plans/13第六节，**假设输入**）
包角：`wrap_angle_rad = π/2`（90°）
传感器位置声明：`sensor_on_tight_side = False`（传感器在跨段＝松弛端，落位点在导轮下游＝张紧端）

## 二、参考解出处

**②无闭式解——生成脚本入库**：`cases/closed_loop_tension_step/generate_oracle.py`，
SHA-256钉在`oracle.json`的`generator.sha256`字段。

严格说金标是**闭式结构＋机器精度求根**：线性化后的闭环是一个四阶系统，
特征多项式的五个系数是手推的（生成脚本docstring第二节给出消元全过程），
时域解是精确的留数展开

    δT(t) = Δv·K·Σᵢ [ (τrᵢ² + (1+dτ)rᵢ + d) / D'(rᵢ) ] · e^{rᵢt}

**只有"求`D`的根"这一步是数值的**，用Durand-Kerner做到机器精度（收敛判据1e-16相对）。
本仓已有先例：`euler_buckling`的临界载荷同样是特征方程求根而非抄表。

生成脚本**不import被验的任何模块**（`tension_control`/`drives`/`transport`一个都没有），
只import`math`、`cmath`与清单写入器`physics_engine.oracles`。

**跨案例对拍**：开环那一档必须重现`free_span_tension_step`独立算出来的峰值。
实测差**4.60e-7**相对，而差在哪里查得出来——两条案例的线性化参考点不同
（`free_span`取阶跃后`v = 22`，本案例取阶跃前`v = 20`），推算给4.63e-7，
**与实测对上**。有一条门判这个差落在`(1e-8, 1e-6)`：大了说明两条案例开始各说各的，
小了说明有人把两条闭式接成了同一条路。

## 四、已知失效清单

1. **`fast`档的`τ = 0.5 ms`不是一台机器**。磁粉离合器的磁滞响应在几十毫秒量级，
   0.5 ms比任何一台都快。这一档存在的唯一理由是**把"环写错了"与"执行器太慢了"分开**：
   没有它，"压不下去"这个结论分不清是哪一种。**它的数不许被当成真机性能引用。**
2. **本案例没有证明真机能压住跨段谐振——它证明的是压不住**。`nominal`档
   （τ = 50 ms、纯积分）实测峰值×1.0727、ISE×1.3882，**两个数都大于1**。
   真机上这条谐振是靠摆杆/储带机构（dancer）压下去的，**而本仓没有摆杆模型**。
   已登记进`docs/plans/07`第六节。
3. **额定档上不是"所有增益都没用"，是"这套设计没有可行域"**。扫描实测：
   纯积分在`0.1×界`处给峰值×0.99841（压了0.16%）；把`Kd`加到设计值的100倍
   （`9.5e-4 A·s/N`）能给×0.3449——**但那是在理想传感器、1 MHz控制率、
   无量化噪声下**。真机12位ADC的台阶是0.012 N，1 ms周期上微分项的量化噪声是
   12 N/s量级，乘那个`Kd`就是11 A的抖动指令。**本轮没有建噪声通道，
   所以"大`Kd`能不能用"这个问题本案例回答不了**，已登记。
4. **闭环的时间步收敛阶本轮没有量清楚**。实测（`fast`档、`t = 0.01 s`、
   `dt`逐次减半）：`Δv = 2`给比值2.4635/2.5472/3.2604、`Δv = 0.2`给
   2.3066/2.1869/2.1211、`Δv = 0.02`给2.2746/2.1370/2.2225。
   **比值稳定在2.1—2.3而不是干净的2**，且它不随`Δv`变——所以**不是**线性化floor。
   `drives.py`的模块docstring记过同一族现象（"精确ZOH的对象与Euler的控制器
   组合起来给了更高的阶"），本轮没有把这个"稍好"解释清楚，**故不设收敛阶门**，
   登记为欠账。**不设门比设一个自己都不信的门诚实。**
5. **绞盘是一层观测，不是一个动力学环节**。导轮把两侧解耦（这正是绞盘存在的理由），
   所以`laydown_tension_n`是对读数的一次乘法，跨段动力学看不见它。
   **后果**：本案例算不了"落位点张力反过来改变跨段张力"，
   而真机上导轮的滑移状态一变那件事就会发生。
6. **`decimation = 1`那一档的控制周期等于推进步长（1 µs）**。**那不是一台机器的
   采样率**，是把采样-保持的离散误差压到判据分辨率之下的口径，闭式对拍用它。
   真机量级的控制周期实测在第五节的多速率表里，1 ms那一档这套增益**已经不稳**。
7. **注错验证九轮全红，但第一轮有一条没红**（逐轮清`__pycache__`）。
   把"对象用步首扭矩推进"改成"用步末扭矩"——**把测量与执行的因果次序反过来**——
   九条里唯一一条全绿的。病根是那个差是`O(dt)`的，`dt = 1e-6`下落在每条容差之下。
   **补法不是调紧容差**（那会让别的东西假红），是换一个能分辨它的量：
   一步、逐位、粗步长（`dt = 1e-4`）的因果次序门，见
   `tests/test_tension_control.py::test_the_plant_advances_on_the_step_start_torque_bit_for_bit`。
   **这条经历本身就是"每个门要红过"存在的理由**——模块docstring里
   "次序不是随手排的"那句话，当时是没有门守着的。
8. **没有跳过任何断言，没有静默skip。**

## 六、本案例不是什么

* **不是"张力闭环能用"的证明**。它证明的是**在这条通道上、用这个执行器，
  跨段谐振压不住**——`nominal`档两个指标都比开环差。要压住它需要的东西
  （摆杆、第二通道、或一个快二十倍的执行器）本仓一件都没有；
* **不是控制器整定指南**。三档的增益是**为了让判据说得清**而反解的，
  不是为真机整定的。`fast`档的增益配的是一台不存在的离合器；
* **不复现ATC600**。官方没有公开完整的通信/参数/寄存器手册（0062第二节裁决3），
  本案例的PID是控制教科书上那个能被闭式验证的东西。真机口径是ATC600置手动模式
  只当功率级，用户自己的环跑在Trio上——**本案例验的是那个口径下装配层的形状**；
* **不判绞盘的接触力学**。`CapstanSpan`只做`exp(μθ)`这一次乘法。
  真正走接触与多槽位摩擦的是`cases/capstan_tension_ratio`，
  两条案例判的不是同一件事：那里判"这条式子在引擎的接触层上成不成立"，
  这里判"闭环看不看得见它"；
* **不判材料输运、不判落位几何、不判带材横向行为**。跨段几何长度取常数
  （plans/14第3.3节的三号缺口），带材是一根只有`EA`的一维弹簧；
* **不判噪声**。传感器有量程截断与ADC量化，**没有**零漂、温漂、非线性、蠕变。
  第四节第3条那个"大`Kd`能不能用"的问题因此回答不了；
* **产物永久`hypothesis_only`**。带材`EA`、跨段长度、放线盘转动惯量、
  轴承阻力矩、离合器时滞与电流-扭矩增益、绞盘`μ`与包角——**一条实测都没有**，
  逐条出处见0062第二节裁决2那张"只有现场实测能补"的清单。
