# scalar_diffraction_airy 圆孔艾里斑：引擎第一次算一条光学闭式解

`case/scalar_diffraction_airy`。B档，spec/15（光学域进引擎）+ `optics/diffraction.py`。
**这是引擎的第二个物理域第一次给出一个可对拍的数。**
同行案例复用（research/05第2.3节光学族第一条：艾里斑`E(x) = 2·J1(x)/x`、
首零`x = 3.8317059702`）。

## 一、物理/几何设定

标量夫琅禾费衍射，均匀照明的圆孔，远场归一化振幅
`E(x) = 2·J1(x)/x`，`x = k·a·sin(θ) = 2π·a·sin(θ)/λ`。

| 量 | 值 |
|---|---|
| 采样自变量x | 0、0.5、1、2、3.8317059702、5、8、11.9、12、12.028、12.1、14、20、30、50、60（16点） |
| 波长λ | 632.8e-9 m（HeNe） |
| 孔径直径D | 1.0e-3 m |
| 孔径半径a | D/2 = 5.0e-4 m |
| `J1`分段点 | 12.0（级数↔Hankel渐近） |
| 首零文献引用值 | 3.8317059702（截到1e-10） |
| 二分区间 | [3.0, 4.5]，100次 |

采样点的选法是有理由的：覆盖级数段、**分段点两侧各一点**、以及实测最坏点
x=12.028（分段点右侧渐近展开误差的峰）。只在"好算的地方"采样是这类案例
最容易犯的错。

## 二、参考解出处

Born & Wolf《Principles of Optics》第8.5.2节（圆孔的夫琅禾费衍射）；
首零`j_{1,1}`取Abramowitz & Stegun表9.5（真值3.8317059702075123156）。

**生成器走的是另一条算法**：贝塞尔积分`J_n(x) = (1/π)·∫_0^π cos(n·t − x·sin t) dt`
的周期梯形求值。被积函数解析且2π周期，周期解析函数上梯形法几何收敛，
在float64上直接到浮点地板；生成器自己用两档节点互相印证，
互差超过1e-15即拒绝落盘。这条路与被验实现（上升级数 + Hankel渐近展开）
**没有任何共用代码**。首零由生成器**二分它自己的参考`J1`**求出，不抄文献值。

生成器不调`bessel_j1`、不调`airy_amplitude`、不import `physics_engine.optics`。

## 三、判据表

| 量 | rel/abs | 理由 |
|---|---|---|
| `j1_values`（16点） | abs 1e-12 | 被验实现申报的绝对精度。**判绝对不判相对**：`J1`有零点，x=3.83处值3e-12而绝对误差9e-17，相对误差3e-5毫无意义。实测最坏8.27e-13落在x=12.028，余量1.2倍 |
| `airy_amplitude_values`（16点） | abs 5e-13 | `E = 2·J1/x`，除以x把`J1`的绝对误差按1/x缩小；最坏点仍是x=12.028，实测1.38e-13，取值是它的3.6倍 |
| `first_zero_x` | abs 1e-14 | 两侧都二分到浮点地板，差异只来自`J1`求值：首零邻域走级数段无相消，绝对误差约1e-16，经`|J1'(x1)| = |J0(x1)| = 0.40276`折算成自变量偏差约2.5e-16。实测4.4e-16，取值是它的23倍 |
| `constant_matches_literature_quote` | abs 0 | 布尔：模块常量`AIRY_FIRST_ZERO_X`与A&S引用值逐位相同。锁的是research/05写下的那个判据数没有被实现改掉 |
| `amplitude_at_axis` | abs 0 | `E(0)=1`是极限的精确值，实现直接返回1.0不走除法——零容差 |
| `amplitude_at_literature_zero` | abs 3e-12 | 物理上E在首零处**恰为0**。偏差全部来自文献引用值被截断了7.512e-12：`|dE/dx| = 0.210225`，预测残值1.5793e-12，实测1.5793e-12吻合到四位。取值是预测的1.9倍。**容差是算出来的**：换一个位数更多的引用值它会更小 |
| `intensity_at_literature_zero` | abs 1e-23 | `I = E²`，容差是振幅容差的平方(3e-12)²=9e-24，实测2.49e-24。与上一条不重复：它验的是`intensity`真的是`amplitude`的平方而不是另写了一遍 |
| `first_minimum_half_angle_rad` | rel 1e-15 | `arcsin(x1/π·λ/D)`，三次乘除一次`arcsin`，各1eps量级；1e-15约4.5eps |
| `argument_at_first_minimum` | rel 1e-15 | **单位边界的往返**：角度→`sin/λ`（空间频率，周/米）→乘`2π·a`（角波数×半径）必须落回首零。实测往返偏差恰为0 |

**必须红（实测）**：

- 把生成器的`argument_at_first_minimum`期望值写成"真零点"而不是文献引用值时，
  这条**当场红**，报`expected 3.831705970207512, got 3.8317059702 — exceeds abs=1e-14
  by 7.502e-12`。红得对：引擎的1.22因子按定义就是引用值除以π，
  金标若换成真值，这条判据测的就变成"那个引用值被截了7.5e-12"而不是单位换算。
  **oracle的独立性要求的是算法不同，不是把物理常数换掉**——这是本案例最贵的一条发现。
- `tests/test_optics.py`里有一条把直径当半径传的用例，实测自变量差**恰好2倍**：
  传错了图样宽一倍且不报任何错。

## 四、已知失效清单

- **`J1`的精度只在`x ∈ [0, 60]`上实测**（1936个点，步长0.031，最坏8.2734e-13
  落在x=12.028；这一整段由`tests/test_optics.py`的`batch`档门逐点守着，
  本案例只冻结其中16点）。渐近段在更大的x上只会更好（x=50实测1.4e-17），
  但"只会更好"是推断不是实测，所以域外写作**未测**。
- **只验标量近似**。矢量衍射、偏振、近场都不在本案例；`E(x)`本身就是标量近似的产物。
- **只验远场**。菲涅耳数不进本案例，什么时候"够远"由调用方判断，引擎不代判。
- **不验二维图样**。本块只有沿径向的一维闭式；二维场传播要NumPy与FFT，是下一块。
- **首零判据受限于引用值的位数**。`amplitude_at_literature_zero`的容差3e-12里
  只有约2e-16是实现的，其余全是那个被截到1e-10的引用常数——
  即**本案例对`J1`零点精度的判别力止步于1e-10量级**。要更严就得换更长的引用值。
- **`airy_first_minimum_half_angle_rad`在`λ/D`过大时拒答**，不返回nan也不夹到π/2。
  这是失败关闭不是失效，但列在这里以免被当成缺口。
- 未在Windows/Linux复核。

## 五、档位与负载级

B档，**interactive**（<1s）。实测：三条测试共**0.03 s**（其中最贵的一条是主瓣
单调性的64点扫描）。生成器一次**0.44 s**（16点×两档周期梯形求值，另加二分首零时
每次求值都走两档自校验）。

## 六、本案例不是什么

- **不是"引擎能做衍射了"的证据**。它算的是一个圆孔的一维远场闭式，
  没有任何场传播、没有任何孔径形状变化。
- **不是`J1`的通用实现证明**。只在`[0, 60]`上、只对一阶、只按绝对误差申报。
- **不是光学系统仿真**。没有透镜、没有像差、没有多元件。
- **不验FTS那一侧**——那是`cases/fts_instrument_line_shape`。
- **不是性能证明**：每次调用几十个浮点运算，没有规模可言。
