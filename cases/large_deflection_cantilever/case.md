# large_deflection_cantilever 大挠度悬臂梁：引擎第一次把一个几何非线性的闭式解算对

`case/large_deflection_cantilever`。B档，spec/12第三节（能量项）+第4.1节（准静态求解）。
**这是几何精确弯曲（DER的``κ = 2·tan(θ/2)``）的进仓门。**
同行案例复用（research/05第2.3节的C2：大挠度悬臂对椭圆积分，
Bisshopp-Drucker 1945；WDS的B1 `tests/test_validation_b1.py`是同一个案例的先例）。

与`cantilever_self_weight`的分工要说清楚：那一个验的是**小挠度线性方程**
（`LinearBending`，位置的二次型）对它自己的收敛性，案例页第四节已如实登记
"实测挠度3125mm对长度1000mm在真实梁上早已是大挠度"。
本案例把那条登记补上：同一个载荷下，小挠度理论的端点偏差**49.1%**，
本案例的几何精确项在最细档只有**0.032%**，相差1519倍。

## 一、物理/几何设定

平面细长杆（elastica），固支端在`s=0`、自由端在`s=L`，
端部受**方向固定**的横向集中载荷`P`（dead load，不随杆转动）。

| 量 | 值 |
|---|---|
| 长度 L | 100.0 mm |
| 弯曲刚度 EI | 100.0 N·mm² |
| 轴向刚度 EA | 1.0e4 N |
| 无量纲载荷 β = P·L²/EI | 3.0 |
| 端部载荷 P | 0.03 N |
| 重力 g | 9806.65 mm/s² |
| 端部集中质量 | 3.059148638933785e-3 kg（= P·1000/g） |
| 非端点节点寄生质量 | 1.0e-15 kg |
| 加密阶梯 | 10 / 20 / 40 / 80 段 |
| 载荷步数 | 4（**案例做的，不是求解器做的**） |
| 牛顿绝对残差容差 | 1.0e-7 N |

离散：等分链，节点0与节点1的**全部分量钉住**——钉住第一条边就同时钉住了位置
与切向，不需要额外的斜率约束。面外（z）自由度全钉：本案例是平面问题。
轴向由`AxialStretch`承担（elastica是不可伸长的，用一根很硬的弹簧逼近，
`EA·L²/EI = 1e6`）。弯曲由`DiscreteElasticBending`承担。

**固支顶点的Voronoi长度是`3h/2`，不是`h`**——这不是配出来的数，是把被钉死的
第一条边所吞掉的那半格柔度做静态凝聚得到的（推导写在
`clamped_chain_bending_vertices`的docstring里，验红见第四节）。

**载荷分步是案例显式做的。** 求解器申报过它没有载荷步生长、没有同伦延拓
（decisions/0027第四节）；从直链一步加到β=3牛顿不收敛——线搜索在几何非线性上
反复回溯，实测停在挠度只有真值1/4的地方。同行先例：WDS的B1也是6步喂载。

## 二、参考解出处

**Bisshopp & Drucker 1945（Quarterly of Applied Mathematics 3(3):272–275）
"Large deflection of cantilever beams"** 的椭圆积分闭式。
`EI·θ'' + P·cosθ = 0`、`θ(0)=0`、`θ'(L)=0`，首次积分后代换
`1 + sinθ = 2k²·sin²φ`（`2k² = 1 + sinα`、`α = θ(L)`）：

    sqrt(β) = K(k) − F(φ₁, k)          sin²φ₁ = 1/(1 + sinα)
    x_L / L = sqrt(2·sinα / β)         （这一支是初等的）
    y_L / L = 1 − (2/sqrt(β))·[E(k) − E(φ₁, k)]

第一式对α严格单调，二分求α。椭圆积分用**Carlson对称形式**`R_F`/`R_D`的
重复化算法（纯标准库，零运行时依赖）。

金标：`x_L/L = 0.7455798154358129`、`y_L/L = 0.603253441129977`、
`α = 0.986016946711354 rad`（56.49°）。

**生成器只算椭圆积分**：不import `physics_engine.energies`、不调`solve_equilibrium`。
生成时跑三条自校验，任何一条不过就不出金标：

1. `K`/`E`对已知值（m=0.25与0.5）逐项相对偏差 < 1e-15；
2. **小载荷极限的第一修正恰为β的二次**——`y_L/L = (β/3)·(1 − 0.1142·β + …)`。
   断言"β十倍则偏差百倍"（实测100.004与99.79），比只断言"趋近`δ=PL³/(3EI)`"强得多，
   且不需要在校验里写下任何系数；
3. 单调性：β增大时`y_L/L`增、`x_L/L`减。

**独立第二路线（跨仓对拍）**：WDS `validation/cantilever.py`用scipy的QUADPACK
对**同一首次积分**做端点奇点代换后的正交求积——与本闭式是完全不同的数值路线。
两者在β=0.2/0.8/1.5/3.0/5.0五档上逐点相对偏差 ≤ 1.3e-14（β=3那一档：
x 3.0e-16、y 5.5e-16、α 1.1e-16）。对拍记录见decisions/0029第三节。

## 三、判据表

| 量 | rel/abs | 理由 |
|---|---|---|
| `tip_x_over_length` | rel 1e-14 | `sqrt(2·sinα/β)`是初等闭式，唯一的数值步骤是二分求α（200次，已到机器精度）；1e-14是与WDS独立正交求积对拍的实测偏差量级 |
| `tip_y_over_length` | rel 1e-14 | 要两个椭圆积分之差；Carlson重复化对已知K/E值偏差<1e-15，对WDS的QUADPACK路线偏差1.1e-15 |
| `tip_angle_rad` | rel 1e-14 | 二分200次的α；与WDS独立路线偏差6.9e-16 |
| `tip_relative_error_max` = 1e-3 | abs 0 | **上界不是等式**。最细档(n=80)实测3.234393e-04，留3.1倍余量；同时比固支权取`h`时的一阶值8.804656e-03低8.8倍——门仍分得开二阶与一阶 |
| 收敛比区间 `[3.9, 4.1]` | abs 0 | **不写死为4**（spec/12第4.3节：比阶不比单点）。实测三档3.9612/4.0512/4.0600。n=5那一档比值只有3.6422，即h=20mm还没进渐近区，所以加密阶梯从n=10起 |
| `linear_theory_relative_error` | rel 1e-14 | 由闭式直接算：小挠度理论在β=3给`(x/L, y/L) = (1, 1)`，对闭式`(0.7456, 0.6033)`偏差49.1%。**这个数存在的意义是证明本案例真的在考几何非线性** |
| `geometric_nonlinearity_margin` = 100 | abs 0 | 几何精确项的误差必须比小挠度理论小至少100倍。实测1519倍。取100是留余量的**下界**，不是实测值——写实测值等于让门迁就当前实现 |
| `all_refinements_converged` | abs 0 | 布尔前置断言：**不收敛的解不许参与收敛阶比较**——那会拿一个没解出来的数去算阶 |
| `newton_iterations_within_bound` = 60 | abs 0 | 单个载荷步的牛顿迭代数上界，实测最大48。**能量不再是二次型，所以这里没有「一步收敛」**（对比`cantilever_self_weight`）；迭代数突增是线搜索在几何非线性上失步的信号 |

**牛顿绝对残差容差1e-7 N是声明的绝对量**（spec/12第4.3节要求不许含糊），
而且**它有下界**：总能量量级约0.7 N·mm，机器eps让能量在残差约1e-8 N时不再可分辨，
线搜索于是无法再降低能量、牛顿停滞。实测取1e-8时某些载荷分步配置会停在残差
1.35e-8——**物理上已经收敛却被判不收敛**。取1e-7留7倍余量。
上界侧：1e-7对应端点位移误差约`1e-7/(3EI/L³)` = 3.3e-4 mm = 3.3e-6相对，
仍比最细档的离散误差3.2e-4低两个数量级，不污染收敛阶。
这是`cantilever_self_weight`那条"绝对残差门在细化时会被污染"的**另一侧**：
那边是容差被刚度标度顶穿，这边是被能量的浮点分辨率顶穿。

## 四、已知失效清单

- **引擎没有点载荷能量项**，端部集中力只能用`UniformGravity` + 集中质量表示，
  而`EnergyContext`要求所有节点质量为正，故非端点节点取1e-15 kg。
  其合力`80×1e-15×9806.65/1000 = 7.8e-13 N`，占端载荷0.03 N的**2.6e-11**。
  实测把它在1e-12/1e-15/1e-18之间换，n=80的误差只变到第5位有效数字
  （3.234355e-04 / 3.234393e-04 / 3.234393e-04）。
  **这是一处声明并量化的近似，不是隐藏的近似**；补它要加一个`PointLoad`能量项，
  那是下一块的事（decisions/0029第六节）。
- **不可伸长是用很硬的弹簧逼近的**：闭式解假定杆不可伸长，引擎侧`EA=1e4`，
  端部轴向应变约`P/EA = 3e-6`。实测把EA换成3e4，n=80的误差从3.234393e-04
  变到3.244194e-04（0.3%），确认它不是误差的来源。**但EA不能随便加大**：
  EA=1e6时牛顿在直链初值上第一步就被线搜索卡死（轴向刚度比弯曲高8个数量级）。
- **求解器在这个问题上是脆的**。载荷步数、残差容差、固支权任一改动都可能
  让某一档不收敛（实测：ramp=8 + tol=1e-8在n=10的第2载荷步停滞；
  EA=3e4在n=20不收敛）。本案例的参数是**选出来的可行点，不是稳健区间**。
  根因是求解器无载荷步自适应、无信赖域、Hessian非正定时无修正
  （几何精确弯曲的Hessian在大挠度下不保证正定）。修它要动`solve.py`，不在本块。
- **固支顶点的Voronoi长度取`h`会把收敛阶从二阶打到一阶**：实测收敛比
  2.0582/2.0323/2.0169，最细档误差8.804656e-03（差27倍）。
  这是decisions/0027那条教训的第二例，**症状相同、病根同类而不同处**：
  那次是梯形求积的端点半权，这次是被钉死的第一条边吞掉的半格柔度。
  两次都**不是**"边界条件的阶次"。本案例把它做成了正向断言
  （`test_dropping_the_clamp_voronoi_correction_costs_an_order`），不是只记在文档里。
- **闭式本身在β≲1e-4时失去有效数字**：`y_L/L = 1 − (…)`是相消形式，
  β=1e-6时相对偏差达4.9e-4（纯数值，非物理）。本案例用β=3，不受影响；
  但**任何人拿这个生成器去做小载荷极限都必须知道这条**。
  生成器的自校验因此选在β∈[1e-3, 1e-1]。
- **只在平面内**：面外自由度被钉住，扭转与三维弯扭耦合不在本案例
  （`DiscreteElasticBending`是各向同性的，没有材料标架、没有`κ1`/`κ2`分解）。
- 未在Windows/Linux复核。

## 五、档位与负载级

B档，**local_batch**（本机批级，<2分钟）。
实测（本机空载）：三条测试共约10秒；加密最细档n=80的四个载荷步各约48次牛顿迭代，
每次迭代一个156×156稠密LU。`accept.py full`实测13.7秒/120秒预算。
`peer_fcl_distance`已经带着`batch` marker，但它在没有同行库环境时整体skip——
所以本案例是batch档里**第一个无条件真跑**的。
慢的原因是可申报的（四档网格 × 四载荷步 × 约48次牛顿迭代 × 稠密LU），
不是可以靠调参省掉的慢。

## 六、本案例不是什么

- **不是"引擎能算杆了"的证据**。它算的是各向同性、平面、无扭转、无接触的
  单根杆，只在一种边界条件、一种载荷下验过。真正的DER杆还差各向异性
  （`EI_easy`/`EI_hard`与材料标架）、扭转、自然曲率。
- **不是`LinearBending`的替代品的证据**。两个能量项适用域不同、都在仓里；
  本案例只证明在β=3这个载荷下几何精确项对而小挠度项错。
  反过来的边界（多小的载荷下两者等价）**没有验**。
- **不是求解器的稳健性证明**——恰恰相反，第四节登记了它在这个问题上有多脆。
- **不是性能证明**：稠密LU，规模是几百自由度，且本案例是本仓最慢的案例。
- **不验证接触、摩擦、约束、动力学、塑性**——那些一个都还没有。
- **不是`κ = 2·tan(θ/2)`在θ→π附近的验证**：那里是模型自身的奇点，
  能量项在此失败关闭；本案例的最大转角是56.49°。
- **不是`energy()`那个表达式的门。** 求解器只用梯度与Hessian找解，
  能量值只进线搜索的"降了没有"判断。实测：**只把``curvature_sq``换成弦长形式、
  梯度与Hessian照旧**，本案例逐档误差与原来**12位有效数字全同**
  （2.107301800853e-02 / 5.319909414263e-03 / 1.313170851257e-03 / 3.234392862362e-04）。
  也就是说，一个只活在`energy()`里的错误可以从本案例底下整个溜过去。
  验`energy()`本身的是`tests/test_energies.py`里那条**手算转角**门
  （θ=90°给κ²=4、θ=120°给κ²=12）。
  这是spec/12第6.1节"两道门缺一不可"的一个新形态：那一节说的是
  "FD验不了物理"，这里是它的镜像——**物理案例验不了能量表达式**。
  把``κ``与它的导数**一起**换成弦长形式，本案例才红（收敛比3.7171/3.8304落在
  [3.9,4.1]之外，且n=80直接不收敛）——所以本案例确实分得开这两个离散，
  但分开它们靠的是梯度那一路，不是能量那一路。
