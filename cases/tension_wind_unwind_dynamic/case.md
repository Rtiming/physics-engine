# tension_wind_unwind_dynamic T-M3：小型放线—测力轮—收线动态链

判据正本为同目录`oracle.json`，生成器为`generate_oracle.py`。本案例把既有自由跨、放线盘、
磁粉离合器和PID与T-M2测力轮/标定/ADC/采样时延通道接在一起。
清单身份：`case/tension_wind_unwind_dynamic`；负载级：`local_batch`。

## 一、物理/几何设定

```text
放线盘制动力矩+收线端速度阶跃
→ 自由跨材料长度与张力
→ 90°测力轮合力+5N tare
→ analog_pre_adc清零+16位ADC+线性标定
→ 100μs采样+0.5ms测量时延+零阶保持
→ 好/坏/开环控制器
```

对象参数沿用`closed_loop_tension_step`的合成工况：EA 60000N、跨长300mm、半径60mm、
惯量5000kg·mm²、轴承阻尼50N·mm/(rad/s)、制动力矩1200N·mm、线速度20→22mm/s。
本案例把推进步放宽到10μs，跑0.1s，共三档30000步；目的是验证装配与分辨力，不替代
原案例1μs步长的闭式精度门。

测量通道取100N/20mV/16位ADC，五级正反程标定使用精确90°测力轮增益。采样周期100μs，
显式时延5个样点即0.5ms。所有参数都是合成假设，永久`hypothesis_only`。

## 二、参考解出处

生成器不import`transport`、`drives`、`tension_control`、`tension_measurement`或
`tension_readout`，独立重写半隐式Euler、离合器精确一阶ZOH、PID、测力轮增益、ADC、
采样队列和时延。它给出三档峰值、ISE、末态误差与半径60/80mm的稳态值。

## 三、判据表

| 量 | rel | abs | 理由 |
|---|---:|---:|---|
| 三档真实/测量峰值 | 2e-7 | 2e-8N | 对独立标量离散推进；一步错序远超余量 |
| 三档ISE与末态误差 | 2e-7 | 2e-8 | 好控制器ISE必须显著低于开环 |
| 好/坏峰值比 | 2e-7 | 2e-8 | 好控制器小于0.7，坏控制器大于0.9 |
| 采样与时延 | 0 | 0 | 100μs与0.5ms由整数计数给出，不做浮点猜测 |
| 半径变化 | 2e-15 | 0N | 60→80mm时按独立稳态力矩平衡下降 |
| 显示张力 | 3e-15 | 3e-14N | 经测力轮、16位ADC和标定后对独立量化值 |

## 四、已知失效清单

1. 不是真机标定；EA、惯量、阻尼、离合器时滞和控制增益均是假设。
2. 只做固定半径的两档对比，不在单次运行中连续更新卷径。
3. 测力轮两侧张力取相等，不把绞盘滑移反作用接回跨段。
4. 不含摆杆、轴承库仑摩擦、温漂、噪声、蠕变和ADC前端滤波。
5. 好控制器只证明这个合成快离合器工况有分辨力，不是现场整定建议。
6. 不接WII/GCW真实模型，不改变端到端0/6。
7. 无skip。

## 五、档位与负载级

**B档/本机批级（`local_batch`）**。独立金标与生产路径各跑三档10000步。

## 六、本案例不是什么

- 不是场景⑥端到端完成；
- 不是现场控制器整定指南；
- 不是连续卷径生长模型；
- 不是WII/GCW真实模型回放；
- 不是摆杆、接触、横漂或落位偏差模型；
- 不是现场张力准确度验收。
