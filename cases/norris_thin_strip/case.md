# norris_thin_strip Norris薄带：场景①第一个可跑通的解析基准

`case/norris_thin_strip`。B档，`electromagnetics/superconductor.py`（决策0047）。
**引擎的第三个物理域第一次给出一个可对拍的数。**
判据来源是research/12第3.1节判定的第1档（解析闭式）oracle。

> ## ⚠️ 先读这一条：**本案例不进0040的成功标准分母**
>
> **它验的是公式不是引擎。** 今天`shapes`里没有"带材"这个形状，
> `state`里没有电流这个自由度，`solve`里没有任何东西会解出电流分布。
> 本案例算的是一个**独立闭式**，不经过引擎的状态、不经过求解器、
> 不经过任何会被别的案例复用的数值路径。
>
> 换句话说：**它绿了不代表"引擎能算超导了"**，只代表
> "场景①唯一那条第1档oracle被钉住了、并且验过红"。
> 0040的C档分母13条里，本案例**一条也不加**（research/12第4.1节A4已先写下这一句，
> 本页原样重复，因为这正是最容易被读成进展的地方）。

## 一、物理/几何设定

无限长、无限薄的超导带材，横截面上宽`w`、超导层厚`d`，通传输电流`I`。
横坐标`x`从带中心量起，`|x| ≤ w/2`。临界态（Bean）模型。

| 量 | 值 | 说明 |
|---|---|---|
| 带宽`w` | 4.0e-3 m | 代表性REBCO带材（4 mm） |
| 超导层厚`d` | 1.0e-6 m | 1 μm |
| 临界电流密度`Jc` | 3.0e10 A/m² | 体电流密度 |
| 临界片电流密度`Kc = Jc·d` | 3.0e4 A/m | **厚度在这一步被吸收掉** |
| 临界电流`Ic = w·Kc` | 120.0 A | |
| 电流比`i = I/Ic`（分布采样） | 0.01、0.1、0.25、0.5、0.75、0.9、0.99 | 7档 |
| 采样点`\|x\|/b`（未穿透区内） | 0、0.25、0.5、0.75、0.9、0.99、0.999 | 7档，共49点 |
| 采样点（饱和区） | `(b+w/2)/2`与`w/2` | 每档2点，共14点 |
| 电流比（守恒扫描） | 0.1、0.25、0.5、0.75、0.9、0.99 | research/12实测的那一段 |
| 代换式Simpson区间数 | 256 | |

| 渐近判据点 | `i = 1e-3` | |
| 量幂次的十倍程 | `i = 1e-4 → 1e-3` | |
| 量纲损耗判据点 | `Ic = 120 A`、幅值`60 A` | |
| `μ0` | `4π×10⁻⁷ H/m` | 2019年SI重新定义**之前**的定义值 |

**长度制**：本域按米（`SUPERCONDUCTOR_LENGTH_UNIT = "m"`），
与力学的mm制不混一条材料记录。`Jc`/`Ic`是**案例输入不是材料记录字段**——
材料记录今天装不下安培，实测与裁决请求见决策0047第四节。

**采样点的选法是有理由的**：`i = 0.01`那一档磁通前沿几乎贴着带边
（`b/a = 0.99995`），是相消最凶的一档；`|x|/b = 0.999`那一档**故意贴着磁通前沿**，
那里`b² − x²`相消最凶。只在好算的地方采样是这类案例最容易犯的错。

## 二、参考解出处

**片电流分布**：W. T. Norris, *J. Phys. D: Appl. Phys.* **3** (1970) 489，
conformal mapping闭式

    K(x) = (2·Kc/π)·arctan( sqrt( ((w/2)² − b²) / (b² − x²) ) )    |x| < b
    K(x) = Kc                                                      b ≤ |x| ≤ w/2
    b    = (w/2)·sqrt( 1 − (I/Ic)² )

采信的写法取自Pardo等《Electromagnetic modelling of superconductors with a
smooth current-voltage relation》（arXiv:1410.0772）。
**核实结果与research/12有一处出入，如实记下**：research/12把它记作**式(69)**，
本轮公开检索到的引用给的是**式(67)**——**节号本轮未能定论**，
本页因此只引论文不引式号。形式本身两处一致，且由下面两条独立地确认过：
（一）两个零容差极限（`I=0 ⟹ b=w/2`、`I=Ic ⟹ b=0`）——research/12记原文把`b`的
分母写作`I_m`，正是靠这两个极限反推它应当是`Ic`；（二）电流守恒`∫K dx = I`
（本页判据表第2、3行），它对`b`的形式**极其敏感**。

**交流损耗两式**：Grilli等《Computation of Losses in HTS Under the Action of
Varying Magnetic Fields and Currents》（arXiv:1306.6251）式46、47。

    薄带：  2π·Ql/(μ0·Ic²) = 2·[ (1+i)·ln(1+i) + (1−i)·ln(1−i) − i² ]   → i⁴/3
    椭圆：  2π·Ql/(μ0·Ic²) = (2−i)·i + 2·(1−i)·ln(1−i)                  → i³/3

**本轮独立核实过形式**：检索到的等价写法是单位长度损耗**功率**
`P/l = f·μ0·Ic²·g(i)/π`（薄带，`g(i) = (1−i)ln(1−i) + (1+i)ln(1+i) − i²`）
与`P/l = f·μ0·Ic²·e(i)/(2π)`（椭圆，`e(i) = (2−i)·i + 2(1−i)ln(1−i)`）。
除以频率`f`得每周期损耗`Ql`，归一化后分别是`2·g(i)`与`e(i)`——
**与任务书给的形式逐字一致，两条式都不改**。

**生成器走的是另一套算术**：`cases/norris_thin_strip/generate_oracle.py`
用**50位十进制定点**（`decimal`，标准库）重算同一条闭式。
`sqrt`/`ln`是`Decimal`自带的正确舍入实现，`arctan`由生成器自己用
半角约化＋Taylor写（`atan(t) = 2·atan(t/(1+sqrt(1+t²)))`），
`π`用Machin公式从同一个`atan`得出（落成float64后与`math.pi`逐位相同，已断言）。
生成器**不import被验模块**。脚本SHA-256钉在`oracle.json`的`generator.sha256`。

**参考路径与被验实现连代数形式都不同**：被验实现把arctan自变量写成
`(a·i)/sqrt((b−|x|)(b+|x|))`（无相消），参考按原式`sqrt((a²−b²)/(b²−x²))`算；
被验实现在`i ≤ 0.7`走幂级数，参考在50位下直接按对数式算。

## 四、已知失效清单

- **`|x|/b → 1`时闭式病态**：`|x|/b = 1 − 1e-9`处相对精度掉到约**2.3e-9**，
  **且换代数写法救不回来**——`(a·i)/sqrt((b−|x|)(b+|x|))`与
  `sqrt((a²−b²)/(b²−x²))`两条路在那里给出同一个量级的误差。
  这是**问题的条件数**不是实现缺陷（`dK/dx → ∞`，1 ulp的`b`扰动被放大）。
  申报精度因此只在`|x| ≤ 0.999·b`上给出，域外**写作未测**。
  `tests/test_superconductor.py`有一条门守着"这个病态还在"，
  哪天有人压下去它会红，那时删掉本行。
- **`i ≪ 1`时两条损耗式在float64上会塌**。本实现在`i ≤ 0.7`走幂级数避开，
  但**用它的人如果自己按原式重算一遍就会踩**（`i=1e-3`处差6.6e-4）。
  research/12记的"薄带`i=1e-3`给3.331e-13"正是那条塌掉的写法给出的数——
  **那是数值噪声不是物理**，真值是3.3333346666673814e-13。
- **超临界`i > 1`拒答**，不外推也不夹到1。这是失败关闭不是失效，
  列在这里以免被当成缺口。
- **`|x| > w/2`拒答**。同上。
- **只验临界态极限（`n → ∞`）**。有限`n`的幂律本构不在本案例，
  也不在本模块——**引擎今天没有任何东西能解幂律本构**。
- **幂律指数`n`"典型20—30"这一说标《未核实》**：research/12核不到权威出处，
  核到的具体数字是Pardo等取`n = 1000`模拟临界态、扫描`n = 5…200`、
  以及一份实测`n = 15`。本案例与本模块**都不使用`n`**；
  `tests/test_superconductor.py`有一条门守着"这个数不许脱离标记出现在本轨道的产物里"
  （research/09价格条那次事故的形制）。
- **`μ0`取2019年SI重新定义之前的定义值**`4π×10⁻⁷`。换成CODATA实测值
  （差约1.3e-10相对）本案例会红——**红得对**，换物理常数是一次决定不是优化。
- **`Jc`/`Ic`没有进材料记录**，是案例的输入常数。它们是材料属性不是物理常数，
  按spec/14规则1本该与杨氏模量同处一条记录，今天**装不下**（实测拒收点见决策0047
  第四节）。这是**临时避开不是长期方案**，缺口有绊线守着。
- **未在Windows/Linux复核**。全部判据只用`math`的`atan`/`sqrt`/`log1p`，
  平台间libm末位差异在1e-12/1e-14的容差下不构成风险，但"不构成风险"是推断不是实测。

**禁止静默skip**：本案例没有任何被跳过的判据。

## 五、档位与负载级

B档，**interactive**（`<1s`，与`oracle.json`的`load_tier`逐字一致，无pytest marker）。

实测：本案例的conformance共**0.72 s**，其中**0.71 s**是那一条
`direct_quadrature_currents_a`（4e5点×2档的直接Simpson，纯Python的80万次
`atan`调用）——**它一条就占了全部耗时的99%**。模块级门
（`tests/test_superconductor.py`，19条）共**0.05 s**。生成器一次**0.04 s**。

保留那条昂贵判据是**明知代价的选择**：它是"为什么另一条能到1e-9"的唯一对照，
删掉它整张判据表就只剩一个没有解释的1e-9。若将来它挤占交互档，
正确的做法是把它单独打`batch` marker，不是把节点数调小
——调小它就不再复现research/12那两个数了。

## 六、本案例不是什么

- **不是"引擎能算超导带的电流分布了"的证据**。见本页顶部那一条：
  它验的是公式不是引擎，**不进0040的分母**。
  今天没有"带材"形状、没有电流自由度、没有电磁求解器，
  所以**没有被验的对象**——research/12第4.3节C3把"超导带的电流分布图"
  列为"今天做出来只能是演示"，本案例做的恰恰是它的另一半：
  把那条曲线的oracle先钉住并验过红，**而不是把它画出来当成果**。
- **不是临界态模型成立的证据**。临界态（Bean）本身是**理想化**：
  它假设`Jc`与局部磁场无关（真实REBCO的`Jc(B, θ)`随场显著下降、
  各向异性可达数倍）、忽略磁通蠕动、假设带材无限薄无限长、
  无邻近导体、无外加磁场、只有单调加载的传输电流。
  **本案例不检验这些假设中的任何一条**，它只检验"在这些假设下那条闭式算得对"。
- **不是"三维带厚度"的答案，反而是它的反面**。同行绕开HTS带材长细比的主流手段
  （T-A薄带、H-φ薄壳）就是**把厚度降维掉、不画进网格**，
  本闭式更彻底——厚度整个被吸收进`Kc = Jc·d`，此后一次也不出现。
  这与"我们是带厚度的三维"直接相抵（research/12第3.1节），
  是一处必须让用户知道的张力，不是本案例能解决的事。
- **不验外场**。Brandt-Indenbom/Zeldov（1993）那条垂直外场下的解析解
  research/12已备好但不在本案例，它有自己的适用限制
  （只在临界区单调穿透时成立）。
- **不验历史相关性**。屏蔽电流与磁滞依赖加载历史，本案例只有单调加载的一个终态。
- **不是性能证明**。每次调用几十个浮点运算；那0.71 s是**判据故意选的**代价，
  不是内核的规模。
- **不验`electromagnetics`域的其他任何东西**。本子包今天只有这一个模块。
