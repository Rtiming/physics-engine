# roller_skew_lateral_drift 导轮轴偏斜引起的带材稳态横漂

**这一条回答的是"几个轮子不在一个平面时带材偏多少"，而且它不需要材料输运。**

WDS `research/05`第三节把材料注入列为横漂定量化的最大缺口。那条对**瞬态**
（`τ ≈ 3 s`）与**持续横走**成立，对**稳态**不成立——Shelton正规入轮定律
`y'(L) = θ_r`**本身就是输运的结果**，把它当边界条件写下来，稳态就是一个静力边值问题。

判据值的正本是同目录的`oracle.json`，`case_id`为`case/roller_skew_lateral_drift`。
**本案例永久标`hypothesis_only`**：带材EA/EI、摩擦、轮轴偏斜角全是假设输入。

## 一、物理/几何设定

自由跨段：上游轮的包覆stick弧把带材钉住，下游轮的轴向偏斜`θ_r`。

| 项 | 取值 | 出处 |
|---|---|---|
| 带材 | 4 mm宽×0.1 mm厚，`E ≈ 150 GPa` | **假设**（`research/05`列为五项实测缺口之一） |
| 硬轴弯曲刚度`EI₁ = E·t·w³/12` | **8.000×10⁴ N·mm²** | 与`research/04`记的`≈8.0e4`一致 |
| 轴向刚度`EA` | 6.000×10⁴ N | 同上材料 |
| 自由跨长`L` | 200 mm（另扫100/300/500） | **设定** |
| 张力`T` | 20 N（另扫10/30/40） | 真机张力区间10—30 N |
| 轮轴偏斜`θ_r` | 1° | **设定**，非实测 |
| `1/K = sqrt(EI₁/T)` | 63.25 mm | 与`research/04`记的`≈63 mm`一致 |
| `u = KL` | 3.1623（L=100—500给1.58—7.91） | 与`research/04`记的`≈1.6—8`一致 |
| 半间隙 | **2.0 mm** | R1槽底宽8.000 mm、带宽4 mm。**2026-08-17订正**，见第七节 |
| 离散 | N=20/40/80/160/320段 | 收敛阶要多档才判得了 |
| 尖端振幅`A` | 1×10⁻³ mm（线性区） | 见第四节第2条 |

## 二、参考解出处

`research/04`第2节（Shelton正规入轮理论）。自由跨段满足梁-弦方程

    EI₁·y'''' − T·y'' = 0,    K = sqrt(T/EI₁),    u = K·L

四个边界条件：`y(0)=0`与`y'(0)=0`（上游stick弧冻结位置与方向）、
`y''(L)=0`（下游入轮线经短包覆微滑，**不能传递弯矩**）、
`y'(L)=θ_r`（**正规入轮**：稳态时带材垂直于倾斜后的下游轮轴入轮）。

解得

    y_ss = θ_r · L · f(u),    f(u) = (sinh u − u·cosh u) / (u·(1 − cosh u))

`f(0)=2/3`（纯梁）、`f(∞)→1`（纯弦），**单调递增**。
`research/04`明写本工位"处在梁弦之间的中间区，**纯弦或纯梁公式均不适用，必须带f(KL)**"。

金标生成器只写这三条式子，**不调`solve_equilibrium`、不引任何力学模块**。

## 四、已知失效清单

1. **`solve_equilibrium`钉不了"斜率"**，只有`fixed_indices`。
   处理：钉尖端**位置**`A`、解、读尖端斜率`s(A)`，再按线性缩放`y_ss = θ_r·A/s(A)`。
   **前提是线性，而线性是判出来的不是假定的**（下一条）。

2. **线性区的边界是量出来的。** 以`A = 1e-5`为参考实测（N=80）：
   `A ≤ 1e-2`的偏差在求解器残差量级（`1e-9 N`），**不是物理**；
   `A ≥ 0.1`起是**干净的二次律**，系数约`9.9e-3 /mm²`；`A = 1.0 mm`时偏**+0.9%**。
   本案例取`A = 1e-3`。

3. **那0.9%是物理不是误差。** 横漂让带材多走弧长`∫y'²/2 dx`，张力被抬高。
   `A = 1 mm`时估得`ΔT ≈ +6.7%` ⟹ `u`涨3.35% ⟹ `y_ss`涨约**+0.94%**，
   **与实测的+0.9%对上**。**闭式是线性化的，看不见这一项；引擎算得出。**

4. **稳态不需要输运，瞬态需要。** `τ = y_ss/(V·θ_r) ≈`跨段通过时间
   （`research/04`算例：V=50 mm/s时`τ≈3.0 s`）。本案例**不算瞬态**。
   **持续横走区**（Yang速度匹配模型：回路拓扑使正规入轮永远无法满足）同样不算。

5. **小角度线性化的适用范围**：`research/04`记`θ_r ≲ 5°`（8°以内误差<1%）。
   本案例取1°。
   **2026-08-17订正把这一条从"有问题"变成"没问题"**：第一版里L=100 mm那档
   给5.381°、正好压在适用边界上，当时写着"那一档要按约5°读，不按四位有效数字读"。
   半间隙订正后四档是1.656/0.766/0.476/0.262°，**全部落在适用范围的深处**。
   记这一笔是因为**订正改善了适用性这件事本身要留痕**——
   否则下一个人会以为那条边界警告是被删掉的，而不是被解掉的。

6. **入口无滑移的前提未验**：`research/04`记`μ_⊥·β ≫ |θ_r − y_x(L)|`。
   本案例把上游stick弧当作**理想固支**，没有验这条不等式。

7. 无skip。

## 六、本案例不是什么

* **不是瞬态，也不是持续横走**。只算稳态`y_ss`。那两件要材料输运（第四节第4条）。
* **不是多轮**。一段自由跨、一个下游偏斜角。真机是R4→R3→R2→R1加两只活动小导轮，
  多轮的偏斜要逐段累加，**而累加规则本案例没有验**。
* **不含摩擦**。上游当理想固支，没有建包覆弧内的粘滑；
  而引擎的`coulomb_return_map`是**各向同性径向返回**，
  WDS已证伪它在`μ_∥:μ_⊥ = 5:1`时混合角耗散短缺最高60%、**会系统性偏置`e_lat`**。
  真做各向异性要补摩擦椭圆。
* **不含面外倾斜**。`research/04`第104行明写**两种倾斜都应测试**：
  面内（Shelton情形，本案例）与面外（Yang速度匹配情形）。后者要扭转（GJ），引擎没有。
* **不判蹭边本身**。临界偏斜角是闭式反解出来的**阈值**；
  真的蹭上之后的边缘力与事件区间在`winding_line_endtoend`。
* **不判定量**。带材EA/EI、摩擦、实际轮轴偏斜角全是假设输入
  （`research/05`第三节的五项）。**产物永久`hypothesis_only`**。

## 七、2026-08-17订正：先撞的不是原来写的那只轮

**本案例第一版把更松的那条约束当成了约束，临界偏斜角因此全体偏大3.25倍。**

原来取半间隙`6.5 mm`，出处写的是"真机导轮有效宽度17 mm、带宽4 mm"。
那个数属实——但它是**现场两只可调平轮**（Ø100×17、平面无凸缘）的半宽，
而带材**先**过的是张力机上的R4→R1，它们是**带凸缘的槽轮**。

R1槽型在消费方WII自己展示的那份`static_009_new1.stl`上被复量过
（`docs/records/r1-contact-radius-cross-check-20260726.md`第104—111行），
并与WDS从另一份网格提取的`config/roller_flange_profile.v1.json`互证：

| 量 | R1/R3 | R2 | WDS那份 |
|---|---|---|---|
| 槽底半径 | 45.224 mm | 45.168 | 45.0 |
| **槽底宽度** | **8.000 mm** | 8.000 | 8.0 |
| 凸缘半径 | 60.398 mm | 60.460 | 60.0 |

4 mm带材在R1里的半间隙是`(8.000 − 4.0)/2 = 2.0 mm`。于是：

| 自由跨长 | 第一版（6.5 mm，平轮） | 订正后（2.0 mm，R1槽底） |
|---|---:|---:|
| 100 mm | 5.381° | **1.656°** |
| 200 mm | 2.489° | **0.766°** |
| 300 mm | 1.546° | **0.476°** |
| 500 mm | 0.852° | **0.262°** |

**装配公差从"度"级掉到"零点几度"级。**

**订正的做法不是把常数改小，是让"谁先撞"变成一条能红的判据**：两个半间隙
都进`inputs`、两组临界角都进`expected`，判据要求两组比值逐档恒等于半间隙之比
（`f(u)`与半间隙无关，所以这个恒等是结构性的）且小于1。
把`min`改成`max`的注错在**两条门上都红**（实测）。

### 7.1 这条订正没有解决的两件

1. **槽壁是两段外倾锥面，不是垂直壁**（`wall_kind: two_cone_sloped`，
   型面环`(a=4.0, ρ=45.0) → (6.0, 50.0) → (7.76, 60.0)`）。
   本案例的临界角是"带材边缘走到槽底边缘"那一刻，**它之后不是硬碰，是逐渐爬升**。
   真的爬升力要锥面接触，而本仓的`PenaltyAnnulusLimit`建的是**平面环带**，形制对不上。
2. **`effective_contact_radius`那个候选值50.0 mm是hypothesis，比槽底45.22大4.78 mm**，
   且既非槽底也非凸缘外缘，是斜壁中途的一个半径——**带材不会稳定停在那里**。
   本案例不取它，但下一个要算R1出带切点的人第一个会碰到它。
