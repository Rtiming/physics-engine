# helix_laydown_closure 落位点几何与闭合残差

**这一条回答的是"这一瞬落位的是槽上哪一点、它的帧朝哪、要放多少带材"，
以及"位姿时间线与送带账对不对得上"。**

plans/14第3.3节订正过一次场景（用户2026-08-14口述）：**张力机不动**，
入带点是**世界系里固定的一个点**，在途自由段是空间里**一条不动的线段**。
不是带材去找线圈，是**机器人把线圈上该绕的那一段送到这个固定点**。
**于是臂动扰动张力的通道不是跨段长度**（它是常数）**，是落位点的几何**——
线圈从那条不动的线段下方转过，槽的切向在转、槽面法线在转，
入射角与"这一瞬要放出多少带材"跟着变。

判据值的正本是同目录的`oracle.json`，`case_id`为`case/helix_laydown_closure`。
**本案例永久标`hypothesis_only`**：中心线、位姿、送带率全是假设输入
（真实中心线在GCW那边，plans/14第四节明写"没验证哪一条是现场在用的那条"）。

## 一、物理/几何设定

中心线取解析**圆柱螺旋线**，位姿取"姿态随便选、平移反解"的解析轨迹——
于是落位点的每一个量都有闭式，金标**不调任何力学模块**。

| 项 | 取值 | 出处 |
|---|---|---|
| 螺旋线半径`R` | 60 mm | **设定** |
| 螺距系数`p` | 25 mm/rad | **设定**；`a = sqrt(R²+p²) = 65`恰好是整数 |
| 曲率`κ = R/a²` | 0.0142012 /mm（`ρ` = 70.4 mm） | 闭式 |
| 挠率`τ = p/a²` | 0.0059172 /mm = **0.339 °/mm** | 闭式；真实工件0.454—6.648 °/mm（plans/14第2.2节），**量级对得上** |
| 每匝弧长`2πa` | 408.407 mm | 真实工件850—1966 mm，本档偏短 |
| 转速`ω` | 0.4 rad/s | **设定** |
| 送带率`u` | 52 mm/s（`= 2aω`） | **设定**；真机量级50 mm/s（`research/04`算例） |
| 世界系三标架转速`u/a − ω` | **0.4 rad/s** | 取`u = aω`会让它为零、这一档退化，见第二节 |
| 入带点 | (1126.0, 0.0, 300.0) mm | `x = 1126.0`抄WII的Frame-A原点（plans/14第3.3节），**其余是设定** |

| 位姿举偏`δ_n` | 1.5 mm（曲率半径的1/47） | 病因二 |

## 二、参考解出处

没有外部文献——**本案例的闭式是自造的**，推导逐行写在
`cases/helix_laydown_closure/generate_oracle.py`的模块docstring里（生成器入库并带SHA）。
四条关键式子：

    落位点弧长坐标      σ(t) = σ₀ + u t
    世界系三标架        triad_world(t) = triad(χ(t)),  χ(t) = θ(t) − ω t
    入射角              cos θ_inc = (R² cos φ + p²)/a²,  φ = (u/a − ω)t
    送带账偏Δ的残差     |r| = sqrt(4R² sin²(δ/2) + p²δ²),  δ = Δ/a
                        沿槽 = (R² sin δ + p² δ)/a
                        法向 = R(1 − cos δ)
                        带宽向 = (R p/a)(δ − sin δ)

**闭合条件为什么可以精确构造**：`pose(t)·C(σ(t)) = 入带点`是三个标量约束配一个
未知量`σ`，一般无解。但机器人有六个自由度——**姿态三个可以随便选，
平移三个正好把落位点钉在固定入带点上**。于是取
`Rot(t) = Rot_z(−ωt)`、`p(t) = 入带点 − Rot(t)·C(σ(t))`，闭合恒成立。

**`u = 2aω`是刻意的**：若取`u = aω`（材料前进恰好抵消转动），
世界系三标架会**恒定**——那是螺旋线自身的螺旋对称性，入射角变成常数，
**这一档就退化成测不出东西的算例**。取`2aω`让三标架以`ω`转，
实测入射角在四个采样时刻上跨**1.089 rad**。

## 三、判据表

| 量 | rel / abs | 理由 |
|---|---|---|
| `a`、`κ`、`τ`、`2πa` | rel 1e-15 | **闭式自洽**，没有数值过程参与。附带判`κ² + τ² = 1/a²`——这条恒等式不是本页凑出来的 |
| 所需送带率 | abs 1e-6 mm/s | `dσ_pose/dt`**只由位姿算**（送带账一个字节都没参与）。实测偏差**2.03e-09**，abs是其五百倍余量 |
| 入射角三个量 | abs 1e-5 rad + rel 3e-4 | 偏差**全部来自帧插值**。512站点/匝实测：总角6.69e-07、离面2.13e-08、**槽面内方位6.68e-06**。方位角那一路最差（它是两个大量之差），**相对判据在它身上没有意义**，所以abs给到1e-5 |
| 闭合残差·模长（送带账偏0.7） | rel 1e-6 | 闭式弦长；实测rel **2.7e-11** |
| 闭合残差·沿槽 | rel 1e-6 | 实测rel 1.1e-10。**这一份是送带账修得掉的** |
| 闭合残差·法向 | rel 1e-4 | `R(1 − cos δ)`纯曲率效应；实测rel 4.7e-06 |
| 闭合残差·带宽向 | rel 1e-1（**且只在2048站点/匝判**） | 三阶小量，只有4.80e-06 mm。**512站点/匝根本判不了它**（实测偏96%），加密四倍才到6.0e-02。已知失效清单第2条 |
| 弧长坐标差（送带账偏） | abs 1e-8 mm | **恰等于**挪动量0.7；实测4.4e-12 |
| 举偏1.5 mm的六个量 | abs 1e-7 / 1e-6 mm | **弧长坐标差恰为零**是本案例最要紧的一个数；实测1.6e-08 |
| 平面圆退化档 | abs 1e-5 / rel 1e-15 | 挠率恒零、三标架恒定、入射角恒零、送带率恒为`Rω`。实测入射角2.96e-08 rad、送带率1.14e-09 mm/s、三标架漂移2.45e-08 |
| 收敛阶（位置语义） | 比值落在`[3.6, 4.6]`与`[13.5, 20.0]` | **不写死为4与16**，与`harmonic_oscillator`同源。两个区间不相交 |
| 收敛阶（帧语义） | 比值落在`[1.8, 2.3]`与`[3.2, 4.8]` | 同上。零阶保持一阶、重正交线性二阶 |

### 3.1 收敛阶实测（33个时刻的最大偏差，站点/匝翻倍一档）

| 语义 | 量 | 64→128 | 128→256 | 256→512 | 阶 | 512档绝对值 |
|---|---|---:|---:|---:|---|---:|
| `chord_linear` | 闭合残差 | 4.00 | 4.30 | 3.87 | **二阶** | 1.09e-03 mm |
| `chord_linear` | 弧长坐标 | 7.99 | 9.01 | 7.35 | **三阶** | — |
| `hermite_tangent` | 闭合残差 | 16.02 | 18.47 | 14.97 | **四阶** | 3.28e-09 mm |
| `hermite_tangent` | 弧长坐标 | 33.02 | 31.15 | 30.76 | **五阶** | — |
| `hold_station` | 入射角 | 2.01 | 2.04 | 2.07 | **一阶** | 1.06e-02 rad |
| `reorthonormalised_linear` | 入射角 | 3.73 | 4.25 | 3.70 | **二阶** | 2.16e-06 rad |

**弧长坐标比位置高一阶**，是最近点条件`(C − p)·C' = 0`的驻点性质：
在极小点附近，参数的一阶偏差只带来距离的二阶变化。**这是量出来才知道的，不是先验的。**

比值不干净（4.30、18.47那两档）是因为采样误差**振荡**——它取决于采样点落在段内哪里。
9个时刻的采样下`hold_station`甚至给出过1.690，所以本案例的收敛扫用**33个时刻**。

### 3.2 两个病人：模长同量级，病因与处置完全相反

| | 送带账偏0.7 mm | 位姿举偏1.5 mm |
|---|---|---|
| 残差模长 | 0.699997 mm | 1.500000 mm |
| 沿槽 | 0.699988（**99.999%**） | 0（实测3.2e-08） |
| 横向 | 0.003479（0.5%） | 1.500000（**100%**） |
| 弧长坐标差 | **恰为0.7** | **恰为0**（实测1.6e-08） |
| 位姿不可约偏距 | 0（实测3.5e-09） | **1.5** |
| 处置 | 多放0.7 mm带材 | **多放少放都修不掉** |

**一个只报"残差2.3 mm"的实现分不清这两件事**，而"调送带账把残差压下去"
正是那种实现最自然会做的事——它会把账算到无辜的一方。

## 四、已知失效清单

1. **最近点搜索不保证全局最优**。做法是分段弦投影粗扫 + 最优段与两个邻段上各走
   若干步安全牛顿。曲率半径与采样步同量级时它可能停在局部极小。
   本案例的采样比（每段转0.7°—5.6°）离那个区域有两个数量级，
   但**门里没有任何东西守着"全局"这个词**。

2. **`across_width`那一路在生产档判不了**。它是三阶小量（4.80e-06 mm），
   而残差0.7 mm乘上帧的角误差（512站点/匝约2e-06 rad）就已经与它同量级——
   实测相对偏差**96%**。本案例把它单列一门并加密到2048站点/匝才判（偏差6.0e-02）。
   **写出来比让读者以为它被验过诚实。**

3. **闭合是构造出来的，所以"残差为零"这一档没有验到真正的不自洽**。
   真实时间线里位姿与送带账各来自不同的上游，闭合几乎必然不成立；
   本案例只验了**两种人造的不自洽**（沿槽、横向），
   **没有验**两者叠加、也没有验残差随时间漂移的情形。

4. **所需送带率是差分出来的，不是解析的**。`MotionSource`只给`pose_at`，
   没有twist，所以`dσ_pose/dt`只能差分。本案例的`σ_true(t)`恰好是**线性**的，
   中心差分对线性函数无截断误差——**于是这条门没有验到差分格式本身的截断阶**。
   真实时间线上会有。

5. **`τ`只有0.339 °/mm，落在真实工件区间（0.454—6.648）之外的下沿。**
   高扭转档没有验。plans/14第2.2节记的`v1-coil-1`是本档的**19.6倍**。

6. **`hypothesis_only`**：中心线、位姿、送带率、入带点位置、跨段长度全是假设输入。
   本案例**不判任何真实工件的数**。

7. **平面圆退化档只走了1.273匝**。回绕被走到了，但"绕很多匝之后弧长坐标的
   浮点累积"没有验。

8. 无skip。

## 六、本案例不是什么

* **不是张力**。本层只交出`drives`要的那几个几何量，**一个牛顿都不算**。
  "入射角怎么变成张力"是`drives`那条轨道的事。
* **不是接触**。槽壁是两段外倾锥面（plans/14第3.4节），本层连槽宽都不知道，
  更没有法向力、没有摩擦、没有蹭边判定。
* **不是带材的形状**。带材可以绕自身切向扭转把硬弯换成扭转（plans/14第2.3节，
  `GJ`比`EI_hard`软约1000倍），那是轨道A的杆。**本层给的是槽的帧，不是带材的帧。**
  两者之差正是"能不能绕"的答案，而本案例**不回答它**。
* **不解闭合**。本层只报残差，**不去调送带账也不去调位姿**——两条都不是它的权力。
  谁对谁错要上游两个仓自己去对，本层提供的是**能把这场争论量化的那个数**。
* **不判真实工件**。真实中心线在GCW那边（`groove_centerline_workbench`），
  本仓一份都没有。第2.2节那张39包/9几何的表是plans/14读出来的，**不是本案例算的**。
* **不含暂停区间**。`motion`的`pause_hold`语义在本案例的解析位姿上不适用
  （`AnalyticPose`没有样点、没有暂停区间）。真实WII时间线有。
* **不判性能**。本层的最近点搜索是`O(站点数)`的全扫；512站点/匝、100个时刻实测
  0.15秒（每时刻1.5 ms）。**空间索引没有做**，真实工件607站点、整条时间线数千帧时
  这条要回来量。
