# harmonic_oscillator 无阻尼谐振子：收敛阶与能量漂移排序

`case/harmonic_oscillator`。B档，spec/12第九节判据3与判据4。

## 一、物理/几何设定

一维无阻尼线性振子 `ẍ = −ω²x`，无接触、无耗散。

| 量 | 值 |
|---|---|
| ω | 2.0 /s |
| 初位置 / 初速度 | 1.0 mm / 0.0 mm/s |
| 收敛阶：总时长 | 3.0 s，步长 0.02 / 0.01 / 0.005 s |
| 漂移排序：步长与步数 | 0.01 s × 2000步 |

解析解 `x(t) = cos(ωt)`；机械能 `E = v²/2 + ω²x²/2` 严格守恒。

## 二、参考解出处

解析解为教科书结论（简谐振动）。收敛阶与漂移排序的**判据形制**取自
MuJoCo `engine_forward_test.cc`：判据是积分器之间的**相对优劣**，
不是某个绝对数——相对优劣不随机器与编译器漂移。
生成器只写解析解与判据区间，不调被验内核。

## 三、判据表

| 量 | rel/abs | 理由 |
|---|---|---|
| `position_mm`（解析解） | rel 1e-15 | cos(ωT)，只受libm与双精度舍入影响 |
| 收敛比值区间 `[3.9, 4.1]` | abs 0 | **不写"恰为4"**：4是渐近值，粗档还没完全进渐近区（实测3.9985与3.9996）。写死会让正确实现在粗档上红——与spec/12第4.3节"比收敛阶不比单点"同一条纪律 |
| `ordering`（顺序列表） | abs 0 | 非数值量必须零容差 |
| `all_nonzero` | abs 0 | 布尔前置断言，防三者全零时排序假通过 |

实测漂移：显式Euler `1.2252e+00` > 半隐式 `1.0052e-02` > Verlet `5.5453e-05`。

## 四、已知失效清单

- **漂移排序只在这一组参数上验过**。步长取到稳定边界附近时显式Euler会发散，
  排序仍成立但数值失去意义。
- **"能量漂移"用的是末态与初态之比，不是全程包络**。全程最大漂移是另一个量，本案例不测。
- **不覆盖辛性本身**。半隐式与Verlet都是辛的，本案例只看漂移大小不看相空间体积保持。
- 未在Windows/Linux复核；`cos`走libm，末位可能与本机不同。

## 五、档位与负载级

B档（需要`integrate.py`），**interactive**（<1s）。实测：3条oracle含2000步积分共0.03s。

## 六、本案例不是什么

- **不是"velocity Verlet更好"的证据**。它证明的是三者的相对秩序与各自的阶数，
  而"该用哪个"取决于问题（有接触/刚性时这三个都不该用，见spec/12第4.2节）。
- **不是长时间稳定性证据**。2000步不是"长时间"。
- **不是性能基准**。
