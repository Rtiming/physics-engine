# capstan_tension_ratio 绞盘张力比：带材绕过导向轮

**一条装置穿四层**：`PenaltyCylinderContact`（法向）、`TangentialStickSpring`与
`coulomb_return_map`（摩擦）、`advance_contacts_quasistatic`（多槽位同时迭代）、
`AxialStretch`（张力沿带材传递）。这是决策0062第五节判据表里的J1。

判据值的正本是同目录的`oracle.json`（本页只解释，不重复声明），
`case_id`为`case/capstan_tension_ratio`。

**本案例永久标`hypothesis_only`**：摩擦系数、包角、带材EA全是假设输入，
出处见第四节。它证明的是**机制**，不是这台绕线机的定量行为。

## 一、物理/几何设定

带材绕过一只固定导向轮，松弛端固支、张紧端受切向拉力，全段滑移。

| 项 | 取值 | 出处 |
|---|---|---|
| 轮半径``R`` | 50.0 mm | **真机实测**：外径100 mm（`winding-machine/HARDWARE_TOPOLOGY.md`第79行，2026-07-07现场确认）。**是哪只轮见下面的第1.1节** |
| 轮轴向半宽 | 8.5 mm | **真机实测**：有效宽度17 mm，同上第80行 |
| 包角``θ`` | 90°（``π/2``） | **设定**，非实测 |
| 摩擦系数``μ`` | 0.30 | **假设输入** |
| 带材``EA`` | 60 000 N（4 mm×0.1 mm、``E ≈ 150 GPa``） | **假设输入** |
| 预张力 | 10.0 N | 真机张力区间10—30 N的下端 |
| 拉力 | 30.0 N | 同区间上端 |
| 段数 | 8（``Δφ = π/16 = 11.25°``） | |
| 罚刚度``k_n = k_t`` | 1.0×10⁴ N/mm | 穿透``N/k ≈ 4×10⁻⁴ mm``，是带厚的0.4% |
| 重力 | **0** | 整匝带材自重``3.5×10⁻² N``比张力小三个量级（与WDS design/14同一裁决） |
| 自由度 | ``x``、``y``自由；**全部``z``钉住**；节点0三个分量全钉 | 见下 |
| 载荷步 | 60 / 120 / 240 | 收敛阶要三档才判得了 |
| 求解器残差容差 | 1.0×10⁻⁶ N | 见第四节第2条 |

**``z``为什么必须钉住**：`PenaltyCylinderContact`在**轴向零刚度**
（``H·a`` 恰为0，因为沿轴移动不改变到轴的距离）。不钉就是欠约束，
`solve_equilibrium`当场报奇异。**这不是随手加的边界条件，
是那条几何性质在案例层的直接后果。**

### 1.1 这是哪只轮——真机上有**两族**，尺寸完全不同（2026-08-17补）

本案例建的是**现场那两只黑色导向轮**，不是张力机上的R1/R2/R3。
两族都在带材的路线上，**带材两族都要过**，而它们的尺寸差得很远：

| | 现场可调平轮（**本案例建的**） | 张力机R1/R3（R2型面相同） |
|---|---|---|
| 数量 | 2只 | 3只（R4→R1那一串里） |
| 外径 | **100 mm**（R=50） | **120.796 mm**（槽底R=45.224） |
| 轮面 | **近似平面、无凸缘** | **带凸缘的槽**，两段外倾锥壁 |
| 带材可横移的半间隙 | **6.5 mm**（有效宽17、带宽4） | **2.0 mm**（槽底宽8.000、带宽4） |
| 出处 | `winding-machine/HARDWARE_TOPOLOGY.md`第79—80行，2026-07-07现场目视确认 | WII `docs/records/r1-contact-radius-cross-check-20260726.md`第104—111行，两份独立网格互证 |
| 证据级别 | **现场实测**（目视＋记录尺寸） | **CAD网格实测**，非实机 |

**为什么本案例取平轮是对的**：绞盘比``T₂/T₁ = e^{μθ}``**与半径无关**，
半径只决定离散几何。取哪一族都能验这条式子，而平轮那一族的尺寸是现场实测的、
证据级别更高。**但"是哪只轮"此前没写，现在补上。**

⚠ **一个危险的数值巧合，谁碰这块都要知道**：本案例的``R = 50.0 mm``
（平轮外径100的一半，**现场实测**）与WII审计里那个
``effective_contact_radius.working_candidate_mm = 50.0``（**是R1的、标着`status: hypothesis`**）
**是两个不同的数，只是恰好都等于50.0**。后者比R1实测槽底45.224大**4.78 mm**，
既非槽底也非凸缘外缘，是斜壁中途的一个半径——**带材不会稳定停在那里**。

**把两者当成同一个数，就会给R1引入一个4.78 mm的系统偏差**，
而横向定位误差的目标量级只有2 mm。本案例不取后者。

## 二、参考解出处

Euler-Eytelwein（绞盘）公式，任一机械设计或摩擦学教材：

    T2 / T1 = exp(mu * theta)

**但它是连续极限，本案例判的是离散关系。** 对一个接触节点做力平衡
（两侧带材张力``T⁻``、``T⁺``，各偏离节点处切线``Δφ/2``）：

    法向    N = (T⁻ + T⁺) · sin(Δφ/2)
    切向    (T⁺ − T⁻) · cos(Δφ/2) = μ·N          （全滑移，摩擦取满）

消去``N``得逐节点比

    T⁺ / T⁻ = (1 + μ·tan(Δφ/2)) / (1 − μ·tan(Δφ/2))

两条都是精确代数恒等式。连续式是它的极限，**不是另一个独立判据**。
金标生成器`generate_oracle.py`只写这三条式子，
**不调`solve_equilibrium`、不调任何接触项**（轴7规则3）。

## 三、判据表

| 量 | rel / abs | 理由 |
|---|---|---|
| ``\|T_i\| / (μ·N_i)`` | abs 1e-12 | **恒等式**：全滑移下每个接触精确落在摩擦锥面上，这是return-map理想塑性修正的**定义性质**，与载荷步数无关。实测最大偏差**2.22e-16**（一个ulp）。判绝对不判相对：真值恰为1 |
| ``N_i`` 对 ``−(T⁺d⁺ − T⁻d⁻)·n_i`` | abs 4e-6 N | **恒等式**：法向力就是两侧张力的法向合量。**用实际段方向``d±``，不用名义``sin(Δφ/2)``**——带材滑过后角间距不再均匀，照名义角算有2.8e-4的**几何**系统偏差。实测最大相对偏差2.44e-07，恰等于残差容差1e-6 N除以法向力≈4 N |
| 包角中点的``T⁺/T⁻`` | rel 6e-3 | **收敛结果**：载荷步一阶误差。8段240载荷步实测4.256e-3，取1.4倍余量 |
| 载荷步误差的收敛比 | 落在``[1.7, 2.4]`` | **一阶收敛**：60/120/240步实测``1.833e-2 / 8.749e-3 / 4.256e-3``，两个比值**2.10与2.06**。**不写死为2**——与`harmonic_oscillator`那条"收敛比不写死为4"同源：一致才是收敛的证据 |
| 离散连乘→连续式的收敛比 | rel 0.05 于 4.0 | **案例自洽**（不碰引擎）：16/32/64段对``exp(μθ)``的偏差``4.13e-4 / 1.03e-4 / 2.58e-5``，比值4.00/4.00，二阶 |

**恒等式两条与收敛结果两条必须分开**，因为它们红了说明的事完全不同：
第一条红说明return-map错了，第二条红说明力平衡装配错了，
后两条红说明载荷步不够或摩擦系数用错了。

**落点与收敛阶也必须并存**：只判落点会被一个碰巧的常数骗过，
只判阶会被一个系统偏移骗过（偏移不改变阶）。

## 四、已知失效清单

1. **端到端的``T_last/T_first``判不动东西，本案例不判它。**
   两端是半节点（尖端加载、根部固支，各自少一侧张力），端到端比里混着这两个
   边界效应。实测它随载荷步数**非单调**：8段时120步给1.6030、240步给1.5562、
   480步给1.5341。**那个数看起来更像教科书，但它不是一个可收敛的量。**

2. **求解器残差容差是1e-6 N，比刚度地板高25倍，理由是能量分辨率。**
   `PointLoad`让总能量到``−550 N·mm``量级，而接触与拉伸的能量变化是``1e-4``量级；
   线搜索在残差``4e-8``处再也分辨不出"能量真的下降了"（2026-08-17实测，
   判别翻转那一趟9459次回溯）。**这不是调松容差，是这个装置能达到的精度。**
   残差1e-6 N对张力10—30 N是1e-7相对，判据判的量都在这之上。

3. **拿``e^{μΔφ}``当逐节点判据会给误差垫一个floor。**
   两条闭式的系统偏差是``μΔφ³/12``：实测``Δφ = π/16``给2.07e-4、
   ``π/8``给1.68e-3、``π/4``给1.41e-2。今天这一档只占容差的3.5%不会红，
   但**它不随载荷步数变小**，于是收敛阶那条门在载荷步足够多时会先撞上它然后停住，
   而症状看起来像"收敛阶坏了"。有一条门专记这件事。

4. **起点必须已经穿透。** ``g = 0``落在活动集边界外（判据是``g < 0``），
   那里径向没有刚度、牛顿迈不出第一步——与`test_contact_normal.py`记的
   "分离态切线刚度奇异"是同一条模型性质。本案例起点半径下沉``N/k``。

5. **载荷步不是自适应的，也没有回退。** 步数是写死的三档。
   迭代发散时今天仍是抛错（0050登记、0062重新登记）。

6. 无skip。

## 六、本案例不是什么

* **不是场景⑥端到端**。它只有一只轮、一段带材、一个方向的滑移；
  放线盘、张力轮、收线盘、执行器与传感器都不在。
* **不是"带材"的接触**。带材在这里是**中心线上的点**，没有宽度——
  所以它碰不到法兰，蹭边不在本案例（那是S6.6，另一个案例）。
  WDS的宽度方向五点采样引擎侧仍为零。
* **不是导轮的动力学**。轮是**固定**的，不自旋、无轴承阻力矩。
  自由轮自旋要转动自由度（0051），0062第七节明确本轮不做。
* **不判定量**。摩擦系数、包角、EA全是假设输入；WDS `research/05`第三节
  把``μ_∥``/``μ_⊥``、轮有效半径、轮轴偏斜角列为"只有现场实测能补"。
  **产物永久`hypothesis_only`**，摘除要按项写行（0062第八节）。
* **不是各向异性摩擦**。这里``μ_∥ = μ_⊥``，退化成径向返回；
  真实带-轮摩擦是椭圆锥，WDS侧已有KKT投影，引擎侧没有。
* **不验穿透量**。罚接触的位置有``O(1/k)``误差而力没有——
  判据据此只判力与比值，不判位置（与`incline_slide_threshold`同口径）。
