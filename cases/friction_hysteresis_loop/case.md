# friction_hysteresis_loop 摩擦迟滞回线：引擎第一次记住历史

**本案例验的是形制，不是公式**（决策0050第三节第3条）。

前一个接触案例`incline_slide_threshold`是**静置**问题：阈值下方锚点不动、
阈值上方本来就没有静平衡，所以它**碰不到锚点被改写**这件事。
本案例是第一个真的改写锚点的——**而锚点被改写，就是"历史发生了"**。

判据值的正本是同目录的`oracle.json`（本页只解释，不重复声明）。

## 一、物理/几何设定

滑块压在**水平**面上，切向**位移控制**（拖拽）。

| 项 | 取值 |
|---|---|
| 质量 | 2.0 kg |
| 重力 | 9810 mm/s²（沿``−z``） |
| 面法向``n`` | ``(0, 0, 1)``；面过原点 |
| 摩擦系数``μ`` | 0.30 |
| 法向罚刚度``k_n`` | 5.0×10⁴ N/mm |
| 切向粘着刚度``k_t`` | 3.0×10⁴ N/mm |
| 摩擦锥限``T_max = μ·W`` | 5.886 N |
| 屈服位移``u_y = T_max/k_t`` | 1.962×10⁻⁴ mm |
| 自由度 | ``x``、``y``**钉住**（位移控制），``z``自由（法向平衡由求解器出） |
| 回线幅值 | 2、5、20倍``u_y`` |
| 每段步数 | 500 |

**为什么是位移控制而不是载荷控制**：载荷控制下``T > μN``**根本没有静平衡**
（与``θ > θc``同理），块会加速——那是瞬态问题，而本仓没有隐式积分族。
位移控制永远有解，且它正是同行做摩擦迟滞的标准装置。

## 二、参考解出处

弹性-理想塑性滑块（切向刚度``k_t``串联库仑滑块，限``T_max = μN``），
任一本塑性力学或接触力学教材；同行出处见research/05第2.3节C档接触族。

    屈服位移      u_y = T_max / k_t
    力的饱和      |T| ≤ T_max
    整循环耗散    W = 4·T_max·(u_max − u_y)

耗散那条的推导：稳态回线是平行四边形。卸载支从``+T_max``弹性降到``−T_max``
用掉``2u_y``，其余段力恒为``∓T_max``；上下支各积一次相减即得。

### 路径相关性（本案例判据强度最高的一条）

取``u_final = 2.5·u_y``，两条**终点位置相同**的路径：

| 路径 | 走法 | 锚点 | ``T`` | 判别 |
|---|---|---|---|---|
| A | ``0 → 3u_y → 2.5u_y`` | ``2u_y`` | ``0.5·T_max`` | **粘** |
| B | ``0 → 2.5u_y`` | ``1.5u_y`` | ``T_max`` | **滑** |

**比值恰为1/2，且判别相反。**

这一条为什么最要紧：**锚点若能从当前位形算出来，两条路径会给出同一个答案**。
`incline_slide_threshold`的两条判据（分解与阈值）在那种实现下**照样全绿**——
它们只看当前位形。**只有本条能把"历史是不是真的历史"验出来。**

## 三、判据表

| 量 | rel | abs | 理由 |
|---|---|---|---|
| ``T_max``饱和值 | 0 | 0 | **零容差**：饱和是return-map投影出来的上界，``|T| = μN``是构造保证的等式，不是数值逼近。不逐位相等即投影写错 |
| ``u_y`` | 1e-15 | 0 | ``μN/k_t``是一次除法 |
| 拖拽全程的``N`` | 4e-16 | 0 | 面水平、粘着项扣掉法向分量，故``N``全程不变。**它若随切向位移漂，说明粘着弹簧漏了法向投影** |
| 三个幅值的回线耗散 | 1e-14 | 0 | 分段线性 + 梯形积分在线性段上精确，且步数取5的倍数让拐点落在步长边界，实测偏差为0。**取1e-14而不是0**：零容差会把"有人改了步数"变成一次神秘的红，而那本该是关于离散化的可读警告 |
| ``T_A/T_B`` | 1e-15 | 0 | 分子分母同源，比值是一次除法 |
| 两条路径的锚点 | 1e-15 | 0 | **锚点是被断言的量，不是中间变量**——它若对不上，说明历史没有被正确写回状态 |
| A粘 / B滑 | 0 | 0 | 定性判据零容差。**两条路径判别相反才叫路径相关** |

**那个"实测偏差为0"必须带解释，否则它是个可疑的数**：回线是分段线性的，
梯形积分在线性段上本就精确；拐点落在``u_max ∓ 2u_y``，对``u_max = 5u_y``
是全程的0.2与0.8处，**步数取5的倍数时拐点恰好落在步长边界上**，
于是没有一个panel跨越拐点。**不对齐时的实测偏差**：K=333给1.35e-05、
K=337给1.32e-05、K=999给1.00e-06——**机械是真的，零不是巧合也不是运气**。

## 四、已知失效清单

每条一行理由，**禁止静默skip**。

1. **法向与切向在本案例是解耦的。** 面是水平的、粘着项扣掉了法向分量，
   所以``N``与``T``的Hessian块正交、互不影响。**一般曲面接触不落在这个前提内**
   （法向随位置转），那时`advance_contact_quasistatic`一趟预测-修正不再够。
   已登记，触发条件：第一个法向随位形变化的接触问题。
2. **一趟预测-修正，不在牛顿里反复迭代。** 理想塑性的return-map修正后屈服条件
   恰好成立，**而这条性质依赖切向是位移控制的**。载荷控制下``x``随锚点变、
   锚点又随``x``变，那才需要真迭代。**本案例不做，也不假装做了。**
3. **没有硬化、没有率相关。** 理想塑性一条直线到底；``μ``是常数，
   不随滑移速率变（速率是瞬态量）。静摩擦与动摩擦不分。
4. **单点接触、单个滑块。** 多点分布与多体接触不涉及。
5. **耗散是数值积分出来的，不是引擎报的。** 本仓今天没有能量耗散的记账通道——
   `EnergyRegistry`只报势能。**这条登记为缺口**：一个声称做接触的引擎迟早要
   自己报耗散，而不是让案例去梯形积分。
6. **回线只跑一整圈。** 多圈的稳态性（第二圈与第一圈是否逐位相同）没验；
   理想塑性下它应当相同，但没测过就是没测过。

## 六、本案例不是什么

- **不是摩擦模型的标定**。``μ``、``k_t``都是**声明的输入**；判据里的耗散公式
  含``μN``与``k_t``，但**路径相关那一条与它们都无关**——它只依赖"锚点是历史"。
- **不是率相关摩擦或Stribeck曲线**。那些要速度，而准静态没有速度。
- **不是磨损、不是热**。滑移在这里只挪锚点，不改变任何材料属性。
- **不是C档接触族任何一条的兑现**。C档第7、9条要多体与恢复系数；
  本案例**不进0040分母**，它验的是本仓自己的形制对不对。
