# box_tipping_threshold — 翻倒：重心投影出底面

plans/16的M4，裁决与注错表见
[0082](../../docs/decisions/0082_翻倒进多支承点接触_底面是一组物质点_20260818.md)，
同行依据见[research/17](../../docs/research/17_同行的刚体接触动力学_六问与它们各自改了什么_20260818.md)。

**本案例是本仓第一条多接触点对同一平面的动态案例**，也是第一条
把"承载点从一个面整体换到另一个面"当判据的案例。
清单`case_id`是`case/box_tipping_threshold`。

## 一、物理/几何设定

长方体刚体在无限大斜面上。全部量：长度mm、力N、质量kg、时间s。

| 量 | 值 | 出处 |
|---|---|---|
| 半宽`w`（沿坡向） | 5.000 mm | 设定 |
| 半宽`d`（横坡向） | 5.000 mm | 设定；本案例的判据不依赖它，见第六节第4条 |
| 重心高`h`（垂直底面） | 10.000 mm | 设定；`w/h = 1/2`是**有理数** |
| 质量`m` | 0.050 kg | 设定 |
| 惯量 | `geometry.mass_properties(RoundedBox(fillet=0))` | **本案例一行不重推** |
| 重力`g` | 9810.000 mm/s² | 重量`W = m·g/1000 = 0.4905 N` |
| 法向罚刚度`k_n` | 50.000 N/mm（二分那组另取200.000） | 见第四节第2条 |
| 切向系数`k_t` | 0.030 N·s/mm | **被稳定上限逼出来的**，见第四节第2条 |
| 法向阻尼`c_n` | 0.010 N·s/mm | 约`ζ = 0.4`，压掉起手瞬态 |
| 摩擦`μ` | 1.200 | 远大于`tan ψc = 0.5`，**保证它翻而不是滑走** |
| 积分器 | `RK4_BODY` | `rigidbody`已有的四阶显式 |

三组装置：

| 组 | 倾角 | 支承点 | 步长／步数 | 判什么 |
|---|---|---|---|---|
| 稳定侧 | 20.000° | 底面四角 | `2e-4` s ／ 3000（0.600 s） | 撑住、承载分配、压心、漂移上界 |
| 失稳侧 | 32.000° | **八个角** | `2e-4` s ／ 1500（0.300 s） | 真的翻过去并落到侧面上 |
| 二分 | 搜索`ψc ± 0.01` rad | 平面两点（`y = 0`底棱） | `4e-4` s ／ 1000与1100 | 临界角、夹取宽度、与闭式的偏差 |

失稳侧必须声明**八个角**：翻过去之后贴地的是另一个面，只声明底面四角的话
那个面根本不存在，体会直接穿过去。稳定侧与二分组的起手位形取**闭式静态位形**
（逐角穿透`δ_i = F_i/k_n`、体倾`sinβ = (δ_dn − δ_up)/2w`、外加稳态蠕滑初速），
失稳侧起手取**平放**——那样"承载点从整个底面开始"这句话才有干净的起点。

## 二、参考解出处

**闭式在`generate_oracle.py`的文件头自己推了两遍，不抄。** 0081第四节写着
"没有裁翻倒那一支的判据……等实现到那一步再裁"，本页与那份生成器就是那一次裁。

| 量 | 闭式 | 本案例 |
|---|---|---|
| 几何阈值 | `tanθ ≤ w/h` | `1/2`（`Fraction`精确，`ψc = 0.463647609` rad） |
| 已倾`φ`时绕下坡棱的力矩 | `mg√(w²+h²)·sin(ψc − θ − φ)` | 平衡角`φ_eq = ψc − θ` |
| 底面单点法向力 | `F = W cosθ/n_b ± W·h·sinθ/(n_b·w)` | `n_b = 4` |
| **压心** | `x_N = Σ x_i F_i / Σ F_i = h·tanθ` | `3.639702343` mm（`w = 5`，比值`0.727940`） |
| 罚柔度把阈值挪多少 | `θc = ψc − β_c`，`β_c = W cos ψc/(2 n_d w k)` | `8.774e-4`（`k=50`）／`2.194e-4`（`k=200`） |
| 速度型摩擦的稳态蠕滑 | `Σ min(k_t v, μF_i) = W sinθ` | 上坡侧饱和支：`1.542040` mm/s |

两条**互相独立**的几何阈值推法给同一个不等式：力矩平衡给`w cosθ = h sinθ`，
重心投影给`h·tanθ = w`。`w/h`是有理数，所以这个阈值一个浮点数都不欠。

**压心那一条是本页的物理核心**：`x_N = h tanθ`不是载荷分配的近似而是
**力矩平衡的恒等式**（法向力的一阶矩恒等于摩擦力在底面高度上的力偶），
于是"重心投影出没出底面"从一句几何话变成了一个**被引擎算出来的数**。

| 单点法向力（上坡/下坡） | 4e-3 | 0 | 闭式是**刚体**载荷分配，罚接触平衡带`O(1/k)`柔度修正，且上坡侧摩擦已饱和、切向力不是均分。实测−2.52e-3与+3.96e-4，余量1.6倍与10倍 |
| **压心`x_N`与`x_N/w`** | 1e-4 | 0 | 力矩平衡的**恒等式**，柔度在分子分母同阶相消。实测+1.76e-5，余量5.7倍。**它比单点力紧40倍，这个差本身是判据**：把载荷分配算错但总力矩仍对的实现在上一行红、这一行绿 |

## 四、已知失效清单

1. **临界角与刚体闭式差`8.79e-4` rad，那不是缺陷是罚柔度。**
   本页把它判成两条（刚体闭式落在夹取区间**之外**；偏差之比等于刚度之比）。
   **但一阶修正只在硬档准**：离线实测`k=10`时比值1.322、`k=25`时1.124、
   `k=50`时1.002、`k=100`时1.024、`k=200`时0.979——**软端有未展开的高阶项**。
   本案例因此取`k=50`与`k=200`两档而不是`k=10`。触发条件：需要在软罚刚度下
   声称阈值精度的消费方；届时要展开的是`β`对`θ`的自洽方程而不是一阶代入；
2. **`k_t`不能取大，而理由与`rolling_ball_incline`相反。**
   那里`k_t`大会进颤振区；这里`k_t`大会让**切向阻尼模态的显式稳定上限**
   压到步长以下。四点组的偏航阻尼率是`k_t·Σr⊥²·1000/I_zz`，本几何下
   `k_t = 0.03`、`dt = 4e-4`时它是`2.88 > 2.785`——**实测当场发散**
   （横坡角速度从舍入量级长到0.1 rad/s量级、上坡角力差17%）。
   四点与八点两组因此取`dt = 2e-4`，两点平面组才用`4e-4`。
   **`k_t`的上限判据本身没做**，登记在plans/07；
3. **步长没有做收敛阶。** 三组各一档步长，没有扫多档给阶。
   已做的是**不变性**：临界角对`dt`（4e-4／2e-4／1e-4）、对时长（0.26—2.08 s）、
   对起手蠕滑初速（×0／×1／×2）**逐位不变**（离线实测，见0082第四节）。
   收敛阶登记为GAP；
4. **底面形状是调用方声明的一组点，不是从几何导出的。**
   支承多边形的凸性与冗余不被校验；不从网格导出接触足印；
   圆底/线接触要的是分布压力而不是有限个点，本档给不出。
   **这是plans/16的M4写着"底面形状怎么声明未裁"那一条的最小裁法**，
   登记在0082第五节；
5. **只有一个体对一个静止平面。** 多体、动平面、非长方体都不在内；
6. **不是滚动阻力，也不是恢复系数。** 落到侧面上那一下是罚接触加线性阻尼，
   **不对恢复系数做任何声称**（那是`bouncing_ball_restitution`的题）；
7. **横坡对称不是逐位的**（第三节倒数第三行）。四点组实测4e-14相对差，
   病根是逐点累加次序。两点平面组才真是逐位的零；
8. **`sliding`不等于"物理上在滑"**，它是"切向力已饱和在摩擦锥上"——
   与`rolling_ball_incline`第六节第5条同一句话。

## 五、档位与负载级

**B档**（对独立闭式解），负载级**local_batch**（本机批级，清单`load_tier`
为`local_batch`，pytest marker是`batch`）。实测14条门合计约7.6秒，
其中二分那一组占5.7秒（两次二分共18趟积分）。

## 六、本案例不是什么

1. **不是"翻倒"的完整模型，是翻倒**阈值**的两侧判据。**
   落地之后的弹跳、二次翻转、堆叠一个都不在内；
2. **不是重心投影这句话的重述，是它的测量。** 判的是压心`x_N`——
   由引擎逐点算出的法向力的一阶矩，**没有一个量是声明的**。
   一个"直接拿`h tanθ`当答案"的实现在这条门上会绿，
   而它在承载点下标那三条上过不去；
3. **不是长期稳定性的声明。** `rigidbody`文件头自陈RK4**不是辛的**，
   本案例最长跑0.6秒，长时程漂移一个字都没验；
4. **横坡向那个半宽`d`不参与任何判据。** 翻倒在本案例里是平面问题，
   `d`只决定四个角摆在哪；二分那一组干脆只用两个点，
   **而"这样做不改答案"是被判的**（横坡状态分量逐位为零那一条）；
5. **不是接触检测。** 接触对与支承点都是声明的，与`contact/`同纪律。
