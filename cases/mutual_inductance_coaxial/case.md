# mutual_inductance_coaxial 同轴圆环互感：引擎第一次算一条电磁闭式解

`case/mutual_inductance_coaxial`。B档，决策0042 + `electromagnetics/inductance.py`。
**这是引擎的第三个物理域第一次给出一个可对拍的数**，也是
plans/04六个真实场景里第一个能落地的电磁能力（场景②"多线圈之间的干扰"的互感那一半）。

判据**六层，每层独立**：闭式互感值 / 椭圆积分本身 / 互易 / 远场退化 / 匝数 / 单位边界。

## 一、物理/几何设定

真空中两条**共轴**圆形丝状回路，平面垂直于公共轴。**全部长度按米**
（`electromagnetics.EM_LENGTH_UNIT`，与spec/11的几何主单位mm不同——见第六层）。

| 量 | 值 |
|---|---|
| 真空磁导率μ₀ | 1.25663706127e-6 H/m（CODATA 2022，**测量值不是按定义精确**） |
| 旧的按定义值 | 4π×10⁻⁷ H/m（2019 SI重定义前） |
| 回路半径r₁、r₂ | 见下表七组 |
| 轴向间距d | 见下表七组，含**d恰为0** |
| 匝数N₁、N₂ | (1,1)、(3,5)、(12,40)、(200,7) |
| 电流I | 0、1、−3.5、1e6 A（只进磁链判据） |
| 参考求积节点 | 8192（自校验档2048），周期梯形 |

七组构型（`(r₁, r₂, d)`，米），每一组的选择都有理由：

| # | r₁ | r₂ | d | k | 为什么选它 |
|---|---|---|---|---|---|
| 1 | 0.050 | 0.050 | 0.020 | 0.980581 | 等径近距，典型线圈对 |
| 2 | 0.100 | 0.020 | 0.050 | 0.688021 | 半径比5:1，破掉"等径下才对"的巧合 |
| 3 | 0.030 | 0.030 | 0.001 | 0.999861 | **近重合，本组条件数最差**（`1−k²`只剩2.8e-4） |
| 4 | 0.020 | 0.040 | 0.300 | 0.184900 | 中远场 |
| 5 | 0.100 | 0.010 | **0.000** | 0.574960 | **共面同心，d恰为0**——合法构型不是退化 |
| 6 | 0.010 | 0.010 | 1.000 | 0.019996 | 远场 |
| 7 | 0.005 | 0.005 | 5.000 | 0.002000 | **极远场**，教科书分组在此处已崩（见第三节） |

远场退化判据另用一组：r₁=0.010、r₂=0.020，d从0.2 m起按倍频程排六档到6.4 m。

**采样点不是只挑好算的地方**：第3组与第7组分别是两端的最坏条件数，
第5组的`d=0`是很多实现会当成除零来特判的地方。

## 二、参考解出处

**闭式**：Maxwell《A Treatise on Electricity and Magnetism》第二卷第701节；
Grover《Inductance Calculations: Working Formulas and Tables》第十三章。采信的形式是

    k² = 4·r₁·r₂ / ((r₁+r₂)² + d²)
    M  = μ₀·√(r₁·r₂)·[ (2/k − k)·K(k) − (2/k)·E(k) ]

**约定必须写死**：这里的`K`、`E`按**模k**取值，**不是参数m = k²**。
本仓两种约定都在用——`cases/large_deflection_cantilever`的`complete_k(m)`收的是**参数**，
而Maxwell这条式子收的是**模**。混用差约10%（`K(k=0.5)=1.6858`对`K(m=0.5)=1.8541`），
在一条跨十几个数量级的互感值上没有任何"看起来不对"的提示。
`electromagnetics/elliptic.py`为此给了两对函数、名字里写死收哪一个，
本案例第二层有一条判据同时钉住"换算对"与"两者确实不同"。

**金标不靠引文**——生成器走两条与被验实现无共用代码的路：

1. **互感值**：Neumann双回路线积分，对共轴圆环化成单重积分后用**周期梯形**求值
   （被积函数解析且2π周期，梯形法几何收敛，与`cases/scalar_diffraction_airy`同形制）。
   生成器两档互证（8192与2048），相对互差超过1e-14即拒绝落盘；
   实测六组**逐位相同**，第3组2.2e-15。
   **这条积分被改写成全正被积函数**：直接写`∫cos φ dφ / √(…)`在远场会被相消吃掉
   （实测d=1 m处相对误差1.1e-8，比要测的量还大），改用
   `M = (μ₀r₁r₂/2)·(q/√c)·∫cos²φ/(s(1+s))dφ`（`c = r₁²+r₂²+d²`、`q = 2r₁r₂/c`、
   `s = √(1−q cos φ)`）后整条被积函数恒正，一次减法都没有。
2. **椭圆积分**：Carlson对称形式`R_F`/`R_D`的重复化算法，
   **原样复用`cases/large_deflection_cantilever/generate_oracle.py`那一份**
   （生成器之间复用正当，两侧生成器与被验的AGM仍然无共用代码）。

生成器不import `physics_engine.electromagnetics`，只用`physics_engine.oracles`写清单。

## 三、判据表

**六层，每层独立**。容差全部是算出来的，不是放宽到能过。

| 量 | rel | abs | 理由 |
|---|---|---|---|
| `moduli`（7点） | 4e-16 | 0 | 两侧同一表达式，差异只有一次sqrt舍入（≤1eps）；4e-16约2eps。**这条钉的是k²表达式本身**，尤其最容易漏的`+ d²`：漏了它k与间距无关、等径时恒为1、K发散 |
| `mutual_inductances_h`（7点） | 1e-12 | 0 | 闭式（AGM）对Neumann积分。实测最坏4.86e-14在第3组（k=0.99986）——那里`1−k²`只剩2.8e-4，K对k'的对数依赖把k'的4e-13相对误差折算成K的4.5e-14，与实测吻合；其余六组≤1.4e-15。取1e-12是最坏值的**20.6倍**。**它同时是教科书分组的捕手**：第7组照`(2/k−k)K−(2/k)E`直算的相对误差是1.1e-4，红过头1e8倍 |
| `complete_elliptic_k`（7点） | 1e-14 | 0 | AGM对Carlson，两条不同算法。实测最坏3.24e-15在k=0.99986，**差异主要来自Carlson那一侧**（它算`1−m`，AGM算`(1−k)(1+k)`，后者在k→1少一次相消）；其余≤4.4e-16。取1e-14是3.1倍 |
| `complete_elliptic_e`（7点） | 5e-15 | 0 | 同上。E无对数奇性，k→1处条件数远好于K，实测最坏6.66e-16（3eps）。取5e-15是7.5倍 |
| `parameter_convention_agrees` | 0 | 0 | 布尔：`K_of_parameter(0.25)`与`K(0.5)`**逐位相同**。零容差因为前者实现就是`K(√m)`而`√0.25=0.5`精确 |
| `parameter_convention_is_not_the_same_as_modulus` | 0 | 0 | 布尔：`K_of_parameter(0.5) ≠ K(0.5)`。**一条判据守两件事**：换算对、两种约定确实不同。只断前一条的话，把两个入口写成同一个函数照样绿 |
| `scalar_reciprocity_max_abs_difference_h` | 0 | 0 | `M(1→2)`与`M(2→1)`必须**逐位相同**。**零容差是算出来的**：`r₁*r₂==r₂*r₁`、`r₁+r₂==r₂+r₁`、`√(r₁r₂)`对称、`\|z₂−z₁\|==\|z₁−z₂\|`在IEEE754下都成立。它抓闭式抓不到的一类错：把`√(r₁r₂)`写成`r₁`（量纲、量级、远场退化阶全部照旧） |
| `loop_reciprocity_max_abs_difference_h` | 0 | 0 | 回路级同上且**匝数不同**（3与7）：`N₁·N₂`是整数乘法，可交换且精确。另抓一类错：匝数因子的结合次序若从`(N₁N₂)·M`改成`N₁·(N₂·M)`，浮点下末位可能不同 |
| `dipole_ratio_deviations`（6点） | 0 | 5e-14 | `M/M_dipole − 1`。两侧`M_dipole`同表达式同μ₀，故偏差之差只等于M的相对误差（因`M/M_dipole≈1`），实测≤8.2e-16。**判绝对不判相对**：偏差本身从1.8e-2扫到1.8e-5跨三个数量级，相对容差会在小端把噪声放大成判据。取5e-14是实测的61倍。**这一层只有无相消求值做得到** |
| `dipole_convergence_orders`（5点） | 0 | 1e-9 | 相邻两档偏差之比取log2。理论值恰为2（`M/M_dipole−1 ≈ −3(r₁²+r₂²)/(2d²)`，d翻倍偏差降4倍）。实测1.980619→1.999923单调逼近2，**不写死为2**（`harmonic_oscillator`那条纪律：收敛阶是测出来的）而是把五个数逐个钉住。误差来源是M的1e-15折算到最小偏差1.8e-5再除ln2，约8e-11；取1e-9是12倍 |
| `mutual_inductances_h`（匝数4点） | 1e-12 | 0 | `M_N = N₁N₂M₁`，金标是`N₁N₂ ×`Neumann积分值。容差与第一层同源（同构型实测1.37e-15）加一次整数乘法舍入。抓匝数写漏、写成`N₁+N₂`、只乘一侧、按`(N₁N₂)²`——四种错在N=(200,7)分别差1400、6.8、7、1400倍 |
| `turns_factor_is_bit_exact` | 0 | 0 | 布尔：`M(N₁,N₂)`与`(N₁·N₂)·M(1,1)`**逐位相同**。与上一条不重复：上条验数对不对，本条验**因子的结合次序**。0030记过同型的一次末位漂移（`k*(d_a·d_b)`写成`(k*d_a)·d_b`） |
| `millimetre_round_trip`（4点） | 0 | 0 | mm→m→mm**逐位复原**。零容差是算出来的：两个方向共用同一个因子1000（2的幂乘5³），这四个值除1000再乘1000在double下精确可逆（实测四个全等）。**方向写反不报任何错**，只把互感放大1e6倍 |
| `mutual_inductance_from_millimetres_h` | 1e-12 | 0 | 从mm制声明的几何算出的互感，金标由米制Neumann积分给出。与上条不重复：往返只验**可逆**、验不出**方向**（乘1000再除1000同样可逆）。本条把方向钉死在一个物理值上 |
| `millimetre_and_metre_declarations_agree` | 0 | 0 | 布尔：同一几何用mm声明与用m声明给出**逐位相同**的M。零容差成立是因为50.0/1000恰是0.05的double表示。**若哪天不成立，说明换算路径上多了一步运算，本条该红** |
| `mu0_relative_deviation_from_legacy` | 1e-12 | 0 | 本仓采信的μ₀与2019年前按定义值的相对偏差，实测**1.3203e-10**，落在CODATA相对标准不确定度1.6e-10之内——两值物理上不冲突，冲突的只是`benchmark_constant`那条"按定义精确"的声明（research/08第4.4节）。两侧是同一对字面量的两次独立抄写，差异≤2eps。**这条是μ₀量级错的捕手**：写成1.2566e-5本量从1.32e-10跳到9.0 |
| `flux_linkages_wb`（4点） | 1e-12 | 0 | `λ = M·I_source`，M已含两侧匝数。抓**再乘一次匝数**这个最常见的错（本组差6倍），以及对电流的线性（I=0恰为0、I=1e6不溢出） |

### 必须红（12种错法逐条实测，`哪条错法被哪条门抓住`）

**12种全部被抓住**，但**抓住它们的门各不相同**，这张表本身是本案例最贵的产出：

| 错法 | 闭式 | 椭圆 | 互易 | 远场 | 匝数 | 单位 | 协议门 |
|---|---|---|---|---|---|---|---|
| A `k²`漏`d²` | ● | | ● | ● | ● | ● | ● |
| B **`K`/`E`次序颠倒** | | **●** | | | | | ● |

| D mm/m转换方向反 | | | | | | ● | ● |

| I 教科书分组求方括号 | ● | | | ● | | | ● |

| L 匝数写成`N₁+N₂` | | | | | ● | ● | |

**三条要单独说的**：

1. **B（`K`/`E`次序颠倒）只有第二层抓得住**——五条互感判据一条都不红。
   原因是本仓的M**不经过`K − E`**（`elliptic.py`第三节把方括号改写成AGM中间量的
   无相消形式），所以两个公开椭圆积分函数对调对互感路径完全没有影响。
   **没有第二层，这个错会静默进入公开API。** 这就是"椭圆积分那一层不是闭式那一层的
   附属品"的实证。
2. **K（偶极子近似漏因子2）只有远场那一层抓得住**——它不在互感主路上，
   只在判据里当参照。一条只出现在判据里的公式**同样会写错**，
   而除了那条判据没有任何东西看着它。
3. **C（μ₀量级错）恰好不被远场那一层抓住**：远场判的是`M/M_dipole`的**比值**，
   μ₀在分子分母上同时出现、精确抵消。**这是设计使然不是漏网**——
   也正因如此`mu0_relative_deviation_from_legacy`必须单独成一条判据。

`tests/test_electromagnetics.py`另有三条**必须红**的守门测试，把三条边界钉成会红的断言
（教科书分组会崩、AGM不停机会静默出错、两种约定混用差10%）——
**边界不是免责声明，是要有门守着的**。

## 四、已知失效清单

- **不做自感**。丝状回路自感对数发散，有限值要引入导线截面半径。本案例对
  `r₁=r₂`且`d→0`的极限**拒跑**（`k² > MODULUS_MAX²`失败关闭），不是给一个大数。
- **模的上界是`1 − 1e-12`**，超过拒跑。此处`1−k²`仍有约2e-12、保住约4位十进制余量；
  再往上`K`的精度按`1/ln(4/k')`退化（实测k=1−1e-8时相对误差2.7e-11）。
  **域外未测**，按诚实条款写"未测"不写"成立"。
- **`K`/`E`/方括号的精度只在`k ∈ [1e-12, 1−1e-8]`上实测**（对60位`decimal`高精度AGM
  逐点对拍410个点，最坏3.4e-16 / 9.8e-16 / 7.7e-16）。本案例只冻结其中7个模。
- **只验共轴**。倾斜、偏心、非共轴一概不在本案例，也不在实现里——
  一般位形要Neumann双重线积分与细丝离散（plans/04第五节第3条）。
- **匝数是集中匝的理想化**。`N₁N₂M₁`对"N匝全部叠在同一条几何回路上"**精确**，
  对真实多层线圈只是零阶近似（真实匝有轴向与径向间距）。
  本案例**只验前者**，不声称后者。
- **不验磁介质**。`M`里的μ₀是真空值。把它换成μ只在无限大均匀介质里成立。
- **物理精度地板是μ₀的1.6e-10**，不是数值的1e-15：算得再准也不会比μ₀本身准。
  本案例的容差全部是**数值**容差，它们比物理不确定度紧五个数量级——
  这不是矛盾，是分工：判据验的是"这段代码有没有实现那条闭式"，不是"这个数有多真"。
- **不读任何材料记录**，因此spec/14规则1那条"一份记录聚合多域字段"的边界
  **没有被本案例关掉**（决策0042第五节有实测的完整交代）。
- 未在Windows/Linux复核。

## 五、档位与负载级

B档，**interactive**（<1s）。实测：六条conformance共**0.02 s**；

## 六、本案例不是什么

- **不是"引擎能做电磁了"的证据**。它算的是两条丝状回路的一个标量闭式，
  **没有场、没有网格、没有自由度、没有求解**。research/08列的六道门槛一道都没撞——
  那不是因为门槛低，是因为这条路绕开了它们。
- **不是线圈设计工具**。没有自感、没有导线截面、没有匝间几何、没有电阻与损耗、
  没有频率相关效应（趋肤、邻近）。
- **不是电容那一半**。plans/04第二节明写"互感先做，电容等网格"。
- **不是"μ₀这个数是对的"的证据**。它只验了本仓采信的值与旧的按定义值差多少、
  以及那个差落在CODATA的不确定度内。μ₀的真值不由本仓判定。
- **不是椭圆积分的通用实现证明**。只对完全椭圆积分、只在申报的模区间、
  只按相对误差申报。
- **不是性能证明**：每次调用几十个浮点运算，没有规模可言。
