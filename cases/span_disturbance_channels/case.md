# 跨段张力的两条扰动通道：臂动与人手触碰

守[plans/15](../../docs/plans/15_从这里到真机介入的分阶段计划_20260817.md)第三节阶段一的
1.3与1.4，裁决见[0071](../../docs/decisions/0071_扰动通道_臂动不改跨长而人手改路径_20260817.md)。
场景正本是[plans/14](../../docs/plans/14_现场场景勘察_真实工件是非平面槽_20260817.md)第3.3节。

0066把张力做成了"速度差经带材弹性生成的量"，于是控制器第一次有东西可控；
但那一轮唯一能造的扰动是**收线端速度阶跃**，而真机上没有人去阶跃收线端。
本案例建的是真机上那两条：**机械臂在动**，与**有人突然碰了一下带材**。

## 一、物理/几何设定

**全部输入是假设**，跨段与放线端逐条与`cases/free_span_tension_step`同值
（轴承阻力矩取真实量级那一档），出处见0062第二节裁决2那张"只有现场实测能补"的清单。

跨段与放线端：
- 带材轴向刚度：EA = 60000 N（4 mm宽×0.1 mm厚、E约150 GPa）
- 自由跨几何长度：L_geo = 300 mm。**它是常数**，两个端点都是世界系固定的
- 放线盘半径：R = 60 mm；转动惯量：J = 5000 kg·mm²
- 磁粉离合器制动力矩：M = 1200 N·mm（给出T = M/R = 20 N，落在真机张力区间10—30 N中段）
- 轴承粘性阻力矩：c = 50 N·mm·s/rad（真实量级；`free_span_tension_step`那个1000
  是为了把响应放到良态区调出来的，本案例不用它——**要判的正是开环不回落**）
- 入带点（世界系固定）：(1126.0, 0.0, 300.0) mm。x = 1126.0抄plans/14第3.3节记的
  Frame-A原点（三只Ø120导轮共面于x约1126），另两个分量是假设输入
- 导轮出带点（世界系固定）：(1426.0, 0.0, 300.0) mm

槽中心线（1.3用）：一条**用切向角α当参数**的平面曲线
- 曲率：κ(α) = κ0/(1 + m·cos α)，κ0 = 1/60 mm⁻¹（基准曲率半径60 mm）
- 曲率调制深度：m = 0.3（κ在1/78—1/42 mm⁻¹之间摆，即曲率半径42—78 mm；
  真实工件最小曲率半径27.6 mm，本档落在真实区间上沿）。**m = 0是平面圆退化档**
- 弧长：s(α) = (α + m·sin α)/κ0；位置与三标架见`generate_oracle.py`第一节
- 站点：α ∈ [0, 2π]均分256段；位置语义`hermite_tangent`、帧语义
  `reorthonormalised_linear`、`topology = open`、`out_of_range = reject`、
  最近点细化2次

机械臂（1.3用）：α(t) = α₀ + Ω·t，姿态取Rz(−α)、平移由闭合反解
- **落位点处槽切向因此恰以Ω匀速转**——Ω就是那条判据里的旋钮
- 扫描四档：Ω = 1、2、4、8 rad/s，对应线速度v₀ = Ω/κ0 = 60、120、240、480 mm/s
- 接线档：Ω = 2 rad/s、α₀ = 0.4 rad、速率探针中心差分步长1e-4 s、
  推进步长dt = 1e-4 s、1500步

人手触碰（1.4用）：矩形保持剖面`rectangular_hold`
- 作用点：距导轮端出带点150 mm（跨段中点）；旁开档75 mm
- 推的方向：(0, 0, 1)，**显式单位向量且与跨段正交**
- 横向位移：δ = 2 mm（量值必须为正，方向由方向字段携带）；扫描档0.5/1/2/4 mm
- 起止：[0.002, 0.022) s，**左闭右开**
- 线速度：20 mm/s；推进步长dt = 2e-6 s、50000步（0.1 s）

## 二、参考解出处

**闭式解，生成脚本入库**：`cases/span_disturbance_channels/generate_oracle.py`，
SHA-256钉在`oracle.json`的`generator.sha256`。该脚本只import`math`与
`physics_engine.oracles`（清单写入器），**不import`transport`、不import`laydown`、
不import`disturbance`、不import任何力学模块**（轴7规则3）。

四组闭式各自的出处：

1. **机制**：σ' = Ω_tan/κ。Frenet关系（切向转速＝曲率乘弧长速率）配上
   "落位点必须待在固定入带点上"这一条闭合约束（0067第二节）；
2. **正弦速度扰动下的张力稳态响应**：把0066第四节那个二阶线性化系统改成正弦驱动，
   |X| = K·a·sqrt(4ζ²ω_n² + ω²)/sqrt((ω_n² − ω²)² + 4ζ²ω_n²ω²)。
   右端两项分别来自"稳态张力随线速度走"与"长度账的导数"，**不是一项**；
3. **路径阶跃下的振铃**：同一个二阶系统，初值改成
   δT(0) = ΔT₀ = EA·p/L_mat、δT'(0) = 0。矩形触碰＝两次阶跃叠加；
4. **路径增量与横向力**：纯几何，L_path = sqrt(a²+δ²) + sqrt(b²+δ²)、
   F = T·(δ/sqrt(a²+δ²) + δ/sqrt(b²+δ²))。

**实测数据不作金标**（spec/08规则1）：本案例一条实测输入都没有，
产物永久`hypothesis_only`。

## 四、已知失效清单

1. **"触碰→尖峰→回落"只做到前两段。** 开环下尖峰**不回落**，本案例把那件事量化成
   一条正向判据（四个阻尼周期后剩71.8%，对闭式偏差1e-8量级）。
   **"有控制器时一个周期之内被压掉"那一半一条都没做**——控制器可插拔与真闭环是
   plans/15的1.1与1.2，归轨道E（决策0070）。**没有那一半，这道门只证明了扰动进得来，
   没有证明它压得下去。**
2. **1.3的旋钮与工作点连在一起。** Ω = 1/2/4/8 rad/s同时决定线速度v₀ = Ω/κ0 =
   60/120/240/480 mm/s，因而稳态张力也跟着从20.83走到26.67 N。
   **这不是可以分开拧的两件事**：v = Ω/κ是几何给的。想固定工作点就得同时改κ0，
   而那就换了一条槽。案例页把两列并排给出，**不许只报幅值不报工作点**。
3. **1.3只做了平面槽，没有做非平面（有挠率）的。** plans/14第2.2节的结论是
   真实工件"非平面与hard-way是通例"，挠率0.454—6.648 °/mm。
   挠率进的是**帧**的转动而不是切向的转动，机制式σ' = Ω_tan/κ本身不变，
   但入射角的面外分量会动。**本案例的surface_normal恒为(0,0,1)。**
4. **触碰只做了位移控制，没有做力控。** 力控要在每一步解一个关于δ的非线性方程
   （T自己也随δ变），判据里会混进一个求解器容差，而那正好盖住这道门本该分辨的东西。
   **横向力在本案例是输出不是输入。**
5. **触碰的时间剖面只有矩形。** 一条真实的人手触碰是什么时间形状，
   **本仓一次都没有量过**，给一个平滑剖面会让人以为那个形状是有出处的。
   矩形是最诚实的理想化，而且两端的阶跃给出精确闭式。
6. **触碰点没有接触力学**：没有摩擦、没有接触斑、没有局部弯曲。
   这里的带材仍是0066那根一维弹簧，只有EA。真实的手指会把带材**局部压弯**，
   而那要过`rod`（轨道A）与`contact`。
7. **σ'走的是位姿那一条，闭合残差在本案例里恒为机器零。** 位姿是"姿态选定、平移反解"
   构造出来的（形制抄0067），所以闭合恒成立。**真实时间线里位姿与送带账来自不同上游，
   闭合几乎必然不成立**——那时σ'与送带账给的速率之差是一个真实的量，
   本案例只在单元门里用一个"账故意快10%"的夹具判了"接的是位姿那一条"。
8. **`ArmLaydownTakeup`每一步都做一次最近点全扫。** 1500步实测0.61秒
   （256站点、每步两次全扫）。真实工件607站点、时间线数千帧时这条要回来量，
   **空间索引没有做**（0067第七节第5条同一笔账）。
9. **扫描档用的是解析速率不是`laydown`速率。** 四档扫描各跑一个整周期
   （最慢那档65973步），全程走`laydown`要做1.3e8次站点访问，本机上分钟级。
   **接线那条另有一门判两条路给出同一条张力曲线**（1500步最大差8.71e-6 N，
   而同窗口的张力摆幅17.54 N），扫描档因此走解析速率。
   **这是一个可以被质疑的取舍，写在这里而不是藏起来。**
10. **产物永久`hypothesis_only`**：一条实测输入都没有。自由跨的两个端点在上游
    （WII）**连定义都还没有**（plans/15第4.2节：`tool_to_tape_exit`被上游用测试断言
    必须缺席、`entry_boundary`零代码零字段），所以L_geo = 300 mm这个数
    **不是量出来的也不是算出来的，是编的**。

B档 + 本机批级。`oracle.json`的`case_id`是`case/span_disturbance_channels`、
`load_tier`是`local_batch`，与pytest marker一致（`batch`）。

## 六、本案例不是什么

- **它不是一个闭环案例。** 全程开环。控制器压不压得下去这件事本案例
  **一个字都没证明**，见第四节第1条；
- **它不证明"臂动让跨段变长"**——**那条因果是错的，本案例正面否掉它**。
  臂动改的是落位点的几何（所需送带率），跨段两端是世界系常量。
  0066第九、十节"真机上跨长逐样点变"那句措辞由0071第二节判为错的；
- **它不证明"切向转得快扰动就大"这件事对任意槽成立**。单调判据是在
  **固定的一条槽**上扫Ω得到的。换一条曲率分布不同的槽，同样的Ω给出的幅值不同——
  机制式是σ' = Ω_tan/κ，**κ也在里面**。平面圆上无论Ω多大扰动都恰为零，
  那正是这一点的反例；
- **它不验落位点的横向精度**。本案例只用`laydown`的**弧长速率**这一个输出，
  入射角、闭合残差的三个分量、槽面法线都只是顺带断言了一下量级。
  那些量的判据正本在`cases/helix_laydown_closure`；
- **它不验带材的横向行为**。带材在这里仍是一根只有EA的一维弹簧：
  没有宽度、没有弯曲、没有扭转、没有横漂。人手按上去时真实带材会局部压弯，
  本模型只让路径变长；
- **它不给"多大的触碰算危险"这个数**。张力尖峰5.33 N（26%）与谷值掉30%都是
  在一组**编出来的**参数上算的。要给现场结论需要五项实测（plans/15第4.1节）；
- **它不是`free_span_tension_step`的替代**。那一条判的是**收线端速度阶跃**下
  张力的二阶响应（初值带斜率冲击、传递函数多一个零点），本案例判的是
  **路径阶跃**（张力当场跳、速度连续）。**同一个二阶系统，两条完全不同的响应**——
  两条峰值时刻差acos ζ、超调差一个1/(2ζ)，套错了不会报错，只会错。
